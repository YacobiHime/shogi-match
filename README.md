# shogi-match

やこび姫と一緒に将棋を指して学べる、ブラウザ用の将棋対局ランタイムです。
単体のWebゲームとして遊べるほか、Webページ・RPG・ノベルゲームへ埋め込めます。
思考エンジンのやねうら王（WASM）を同梱しており、サーバー側の処理なしで動きます。

- 公開版: <https://shogi-64125.web.app>
- ライセンス: GPL-3.0-or-later（[ライセンス](#ライセンス)を参照）

## できること

### 遊ぶ

- **CPU対局**: やねうら王と対局します。強さはLv0〜40の41段階です（2026-10-22に段級位を作り直しました。`docs/level-ladder-design.md`）。Lv0は駒の動きを覚えたての練習相手（レーティングに数えません）、Lv1〜15は15級〜1級（1級位に1つ）、Lv16〜35はアマ初段〜七段（初段〜六段は1つの段に3つ、七段は2つ。同じ名前の段は、LvとRで見分けます）、Lv36〜39は奨励会三段・若手プロ・トッププロ・タイトル保持者、Lv40は藤井聡太並みです。級は算用数字、段位は漢字で書きます。強さは、前の表で校正した強さのどこを使うか（`source`）で決め、自己対局で隣のLvの差がそろうように測って決めました（`docs/difficulty-calibration.md`）。ロジックAI（`logic-ai.mjs`。ルールだけで指す）は、今の表では使いません。
- **学習対局**: 次の局面から始められます。
  - 駒落ち
  - 戦法や囲いが完成した局面
- **学習対局の補助**: 閃き（ヒント）と待ったの回数を選べます（無制限も可）。各マスに利いている駒の数を表示する「駒の利き」も使えます。メニューの「選んだ駒の動きを矢印で表示」をONにすると、選んだ駒が動ける方向を青い矢印で表示します（遠くまで動ける駒は方向ごとに1本）。
- **2人対局**: 1台の端末で、先手と後手を交互に指します（`mode=local`）。
- **やこび姫の将棋問題集**: ホーム画面の「まなぶ」から開きます。「練習問題」「詰将棋」「詰将棋図巧」の3つに分かれています。詰ませる問題と、王手から逃げる問題を、やこび姫が出題・解説します。正解は問題に書かず、合法手をすべて詰み探索で調べて決めます（逃げる問題は、逃げたあと相手に3手以内の詰みがない手が正解）。自分の手が2回以上ある問題では、正解のたびに相手が応じ、続きの手も盤で指して答えます。逃げる問題は、正解のあとも、まちがえた逃げ方なら詰んでいた王手を相手が指し、もう一度逃げて詰まない理由を確かめます。間違えると、逃げられ方や詰まされ方を盤に並べて説明します。並べ終えると、ボタンを押さなくても元の局面に戻り、続けて指し直せます（「もう一度」で待たずに戻すこともできます）。解いた記録は端末に保存します。一発で解けなかった問題（まちがえた・ヒントを見た・答えを見た）は「復習の箱」に入り、1日後に問題集の一覧の上へ「やこび姫からの1問」として1問だけ出ます。出し直した問題を一発で解くと、次は3日後、その次は7日後に出し、7日後も一発で解けたら箱から出します。一発で解けなかったら1日後からやり直します。解かなくても先へ進めます。対局の振り返りで見逃した3手以内の詰みは「あなたの対局から（◯手詰め）」という詰ませる問題になり、同じ復習の箱から日をあけて出ます（正解は問題集と同じ詰み探索で決めます）。箱は`localStorage`（キー`yacobihime:shogi-match:review-queue:v1`、対局からの問題は`yacobihime:shogi-match:review-problems:v1`）に保存します。
  - **練習問題**: やこび姫の台詞付きの10問です。以下の判定のしかたは練習問題のものです。
  - **詰将棋**: まず「詰将棋」と「実戦詰将棋」のどちらかを選び、次に「1手詰め」「3手詰め」「5手詰め」「7手詰め」のボタンで手数を選びます。どちらも手数ごとに30問です。「ランダム出題」を押すと、選んだ種類の問題から手数も問わずに出題し、「次の問題」でも続けてランダムに出します（まだ解いていない問題を優先）。データの手順で判定し、最後の手は詰ませる手ならどれでも正解にします。
    - **詰将棋**: 駒の少ない問題です。やねうら王の実戦の詰み局面を元に機械で作られた詰将棋から、余詰めのない問題を選びました。出典: Shinta Nakayama「[Generated Tsume-Shogi](https://huggingface.co/datasets/tokoroten-jp/generated-tsume-shogi)」（CC BY 4.0）。
    - **実戦詰将棋**: 両方の玉と多くの駒が盤にある、対局に出た局面です。やねうら王の「[詰将棋500万問](https://yaneuraou.yaneu.com/2020/12/25/christmas-present/)」（やねうら王どうしの対局の局面。著作権の主張なし）を先手番にそろえて解き、攻め方の正解が各手で1つだけの問題を選びました。1手詰めは、3手詰めの局面を2手進めたものです。
  - **詰将棋図巧**: 伊藤看寿『将棋図巧』（1755年）の全100問を、原典の番号順（第1番〜第100番）に並べています。通称のある作品（第6番『朝霧』、第94番『襷詰』、第98番『裸玉』、第99番『煙詰』、第100番『寿』）は名前も表示します。作者の手順に沿って1手ずつ解き、相手は手順どおりに応じます。データは[Open Tsume](https://github.com/tokoroten/edo_era_tsume_shogi)（原典はパブリックドメイン、データはCC0 1.0）で、作者の手順と違う手でも詰む場合があります。
  - 詰将棋と図巧では、手順を1手ずつ盤に並べる「答えを見る」が使えます。
  - 解き終えたら（逃げる問題は続きの確かめまで指し終えたら）「次の問題」へ進めます。解き終えた局面からは、先手も後手も自由に駒を動かして確かめられます（1手戻す・全部戻すあり）。
- **やこび姫の助言**: 戦法と囲いの手順を盤上の矢印で案内します。好手を褒め、悪手や詰めろを知らせます。
  - **悪手の理由と相手の狙い**: 「詳しい助言」では、悪手を指したときに、悪手判定の読みの相手のいちばんの応手から理由を1つ添えます（「あちゃ～、やっちゃった…今動かした銀が、△5五歩で取られちゃう。（評価値変動-600）」）。CPUが指したあとは、手番を入れ替えた局面の読み（詰めろの確かめ）で、相手が次に銀以上の駒を取る・飛車や角が成り込む狙いがあり、2手続けて指されると300点以上悪くなるときに、「相手の狙いは△2八角成だよ。飛車が取られそう！」と言います（取り返せる交換は「〜からの攻めだよ」。1500点以上勝っているときと、3000点以上負けているときは言いません）。新しい探索は足しません。
  - **形勢に合わせた方針と手筋のほめ言葉**: 「詳しい助言」の形勢の一言は、中盤（±300点）・終盤（±500点）で駒の損得が歩3枚とすこし（300点）より大きいとき、「駒得してるね！ 駒を交換して、局面を単純にしていこう！」「駒損してるね…。駒の交換は避けて、局面を複雑にして粘ろう！」のように、次にすることを言います。好手は、コレクションと同じ手筋の見分けで「ふんどしの桂！ 桂の両取りだね！」のように手筋の名前でほめます（両取り・王手の形はいつも、叩きの歩などは好手か駒得のときだけ）。
  - **大会の相手の棋風**: 竜王戦・名人戦の1局の始めに（大一番の開幕の一言がない局）、相手の特殊能力と棋風から「中村さんは、終盤で頓死することがある相手だよ。苦しくても終盤まで粘れば、チャンスが来るよ！」のように戦い方を1行言います。設計は`docs/coach-plan-advice-design.md`の11章です。
  - **作戦の助言**: 「詳しい助言」の対局（平手から始めたCPU対局）で、AIの最善手が飛車を振る手で、振らない一番の手より80点以上良いとき、やこび姫が「飛車を4筋に振って、右四間飛車にしたら？ 相手の金矢倉と相性がいい形だよ！」のように作戦の名前で提案します（袖飛車・右四間飛車・中飛車・四間飛車・三間飛車・向かい飛車。振った飛車をもう一度動かす手は「振り直し」として、中盤でも80手目まで促します）。提案の前に、その2手だけを深く読み直して差が60点以上残ることを確かめ、やこび姫補助の欄の札に「AIの読み」として2手の評価値を並べます。札の「◯◯にする」で作戦カードにその戦法を入れ、矢印と薄い駒で案内します（まだ使えない段の戦法でも、押せば次の対局からも使えます。`localStorage`のキー`yacobihime:shogi-match:coach-plans:v1`）。同じ作戦の提案は1局に1回、作戦の助言は1局に2回までです。提案のあとにその作戦へ飛車を振ると、次の手番でほめます。設計は`docs/coach-plan-advice-design.md`、1局に何回出るかは`node scripts/coach-plan-advice-report.mjs`で測ります。
- **作戦カード（やこび姫補助）**: 目指す戦法と囲いは、完成形の小さな盤が描かれた「作戦カード」で選びます。対局準備の「あなたの作戦」（既定は「なし」）の［変更］か、対局中のやこび姫補助の欄から開きます。カードは「居飛車で攻める」「振り飛車で受ける」「びっくり作戦」「囲いだけを組む」に分かれ、一言・攻めか受けか・難しさ（★）・対局で完成させた回数が付きます。押すとくわしい画面で得意なこと・コツ・気をつけることを読み、合う囲い（◎いちばん合う・○合う）を選べます。くわしい画面の［手順を見る］では、自分が指す手（後手なら盤を反転した「△３四歩」のような手）を、同じ小さな盤で1手ずつ動かして見られます（◀▶で1手ずつ戻る・進む）。［おまかせ］を押すと、やこび姫が使える作戦から1枚を選びます（まだ完成させたことのない作戦を優先し、相手が振り飛車と分かっていれば居飛車の作戦から選びます）。最初に使えるのは入門の3枚（棒銀・四間飛車・中飛車）で、入門の作戦を対局で1回完成させると基本の作戦（教室の第4巻でその戦法を練習しても、その戦法だけ）、基本の作戦を2種類完成させると応用の作戦と囲いだけのカード、竜王戦に出るとびっくり作戦が使えるようになります。まだ使えない作戦は、形の影と条件だけを見せます。はじめての案内で「ふだん指している」を選んだ人と、レーティングが初段相当以上の人は最初から全部使え、シートの「ぜんぶの作戦を使う」でも全部開けます（`localStorage`のキー`yacobihime:shogi-match:opening-plans-all:v1`）。解放は新しく保存せず、コレクション・教室の進み具合・竜王戦の成績から毎回計算します。新しく使えるようになったカードには「NEW」を付け（見たカードはキー`yacobihime:shogi-match:opening-plans-seen:v1`に保存）、対局で増えたときは終局画面でも知らせます。対局中は、選んだ作戦の完成形のうち、まだ駒が来ていない空きマスに駒を薄く描き、欄に「完成まで、あと◯マス」を出します。薄い駒は、強くなる道の5段目より前の人と学習対局で既定で出し、欄の「完成形を盤に出す」で切り替えられます（キー`yacobihime:shogi-match:plan-ghosts:v1`）。作戦が続けられなくなったら「作戦を変えよう」の札で、今の局面から近い作戦を残り手数つきで並べます。
- **戦法占い**: 作戦カードのシートの「迷ったら占う」か、定跡図鑑の「迷ったら、やこび姫に占ってもらう」から開きます。3つの質問に答えると、上から下へ分かれる道をたどって、原始棒銀・早繰り銀・腰掛け銀・矢倉・四間飛車・三間飛車・中飛車・向かい飛車のどれかを「君は◯◯タイプ！」と占います。答えるたびに道が伸び、「ひとつ前の質問へ」で戻れます。出た作戦は、まだ使えない段でもその場で使えるようになります（`localStorage`のキー`yacobihime:shogi-match:opening-fortune:v1`）。結果から、その作戦で指す（作戦カードのシートではその作戦を選び、定跡図鑑からは通常対局の対局準備の「あなたの作戦」に入れる）・完成形から指してみる（学習対局）・図鑑で手順を見る、を選べます（後の2つは定跡図鑑から開いたときだけ）。
- **ルール**: 詰み、千日手、連続王手の千日手、打ち歩詰め、入玉宣言に対応しています。
- **棋譜解析**: 終局後に解析します。全局面を軽く読み、怪しい手を読み直し、大事な局面を深く読む3段階で解析します。PCでは解析の間だけエンジンを増やして並行して読みます。評価値グラフをクリックすると、その局面へ移動します。盤で駒を動かすと分岐して「こう指したら？」を試せ、分岐の局面もその場でAIが読みます。閃きと「感想戦」のボタンは、やこび姫のコメントの下（通常時の閃き・待ったと同じ場所）にあります。「感想戦」を押すと、盤で指した手に対局相手のCPUが対局と同じ強さで応えるようになり、もう一度押すとやめます（感想戦中は待ったを何度でも使え、本筋に戻ると感想戦も終わります）。最善の読み筋は解析欄の「その他」から表示でき、盤に並べて1手ずつ確かめられます。終局後の「対局を振り返る」では、開始局面から1手ずつ自動で並べ、敗着や見逃した詰み、タダで取れた駒の見逃しの前で止まって考えさせます。タダの駒を取る問題は、最善手でなくても、その駒をタダで取れる手なら正解です。駒をタダで取られる形にした手や、相手に詰みが生まれた手は、問題の文で何が起きたかを具体的に伝えます。タダの駒を取った手・取られた手・相手が見逃した手にも、やこび姫が一言添えます。見逃した詰みは、相手の応手をやこび姫が指し、詰むまで盤で指して確かめます。振り返りの「速さ」ボタンで、ゆっくり・ふつう・速い・とても速いを切り替えられ、選んだ速さは端末の`localStorage`（キー`shogi-match-guided-review-speed`）に保存します。投了で終わった対局では投了図を深く読んで投了の理由を説明します。解析レベルは「速い」から「最強」までの5段階で、解析を始める前に選べます（中くらいの「藤井聡太並み」はCPUのLv40と同じ探索量、「最強」はその4倍）。
- **盤の反転**: 対局中と検討中に、閃き・待ったと同じ操作列の「ひふみんアイ」で盤を上下反転できます。幅が足りないときは駒の利き・駒の損得と一緒に「表示補助」にまとまります。見出しのメニューからも同じ切り替えができます。
- **自己申告の棋力**: やこびノートで、日本将棋連盟の段級位（15級〜アマ七段）を申告すると、レーティングをその棋力に設定します（対局数は変わりません）。以降の通常対局は、申告した段級位ごとに、CPUのレベル別の勝敗を記録します。「戦績データをコピー」で、レーティング・申告・レベル別と申告別の成績をJSONでコピーでき、CPUの表示名と実際の棋力のずれを調べるのに使えます。
- **棋力測定**: やこびノートの「棋力を測る」を押すと、対局準備を通さずに、平手・先手・作戦おまかせ・助言なしで、レーティングに近いレベルのCPUと1局始まります（測定を離れると元の対局設定へ戻ります）。終局後に自動で棋譜解析を始めます。解析の間は「完了」を隠し、状態表示に「棋力を測定中です…」と進み具合を出します。盤の上には「棋力を測定中」の札を重ね、解析の3段階（全体を確認・怪しい手を読み直し・大事な局面を深読み）を1本にまとめた太い棒と割合、いまの段階、やこび姫の話（何を測っているか。6秒ごとに替わる）を出します。札は「盤を見ながら待つ」で閉じられ、閉じても状態表示の細い棒は残ります。解析が終わると「棋力測定の結果」に、レーティングと級・段の目安（誤差の範囲つき）、測った手数と平均損失、序盤・中盤・終盤ごとの平均損失、大悪手・悪手・疑問手・好手・神の一手の数、一番の悪手を出します。形勢に大差が付いた局面の手は除き、1手の損失は1000で打ち切ります。測れる手が10手に満たないときは、結果に「まだ測りきれていません（測れた手 N手／10手）」と「もう1局指す（Lv.N）」を出します。勝っていれば相手を8Lv上げ、負けていれば8Lv下げて、この対局の測れた手を持ち越し、次の対局の手と合わせて診断します（最初の1局を含めて3局まで。対局準備やホームへ戻ると、持ち越した手は捨てます）。診断が出たときは、何局分の手から診断したかを添えます。結果の「この棋力をレーティングに設定」で自分のレーティングにできます（対局数は変わりません）。平均損失とLvの対応は、`docs/difficulty-calibration.md`の測定値（現在のレベル表でCPUの着手を測った平均損失）から作った目安で、診断はLv0〜36の範囲です。通常対局の棋譜解析の画面でも、同じ診断（レーティングの目安）を表示しますが、「レーティングに設定」できるのは、やこびノートの棋力測定の対局だけです。
- **大会**: タイトル画面の「大会」ボタンから入る独立したモードです（対局設定の種類ではありません）。大会の選択（タイトル画面と同じ見た目）から大会を選び、説明を読んで、エントリー設定をして参加します。いまは「竜王戦」と「名人戦」の2つです（名人戦は下の項目）。竜王戦は、6組のランキング戦から、敗者復活戦、決勝トーナメント、挑戦者決定三番勝負、竜王戦七番勝負へと進みます。エントリーの設定は、対局準備と同じ「項目: 値 - **名人戦（順位戦から名人へ）**: 大会の選択の「名人戦」から入ります（設計は`docs/meijin-design.md`）。プレイヤーはC級2組の最後の順位（新四段）から始め、1期ごとに自分のクラスの順位戦（C級2組・C級1組・B級2組は10局、B級1組は12局、A級は9局の総当たり）を指します。期の画面は、上に「自力／他力／決定」の見込みの1行、真ん中にリーグ表（順位・棋士・勝敗・回戦ごとの○●。自分の行は琥珀、次の相手は朱、ライバルと降級点の札、昇級ラインと降級点・降級ラインの点線）、横長の画面では右（縦長では下）に次の一局の枠（相手の顔・Lv・得意戦法・今期の成績・手番、能力のレーダーチャートとランク・特殊能力、広い画面では得意戦法の使用率、やこび姫の1行、「対局する」）です。勝ち数が同じなら前の期の順位が上の棋士が上になり（頭ハネ）、昇級はクラスの上位（C級2組は3名、C級1組・B級2組・B級1組は2名）、下位は降級点（C級・B級2組）か降級（B級1組・A級）です。C級2組で降級点が3点になっても、フリークラスへは落とさず、降級点を消して再挑戦にします。A級の1位（同じ勝ち数ならプレーオフ）は、名人と名人戦七番勝負（先に4勝）を指し、勝てば名人です。名人になると次の期は防衛戦で、通算5期で永世名人です。羽音もC級2組から始まり、期の後半に必ず1度当たります。入口はドット絵の五重塔（1階C級2組〜5階A級、相輪に名人の座。自分の駒は今のクラスの階）で、エントリーでは難易度・規模（実物どおり／短め7局／みじかい5局）・やこび姫の助言・閃き・待ったを決めます。名人戦は竜王戦とは別の暦で進みます。順位戦の世界（クラスごとの順位・降級点・名人）は棋士の名簿に1つだけあり（`yacobihime:shogi-match:ryuo-roster`の`junni`）、名鑑・竜王戦の相手の紹介・名人戦は同じ世界を読みます。順位戦と名人は名人戦の期でだけ進み、プレイヤーが名人戦に出る前は、竜王戦の期の終わりに名人戦の1期が自動で進みます（設計は`docs/player-world-note-design.md`）。名人戦のキャリア（`yacobihime:shogi-match:meijin-career`）にはプレイヤーの歩み（最後の期・最高クラス・名人の期数・これまでの成績・設定）を、進行中の期は`yacobihime:shogi-match:meijin-season`に持ちます。前の保存のキャリアにある順位戦の世界は、読み込んだときに名簿へ移します。最初の期は棋士名簿の順位戦から作り、期の始めに名簿と照らし合わせます（引退した棋士を外し、新四段をC級2組に足す）。ほかの棋士どうしの対局は自動で決まります。対局から戻ると期の画面に戻り、中断した対局は期の画面の「対局を再開」から続けられます。名人戦の対局も、レーティングとやこびノートの成績に「名人戦」として数えます。期が終わると、結果の画面（判子・クラスと成績・今期の○●・次の期）の「表彰式へ」で期を締めくくります。

- **コレクション**: 対CPUの対局（通常・学習・教室・大会・棋力測定）で、定跡図鑑にある戦法・囲いを組むと印が1つ増えます（同じ形は2回目から回数だけ数えます。基本の「居飛車」は数えません）。レーティングの対象の対局で、CPUのLv1〜40に初めて勝っても印が1つ増えます。神の一手の回数も数えます。終局画面に、この対局で手に入った印と、使えるようになった着せ替え、次の着せ替えまでの残りを出します。やこびノートの「コレクション」は、いちばん上に印の数と、次の着せ替え（小さな絵と名前）までのゲージを出し、「印のアルバム｜着せ替え」で切り替えます。アルバムは「居飛車・振り飛車・奇襲・囲い・手筋・Lvの壁・記念」のページに分け（ページごとに取った数）、戦法・囲いは完成形の小さな盤のカードで見せます（取ったものは金の縁と回数、まだのものは盤を薄く。作戦カードで選べるのにまだ組んでいないものは「挑戦できる」として先頭に）。カードを押すと、作戦カードのくわしい画面（手順の再生と「この作戦にする」）を対局準備で開きます（作戦カードにない形は定跡図鑑、手筋は手筋図鑑）。Lvの壁はLv1〜40を10段ずつ4本の階段にし、次に勝つと印が増えるLvを縁取り、おすすめの強さの前後に印を付けます。記念のページに、神の一手の回数・竜王戦の予想の的中・賞状の枚数・勝ったLvを出します。前にコレクションを開いたあとに初めて取った印には「NEW」を付けます（最後に開いた時刻は`yacobihime:shogi-match:collection-seen:v1`、開いていたページは`yacobihime:shogi-match:note-album-page`）。盤と駒の着せ替えは、盤・駒とも2つは最初から使え、残りは印の数で使えるようになります（盤: 暖色木目3個・濃色8個・樹脂15個、駒: 一文字・ゴシック3個・二文字6個・一文字・濃色10個・一文字・ゴシック濃色15個）。前から選んでいた着せ替えは、印の数にかかわらず使えます。定跡図鑑の一覧では、組んだことのある戦法・囲いに★（2回目からは回数）を付けます。手筋図鑑の手筋のうち、指した手の形だけで見分けられるもの（頭金・両王手・ふんどしの桂・桂の王手・十字飛車・腹銀・叩きの歩・金底の歩・5三のと金）を対局で指しても印が増え、手筋図鑑の一覧に★が付きます。初めて手に入った戦法・囲い・手筋には、終局画面でどんな形かを一言添えます。対局中にプレイヤーが定跡図鑑の囲いを完成させると、その瞬間に盤の上へ「美濃囲い 完成！」を1.6秒出します（1局で同じ囲いは1回だけ。開始局面ですでに組んである囲いは出しません。まだ印のない囲いなら「はじめて！」と添えます）。詰んだ局面（終局後・検討中）では、詰んだ玉のまわりに相手の駒が利いているマスの×を出します。やこびノートの「コレクション」の記念のページには、組んだ戦法・囲いを得意にしている竜王戦の棋士を並べ、棋士名鑑の各棋士には「あなたも組んだ形」を出します。対局準備の強さの選択肢では、おすすめより強く、まだ勝っていないLvに「初めて勝つと★」を添えます。記録は`localStorage`（キー`yacobihime:shogi-match:collection:v1`）に保存します。
- **駒の損得**: 対局中と振り返りの操作列（閃き・待った・駒の利きの並び）の「駒の損得」を押すと、状態表示に自分から見た駒の損得の札（「駒得 ＋315」は緑、「駒損 −180」は赤、「駒の損得 ±0」）を出し、駒を取ったマスに「＋540」「−495」を浮かべます（学習対局では、押さなくても数字を浮かべます）。点数は盤の上と持ち駒の駒図鑑の「将棋AI（やねうら王）が使う駒の価値」（歩90・香315・桂405・銀495・金540・角855・飛990、と金・成香・成桂・成銀540・馬945・竜1395）の合計を比べたものです。二人で指すときは先手から見ます。振り返りでは見ている局面の損得です。付け外しは`localStorage`（キー`yacobihime:shogi-match:material-guide:v1`）に覚えます。
- **プレイヤー名**: ホーム画面の記録の帯（やこびノート）の左のボタンから、プレイヤー名を入れられます（10文字まで。入れていないときは「名前を入れる」）。CPUとの対局のプレイヤー側の盤の名札、対局準備の自分の側、竜王戦のトーナメント表とVS画面に出ます（入れていなければ、盤の名札は先手・後手の表示名、ほかは「あなた」）。進めている竜王戦の期があるときに変えると、その期の表の名前も替わります。空にして決めると「あなた」に戻ります。`localStorage`（キー`yacobihime:shogi-match:player-name:v1`）に保存します。
- **はじめての案内**: ホーム画面がある表示（`show-home`）で、この端末にアプリの記録が何もないときだけ、最初にやこび姫が将棋をどのくらい知っているかを聞きます。札は易しい順に4つです（`docs/first-play-design.md`）。「はじめて」は将棋教室の第1巻、「ルールは分かる」は将棋教室で始める場所を決める1問（下の教室の項目）、「少し指せる」と「よく指している」は1級くらい（Lv15）の相手との棋力測定へ案内します。案内から測った棋力は、測れたらそのままレーティングにし、結果の画面に「あなたは5級くらい。竜王戦は難易度Nがちょうどいいよ」と「竜王戦に出る」（竜王戦の入口を、測った棋力に合う難易度で開く）・「ホームへ」を出します（「よく指している」は「竜王戦に出る」、「少し指せる」は「ホームへ」が主ボタン。測りきれなくても竜王戦へは進めます）。強くなる道は、「ルールは分かる」「少し指せる」「よく指している」で駒を覚える段を終え、「少し指せる」「よく指している」は測ったら初めての対局の段、「よく指している」は詰みの段も終えたことにします。「自分で選ぶ」やブラウザの戻る操作で閉じられます。一度閉じると、`localStorage`（キー`yacobihime:shogi-match:welcome:v1`）に記録し、二度と出しません。
- **自動保存**: 対局中と終局後の状態を自動で保存します。リロードしても続きから再開できます。
- **対局の中断**: ホーム画面がある表示（`show-home`）では、対局中に「中断」（狭い画面ではメニューの「対局を中断する」）で、対局を保存してホームへ戻れます。ホームの「つぎはこれ」に出る「対局を再開」から、保存した局面と設定のまま続けられます。竜王戦の対局を中断したときは、竜王戦の画面の次の一局の枠でも「対局する」が「対局を再開」（何手目まで指したかを添える）に替わり、そこから続けられます（VS画面は出さずに盤へ戻ります）。リロードしても中断した対局は残り、再開するまで自動では開きません。中断した対局があるときに新しい対局（教室の対局・棋力測定を含む）を始めると、確認のうえで中断した対局は消えます。中断は結果に数えず、レーティングも動きません。

- **やこび姫の将棋教室**: 5巻13章・68レッスンの教室です。
  - 範囲は、駒の動かし方から戦法・格言・形勢判断までです。説明を聞くより、盤で手を動かす課題が中心です（課題は全ステップの約6割）。

  - 章の最後に「腕だめし」があります（観戦だけの章を除く11章）。その章の課題に、前の章の課題を混ぜて出します。腕だめしの★で、章のメダル（★3で金・★2で銀・★1で銅）が決まり、地図の章の看板と章クリアの画面に出ます。
  - 巻のレッスンを全部終え、その巻の腕だめしをすべてクリアすると、称号「将棋教室 第N巻 修了」（第5巻は「将棋教室 卒業」）がもらえます。やこびノートの称号に残ります。
  - 正解すると、盤の上に「正解」「詰み！」「最短！」の印を押し、何が良かったかを一言でほめます。まちがえずに続けて解くと「2れんぞく！」と知らせます。レッスン中は、見出しの帯に「めあて」（このレッスンでできるようになること）を出します。
  - 成績は★1〜3で記録します。レッスンは順番に解放され、スキップもできます（レッスン中は見出しの右端の「スキップ」、章ごとなら地図の章の看板の「この章をとばす」）。
  - 腕だめしで飛び級できます。まだ届いていない章の腕だめしにも鍵がかからず、まちがいとヒントが合わせて2回まで（★2以上）で合格すると、その章の終えていないレッスンを「修了」に、それより前の遊んでいないレッスンを「とばした」にして、次の章へ進めます。★が足りなければ★だけを記録して地図へ戻ります。「修了」は教室の記録（`yacobihime:shogi-match:tutorial:v1`）に`tested: true`として残し、遊び直してクリアすれば★に変わります。
  - 教室を開くと、全レッスンを学ぶ順に1本の道に並べた地図が出ます（巻の看板・章の看板・レッスンのマス）。いま進めるマスに「ここから！」を付け、そこまで自動でスクロールします。マスを押すとすぐレッスンが始まります。マスの文字はレッスンの種類（駒のレッスンはその駒、詰・指・問・局・観など）です。
  - 同じ章のレッスンは、結果の画面を挟まずに続けて進みます。レッスンを終えると盤の上に「クリア！」と星を短く出し、約1.7秒で次のレッスンが始まります（押せば待たずに進み、「地図へ」で戻れます）。章の最後のレッスンを終えると「章クリア」の画面で、章の星と、レッスンごとの「できるようになったこと」を札にしてまとめて見せ、「次の章へ」にフォーカスを置きます。札を押すと、そのレッスンをもう一度遊べます。レッスン中は、見出しの下の帯に、章のレッスンの区切りと、いまのレッスンの進み具合を出します。
  - 説明は画面のどこを押しても進みます（盤を押しても進みます。Enter・スペース・→キーでも進みます）。盤で指す課題と選択問題は、正解すると自動で次へ進みます（選択問題は解説を読む時間をとってから。画面を押せば待たずに進めます）。まちがえた選択肢は押せなくなり、残りから選べます。
  - 盤の課題で10秒操作がないと、ヒントがそっと出ます。このヒントは★の数に数えません。ヒントは1段目で「見方」（正解の一手を探す課題は駒の利き、詰ませる課題は玉の逃げ道）、2段目で答えの矢印を出します。
  - **駒得の数字**: 教室の盤で駒を取ると、取ったマスにその駒の値段を緑で「＋6」のように浮かべ、取られると赤で「−5」を浮かべます。値段は駒図鑑の「駒の価値 tier表」と同じで（歩1・香3・桂4・銀5・金6・角8・飛10）、成った駒を取ったときは、持ち駒になる元の駒の値段で数えます（と金を取ったら＋1）。課題の中で駒の取り合いが起きると、吹き出しの上の札に「駒得 ＋1」「駒損 −4」「とりかえ ±0」と合計を出します。観戦では、先手から見た合計（「▲先手 駒得 ＋3」）を出します。
  - **利きメガネ**: 第2巻の「利きを見よう」を終える（スキップでもよい）と手に入る道具です。見出しの「利き」ボタンでかけると、どのレッスンでも、各マスに利いている駒の数（先手は青、後手は赤）と、駒を選んだときに動かすと取られるマス（赤い輪）が見えます。かけても★は減りません。かけているかどうかは`localStorage`（キー`yacobihime:shogi-match:tutorial-kiki-glasses:v1`）に保存します。レッスンによっては、メガネがなくても利きや取られるマスを出します。取られるマスへ動かしてまちがえると、相手が取り返す手を見せてから局面を戻します。
  - **玉の逃げ道**: 詰ませたときと、王手を受けるレッスンでは、玉のまわり8マスに印を付けます。逃げられるマスは緑、相手の駒が利いているマスは×（先手の利きは青、後手の利きは赤）です。
  - **にがてをもう1回**: レッスンでまちがえた課題（まちがい・ヒントがあった盤の課題と選択問題）を、レッスンごとに記録します。章クリアの画面と地図の章の看板に「にがてをもう1回（N問）」を出し、その章の苦手だけを解き直せます。まちがえずに解いた課題は苦手から消え、★は付けません。レッスンをもう一度最後まで遊ぶと、その回の結果で置き換えます。記録は`localStorage`（キー`yacobihime:shogi-match:tutorial-weak:v1`）に保存します。
  - **駒を並べよう**: 第1巻の「駒を並べよう」では、玉と歩を置いた盤に、持ち駒の飛車・角・金銀・桂香を薄く見せたマスへ打って、最初の並べ方を作ります。違うマスに打とうとすると、置く場所を一言で伝えます。
  - 第4巻の定跡の練習では、形ができたあとに先手の利き（青い数字）を見せ、最後に作戦カードと同じ小さな盤で手順を1手ずつおさらいします。
  - **盤の上のひとこと**: 見るマスのそばに、しっぽ付きの短い札（14字まで）を1つだけ出します（「ねらう駒」「ここまで」「逃げ道 2」「動けるマス」など）。札はステップのデータから自動で作り、印のマスと駒をなるべく避けて置きます。正解したときは動かした駒のそばにほめ言葉の最初の一句（「両取り！」など）を、取られる場所へ動かしたときは「取られる！」を出します。吹き出しの文は1ステップ60字までにし、「緑のマス」「赤い数字」などの言葉の前には、盤と同じ色の小さな札を付けます。
  - **その場の図鑑**: 図鑑の項目（頭金・駒の価値・囲い・定跡）を、図鑑の画面へ移らずにレッスンの盤と吹き出しで見せます。図鑑の一言から始め、画面を押すたびに図鑑の行を1行ずつめくります。駒の価値は値段の札を1行に並べます。吹き出しの「図鑑でくわしく」を押すと図鑑をレッスンの上に開き、閉じると同じステップへ戻ります。
  - **格言札と格言帳**: 第1巻の銀・香・玉・成る・持ち駒のレッスンから第4巻の棒銀まで、16のレッスンの課題に格言札が1枚ずつ付きます。課題を解き終えると（まちがえても）、盤の上に「いま君が指した手が、これ！」と格言の名前・一言の札を出し、いま指した駒に「この手！」と添えます。札は押すと閉じて次へ進みます。初めて出会った格言は格言帳に入り、手筋図鑑の一覧に「札」の印が付きます（対局で指した手筋の★とは別の印です）。記録は`localStorage`（キー`yacobihime:shogi-match:tutorial-proverbs:v1`）に保存します。
  - **読み上げ**: 日本語の声がある端末では、レッスン中の見出しに「声」のボタンを出します。オンにすると、ステップが変わったとき（図鑑の行をめくったとき・観戦で1手進めたときも）の吹き出しの文と、正解・まちがいの一言を、端末の音声合成（Web Speech API）で読み上げます。新しい文を読むときは前の読み上げを止め、レッスンを離れると止めます。符号や駒の名前は読み違えないように直します（「▲７六歩」を「せんて、なな ろく ふ」など）。既定はオフで、選んだ状態は`localStorage`（キー`yacobihime:shogi-match:tutorial-voice:v1`）に保存します。盤の上のひとことは読みません。
  - **攻めくらべと囲いを組もう**: 第3巻では、同じ攻め駒（5五の竜と持ち駒の金）で、居玉（3手で詰む）と美濃囲い・舟囲い（詰まない）を王手だけで攻めくらべて、囲いの強さを確かめます。そのあと、薄く見せた完成形に向けて、自分で玉と金銀を動かして美濃囲い・舟囲い・金矢倉を組み立てます。手順は定跡図鑑の囲いの定義と同じで、最短の手数で組むと「最短！」です。腕だめしでは完成形を伏せて組みますが、「完成形を見る」を押すと薄い駒を出せます（ヒント1回に数え、そのレッスンの★は2つまでになります）。
  - ホーム画面の「つぎはこれ」（将棋教室ではじめる・将棋教室のつづき）と、はじめての案内の「はじめて」からは、本棚を通さずに次のレッスンが始まります。「まなぶ」の「将棋教室」からは地図を開きます。
  - 教室を初めて開いたとき（レッスンの記録が何もないとき）だけ、やこび姫が「将棋、どのくらい知ってる？」と聞きます。札は「はじめて」（駒の動かし方から）、「駒の動きは分かる」（成る・持ち駒・反則から）、「ルールは分かる」（第2巻のタダの駒・両取り・詰みから）、「1手詰めなら解ける」（第3巻の囲いと戦法から）の4枚で、押すとそのレッスンがすぐ始まります。それより前のレッスンは「とばした」の記録になり（★・メダル・巻の称号は付きません）、地図からいつでも遊べます。はじめての案内で「少し指せる」「よく指している」を選んだ人には、合う札に「おすすめ」を付けます。「はじめて」を選んで来た人には聞きません。「ルールは分かる」を選んで来た人には、札の代わりに1手詰めを1問出します。まちがえずヒントも使わずに解けたら第3巻（戦法と囲い）、まちがえた・ヒントを使った・スキップしたら第2巻（利き・タダの駒・両取り・詰み）から始め、そのレッスンがすぐ始まります（1問の記録は残しません）。「地図から自分で選ぶ」でも閉じられます。答えは教室の記録（キー`yacobihime:shogi-match:tutorial:v1`の`placement`）に残し、二度は聞きません。
  - 先から始めた人の地図には「はじめから学ぶ」を出し、とばした最初のレッスンを始めます。始めた章で続けて2つのレッスンを★1で終えたときは、一度だけ「少しむずかしかったかな？」と、とばした中でいちばん近い章からの復習を勧めます（`reviewOffered`に記録）。
  - 対局のレッスンだけは、終局後に結果の画面（勝ち負け・やこび姫の一言・★）を出し、「次へ進む」で同じ章の次のレッスンか章クリアへ進みます。
- **図鑑**: 盤面付きの図鑑が5つあります。
  - 駒図鑑
  - 手筋図鑑（格言と使いどころ）
  - 定跡図鑑（戦法41種・囲い30種の手順）
  - 将棋界図鑑（歴史と名棋士。代表局は分岐・読み筋の再生・投了の理由の解析ができます）
  - 将棋用語辞典（「詰めろ」「さばき」など70語。読みや解説から検索でき、関連する用語へ移れます）
  - 対局中・検討中も、見出しの「図鑑」（本の絵）から開けます。ホームの「しらべる」と同じ絵の5つの図鑑から選ぶと、対局の上に図鑑を開き、「対局へ戻る」で同じ局面に戻ります（対局は保存したままです。図鑑を見ているあいだもCPUは指します）。対局から開いた図鑑では、将棋界図鑑の代表局のAI解析は出さず、定跡図鑑の戦法占いからは「図鑑で見る」だけを選べます（対局のエンジンを借りないため・指している対局を消さないため。設計は`docs/match-dex-design.md`）。

### 組み込む

- **Custom Element**: `<shogi-match-game>`（対局画面一式）と`<shogi-match-board>`（盤面だけ）を公開しています。
- **iframe連携**: `game.html`をiframeで開くと、結果を`postMessage`で受け取れます。ティラノスクリプト用のタグもあります。
- **レスポンシブ**: 画面の大きさと向きに合わせて、盤の大きさと配置を自動で切り替えます。PC、タブレット、スマートフォンの縦横で使えます。どの画面もページをスクロールさせずに1画面に収めます（将棋教室の地図、トーナメント表、図鑑・辞典の一覧、コレクションは枠の中だけを動かします）。スマホの横向きでは、ホーム・対局準備・終局の結果・はじめての案内・やこびノート・大会を左右の2列に並べ、将棋教室と問題集は盤を左、やこび姫の台詞を右に置きます。
- **RPG向けランタイム**: `integrations/shogi-rpg.js`を含みます。対局準備、消費する棋具、セーブ連携、敵ごとの定跡を扱えます。

## すぐに動かす

Node.js 20以上とnpmが必要です。

```sh
git clone https://github.com/YacobiHime/shogi-match.git
cd shogi-match
npm install
npm run build
npm run opening-editor
```

開発サーバーが起動したら、<http://127.0.0.1:5173/game.html> を開きます。

`game.html`は`dist/`のビルド結果を読み込みます。`src/`を変えたら、`npm run build`をやり直してから開き直してください。
初回準備、定跡エディター、よくある問題の対処は[ローカル起動・定跡編集ガイド](docs/local-development.md)にまとめています。

### 自分のサーバーへ置く

`game.html`、`dist/`、`vendor/`を同じ階層に置き、HTTPサーバーから`game.html`を開きます。
`dist/chunks/`には、教室・問題集・図鑑・やこびノート・大会の画面と、対局の共通部分が入っています。`dist/shogi-match.js`がそこから読み込むので、`dist/`はフォルダーごと置いてください。
WASMエンジンは`SharedArrayBuffer`を使います。そのため、サーバーは次の2つのヘッダーを返す必要があります。

```text
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

埋め込み先のページにも、同じ分離設定が必要です。
やねうら王を取得・起動できない場合は、合法手から選ぶ軽量CPUへ自動で切り替わります。

## URLパラメーター（`game.html`）

```text
game.html?mode=cpu&player_color=black&match_id=chapter1-boss
```

| パラメーター | 内容 |
| --- | --- |
| `mode` | `cpu`（既定）: 同梱のやねうら王と対局。`local`: 1台の端末で2人対局 |
| `player_color` | `black`または`white`。CPU対局で人間が持つ側 |
| `initial_sfen` | 開始局面のSFEN |
| `match_id` | 対局を識別するID。保存の識別と、`postMessage`の結果に使う |
| `engine_nodes` | CPUの強さの識別値（既定値30000＝Lv21、六級程度）。最も近いレベルへ丸める。旧版の値（2000〜480000）や、整理して削った段位の値は、同じ段級位のレベルへ引き継ぐ |
| `black_name`、`white_name`、`cpu_name` | 盤や結果画面に表示する対局者名。CPU側の名前には「Lv.15」などのレベルと棋力の目安を添える |
| `handicap` | 手合割の表示名 |
| `exhibit` | 公開ページでは既定で有効。`1`も互換用に受け付ける（タイトル画面の左下に「データリセット」を出す。下の「展示用パッケージ」） |

`mode`も`initial_sfen`も指定しないで開くと、ホーム画面（タイトル）から始まります。ホーム画面の上には、いまの状態に合った「つぎはこれ」を1つだけ大きく出します。中断した対局があれば「対局を再開」を最優先にします。竜王戦の期の途中なら、次の相手との「続きを指す」（竜王戦の期の画面を開く）か「○○対策」（相手のLv・棋風と特殊能力・相手の手番でいちばん多い得意戦法で、本番と同じ手番の学習対局。レーティングにも竜王戦にも数えず、終局画面の「本番へ」で期の画面へ）を出し、主役でない方を下に小さく添えます。山場の一局（組の決勝・番勝負・羽音戦）と、番勝負で前の局を落としたときは対策を主役にし、対策をしたあとは「対策はばっちり。本番の○○さんへ」と続きを主役にします（対策をした次の一局は`localStorage`のキー`yacobihime:shogi-match:ryuo-counter:v1`で覚えます）。期を終えたばかり（直前のレーティングの対局が竜王戦）なら「第N期 竜王戦へ」を出します。竜王戦に出たことがなく、棋力が分かっている（棋力測定を終えたか、レーティングの対局が3局以上）なら、強くなる道の段を待たずに「竜王戦に出よう」（「あなたは8級くらい。難易度3の6組なら、勝ち上がれるよ」。押すと竜王戦の入口を、おすすめの難易度で開きます。練習を始めてから2局たつまでは出しません）、竜王戦の期を1つ終えて名人戦に出たことがなければ「名人戦に出よう」（名人戦の入口）を出します（`src/core/play-coach.mjs`の`tournamentInvite`、設計は`docs/first-play-design.md`の6章）。それ以外は「強くなる道」のいまの段の行き先です。理由の1行は、同じ状態なら同じ文で、対局が1つ進むと言い換えます（最近5局の成績・前の対局・そのLvとの通算・次の級まで、など。設計は`docs/home-next-adaptive-design.md`の13章）。強くなる道は、①駒を覚える（教室の第1巻）②初めての対局 ③詰みを覚える（教室の第2巻か問題集10問）④竜王戦に出る ⑤大会で勝ち上がる、の5段で、「つぎはこれ」の見出しの横に丸を線でつないで見せます（終えた段は✓、いまの段は大きく光る）。段は保存してある記録（教室の進捗・通常対局の数・問題集の解いた数・竜王戦の成績・はじめての案内で選んだ道）から決め、後の段を終えていれば前の段も終えたことにします。いまの段のおすすめの入口には「おすすめ」の札を付け、2つ以上先の段の入口（大会・終盤戦・問題集）は薄くして「1局指したら」のように添えます。鍵はかけないので、薄い入口も押せばそのまま遊べます（設計は`docs/home-roadmap-design.md`）。5段目の「つぎはこれ」と「はじめての対局」の強さは、レーティングと最近の勝ち負けから決める「勝ち越せそうな相手」です（`src/core/play-coach.mjs`、設計は`docs/home-next-adaptive-design.md`）。勝率6割の見込み（レーティングのLvより約1つ下。Lv0は勧めません）を基準に、最近10局の成績が低ければ早めに下げ、3局以上勝てていないLvは勧めません（1つ下で勝てば、また勧めます）。10局を指したあとは、同じLvに2連敗で1つ下、3連敗で「Lv.（2つ下）で腕ならし」（下に小さく「香落ちでLv.Nに挑む」。15級のLv1では「Lv.0で腕ならし」と「飛車落ちでLv.1に挑む」）、2連勝で「Lv.（1つ上）に挑戦」、初めて勝ったLvの次は1つ上、次の級まで勝ち1回分なら「昇級をかけた一局」を、理由の1行（「Lv.15に3連敗。2つ下で、勝つ感覚を取り戻そう」など）と一緒に出します。1回で動くのは、直前に指したLvから2つまでです。自由対局（レーティングの対象のもの）は、終局後に対局用とは別の軽いエンジンで1手ずつ浅く読み、要約（序盤・中盤・終盤の損、大きな悪手、逃した3手以内の詰み、駒をタダで取られて大きく損をした手、30手目の形勢）を`localStorage`（キー`yacobihime:shogi-match:play-insight:v1`、直近20局と解析待ちの対局）に残します。解析は結果画面やホームにいるあいだに1局ずつ進め、対局を始めると止めて、続きは次の機会に読みます（リロードしても続きから）。エンジンが使えない環境では勝ち負けだけを残します。最近の対局で測れた手が合わせて40手以上あれば、平均損失から出した内容の強さを、結果の強さと6：4で混ぜて見立てます（結果の強さからR120（Lv2つ分）より外へは動かしません）。ふだんの対局を勧める場面では、復習の期日が来た問題があれば「やこび姫からの1問」、直近3局の中身に目立つ弱点があれば弱点の練習を出します。行き先は、まず将棋教室の章（その章の腕だめしをまだクリアしていなければ。詰みを逃した → 第2巻3章「玉をつかまえよう」（3手詰めなら「3手詰めに挑戦」から）、タダで取られる手が多い → 第2巻1章「三手先まで考えよう」、序盤で押された → 第3巻1章「戦法と囲いを知ろう」から第4巻（振り飛車が多ければ1章、ほかは2章）、終盤で損が増えた → 第3巻3章「攻めと守りのコツ」から第5巻2章「序盤・中盤・終盤の作戦」。その章のまだクリアしていないレッスンをすぐ始めます）、章を終えていれば問題集の5問（逃した詰みの手数の詰将棋（5手詰めを10問解いていれば7手詰め）・練習問題・実戦詰将棋。逃した局面の問題があればそれから始め、「練習 n/5問」を数えて、5問解いたら「つぎはこれへ戻る」）と、今までの練習（詰みを逃した → その局面の問題、終盤 → 自分の対局の終盤から指す、タダで取られる → 「駒の利き」を付けた学習対局、序盤 → 学習対局の対局準備で作戦カードを選ぶ）を交互に勧めます（前にその弱点で行った先を`yacobihime:shogi-match:play-insight:v1`の`practice.via`に覚えます）。竜王戦の対局も、大会の統計のための裏の解析から同じ要約を作って加えます（二度は読みません）。対局の中身に目立つ弱点がなければ、戦型の成績から、苦手な戦型（相手の居飛車・振り飛車の片方に勝率4割以下で、もう片方より2割以上低い。両方5局以上）なら「振り飛車党と対局」（CPUの戦法の傾向をその戦法にした、おすすめの強さの学習対局）、自分の戦法が9割以上どちらかなら「振り飛車を試そう」（作戦カードの学習対局）を出します。練習で変えたCPUの設定は、練習を離れると元に戻ります。前の対局に大きな悪手がなかった、またはいつもより損が少なかったときは、「対局する」の1行で「前の局は大きな悪手なし！」のように伝えます。練習は対局2局に1回までで、同じ弱点の練習を続けては出しません。ふだんの対局を勧める場面では、その日まだ1局も指していなければ「今日の1局」（続けて遊んでいる日数か、休んだあとは「おかえり！」）、今日1局以上指していて対局数が3の倍数のときは、まだ開いたことのない遊び（終盤戦・定跡図鑑・手筋図鑑・将棋界図鑑・駒図鑑・用語辞典・棋力測定の順。開いたことは`localStorage`のキー`yacobihime:shogi-match:seen-features:v1`）を1つ紹介します。「対局する」の1行には、そのLvにまだ勝っていなければ「初めて勝つと★がもらえるよ」、次の着せ替えまで印あと2個以内ならその残りも、言い換えの候補として出します。逃した詰みは、振り返りと同じく「あなたの対局から」の問題として復習の箱に入ります。「対局する」は対局準備を開かず、この強さ・平手で、先後を振り駒（歩5枚のうち歩が3枚以上ならプレイヤーが先手）で決めてすぐ始めます。助言や作戦などは前に対局準備で選んだ設定を使います。設定を選んで始めたいときは「あそぶ」の「自由対局」から対局準備を開きます。その下に、レーティング・級・所属の帯（押すとやこびノート）と、「あそぶ」（自由対局・大会・終盤戦）、「まなぶ」（将棋教室・問題集）、「しらべる」（駒・手筋・定跡・将棋界の図鑑と用語辞典）の入口を並べます。3つの区分は混ぜずに、区分ごとに1行にして上から積み、行の中の入口はどの画面でも横1列に並べます。区分は枠で囲まず、行の上の小さな見出し（あそぶ: 琥珀、まなぶ: 緑、しらべる: 薄紫）と余白で分けます。
ホーム画面がある表示では、ブラウザの戻る操作がアプリ内の「1つ前の画面へ戻る」になります。

- 図鑑・教室・対局準備は、1段ずつ閉じてホームへ戻ります。
- 対局中と検討中は、開いているメニュー・図鑑・解析を閉じるだけです。対局画面からは離れません。
- ホームでもう一度戻ると、元のページへ移ります。

## Custom Elementとして埋め込む

```html
<link rel="stylesheet" href="./dist/shogi-match.css">
<script type="module" src="./dist/shogi-match.js"></script>

<shogi-match-game
  mode="cpu"
  player-color="black"
  asset-base-url="./dist"
  engine-base-url="./"
  cpu-player-name="将棋CPU"
></shogi-match-game>
```

Shadow DOMを使わずに描画するため、同梱のCSSを読み込んだページでそのまま表示されます。

### 属性

| 属性 | 既定値 | 内容 |
| --- | --- | --- |
| `mode` | `cpu` | `cpu`または`local` |
| `player-color` | `black` | CPU対局で人間が持つ側 |
| `initial-sfen` | 平手 | 開始局面のSFEN |
| `asset-base-url` | `.` | 盤・駒・キャラクター画像と音声の公開先 |
| `engine-base-url` | `.` | `vendor/`（やねうら王）を置いた場所 |
| `engine-nodes` | `30000` | CPUの強さの初期値（`engine_nodes`と同じ） |
| `black-player-name` | `先手` | 先手の表示名 |
| `white-player-name` | `後手` | 後手の表示名 |
| `cpu-player-name` | `CPU` | CPUの表示名 |
| `cpu-delay-ms` | `350` | CPUが指すまでの待ち時間（ミリ秒） |
| `handicap-name` | なし | 手合割の表示名 |
| `hint-count` | `3` | 通常対局の閃き（ヒント）の回数 |
| `undo-count` | `3` | 通常対局の待ったの回数 |
| `mobile` | `false` | タッチ端末向けにする。素早く続けてタップしても、成・不成の選択が消えない |
| `enable-drag-and-drop` | `true` | 駒のドラッグ操作を許可する |
| `show-home` | `false` | ホーム画面（教室・図鑑・対局の入口）を表示する |
| `exhibit` | `false` | 公開ページでは既定で有効。タイトル画面の左下に「データリセット」を出す。押すと確認のうえで、このゲームの保存（音と盤・駒の見た目を除く）を`localStorage`と`sessionStorage`から消して、ページを読み直す |

### イベント

| イベント | 発生する時点と、渡される値 |
| --- | --- |
| `match-ready` | 対局の準備ができたとき。`{ mode, sfen }`を渡す。リロードで復元したときは`restored: true`も付く |
| `match-move` | 1手指したとき。`{ usi, actor, moveCount, sfen }`を渡す |
| `match-end` | 終局したとき。勝者、理由、手数、USIの指し手列、最終局面のSFENを渡す |
| `match-error` | 開始局面が不正な場合などのエラー。`{ message }`を渡す |

VueのCustom Elementでは、イベントの値は`event.detail[0]`に入ります。

```js
document.querySelector("shogi-match-game").addEventListener("match-end", (event) => {
  console.log(event.detail[0]);
});
```

## ノベルゲームから呼ぶ（iframe・ティラノスクリプト）

`game.html`を同一オリジンのiframeで開きます。終局すると、親ウィンドウへ次のメッセージを送ります。

```js
{
  type: "shogi-match:result",
  version: 1,
  matchId: "chapter1-boss",
  result: {
    outcome: "black-win",
    winner: "black",
    reason: "checkmate",
    moveCount: 57,
    moves: ["7g7f", "3c3d"],
    finalSfen: "..."
  }
}
```

受け取る側では、`event.origin`、`event.source`、`matchId`を必ず確かめてください。

ティラノスクリプトでは、初期化の後に一度だけタグを登録します。

```html
<script type="module">
  import { registerTyranoShogiMatch } from "./shogi-match.js";
  registerTyranoShogiMatch(window.tyrano, { gameUrl: "./game.html" });
</script>
```

その後は、シナリオにタグを書くだけで対局できます。

```ks
[shogi_match match_id="chapter1:boss" mode="cpu" player_color="black"]
```

終局結果は`f.match_result`に入り、シナリオが次へ進みます。
ティラノ以外のノベルエンジンでは、`openShogiMatch()`を直接呼んでください。同じ全画面iframeと結果の検証を使えます。
URLの組み立てと結果の検証だけを使う場合は、`buildGameUrl()`と`parseMatchResultMessage()`もあります。

## 対局の仕組み

### 自動保存とリロード復元

対局を始めると、状態をブラウザの`localStorage`へ30日間保存します。同じURLをリロードすると、次のものを復元します。

- 指し手、先後、CPUの設定と、CPUが選んだ作戦
- 選んでいた戦法・囲い、閃きと待ったの残り回数、終局結果
- 学習対局の種類・開始局面・回数設定・「動きの矢印」の表示と、「駒の利き」の表示（対局の種類を問わない）
- 局面ごとに表示したやこび姫の助言（棋譜解析で同じ局面を開くと、また表示する）
- 「ひふみんアイ」で変えた盤の向き（棋譜検討中に変えた向きは保存しない）

その他の動き:

- 保存を識別するのは、URLのパスと`match_id`です。
- 開始局面と対局モードが同じなら、保存済みの先後とCPUの強さを、URLの`player_color`や`engine_nodes`より優先します。
- ホーム画面がある表示でも、保存した対局があれば、ホームを通らずに対局画面から再開します。
- 手の重さに応じて手応えを変えます。取る・打つ・成る手は、それぞれ違う着地の動きをし、取った駒は駒台で跳ねます。王手・大駒を取る手・ほめ言葉のあとは、CPUの応手を出す前に一瞬止め、神の一手と詰みでは盤の縁を光らせます。詰みで決まったときは、止めてから結果画面を出します（勝ちは0.4秒、負けは0.2秒。盤を触ると打ち切ります）。ホームの「対局する」で振り駒をするときは、歩を振る音のあいだ歩を揺らし、駒台に撒く音で表と裏と先後を見せます（知らせを押すか、どちらかが指すとすぐ結果を出します。効果音を切っているときは、すぐ結果を出します）。効果音は見出しのメニューの「効果音」で切り替えられ、`localStorage`（キー`yacobihime:shogi-match:sound`）に保存します。教室と問題集も同じ設定に従います。動きを減らす設定（`prefers-reduced-motion`）では、揺れと移動をなくします。
- 結果画面の「もう一局」は、対局準備を通さずに直前と同じ設定で次の対局を始めます。平手の通常対局では先後を入れ替えます。レーティングの対象の対局で同じLvに3連敗すると（申告・測定の記録は数えません）、「もう一度挑む」「Lv.（2つ下）で腕ならし」「香落ちで挑む」（学習対局、CPUが上手。15級のLv1では「Lv.0で腕ならし」「飛車落ちで挑む」）を並べて選ばせます。強さは自動では変えません。平手の通常対局で勝つと、主ボタンが「Lv.（1つ上）に挑戦」になり（初めて勝ったLvなら「初勝利！」と添えます）、同じ相手との「もう一局」は小さく残します。Lv40に勝ったときは「もう一局」のまま、香落ち・飛車落ちで勝ったときは「平手でLv.Nに挑む」、Lv0（練習相手）に勝ったときは「Lv.1に挑戦」です。終盤戦・敗着の前から・教室・棋力測定・竜王戦の対局は、今までどおりです。レーティングが動いた対局では、次の級・段までの残りを帯で示し、級・段の目安が上がったときは知らせます。
- 負けた対局の「対局を振り返る」では、敗着の答え合わせのあとと振り返りの最後に「敗着の前から指し直す」を出します。敗着を指す前の局面から、同じ相手・同じ手番で指し直せます（平手の初期局面からではないので、レーティングの対象外です）。この対局の「もう一局」は、同じ局面から始め直します。
- 結果画面の「ホームへ」（ホーム画面を出さない構成では「対局準備」）や、棋譜解析の「完了」で対局を離れると保存を削除し、次の対局は何も選んでいない状態から始まります。ホーム画面を出す構成（`show-home`）では、終局後はホーム画面へ戻ります。棋譜解析・振り返りの「完了」は、狭い画面でもメニューにしまわずにツールバーに出し、「完了してホームへ」「完了して竜王戦へ」「完了して教室へ」「完了して対局準備へ」のように行き先を書きます。

### CPUの強さと作戦

- **強さを選ぶ場所**: 対局準備で選びます。埋め込みでは`engine-nodes`属性、URLでは`engine_nodes`で初期値を指定できます。調整の根拠は[CPU難易度の調整方針](docs/difficulty-calibration.md)にあります。
- **手の選び方**: Lv1〜39は、駒を取る・逃げる・受ける・攻めを用意する・駒組みを進める狙いを確かめて候補を選びます。Lv1〜10は盤の計算だけ、Lv11〜39は局面への気づきとエンジンの評価値を使い、気づかない・浅く読む・迷うことで強さを分けます。Lv0は自然さで選び、Lv40は従来どおり720,000nodes・2スレッドで読んだ最善手を選びます。Lv11〜39でエンジンが使えない場合は、Lv10のロジックへ戻ります。
- **おまかせの戦法**: 相手の作戦を「おまかせ」にすると、実戦での出現率に近い比率で戦法を選びます。
  - Lv0〜21（六級程度まで）: 将棋ウォーズの級位帯のように、振り飛車・棒銀・急戦・奇襲が多めです。
  - Lv22〜31（五級〜一級）、Lv32〜36（アマ初段〜五段）: レベルが上がるほど居飛車の本格的な戦型が増えます。
  - Lv37〜40: プロ公式戦のように、角換わり・相掛かり・矢倉が中心です。
- **比率の調整**: 比率は目安の概数です。`src/core/cpu-opening-repertoire.mjs`の`OPENING_DISTRIBUTION`で調整します。「居飛車」「振り飛車」「奇襲戦法」を選んだ場合も、その中で同じ比率を使います。
- **ランダムな組み合わせ**: 「おまかせ」では、その局面で成り立つ戦法と囲いをランダムに組み合わせることもあります。割合は低レベルでも2割までで、レベルが上がるほど減り、最高レベルでは使いません。
- **囲いの決め方**: 囲いを指定しない場合は、相手の指し手を見て決めます。
  - 相手が居飛車の形（飛車先の歩を突く、銀を4八・3七・4七へ上がるなど）なら、対居飛車の囲いを組みます。
  - 相手が飛車を振ったら、対振り飛車の囲いを組みます（CPUも振り飛車なら相振り飛車の囲い）。
  - 上のレベルほど、穴熊・銀冠・ミレニアムなど手数のかかる囲いを選びやすくなります。
  - 囲いの駒を動かし始めたら、途中で囲いは変えません。
- **角交換への対応**: 戦法を指定していない居飛車のCPUは、相手から角交換されると、角換わり腰掛け銀か角換わり4五桂速攻へ切り替えます。
- **CPUの作戦を選ぶ場所**: 対局準備のCPUの「作戦」の［変更］で、作戦カードのシートを開きます。「大まかに決める」（おまかせ・居飛車・振り飛車・奇襲戦法。細かい戦法は上の比率でCPUが選びます）か、作戦カードの1枚を選びます。カードには、CPUが指せる戦法と、CPUの手番の色で使える作戦だけを、解放とは関係なくすべて並べます。カードでは囲いも選べ、「囲いはCPUにまかせる」なら下のとおり相手の指し手を見て決めます。
- **CPUの序盤の傾向**: 対局準備の「序盤傾向」で指定できます。
  - 角道（開けたまま、開けてから閉じる、CPUから角交換、こちらからの角交換を待つ、閉じたまま）
  - 飛車の方針
  - 指し方

### 学習対局

- **開始局面**: 対局準備で「学習対局」を選ぶと、平手・駒落ち・戦法や囲いが完成した局面から選べます。
- **駒落ち**: 上手（駒を落とす側）を後手に置き、上手から指し始めます。
- **完成局面の作り方**: 選んだ作戦を、案内どおりに両者で指し進めて作ります。完成できない組み合わせでは開始できません。
- **定跡補助**: 平手以外の局面から始めた対局では、平手用の定跡補助は使いません。
- **駒の利き**: 対局中の「駒の利き」ボタンで、各マスに利いている先手（青）・後手（赤）の駒の数を表示します。学習対局だけでなく、通常対局（自由対局・終盤戦など）と竜王戦でも使えます。押すまでは出さず、付けたかどうかは次の対局にも引き継ぎます（ページを開き直すと消えた状態から）。補助なので、付けていてもレーティングと大会の結果は変わりません。
- **取られるマスと玉の逃げ道**: 将棋教室で利きメガネを手に入れていると、「駒の利き」を付けているとき、駒を選ぶと動かすと取られるマスに赤い輪が出ます。「駒の利き」を付けているときに自分の玉が王手されると、玉のまわりに逃げられるマス（緑）と相手の駒が利いているマス（赤い×）を出します。
- **駒得の数字**: 学習対局（教室から始めた対局を含む）では、駒を取ると取ったマスにその駒の値段を緑で「＋540」、取られると赤で「−495」などと浮かべます。値段は駒図鑑のAI用の表と同じで、成った駒は元の駒の値段で数えます。

### 定跡エディター

`npm run opening-editor`で開く「やこび姫 定跡編集」では、戦法・囲いの案内手順を画面上で編集できます。

- 囲いの完成形と、「ほぼ完成形」を編集できます。
- 盤上の条件（ANDとORの組み合わせ）と、応手による分岐を付けられます。
- 定跡をJSONで書き出せます。
- 下書きはそのブラウザの`localStorage`にだけ保存され、公開版には自動では反映されません。
- 公開版へ反映するには、`npm run import:opening-library`で`src/data/opening-guide-overrides.mjs`を生成してコミットします。

操作手順は[ローカル起動・定跡編集ガイド](docs/local-development.md)を参照してください。

### Firebase Hostingへ公開

Firebase CLIでログインしていれば、次のコマンドで`.firebaserc`に設定したプロジェクトへデプロイできます。

```sh
npm run deploy
```

GitHubからも公開できます。リポジトリのActionsの「Firebase Hostingへ公開」で「Run workflow」を押すと、mainなど選んだブランチを、テストと型チェックのあとに公開します（`.github/workflows/firebase-hosting.yml`）。自動では動きません。公開の鍵は、リポジトリのSecretsの`FIREBASE_SERVICE_ACCOUNT_SHOGI_64125`に、サービスアカウント（ロール「Firebase Hosting 管理者」と「API キー閲覧者」）のJSONを置きます。

- 公開用ファイルは`firebase-public/`に生成されます。このフォルダーと`.firebase/`は生成物なので、Gitには含めません。
- HTMLは毎回再検証します。JSとCSSは内容のハッシュ付きURLにして、長期キャッシュします。入口の`dist/shogi-match.js`とCSSは`?v=`で、`dist/chunks/`のファイルは名前で版を区別します。
- エンジンの版（`vendor/yaneuraou.js?v=…`）は、`vite.config.js`がビルドの時点で`vendor/`の内容のハッシュを埋め込みます。
- 画像・音声・WASM・評価データのキャッシュは`firebase.json`で設定しています。
