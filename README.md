# shogi-match

やこび姫と一緒に将棋を指して学べる、ブラウザ用の将棋対局ランタイムです。
単体のWebゲームとして遊べるほか、Webページ・RPG・ノベルゲームへ埋め込めます。
思考エンジンのやねうら王（WASM）を同梱しており、サーバー側の処理なしで動きます。

- 公開版: <https://shogi-64125.web.app>
- ライセンス: GPL-3.0-or-later（[ライセンス](#ライセンス)を参照）

## できること

### 遊ぶ

- **CPU対局**: やねうら王と対局します。強さはLv0〜49の50段階です（2026-10-22に段級位を作り直し、2026-10-23に下へ24級〜16級を足しました。`docs/level-ladder-design.md`）。Lv0は駒の動きを覚えたての練習相手（レーティングに数えません）、Lv1〜9は24級〜16級（ルールだけで指すロジックAI。タダの駒や取られる駒に気づく確率で強さを分けます）、Lv10〜24は15級〜1級（1級位に1つ）、Lv25〜44はアマ初段〜七段（初段〜六段は1つの段に3つ、七段は2つ。同じ名前の段は、LvとRで見分けます）、Lv45〜48は奨励会三段・若手プロ・トッププロ・タイトル保持者、Lv49は藤井聡太並みです。級は算用数字、段位は漢字で書きます。強さは、前の表で校正した強さのどこを使うか（`source`）で決め、自己対局で隣のLvの差がそろうように測って決めました（`docs/difficulty-calibration.md`）。Lv10〜48は、人間らしい選び方で指します（`docs/cpu-human-model-design.md`）。見えにくい当たり（遠くからの利き・打つ手）ほど見落とし、気づかなかった当たりの損は数えずに比べ（弱いLvほど形勢より駒の損得で考え、長い詰めろに気づきにくい）、見えたものの中で最善を尽くし、指す前に「大駒をただで取られる」「1手詰めを許す」などの台無しの手でないかを確かめます（低い級ではまれに見逃します）。大会の棋士の特徴（「終盤での頓死が多い」「受けが苦手」など）は、見落としやすさと確認の確かさのずれとして効きます。強さは前の選び方とそろえてあります。ロジックAI（`logic-ai.mjs`。ルールだけで指す）は、今の表では使いません。
- **学習対局**: 次の局面から始められます。
  - 駒落ち
  - 戦法や囲いが完成した局面
- **学習対局の補助**: 閃き（ヒント）と待ったの回数を選べます（無制限も可）。各マスに利いている駒の数を表示する「駒の利き」も使えます。メニューの「選んだ駒の動きを矢印で表示」をONにすると、選んだ駒が動ける方向を青い矢印で表示します（遠くまで動ける駒は方向ごとに1本）。
- **2人対局**: 1台の端末で、先手と後手を交互に指します（`mode=local`）。
- **やこび姫の将棋問題集**: ホーム画面の「まなぶ」から開きます。「練習問題」「詰将棋」「詰将棋図巧」「あなたの対局」の4つに分かれています。詰ませる問題と、王手から逃げる問題を、やこび姫が出題・解説します。正解は問題に書かず、合法手をすべて詰み探索で調べて決めます（逃げる問題は、逃げたあと相手に3手以内の詰みがない手が正解）。自分の手が2回以上ある問題では、正解のたびに相手が応じ、続きの手も盤で指して答えます。逃げる問題は、正解のあとも、まちがえた逃げ方なら詰んでいた王手を相手が指し、もう一度逃げて詰まない理由を確かめます。間違えると、逃げられ方や詰まされ方を盤に並べて説明します。並べ終えると、ボタンを押さなくても元の局面に戻り、続けて指し直せます（「もう一度」で待たずに戻すこともできます）。解いた記録は端末に保存します。一発で解けなかった問題（まちがえた・ヒントを見た・答えを見た）は「復習の箱」に入り、1日後に問題集の一覧の上へ「やこび姫からの1問」として1問だけ出ます。出し直した問題を一発で解くと、次は3日後、その次は7日後に出し、7日後も一発で解けたら箱から出します。一発で解けなかったら1日後からやり直します。解かなくても先へ進めます。対局で見逃した詰み（棋譜解析の振り返りと、自由対局・竜王戦の対局のあとの裏の解析で見つけたもの）は「あなたの対局から（◯手詰め）」という詰ませる問題になり、問題集の「あなたの対局」に新しい順に並びます（対局の日付と、解いたかどうかを添えます）。同じ問題は復習の箱からも日をあけて出ます。解析の読み筋が詰みまで確かめられた詰みは15手詰めまで問題にし、その手順を答えにします。読み筋と違う王手でも、詰み探索で残りの手数で詰むと分かれば正解にして、相手の応手も探索で決めて続けます（別の詰み方を不正解にしません）。読み筋のない詰みは、3手詰めまでを、答えを書かない詰み探索だけで判定します。後手で詰ませる問題は、盤を反転して詰ませる側を手前にします。覚えておくのは新しい40問までです。「つぎはこれ」の弱点の練習で数える「詰みを逃した」は、7手詰めまでです。箱は`localStorage`（キー`yacobihime:shogi-match:review-queue:v1`、対局からの問題は`yacobihime:shogi-match:review-problems:v1`）に保存します。
  - **練習問題**: やこび姫の台詞付きの10問です。以下の判定のしかたは練習問題のものです。
  - **詰将棋**: まず「詰将棋」と「実戦詰将棋」のどちらかを選び、次に「1手詰め」「3手詰め」「5手詰め」「7手詰め」のボタンで手数を選びます。どちらも手数ごとに30問です。「ランダム出題」を押すと、選んだ種類の問題から手数も問わずに出題し、「次の問題」でも続けてランダムに出します（まだ解いていない問題を優先）。データの手順で判定し、最後の手は詰ませる手ならどれでも正解にします。
    - **詰将棋**: 駒の少ない問題です。やねうら王の実戦の詰み局面を元に機械で作られた詰将棋から、余詰めのない問題を選びました。出典: Shinta Nakayama「[Generated Tsume-Shogi](https://huggingface.co/datasets/tokoroten-jp/generated-tsume-shogi)」（CC BY 4.0）。
    - **実戦詰将棋**: 両方の玉と多くの駒が盤にある、対局に出た局面です。やねうら王の「[詰将棋500万問](https://yaneuraou.yaneu.com/2020/12/25/christmas-present/)」（やねうら王どうしの対局の局面。著作権の主張なし）を先手番にそろえて解き、攻め方の正解が各手で1つだけの問題を選びました。1手詰めは、3手詰めの局面を2手進めたものです。
  - **詰将棋図巧**: 伊藤看寿『将棋図巧』（1755年）の全100問を、原典の番号順（第1番〜第100番）に並べています。通称のある作品（第6番『朝霧』、第94番『襷詰』、第98番『裸玉』、第99番『煙詰』、第100番『寿』）は名前も表示します。作者の手順に沿って1手ずつ解き、相手は手順どおりに応じます。データは[Open Tsume](https://github.com/tokoroten/edo_era_tsume_shogi)（原典はパブリックドメイン、データはCC0 1.0）で、作者の手順と違う手でも詰む場合があります。
  - 詰将棋と図巧では、手順を1手ずつ盤に並べる「答えを見る」が使えます。
  - 解き終えたら（逃げる問題は続きの確かめまで指し終えたら）「次の問題」へ進めます。解き終えた局面からは、先手も後手も自由に駒を動かして確かめられます（1手戻す・全部戻すあり）。
- **やこび姫の助言**: 戦法と囲いの手順を盤上の矢印で案内します。好手を褒め、悪手や詰めろを知らせます。
  - **悪手の理由と相手の狙い**: 「詳しい助言」では、悪手を指したときに、悪手判定の読みの相手のいちばんの応手から理由を1つ添えます（「あちゃ～、やっちゃった…今動かした銀が、△5五歩で取られちゃう。（評価値変動-600）」）。CPUが指したあとは、手番を入れ替えた局面の読み（詰めろの確かめ）で、相手が次に銀以上の駒を取る・飛車や角が成り込む狙いがあり、2手続けて指されると300点以上悪くなるときに、「相手の狙いは△2八角成だよ。飛車が取られそう！」と言います（取り返せる交換は「〜からの攻めだよ」。1500点以上勝っているときと、3000点以上負けているときは言いません）。新しい探索は足しません。
  - **形勢に合わせた方針と手筋のほめ言葉**: 「詳しい助言」の形勢の一言は、中盤（±300点）・終盤（±500点）で駒の損得が歩3枚とすこし（300点）より大きいとき、「駒得してるね！ 駒を交換して、局面を単純にしていこう！」「駒損してるね…。駒の交換は避けて、局面を複雑にして粘ろう！」のように、次にすることを言います。好手は、コレクションと同じ手筋の見分けで「ふんどしの桂！ 桂の両取りだね！」のように手筋の名前でほめます（両取り・王手の形はいつも、叩きの歩などは好手か駒得のときだけ）。
  - **中身で言う助言・見逃し・相手のミス・弱点の記憶**（`docs/coach-advice-expansion-design.md`の段階1）: 「詳しい助言」では、最善手が2番目の手より300点以上良いとき、答えの手は言わずに最善手の種類（「タダで取れる駒があるよ！ 探してみて」「持ち駒の桂が光る場面だよ！」「『ふんどしの桂』の両取りがありそう！」「守りの一手が大事な場面だよ」など）を言います（8手に1回まで）。考えているあいだの一言も同じ種類で言います。指す前にあった詰みやタダの駒（銀以上）を指した手で逃したときは「いま、5手詰めがあったよ！」「△3三の銀がタダで取れたよ」と知らせます。CPUが読みの最善より300点以上悪い手を指したら「チャンス！ 相手の駒が浮いたよ」と知らせます（応援のみでも。1局3回まで）。前の対局の弱点（詰みの見逃し・終盤の逆転負け・タダ取られ・序盤の不利）があれば、ふつうの対局と大会の始めに一言言い（同じ弱点は3局のあいだ繰り返さない。`localStorage`のキー`yacobihime:shogi-match:coach-weakness:v1`）、乗り越えて勝ったら終局の画面で「前は逃してた詰み、今日は見つけたね！」とほめます。閃きを使わずに詰ませたら「自分の力で7手の詰みを読みきったね！」、AIと同じ手が3手・5手・10手続いたら「冴えてる！」、相手の狙いを受けた・チャンスを生かしたときもほめます。新しい探索は足しません。
  - **盤で指す・終盤の方針**（同じ文書の段階2・10章）: 閃きは、1回押せばすぐ矢印と答えが出ます（いったん3段階にしましたが、2026-10-29に元に戻しました。10-3。前に保存した`yacobihime:shogi-match:hint-style:v1`は読みません）。「詳しい助言」では、相手の狙いを言ったときに、その手を盤に点線の矢印（先手の狙いは青、後手の狙いは赤）で出し、悪手で取られる駒の升に赤い輪を次に指すまで出します。表示補助の「危機センサー」を付けると、相手が指した直後に、その手で取られて損をする形になった自分の駒（歩を除く）に赤い輪を出し、やこび姫が「銀が角に狙われてるよ！」と知らせます（取り合いの計算だけで決めるので、エンジンの読みを待たずにすぐ出ます。逃げ方は言いません。前の局面から当たっていた駒はくり返しません）。決めていなければ、学習対局と7級（Lv18）までの相手との対局で自動で付き、押して決めた付け外しは端末（`yacobihime:shogi-match:danger-sensor:v1`）に覚えます（`docs/coach-advice-expansion-design.md`の12章）。終盤（61手目から、または玉のまわりに相手の利きが集まったとき）は、自玉が詰めろなら「まずは受けよう！」「王手で迫りながら、しのごう！」、詰めろでなければ「相手玉に詰めろをかけて、攻め合いで勝とう！」「一手かけて守ろう」と方針を言います（相手玉に詰めろをかけるかを確かめる読みを1回だけ足します）。
  - **格言・大会の物語・もう一言**（段階3・11章）: 「詳しい助言」では、AIの最善手が格言に沿うときに「居玉は避けよ」「玉飛接近すべからず」「桂の高跳び歩の餌食」を1局に1回ずつ言い、図鑑にある格言は教室の格言帳に入れます。大会の1局では、相手の特徴（逆転の名手・終盤が苦手）、「勝てば○○」、カド番・最終局、羽音との逆転に触れる一言を出します（応援のみでも）。理由のある助言には吹き出しの右に「なぜ？」が付き、押すと理由を1行足します。最善手の種類の一言（「持ち駒の銀が光る場面だよ！」など）では、その手で何ができるか（「割り打ちの銀を打てるよ！ 飛車と金の両取りだよ」「△5五の銀は、取っても取り返されないよ！」など）を言います。やこび姫の顔を押すと、この対局のさっきの話（直近3つ）を見られます。
  - **大会の相手の棋風**: 竜王戦・名人戦の1局の始めに（大一番の開幕の一言がない局）、相手の特殊能力と棋風から「中村さんは、終盤で頓死することがある相手だよ。苦しくても終盤まで粘れば、チャンスが来るよ！」のように戦い方を1行言います。設計は`docs/coach-plan-advice-design.md`の11章です。
  - **作戦の助言**: 「詳しい助言」の対局（平手から始めたCPU対局）で、AIの最善手が飛車を振る手で、振らない一番の手より80点以上良いとき、やこび姫が「飛車を4筋に振って、右四間飛車にしたら？ 相手の金矢倉と相性がいい形だよ！」のように作戦の名前で提案します（袖飛車・右四間飛車・中飛車・四間飛車・三間飛車・向かい飛車。振った飛車をもう一度動かす手は「振り直し」として、中盤でも80手目まで促します）。提案の前に、その2手だけを深く読み直して差が60点以上残ることを確かめ、やこび姫補助の欄の札に「AIの読み」として2手の評価値を並べます。札の「◯◯にする」で作戦カードにその戦法を入れ、矢印と薄い駒で案内します（まだ使えない段の戦法でも、押せば次の対局からも使えます。`localStorage`のキー`yacobihime:shogi-match:coach-plans:v1`）。同じ作戦の提案は1局に1回、作戦の助言は1局に2回までです。提案のあとにその作戦へ飛車を振ると、次の手番でほめます。設計は`docs/coach-plan-advice-design.md`、1局に何回出るかは`node scripts/coach-plan-advice-report.mjs`で測ります。
- **作戦カード（やこび姫補助）**: 目指す戦法と囲いは、完成形の小さな盤が描かれた「作戦カード」で選びます。対局準備の「あなたの作戦」（既定は「なし」）の［変更］か、対局中のやこび姫補助の欄（見出しは「定跡の案内」）から開きます。カードは「居飛車で攻める」「振り飛車で受ける」「びっくり作戦」「囲いだけを組む」に分かれ、一言・攻めか受けか・難しさ（★）・対局で完成させた回数が付きます。押すとくわしい画面で得意なこと・コツ・気をつけることを読み、合う囲い（◎いちばん合う・○合う）を選べます。くわしい画面の［手順を見る］では、自分が指す手（後手なら盤を反転した「△３四歩」のような手）を、同じ小さな盤で1手ずつ動かして見られます（◀▶で1手ずつ戻る・進む）。シートのいちばん上には「やこび姫のおすすめ」の1枚を出し、押すとそのくわしい画面へ進みます（決めるのは［この作戦にする］）。おすすめは乱数を使わずに決め、囲いだけのカードとびっくり作戦を除いて、相手が振り飛車と分かっていれば居飛車の作戦から、まだ完成させたことのない作戦、やさしい作戦、目録の順で選びます。対局準備の行の［おすすめ］は、おすすめのくわしい画面を開きます。最初に使えるのは入門の3枚（棒銀・四間飛車・中飛車）で、入門の作戦を対局で1回完成させると基本の作戦（教室の第4巻でその戦法を練習しても、その戦法だけ）、基本の作戦を2種類完成させると応用の作戦と囲いだけのカード、竜王戦に出るとびっくり作戦が使えるようになります。まだ使えない作戦は、形の影と条件だけを見せます。はじめての案内で「ふだん指している」を選んだ人と、レーティングが初段相当以上の人は最初から全部使え、シートの「ぜんぶの作戦を使う」でも全部開けます（`localStorage`のキー`yacobihime:shogi-match:opening-plans-all:v1`）。解放は新しく保存せず、コレクション・教室の進み具合・竜王戦の成績から毎回計算します。新しく使えるようになったカードには「NEW」を付け（見たカードはキー`yacobihime:shogi-match:opening-plans-seen:v1`に保存）、対局で増えたときは終局画面でも知らせます。対局中の欄は、作戦を選ぶ前は「戦法・囲いを選ぶ」の1行のボタンで、選んだあとは「戦法 ◯◯」「囲い ◯◯」を1行ずつと、［作戦を変える］を出します。対局中のシートには、今の局面から完成形まで届く作戦だけを、カードごとに「あと◯手」を付けて並べます。作戦を選べるのは30手目までで、組める作戦がないときや30手目を過ぎたときは、作戦を選んでいなければ欄ごと消します（選んだ作戦は、組んでいるあいだは出し続けます）。選んだ作戦の完成形のうち、まだ駒が来ていない空きマスに駒を薄く描き、欄に「完成まで、あと◯マス」を出します。薄い駒は、強くなる道の5段目より前の人と学習対局で既定で出し、欄の「完成形を盤に出す」で切り替えられます（キー`yacobihime:shogi-match:plan-ghosts:v1`）。作戦が続けられなくなったら「作戦を変えよう」の札で、今の局面から近い作戦を残り手数つきで並べます。
- **戦法占い**: 作戦カードのシートの「迷ったら占う」か、定跡図鑑の「迷ったら、やこび姫に占ってもらう」から開きます。3つの質問に答えると、上から下へ分かれる道をたどって、原始棒銀・早繰り銀・腰掛け銀・矢倉・四間飛車・三間飛車・中飛車・向かい飛車のどれかを「君は◯◯タイプ！」と占います。答えるたびに道が伸び、「ひとつ前の質問へ」で戻れます。出た作戦は、まだ使えない段でもその場で使えるようになります（`localStorage`のキー`yacobihime:shogi-match:opening-fortune:v1`）。結果から、その作戦で指す（作戦カードのシートではその作戦を選び、定跡図鑑からは通常対局の対局準備の「あなたの作戦」に入れる）・完成形から指してみる（学習対局）・図鑑で手順を見る、を選べます（後の2つは定跡図鑑から開いたときだけ）。
- **ルール**: 詰み、千日手、連続王手の千日手、打ち歩詰め、入玉宣言に対応しています。

- **分身を出場させる・回戦の中継ボード・回戦ごとの観戦**: 竜王戦の入口の「出場する」の上の「分身を出場させる」で出ると、あなたの対局から出した能力（やこびノートの「能力」と同じ）を持つ「分身」があなたの席で指し、あなたは観戦します（設計は`docs/tournament-relay-design.md`の17章・18章）。観戦の対局の投了は棋士ごとに違い（潔い：9手詰め以内で投げる、ふつう：5手詰めあたりまで指す、粘る：3手詰めまで粘る、最後まで指す：詰みまで指す。名簿では25%・45%・20%・10%。劣勢でも崩れない・逆転の名手の特徴があると粘る側へ寄り、善彦は潔い、羽音は粘る、分身はふつう）、名鑑のくわしい情報に「投了」の行を出し、中継の終局で解説者と視聴者が投げ方に反応します（29章）。分身は、あなたが対局で組んだ戦法・囲いの回数（コレクション）から得意戦法（名鑑の棋士と同じ使用率。組んだ戦法が合わせて3回以上で持つ）と棋風（能力の攻めと受けの差に、よく指す戦法の攻めっ気を足す）を持ち、1局ずつ使用率で戦法を選んで、序盤は定跡で指します。やこびノートの「能力」にも、あなたの得意戦法の使用率を出します（28章）。画面・組・昇級降級・竜王・称号・賞状・表彰式は、ふつうの竜王戦と同じです。違うのは次の一局の枠だけで、「対局する」の代わりに「観戦する」と「結果だけ見る」が出ます。「観戦する」（VS画面のあと）でトーナメント表に移り、分身の対局と同じ回戦のほかの対局が同時に進みます（回戦の中継ボード）。札には何手目・形勢のバー・視聴者数が出て、押すとその局の中継をいまの手数から開きます。欄の「注目の対局」には、羽音・善彦・推しの対局が1行ずつ出て、押すとその中継へ行けます。羽音や推しが別の組にいても、組のランキング戦・敗者復活戦のあいだは、同じ時に指されているその組の対局がボードに入ります（31章。ほかの組は組ごとに決まった種で決めるので、先に見た結果と、あとで決まる結果は同じです）。分身の対局と同じ回戦のほかの対局は、エンジンが本当に指して勝ち負けを決めます（分身はあなたの棋力のLv、相手はあなたが当たるときと同じLvと棋風。棋士どうしの対局は、レーティングの差に合わせたLvで指し、分身・羽音・善彦のいない対局は読む量を減らします。設計は20章）。札は指した手まで進み、中継はその手をそのまま見せます。スマホ（画面の短い辺が600px未満）と「結果だけ見る」では、分身・羽音・善彦の対局だけをエンジンで指し、ほかの対局は自動対局の結果で進みます。途中で離れると、指した手は`localStorage`の`yacobihime:shogi-match:engine-game:v1`に残り、次は続きから指します。同じ回戦のほかの結果は、ボードで終局するまで伏せます。全局が終わると「この回戦の結果へ」で竜王への道を登ります。分身の対局は、レーティングと対局の記録には数えず、やこびノートの「能力」の値にも入れません。分身で出る期に選んだ難易度はその期だけのもので、いつもの難易度（自分で出るときの初期値で、能力の値の物差し）は変えません（40章）。期の結果の「このあとの対局を観戦」からは、敗退後の回戦を同じトーナメント表の上で1回戦ずつ見られます（19章。まだ見ていない回戦の結果は伏せ、最後に竜王の発表。見届けた回戦の数は`localStorage`の`yacobihime:shogi-match:ryuo-watch:v1`）。この観戦の対局もエンジンが本当に指し、見終えた回戦の勝者で、その先の回戦と竜王が決まり直します（20-10。あなたの昇級・降級・賞状は敗退した時点で決まり、変わりません）。期の残りの対局は、竜王の発表まで見たとき・結果の画面を見終えたとき・次の期を始めるときに確定し、そこで棋士の名簿が1期進みます。敗退した時点の期の形は、確定するまで竜王戦の期の保存（`rest`）に残ります。
- **中継の楽しみ（予想・次の一手・見どころ・大盤・研究ノート）**: 回戦の中継ボード（竜王戦・名人戦、分身の回戦と敗退後の観戦のどれでも）の「勝敗を予想」で、対局が30手目より前のうちに勝つと思うほうを選べます。終局すると当たり外れが出て、欄に「予想 2/3 的中（通算 5/9）」を出します（`localStorage`の`yacobihime:shogi-match:relay-predict:v1`）。中継の画面の操作の下の行には、「次の一手」（再生を止めて、次に指される手を3つの候補から当てる。指されたら答え合わせ、当たると視聴者のコメントが沸く。正解の数は`yacobihime:shogi-match:relay-quiz:v1`）、「見どころ」（形勢が大きく動いた手・長考・勝負を分けた手・詰みの決め手・終局を、最大8か所続けて見る。まだ指している対局は見たところまで）、「大盤」（解説者がいまの局面からAIの読み筋の手を最大4手、盤の上で進めて見せ、元の局面へ戻る）、「☆ノート」（いまの局面を研究ノートに残す。30局面まで、`yacobihime:shogi-match:relay-notes:v1`）があります。札は盤に重ねず、欄の上に出します。研究ノートは、やこびノートの「大会」の「研究ノート」から、局面の盤を見る・中継のその手から開き直す（棋譜が中継の保存に残っているとき）・消すができます（設計は`docs/tournament-relay-design.md`の24章）。
- **対局後の回戦の中継ボード**: 竜王戦・名人戦（順位戦）を自分で指す期でも、対局を終えて大会の画面に戻ると、分身で出たときと同じ回戦の中継ボードが開きます。自分の対局は終局した札（押すと自分の対局の中継）、対局中の速報で結果を伝えた対局も終局した札で、ほかの対局はエンジンが本当に指します（スマホは羽音・善彦の対局だけ）。注目の対局・勝敗の予想・ほかの組の注目の対局も同じです。見終えると、その結果で回戦を決め直し、竜王戦は竜王への道を登ります（次の相手は回戦の結果から）。戻る操作で閉じると、その時点で終わった対局の結果だけを使います。期が終わる対局（優勝・敗退）と順位戦の最終回戦では開きません（設計は`docs/tournament-relay-design.md`の35章）。

- **駒の損得**: 対局中と振り返りの操作列（閃き・待った・駒の利きの並び）の「駒の損得」を押すと、状態表示に自分から見た駒の損得の札（「駒得 ＋315」は緑、「駒損 −180」は赤、「駒の損得 ±0」）を出し、駒を取ったマスに「＋540」「−495」を浮かべます（学習対局では、押さなくても数字を浮かべます）。駒の値段は駒図鑑の「将棋AI（やねうら王）が使う駒の価値」（歩90・香315・桂405・銀495・金540・角855・飛990、と金・成香・成桂・成銀540・馬945・竜1395）です。取ったマスの数字は持ち駒になる元の駒の値段で、成りの分（成った駒と元の駒の差。馬なら90、と金なら450）は「成り＋90」「成り−90」として、小さく別に浮かべます（成ったとき・成駒を取ったとき・取られたとき）。札の点数は、浮かべた数字を足したものと同じで、取った駒の差と成りの分の差です（歩を1枚取ると＋90、角が成ると＋90、角と馬の交換は馬を取られた側が−90。駒落ちは、開始局面でない駒の差から数えます）。将棋教室の駒得の数字と合計も、教室の点数（角8→馬10なら「成り＋2」、と金を取られたら「−1」と「成り−6」）で同じように数えます。二人で指すときは先手から見ます。振り返りでは見ている局面の損得です。付け外しは`localStorage`（キー`yacobihime:shogi-match:material-guide:v1`）に覚えます。
- **プレイヤー名**: ホーム画面の記録の帯（やこびノート）の左のボタンから、プレイヤー名を入れられます（10文字まで。入れていないときは「名前を入れる」）。CPUとの対局のプレイヤー側の盤の名札、対局準備の自分の側、竜王戦のトーナメント表とVS画面に出ます（入れていなければ、盤の名札は先手・後手の表示名、ほかは「あなた」）。進めている竜王戦の期があるときに変えると、その期の表の名前も替わります。空にして決めると「あなた」に戻ります。`localStorage`（キー`yacobihime:shogi-match:player-name:v1`）に保存します。
- **はじめての案内**: ホーム画面がある表示（`show-home`）で、この端末にアプリの記録が何もないときだけ、最初にやこび姫が将棋をどのくらい知っているかを聞きます。札は易しい順に4つです（`docs/first-play-design.md`）。「はじめて」は将棋教室の第1巻、「ルールは分かる」は将棋教室で始める場所を決める1問（下の教室の項目）、「少し指せる」と「よく指している」は棋力測定へ案内します（最初の相手は、続けて出す「どのくらい指せる？」の札で選びます）。案内から測った棋力も、ほかの測定と同じく、測れたらそのままレーティングにし、結果の画面の主ボタン「竜王戦に出る」から竜王戦の入口へ進めます（測りきれなくても竜王戦へは進めます）。強くなる道は、「ルールは分かる」「少し指せる」「よく指している」で駒を覚える段を終え、「少し指せる」「よく指している」は測ったら初めての対局の段、「よく指している」は詰みの段も終えたことにします。「自分で選ぶ」やブラウザの戻る操作で閉じられます。一度閉じると、`localStorage`（キー`yacobihime:shogi-match:welcome:v1`）に記録し、二度と出しません。
- **自動保存**: 対局中と終局後の状態を自動で保存します。リロードしても続きから再開できます。
- **対局の中断**: ホーム画面がある表示（`show-home`）では、対局中に「中断」（狭い画面ではメニューの「対局を中断する」）で、対局を保存してホームへ戻れます。ホームの「つぎはこれ」に出る「対局を再開」から、保存した局面と設定のまま続けられます。竜王戦の対局を中断したときは、竜王戦の画面の次の一局の枠でも「対局する」が「対局を再開」（何手目まで指したかを添える）に替わり、そこから続けられます（VS画面は出さずに盤へ戻ります）。リロードしても中断した対局は残り、再開するまで自動では開きません。中断した対局があるときに新しい対局（教室の対局・棋力測定を含む）を始めると、確認のうえで中断した対局は消えます。中断は結果に数えず、レーティングも動きません。
- **レーティング**: 平手でCPUと指した自由対局と大会（竜王戦・名人戦・研修会・奨励会）の結果から、プレイヤーのレーティングをElo式で計算して端末の`localStorage`（キー`yacobihime:shogi-match:player-rating`）に記録します。初期値はR30（24級）、最初の10局はK=40、以降はK=20です。CPUのレベルには、Lv1（24級）をR30、1LvあたりR60のレーティングを割り当てます（15級がR570、5級がR1170、1級がR1410、Lv49がR2910）。学習対局・駒落ち・教室の対局・ローカル対局と、Lv0（練習相手）との対局は数えません。段級位を作り直す前に保存した記録（レーティング・Lvごとの成績・申告・コレクションの勝ったLv・大会の期の途中の棋士のLv）は、同じ強さの新しいLvへ1回だけ移し（保存に`ladder: 2`を付けます）、対局したことのある人には、ホームで「段級位の物差しを作り直したよ」と前後の段級位とレーティングを1回だけ知らせます。移すと印の数が減る場合も、それまでに解放した着せ替えは残します。大会の対局は、相手の棋士のLvで計算し、千日手は数えません。終局時の手番と、戦型・戦法・囲い（自分と相手）も、手番別・戦型別の成績として同じキーに記録します。棋戦ごとの成績（`events`）と、直近30局の記録（`history`。棋戦・相手・竜王戦の段階を含む）も残します。棋戦を記録する前に保存した対局は、自由対局として読みます。終局画面に変動を表示し、対局準備では「おすすめの強さ」（勝ち越せそうな相手。下の見立て）を案内し、強さの選択シートでは各LvにそのLvのレーティングと、これまでの勝敗・引き分け数を添えます。

### 学ぶ

- **やこび姫の将棋教室**: 「じっくり基礎」（5巻13章・68レッスン）と「すぐ使えるコツ」（12枚）の2つのコースがあります。地図の上のタブで切り替えます。
  - じっくり基礎のうち、使い道の分かりにくい6つ（駒を並べよう・2つの観戦の章・両王手・評価値）は「寄り道」です。地図では小さな点線のマスに「寄り道」の札が付き、遊ばなくても次のレッスンが開き、巻の称号ももらえます。めあては「対局で何ができるか」の形で書いています。
  - **すぐ使えるコツ**: 明日の対局でそのまま使える将棋の常識を、1枚1〜2分のカードで覚えます。どのカードからでも遊べます。序盤（飛車先の歩の交換・戦う前に囲う・相手が居飛車なら7七銀と7八金・相手が振り飛車ならエルモ囲い・自分が振り飛車なら四間飛車と美濃囲い）、中盤（味方の利きがあるマスへ進む・タダの駒を取る・桂と金の両取り）、終盤（頭金・玉は下段に落とせ・垂れ歩でと金・駒を捨てても先に詰ます）。じっくり基礎の解放・巻の称号・ホームの強くなる道には数えません。教室を初めて開いたときの問いの「すぐ使えるコツだけ見る」からも始められます。
  - **対局でコツどおり**: クリアしたコツを対CPUの対局（棋力測定・検討・教室の対局は除く）で自分の手で使うと数えます。12枚すべてが対象で、序盤の形（飛車先の歩の交換・囲ってから戦う・7七銀と7八金・振り飛車にエルモ囲い・四間飛車と美濃囲い）、中盤の手（味方の利きの上へ進む・タダの駒を取る・両取り・垂れ歩でと金）、詰ませた手（頭金・下段に落とす・駒を捨てて詰ます）です。盤の上の「教室のコツ」の札は、そのコツを使った3回目までだけ出ます（同じコツは1局に1回。対局の始めからできている形には出ません。詰ませた手のコツは札を出しません）。1局で使えたコツは、結果の窓に「教室のコツ」の行でまとめて出ます。使った回数はコツの地図のカードとやこびノートのコレクションの「コツ」のページに「対局で×N」と残り（保存は`tip-uses:v1`）、12枚そろうと地図の看板に判子が押されます。駒の動きを覚えてコツにまだ触れていない人には、ホームの「つぎはこれ」の下に「すぐ使えるコツ（1枚1分）」の小さな入口が出ます。
  - 範囲は、駒の動かし方から戦法・格言・形勢判断までです。説明を聞くより、盤で手を動かす課題が中心です（課題は全ステップの約6割）。
  - 駒のレッスンには「駒取りゲーム」があります。その駒だけを動かして、相手の駒を全部取ります。最短の手数を目標として見せ、最短で取りきると「最短！」、手数がかかってもクリアです（★の計算でまちがい1回に数えます）。
  - 両取りなどの手筋の課題では、手筋をかけたあと、相手の受けを見ながら駒得するまで指します。相手は、損得がいちばん小さくなる受けを読んで指します（両取りなら高いほうの駒を逃がす、守れるなら守る）。取らない手や安い駒を取る手はまちがいに数え、最後に「合計＋6の駒得！」のように合計を伝えます。
  - 第5巻の「序盤・中盤・終盤の作戦」の章では、序盤は定跡で相手に合う形を組むこと（角換わりの角打ちの隙を消す課題つき）、中盤は手筋で駒得や成りをねらい、手筋の形に相手をさそうこと、することがないときは端歩などで待つこと、終盤は囲いを崩し、詰めろをかけ、自玉の詰めろを受け、自玉が詰めろでも連続王手で先に詰ませれば勝てることを、盤の課題で教えます。
  - 「1手詰めドリル」「3手詰めドリル」「王手から逃げよう」などでは、将棋問題集の練習問題と詰将棋を、問題集と同じ判定で解きます。解いた問題は問題集の記録にも付きます。
  - 章の最後に「腕だめし」があります（観戦だけの章を除く11章）。その章の課題に、前の章の課題を混ぜて出します。腕だめしの★で、章のメダル（★3で金・★2で銀・★1で銅）が決まり、地図の章の看板と章クリアの画面に出ます。
  - 巻のレッスンを全部終え、その巻の腕だめしをすべてクリアすると、称号「将棋教室 第N巻 修了」（第5巻は「将棋教室 卒業」）がもらえます。やこびノートの称号に残ります。
  - 正解すると、盤の上に「正解」「詰み！」「最短！」の印を押し、何が良かったかを一言でほめます。まちがえずに続けて解くと「2れんぞく！」と知らせます。レッスン中は、見出しの帯に「めあて」（このレッスンでできるようになること）を出します。
  - 成績は★1〜3で記録します。レッスンは順番に解放され、スキップもできます（レッスン中は見出しの右端の「スキップ」、章ごとなら地図の章の看板の「この章をとばす」）。
  - 腕だめしで飛び級できます。まだ届いていない章の腕だめしにも鍵がかからず、まちがいとヒントが合わせて2回まで（★2以上）で合格すると、その章の終えていないレッスンを「修了」に、それより前の遊んでいないレッスンを「とばした」にして、次の章へ進めます。★が足りなければ★だけを記録して地図へ戻ります。「修了」は教室の記録（`yacobihime:shogi-match:tutorial:v1`）に`tested: true`として残し、遊び直してクリアすれば★に変わります。
  - 教室を開くと、全レッスンを学ぶ順に1本の道に並べた地図が出ます（巻の看板・章の看板・レッスンのマス）。いま進めるマスに「ここから！」を付け、そこまで自動でスクロールします。マスを押すとすぐレッスンが始まります。マスの文字はレッスンの種類（駒のレッスンはその駒、詰・指・問・局・観など）です。
  - 同じ章のレッスンは、結果の画面を挟まずに続けて進みます。レッスンを終えると盤の上に「クリア！」と星を短く出し、約1.7秒で次のレッスンが始まります（押せば待たずに進み、「地図へ」で戻れます）。章の最後のレッスンを終えると「章クリア」の画面で、章の星と、レッスンごとの「できるようになったこと」を札にしてまとめて見せ、「次の章へ」にフォーカスを置きます。札を押すと、そのレッスンをもう一度遊べます。レッスン中は、見出しの下の帯に、章のレッスンの区切りと、いまのレッスンの進み具合を出します。
  - 説明は画面のどこを押しても進みます（盤を押しても進みます。Enter・スペース・→キーでも進みます）。盤で指す課題と選択問題は、正解すると自動で次へ進みます（選択問題は解説を読む時間をとってから。画面を押せば待たずに進めます）。まちがえた選択肢は押せなくなり、残りから選べます。
  - 盤の課題で10秒操作がないと、ヒントがそっと出ます。このヒントは★の数に数えません。ヒントは1段目で「見方」（正解の一手を探す課題は駒の利き、詰ませる課題は玉の逃げ道）、2段目で答えの矢印を出します。
  - **駒得の数字**: 教室の盤で駒を取ると、取ったマスにその駒の値段を緑で「＋6」のように浮かべ、取られると赤で「−5」を浮かべます。値段は駒図鑑の「駒の価値 tier表」と同じで（歩1・香3・桂4・銀5・金6・角8・飛10）、成った駒を取ったときは、持ち駒になる元の駒の値段で数えます（と金を取ったら＋1）。課題の中で駒の取り合いが起きると、吹き出しの上の札に「駒得 ＋1」「駒損 −4」「とりかえ ±0」と合計を出します。観戦では、先手から見た合計（「▲先手 駒得 ＋3」）を出します。
  - **利きメガネ**: 第2巻の「利きを見よう」を終える（スキップでもよい）と手に入る道具です。見出しの「利き」ボタンでかけると、どのレッスンでも、各マスに利いている駒の数（先手は青、後手は赤）と、駒を選んだときに動かすと取られるマス（赤い輪）が見えます。かけても★は減りません。かけているかどうかは`localStorage`（キー`yacobihime:shogi-match:tutorial-kiki-glasses:v1`）に保存します。レッスンによっては、メガネがなくても利きや取られるマスを出します。取られるマスへ動かしてまちがえると、相手が取り返す手を見せてから局面を戻します。
  - **玉の逃げ道**: 詰ませたときと、王手を受けるレッスンでは、玉のまわり8マスに印を付けます。逃げられるマスは緑、相手の駒が利いているマスは×（先手の利きは青、後手の利きは赤）です。
  - **にがてをもう1回**: レッスンでまちがえた課題（まちがい・ヒントがあった盤の課題と選択問題）を、レッスンごとに記録します。章クリアの画面と地図の章の看板に「にがてをもう1回（N問）」を出し、その章の苦手だけを解き直せます。まちがえずに解いた課題は苦手から消え、★は付けません。レッスンをもう一度最後まで遊ぶと、その回の結果で置き換えます。記録は`localStorage`（キー`yacobihime:shogi-match:tutorial-weak:v1`）に保存します。
  - **駒を並べよう**: 第1巻の「駒を並べよう」では、玉と歩を置いた盤に、持ち駒の飛車・角・金銀・桂香を薄く見せたマスへ打って、最初の並べ方を作ります。違うマスに打とうとすると、置く場所を一言で伝えます。
  - 第4巻の定跡の練習では、形ができたあとに先手の利き（青い数字）を見せ、最後に作戦カードと同じ小さな盤で手順を1手ずつおさらいします。
  - **盤の上のひとこと**: 見るマスのそばに、しっぽ付きの短い札（14字まで）を1つだけ出します（「ねらう駒」「ここまで」「逃げ道 2」「動けるマス」など）。札はステップのデータから自動で作り、印のマスと駒をなるべく避けて置きます。正解したときは動かした駒のそばにほめ言葉の最初の一句（「両取り！」など）を、取られる場所へ動かしたときは「取られる！」を出します。吹き出しの文は1ステップ60字までにし、「緑のマス」「赤い数字」などの言葉の前には、盤と同じ色の小さな札を付けます。
  - **その場の図鑑**: 図鑑の項目（頭金・駒の価値・囲い・定跡）を、図鑑の画面へ移らずにレッスンの盤と吹き出しで見せます。図鑑の一言から始め、画面を押すたびに図鑑の行を1行ずつめくります。駒の価値は値段の札を1行に並べます。吹き出しの「図鑑でくわしく」を押すと図鑑をレッスンの上に開き、閉じると同じステップへ戻ります。
  - **格言札と格言帳**: 第1巻の銀・香・玉・成る・持ち駒のレッスンから第4巻の棒銀まで、16のレッスンの課題に格言札が1枚ずつ付きます。課題を解き終えると（まちがえても）、盤の上に「いま君が指した手が、これ！」と格言の名前・一言の札を出し、いま指した駒に「この手！」と添えます。札は押すと閉じて次へ進みます。初めて出会った格言は格言帳に入り、手筋図鑑の一覧に「札」の印が付きます（対局で指した手筋の★とは別の印です）。記録は`localStorage`（キー`yacobihime:shogi-match:tutorial-proverbs:v1`）に保存します。
  - **読み上げ**: 日本語の声がある端末では、レッスン中の見出しに「声」のボタンを出します。オンにすると、ステップが変わったとき（図鑑の行をめくったとき・観戦で1手進めたときも）の吹き出しの文と、正解・まちがいの一言を、端末の音声合成（Web Speech API）で読み上げます。新しい文を読むときは前の読み上げを止め、レッスンを離れると止めます。符号や駒の名前は読み違えないように直します（「▲７六歩」を「せんて、なな ろく ふ」など）。既定はオフで、選んだ状態は`localStorage`（キー`yacobihime:shogi-match:tutorial-voice:v1`）に保存します。盤の上のひとことは読みません。
  - **攻めくらべ・見くらべと囲いを組もう**: 第3巻では、同じ攻め駒（5五の竜と持ち駒の金）で居玉を王手だけで攻め、3手で詰むことを確かめます。続けて「囲いの見くらべ」で、居玉と美濃囲いを札で切り替えながら、3つのめがねでくらべます。逃げ道（いちばん厳しい王手のあと、玉が動けるマス。居玉0・美濃囲い2）、打ち込みの隙（取られずにかけられる王手。居玉は▲5三竜の1つ・美濃囲い0）、ひも（守っている駒→守られている駒を青い矢印で、だれにも守られていない浮き駒を赤で。攻めに出て金銀がばらばらになった玉と美濃囲いをくらべる）。数と台詞は局面から計算します（`src/core/castle-insight.mjs`）。囲いを王手で攻めて駒を捨てさせる攻めくらべはやめました。そのあと、薄く見せた完成形に向けて、自分で玉と金銀を動かして美濃囲い・舟囲い・金矢倉を組み立てます。手順は定跡図鑑の囲いの定義と同じで、最短の手数で組むと「最短！」です。腕だめしでは完成形を伏せて組みますが、「完成形を見る」を押すと薄い駒を出せます（ヒント1回に数え、そのレッスンの★は2つまでになります）。
  - ホーム画面の「つぎはこれ」（将棋教室ではじめる・将棋教室のつづき）と、はじめての案内の「はじめて」からは、本棚を通さずに次のレッスンが始まります。「まなぶ」の「将棋教室」からは地図を開きます。
  - 教室を初めて開いたとき（レッスンの記録が何もないとき）だけ、やこび姫が「将棋、どのくらい知ってる？」と聞きます。札は「はじめて」（駒の動かし方から）、「駒の動きは分かる」（成る・持ち駒・反則から）、「ルールは分かる」（第2巻のタダの駒・両取り・詰みから）、「1手詰めなら解ける」（第3巻の囲いと戦法から）の4枚で、押すとそのレッスンがすぐ始まります。それより前のレッスンは「とばした」の記録になり（★・メダル・巻の称号は付きません）、地図からいつでも遊べます。はじめての案内で「少し指せる」「よく指している」を選んだ人には、合う札に「おすすめ」を付けます。「はじめて」を選んで来た人には聞きません。「ルールは分かる」を選んで来た人には、札の代わりに1手詰めを1問出します。まちがえずヒントも使わずに解けたら第3巻（戦法と囲い）、まちがえた・ヒントを使った・スキップしたら第2巻（利き・タダの駒・両取り・詰み）から始め、そのレッスンがすぐ始まります（1問の記録は残しません）。「地図から自分で選ぶ」でも閉じられます。答えは教室の記録（キー`yacobihime:shogi-match:tutorial:v1`の`placement`）に残し、二度は聞きません。
  - 先から始めた人の地図には「はじめから学ぶ」を出し、とばした最初のレッスンを始めます。始めた章で続けて2つのレッスンを★1で終えたときは、一度だけ「少しむずかしかったかな？」と、とばした中でいちばん近い章からの復習を勧めます（`reviewOffered`に記録）。
  - 対局のレッスンだけは、終局後に結果の画面（勝ち負け・やこび姫の一言・★）を出し、「次へ進む」で同じ章の次のレッスンか章クリアへ進みます。
- **脳トレ道場**: 「計算力」と「記憶力」の2つの部屋で、頭の練習を1回10分ほどのプログラムとして続けます（`docs/brain-training-design.md`の11章）。ホームの「まなぶ」の「脳トレ」から開きます。入口には2つの部屋の扉と、前に開いた部屋の「つづき」（押すとその部屋の今日のトレーニングがすぐ始まる）、6週間の判子のカレンダー（計算力は橙の丸、記憶力は紫の四角）があります。将棋を知らなくても遊べる種目だけでプログラムを組み、今の将棋の種目は各部屋の「将棋の棚」に置きます。
  - **計算力の部屋**: 種目は4つです。どれも白い紙のような面に問題を大きく1つ出し、計算の答えは下の数字キー（0〜9・消す・決定。キーボードの数字・Backspace・Enterでも押せる）で答えます。
    - **スピード計算**: 簡単な計算20問を、できるだけ速く答えます。答えのけた数まで打つと採点し、まちがえたら赤く揺れて打ち直します（合うまで次へ進まない）。段は5つ（1けたの足し算・引き算／九九も／答えが2けた／割り算も／2けた×1けた）。1問の平均が段の目安より速ければ次の回は1段上、とても遅い回が2回続けば1段下。記録は「1問1.8秒（段2）」のように段ごとに残します。
    - **N問前の答え**: 答えが1けたの易しい式が1枚ずつ出ます。答えるのは「N枚前の式」の答えです。1回は10問で、9問以上合えばNが1つ上、6問以下なら1つ下（1回の途中では変えない）。練習は3回、Nは1〜9。
    - **ちらっと見る**: ちらっと盤の記号版です。真ん中の●か■と、まわりに一瞬出た★の方向を答えます（見せる時間とじゃまの印は、ちらっと盤と同じ段）。
    - **色で切り替え**: 数字が青い丸い枠なら偶数か奇数か、赤い二重の角ばった枠なら5より小さいか大きいかを答えます（左右の矢印キーでも答えられる）。2問続けて正解で、枠の色が変わる割合が増え、答える時間（3秒〜0.8秒）が短くなります。
    - **今日のトレーニング**: 最初の日は「測定」（スピード計算は段1で10問・N問前はN=1から合格するかぎり・ちらっと見るは最初の段から）。次の日から「10回のコース」で、毎回ちらっと見るとスピード計算を入れ、N問前の答えと色で切り替えを日替わりで1つ。10回目の最後にもう一度測り、記録の画面と結果に「前と後」を並べます。コースを終えて約1か月後と約3か月後に、4回の「おさらい」を勧めます（やらなくても何も消えません。研究の約1年後・約3年後を短くしたもの）。プログラムの回は1日1回だけ進み、同じ日の2回目からは自由練習です。
  - **記憶力の部屋**: 場所法を身につける学校です。
    - **最初の記憶テスト**: 方法を教わる前に、15個の言葉を60秒見て、順番どおりに思い出します（言葉15枚とじゃまの15枚から順に押す。思い出せない所は「とばす」）。これが「前」の記録で、6週間のコース（毎日の練習30回）のあとにもう一度テストして「前と後」をくらべます。
    - **自分の宮殿を作る**: 場所の種類（自分の家・学校・通学通勤の道・よく行くお店・自由に作る）を選び、場所カードの束（家は44枚、絵文字つき）から、自分の場所に本当にあるものを歩く順に押して並べます。並べたカードを押すと、自分の呼び方に変える・前後に動かす・消す（数秒だけ取り消せる）ができます。束にない場所は「カードを書く」で足します。流しどうし・ドアどうしなど似た場所が続くと、やこび姫が一言だけ知らせます。10か所でできあがり、宮殿は1つ30か所まで、3つまで。やこび姫のお城の30か所を「見本の宮殿」として使うこともできます。
    - **場所法の学校**: 講1 宮殿を歩く（順番・逆順・飛び飛び）、講2 絵にする（大げさに・動かす・場所とからめる）、講3 5個を置く、講4 10個と逆順、講5 20個、講6 数字を絵にする（0〜9の形の絵で10けたの数を覚える）、講7 次の日に思い出す（講5で置いた言葉を次の日に）、講8 宮殿を使い分ける（同じ宮殿にすぐ置くと混ざるのを体験）、講9 使ってみる（買い物リスト・やること・人の名前・将棋の手順と格言）。前の講を終えると次が開き、講7は講5のあとに開きます。
    - **毎日の練習**（講3を終えると開く）: ①前の回に置いた言葉を思い出す（前の日より前の回があれば。前の日なら「きのうの言葉」）→ ②言葉N個を宮殿に置いて思い出す（N＝5〜30。全部合えば＋2、8割未満なら−2）→ ③講6を終えていれば日替わりで数字（2けたずつ場所に置く）。宮殿が2つ以上あれば、前の回と別の宮殿を使います。
  - 記録は、種目ごとの自己ベスト、日ごとのいちばん良い記録（120日分）、部屋ごとの「前と後」です。記録の画面に種目ごとの線（上ほど良い記録）を出します。自己ベストや判子は結果の画面で知らせ、続けた日数が途切れても何も言いません。総合の点数や年齢のような数は作りません。
  - 保存は、記録とプログラムが`yacobihime:shogi-match:brain-training:v2`、自分の宮殿・講の進み・前の回の言葉が`yacobihime:shogi-match:memory-palace:v1`です。前の版（`brain-training:v1`）の段・自己ベスト・日ごとの記録は将棋の棚の記録として残し、前に書いた自分の宮殿（10か所以上）は「自由に作る」の宮殿として引き継ぎます（講の進みは、講が新しくなったので引き継ぎません）。読めない値は捨てて遊べます。
  - **将棋の棚**: 計算力の部屋に「ちらっと盤」（盤が一瞬出て、真ん中の駒と玉の方向を答える）と「頭の中の盤」（文字で流れる指し手を頭の中で追う）、記憶力の部屋に「盤面の記憶」（囲いと戦法の完成形から作った局面を覚えて並べ直す）があります。中身は前の版と同じです。
  - 入口と部屋の「？」から、練習の根拠を読めます。研究で確かめられた範囲（見る速さの練習とおさらいの長い期間の結果・簡単な計算の小さな研究・N-backは似た課題が伸びる・場所法は順番どおりに思い出す力が伸びる・自分の宮殿と見本の宮殿・同じ宮殿の使い回しで混ざる）だけを書き、頭全体が良くなるとは書きません（`docs/brain-training-design.md`の11-2）。
- **図鑑**: 盤面付きの図鑑が5つあります。
  - 駒図鑑
  - 手筋図鑑（格言と使いどころ）
  - 定跡図鑑（戦法41種・囲い30種の手順）
  - 将棋界図鑑（歴史と名棋士。代表局は分岐・読み筋の再生・投了の理由の解析ができます）
  - 将棋用語辞典（「詰めろ」「さばき」など70語。読みや解説から検索でき、関連する用語へ移れます）
  - ホームでは「しらべる」の1枚のタイル「図鑑」にまとめています。押すと、5つの図鑑の棚が開きます。
  - 対局中・検討中も、見出しの「図鑑」（本の絵）から開けます。ホームと同じ絵の5つの図鑑から選ぶと、対局の上に図鑑を開き、「対局へ戻る」で同じ局面に戻ります（対局は保存したままです。図鑑を見ているあいだもCPUは指します）。対局から開いた図鑑では、将棋界図鑑の代表局のAI解析は出さず、定跡図鑑の戦法占いからは「図鑑で見る」だけを選べます（対局のエンジンを借りないため・指している対局を消さないため。設計は`docs/match-dex-design.md`）。

### 組み込む

- **Custom Element**: `<shogi-match-game>`（対局画面一式）と`<shogi-match-board>`（盤面だけ）を公開しています。
- **iframe連携**: `game.html`をiframeで開くと、結果を`postMessage`で受け取れます。ティラノスクリプト用のタグもあります。
- **レスポンシブ**: 画面の大きさと向きに合わせて、盤の大きさと配置を自動で切り替えます。PC、タブレット、スマートフォンの縦横で使えます。どの画面もページをスクロールさせずに1画面に収めます（将棋教室の地図、トーナメント表、図鑑・辞典の一覧、コレクションは枠の中だけを動かします）。スマホの横向きでは、ホーム・対局準備・終局の結果・はじめての案内・やこびノート・大会を左右の2列に並べ、将棋教室と問題集は盤を左、やこび姫の台詞を右に置きます。スマホ縦・タブレット縦の対局画面では、盤の大きさと位置を画面の大きさと対局の種類だけで決め、やこび姫の台詞の長さや札の出入りでは変えません（盤は画面の幅いっぱいまで、盤の下のやこび姫の欄には先に高さを取っておきます。いま答える札（勝負メシ・作戦の提案・振り先など）が出ているあいだは、作戦カードをしまい、台詞を1行に縮め、ボタンを横1列に出します。作戦カードは1行の形にし、戦型の行は決まる前から「―」で取っておきます。設計は`docs/stable-board-layout-design.md`）。
- **RPG向けランタイム**: `integrations/shogi-rpg.js`を含みます。対局準備、消費する棋具、セーブ連携、敵ごとの定跡を扱えます。

## すぐに動かす

Node.js 20以上とnpmが必要です。

```sh
git clone https://github.com/YacobiHime/shogi-match.git
cd shogi-match
npm install
npm run build
npm run opening-editor
```

開発サーバーが起動したら、<http://127.0.0.1:5173/game.html> を開きます。

`game.html`は`dist/`のビルド結果を読み込みます。`src/`を変えたら、`npm run build`をやり直してから開き直してください。
初回準備、定跡エディター、よくある問題の対処は[ローカル起動・定跡編集ガイド](docs/local-development.md)にまとめています。

### 自分のサーバーへ置く

`game.html`、`dist/`、`vendor/`を同じ階層に置き、HTTPサーバーから`game.html`を開きます。
`dist/chunks/`には、教室・問題集・図鑑・やこびノート・大会の画面と、対局の共通部分が入っています。`dist/shogi-match.js`がそこから読み込むので、`dist/`はフォルダーごと置いてください。
WASMエンジンは`SharedArrayBuffer`を使います。そのため、サーバーは次の2つのヘッダーを返す必要があります。

```text
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

埋め込み先のページにも、同じ分離設定が必要です。
やねうら王を取得・起動できない場合は、合法手から選ぶ軽量CPUへ自動で切り替わります。

琥珀、まなぶ: 緑、しらべる: 薄紫）と余白で分けます。
ホーム画面がある表示では、ブラウザの戻る操作がアプリ内の「1つ前の画面へ戻る」になります。

- 図鑑・教室・対局準備は、1段ずつ閉じてホームへ戻ります。
- 来た場所へ戻ります（画面の「←」も同じ）。大会の結果の画面から開いたやこびノートは「大会へ戻る」で結果の画面へ、ノートから開いた図鑑・対局準備（作戦のカードの「この作戦にする」・「対局する」）・棋力テストはノートへ、定跡図鑑の戦法占いから開いた対局準備は図鑑へ戻ります。作戦のカードを選ばずに閉じたときも、ノートへ戻ります（設計は`docs/return-path-design.md`）。
- 対局中と検討中は、開いているメニュー・図鑑・解析を閉じるだけです。対局画面からは離れません。
- ホームでもう一度戻ると、元のページへ移ります。

## Custom Elementとして埋め込む

```html
<link rel="stylesheet" href="./dist/shogi-match.css">
<script type="module" src="./dist/shogi-match.js"></script>

<shogi-match-game
  mode="cpu"
  player-color="black"
  asset-base-url="./dist"
  engine-base-url="./"
  cpu-player-name="将棋CPU"
></shogi-match-game>
```

Shadow DOMを使わずに描画するため、同梱のCSSを読み込んだページでそのまま表示されます。

### 属性

| 属性 | 既定値 | 内容 |
| --- | --- | --- |
| `mode` | `cpu` | `cpu`または`local` |
| `player-color` | `black` | CPU対局で人間が持つ側 |
| `initial-sfen` | 平手 | 開始局面のSFEN |
| `asset-base-url` | `.` | 盤・駒・キャラクター画像と音声の公開先 |
| `engine-base-url` | `.` | `vendor/`（やねうら王）を置いた場所 |
| `engine-nodes` | `30000` | CPUの強さの初期値（`engine_nodes`と同じ） |
| `black-player-name` | `先手` | 先手の表示名 |
| `white-player-name` | `後手` | 後手の表示名 |
| `cpu-player-name` | `CPU` | CPUの表示名 |
| `cpu-delay-ms` | `350` | CPUが指すまでの待ち時間（ミリ秒） |
| `handicap-name` | なし | 手合割の表示名 |
| `hint-count` | `3` | 通常対局の閃き（ヒント）の回数 |
| `undo-count` | `3` | 通常対局の待ったの回数 |
| `mobile` | `false` | タッチ端末向けにする。素早く続けてタップしても、成・不成の選択が消えない |
| `enable-drag-and-drop` | `true` | 駒のドラッグ操作を許可する |
| `show-home` | `false` | ホーム画面（教室・図鑑・対局の入口）を表示する |
| `exhibit` | `false` | 公開ページでは既定で有効。タイトル画面の左下に「データリセット」を出す。押すと確認のうえで、このゲームの保存（音と盤・駒の見た目を除く）を`localStorage`と`sessionStorage`から消して、ページを読み直す |

### イベント

| イベント | 発生する時点と、渡される値 |
| --- | --- |
| `match-ready` | 対局の準備ができたとき。`{ mode, sfen }`を渡す。リロードで復元したときは`restored: true`も付く |
| `match-move` | 1手指したとき。`{ usi, actor, moveCount, sfen }`を渡す |
| `match-end` | 終局したとき。勝者、理由、手数、USIの指し手列、最終局面のSFENを渡す |
| `match-error` | 開始局面が不正な場合などのエラー。`{ message }`を渡す |

VueのCustom Elementでは、イベントの値は`event.detail[0]`に入ります。

```js
document.querySelector("shogi-match-game").addEventListener("match-end", (event) => {
  console.log(event.detail[0]);
});
```

## ノベルゲームから呼ぶ（iframe・ティラノスクリプト）

`game.html`を同一オリジンのiframeで開きます。終局すると、親ウィンドウへ次のメッセージを送ります。

```js
{
  type: "shogi-match:result",
  version: 1,
  matchId: "chapter1-boss",
  result: {
    outcome: "black-win",
    winner: "black",
    reason: "checkmate",
    moveCount: 57,
    moves: ["7g7f", "3c3d"],
    finalSfen: "..."
  }
}
```

受け取る側では、`event.origin`、`event.source`、`matchId`を必ず確かめてください。

ティラノスクリプトでは、初期化の後に一度だけタグを登録します。

```html
<script type="module">
  import { registerTyranoShogiMatch } from "./shogi-match.js";
  registerTyranoShogiMatch(window.tyrano, { gameUrl: "./game.html" });
</script>
```

その後は、シナリオにタグを書くだけで対局できます。

```ks
[shogi_match match_id="chapter1:boss" mode="cpu" player_color="black"]
```

終局結果は`f.match_result`に入り、シナリオが次へ進みます。
ティラノ以外のノベルエンジンでは、`openShogiMatch()`を直接呼んでください。同じ全画面iframeと結果の検証を使えます。
URLの組み立てと結果の検証だけを使う場合は、`buildGameUrl()`と`parseMatchResultMessage()`もあります。

## 対局の仕組み

### 自動保存とリロード復元

対局を始めると、状態をブラウザの`localStorage`へ30日間保存します。同じURLをリロードすると、次のものを復元します。

- 指し手、先後、CPUの設定と、CPUが選んだ作戦
- 選んでいた戦法・囲い、閃きと待ったの残り回数、終局結果
- 学習対局の種類・開始局面・回数設定・「動きの矢印」の表示と、「駒の利き」の表示（対局の種類を問わない）
- 局面ごとに表示したやこび姫の助言（棋譜解析で同じ局面を開くと、また表示する）
- 「ひふみんアイ」で変えた盤の向き（棋譜検討中に変えた向きは保存しない）

その他の動き:

- 保存を識別するのは、URLのパスと`match_id`です。
- 開始局面と対局モードが同じなら、保存済みの先後とCPUの強さを、URLの`player_color`や`engine_nodes`より優先します。
- ホーム画面がある表示でも、保存した対局があれば、ホームを通らずに対局画面から再開します。
- 手の重さに応じて手応えを変えます。取る・打つ・成る手は、それぞれ違う着地の動きをし、取った駒は駒台で跳ねます。王手・大駒を取る手・ほめ言葉のあとは、CPUの応手を出す前に一瞬止め、神の一手と詰みでは盤の縁を光らせます。詰みで決まったときは、止めてから結果画面を出します（勝ちは0.4秒、負けは0.2秒。盤を触ると打ち切ります）。ホームの「対局する」で振り駒をするときは、歩を振る音のあいだ歩を揺らし、駒台に撒く音で表と裏と先後を見せます（知らせを押すか、どちらかが指すとすぐ結果を出します。効果音を切っているときは、すぐ結果を出します）。効果音は見出しのメニューの「効果音」で切り替えられ、`localStorage`（キー`yacobihime:shogi-match:sound`）に保存します。教室と問題集も同じ設定に従います。動きを減らす設定（`prefers-reduced-motion`）では、揺れと移動をなくします。
- 結果画面の「もう一局」は、対局準備を通さずに直前と同じ設定で次の対局を始めます。平手の通常対局では先後を入れ替えます。レーティングの対象の対局で同じLvに3連敗すると（申告・測定の記録は数えません）、「もう一度挑む」「Lv.（2つ下）で腕ならし」「香落ちで挑む」（学習対局、CPUが上手。いちばん下の24級（Lv1）では「Lv.0で腕ならし」「飛車落ちで挑む」）を並べて選ばせます。強さは自動では変えません。平手の通常対局で勝つと、主ボタンが「Lv.（1つ上）に挑戦」になり（初めて勝ったLvなら「初勝利！」と添えます）、同じ相手との「もう一局」は小さく残します。Lv49（藤井聡太並み）に勝ったときは「もう一局」のまま、香落ち・飛車落ちで勝ったときは「平手でLv.Nに挑む」、Lv0（練習相手）に勝ったときは「Lv.1に挑戦」です。終盤戦・敗着の前から・教室・棋力測定・竜王戦の対局は、今までどおりです。レーティングが動いた対局では、次の級・段までの残りを帯で示し、級・段の目安が上がったときは知らせます。
- 負けた対局の「対局を振り返る」では、敗着の答え合わせのあとと振り返りの最後に「敗着の前から指し直す」を出します。敗着を指す前の局面から、同じ相手・同じ手番で指し直せます（平手の初期局面からではないので、レーティングの対象外です）。この対局の「もう一局」は、同じ局面から始め直します。
- 結果画面の「ホームへ」（ホーム画面を出さない構成では「対局準備」）や、棋譜解析の「完了」で対局を離れると保存を削除し、次の対局は何も選んでいない状態から始まります。ホーム画面を出す構成（`show-home`）では、終局後はホーム画面へ戻ります。棋譜解析・振り返りの「完了」は、狭い画面でもメニューにしまわずにツールバーに出し、「完了してホームへ」「完了して竜王戦へ」「完了して教室へ」「完了して対局準備へ」のように行き先を書きます。

### CPUの強さと作戦

- **強さを選ぶ場所**: 対局準備で選びます。埋め込みでは`engine-nodes`属性、URLでは`engine_nodes`で初期値を指定できます。調整の根拠は[CPU難易度の調整方針](docs/difficulty-calibration.md)にあります。
- **手の選び方**: Lv1〜48は、駒を取る・逃げる・受ける・攻めを用意する・駒組みを進める狙いを確かめて候補を選びます。24級〜16級（Lv1〜9）は盤の計算だけ（ロジックAI）、15級〜タイトル保持者（Lv10〜48）は局面への気づきとエンジンの評価値を使い、気づかない・浅く読む・迷うことで強さを分けます。Lv0は自然さで選び、Lv49は従来どおり720,000nodes・2スレッドで読んだ最善手を選びます。Lv10〜48でエンジンが使えない場合は、ロジックAIのLv10へ戻ります。
- **おまかせの戦法**: 相手の作戦を「おまかせ」にすると、実戦での出現率に近い比率で戦法を選びます。
  - Lv0〜19（6級程度まで）: 将棋ウォーズの級位帯のように、振り飛車・棒銀・急戦・奇襲が多めです。
  - Lv20〜24（5級〜1級）、Lv25〜39（アマ初段〜五段）: レベルが上がるほど居飛車の本格的な戦型が増えます。
  - Lv40〜49: プロ公式戦のように、角換わり・相掛かり・矢倉が中心です。
- **比率の調整**: 比率は目安の概数です。`src/core/cpu-opening-repertoire.mjs`の`OPENING_DISTRIBUTION`で調整します。「居飛車」「振り飛車」「奇襲戦法」を選んだ場合も、その中で同じ比率を使います。
- **ランダムな組み合わせ**: 「おまかせ」では、その局面で成り立つ戦法と囲いをランダムに組み合わせることもあります。割合は低レベルでも2割までで、レベルが上がるほど減り、最高レベルでは使いません。
- **囲いの決め方**: 囲いを指定しない場合は、相手の指し手を見て決めます。
  - 相手が居飛車の形（飛車先の歩を突く、銀を4八・3七・4七へ上がるなど）なら、対居飛車の囲いを組みます。
  - 相手が飛車を振ったら、対振り飛車の囲いを組みます（CPUも振り飛車なら相振り飛車の囲い）。
  - 上のレベルほど、穴熊・銀冠・ミレニアムなど手数のかかる囲いを選びやすくなります。
  - 囲いの駒を動かし始めたら、途中で囲いは変えません。
- **角交換への対応**: 戦法を指定していない居飛車のCPUは、相手から角交換されると、角換わり腰掛け銀か角換わり4五桂速攻へ切り替えます。
- **CPUの作戦を選ぶ場所**: 対局準備のCPUの「作戦」の［変更］で、作戦カードのシートを開きます。「大まかに決める」（おまかせ・居飛車・振り飛車・奇襲戦法。細かい戦法は上の比率でCPUが選びます）か、作戦カードの1枚を選びます。カードには、CPUが指せる戦法と、CPUの手番の色で使える作戦だけを、解放とは関係なくすべて並べます。カードでは囲いも選べ、「囲いはCPUにまかせる」なら下のとおり相手の指し手を見て決めます。
- **CPUの序盤の傾向**: 対局準備の「序盤傾向」で指定できます。
  - 角道（開けたまま、開けてから閉じる、CPUから角交換、こちらからの角交換を待つ、閉じたまま）
  - 飛車の方針
  - 指し方

### 学習対局

- **開始局面**: 対局準備で「学習対局」を選ぶと、平手・駒落ち・戦法や囲いが完成した局面から選べます。
- **駒落ち**: 上手（駒を落とす側）を後手に置き、上手から指し始めます。
- **完成局面の作り方**: 選んだ作戦を、案内どおりに両者で指し進めて作ります。完成できない組み合わせでは開始できません。
- **定跡補助**: 平手以外の局面から始めた対局では、平手用の定跡補助は使いません。
- **駒の利き**: 対局中の「駒の利き」ボタンで、各マスに利いている先手（青）・後手（赤）の駒の数を表示します。学習対局だけでなく、通常対局（自由対局・終盤戦など）と竜王戦でも使えます。押すまでは出さず、付けたかどうかは次の対局にも引き継ぎます（ページを開き直すと消えた状態から）。補助なので、付けていてもレーティングと大会の結果は変わりません。
- **取られるマスと玉の逃げ道**: 将棋教室で利きメガネを手に入れていると、「駒の利き」を付けているとき、駒を選ぶと動かすと取られるマスに赤い輪が出ます。「駒の利き」を付けているときに自分の玉が王手されると、玉のまわりに逃げられるマス（緑）と相手の駒が利いているマス（赤い×）を出します。
- **駒得の数字**: 学習対局（教室から始めた対局を含む）では、駒を取ると取ったマスにその駒の値段を緑で「＋540」、取られると赤で「−495」などと浮かべます。値段は駒図鑑のAI用の表と同じで、成った駒は元の駒の値段で数えます。

### 定跡エディター

`npm run opening-editor`で開く「やこび姫 定跡編集」では、戦法・囲いの案内手順を画面上で編集できます。

- 囲いの完成形と、「ほぼ完成形」を編集できます。
- 盤上の条件（ANDとORの組み合わせ）と、応手による分岐を付けられます。
- 定跡をJSONで書き出せます。
- 下書きはそのブラウザの`localStorage`にだけ保存され、公開版には自動では反映されません。
- 公開版へ反映するには、`npm run import:opening-library`で`src/data/opening-guide-overrides.mjs`を生成してコミットします。

操作手順は[ローカル起動・定跡編集ガイド](docs/local-development.md)を参照してください。

### Firebase Hostingへ公開

Firebase CLIでログインしていれば、次のコマンドで`.firebaserc`に設定したプロジェクトへデプロイできます。

```sh
npm run deploy
```

GitHubからも公開できます。リポジトリのActionsの「Firebase Hostingへ公開」で「Run workflow」を押すと、mainなど選んだブランチを、テストと型チェックのあとに公開します（`.github/workflows/firebase-hosting.yml`）。自動では動きません。公開の鍵は、リポジトリのSecretsの`FIREBASE_SERVICE_ACCOUNT_SHOGI_64125`に、サービスアカウント（ロール「Firebase Hosting 管理者」と「API キー閲覧者」）のJSONを置きます。

- `npm run deploy`は、棋力テストの答えを集めるFirestoreのルール（`firestore.rules`）も一緒に公開します。Firestoreのデータベース（`(default)`、東京`asia-northeast1`）が先に要ります。GitHubのActionsはHostingだけを公開し、ルールは公開しません。
- 公開用ファイルは`firebase-public/`に生成されます。このフォルダーと`.firebase/`は生成物なので、Gitには含めません。
- HTMLは毎回再検証します。JSとCSSは内容のハッシュ付きURLにして、長期キャッシュします。入口の`dist/shogi-match.js`とCSSは`?v=`で、`dist/chunks/`のファイルは名前で版を区別します。
- エンジンの版（`vendor/yaneuraou.js?v=…`）は、`vite.config.js`がビルドの時点で`vendor/`の内容のハッシュを埋め込みます。
- 画像・音声・WASM・評価データのキャッシュは`firebase.json`で設定しています。
