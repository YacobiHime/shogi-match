shogi-match 展示版（Windows 10/11・64ビット）

■ 始め方
shogi-match-exhibit.exe をPCへコピーしてダブルクリックします。
ゲーム本体・画像・音・将棋エンジンはexeに内蔵されています。
インターネット接続、Node.js、PowerShellは不要です。
Chrome または Microsoft Edge がインストールされている必要があります。
全画面を閉じるときは Alt+F4。閉じると内蔵サーバーも終了します。
通常の窓で開く場合は、ショートカットのリンク先の末尾に --window を付けます。

■ 次の来場者へ
タイトル画面左下の「データリセット」→確認の「最初からにする」。
名前・成績・教室・大会・中断した対局を消します。音と盤・駒の見た目は残します。
記録は展示専用のブラウザプロファイルへ保存し、普段のブラウザと分離します。

■ 起動できないとき
すでに展示版を起動していれば、その窓を閉じてから再起動してください。
127.0.0.1:8765を他のソフトが使っている場合は起動できません。
署名のないexeなのでWindowsや学校の管理設定で実行を止められる場合があります。
その場合は展示担当者・学校の管理者に確認してください。
このビルドはLinuxで生成・サーバー検証しています。展示前に実機で起動確認してください。
