shogi-match 展示用パッケージ（Windows・Chrome・インターネット不要）

■ 準備（1回だけ）
1. zip ファイルを右クリック →「プロパティ」→ 下の「許可する」に印を付けて「OK」。
   （しないと、起動のときに「WindowsによってPCが保護されました」と出ることがあります。
     出たら「詳細情報」→「実行」で進めます。）
2. zip を右クリック →「すべて展開」。USBメモリーではなく、PCのデスクトップなどに置くと速く動きます。

■ 展示を始める
- start.bat をダブルクリックします。黒い画面と、全画面（キオスク表示）の Chrome が開きます。
- 黒い画面は閉じないでください（ゲームの中身を Chrome に渡しています）。
- 設定を確かめたいときは start-window.bat（ふつうの窓で開く）を使います。

■ 来場者が替わるとき
- ホーム画面の右上の「最初から」→「最初からにする」で、成績・教室の進み具合・竜王戦・中断した対局を消して、はじめの状態に戻します。
- 音の設定と、盤・駒の見た目は残ります。

■ 展示を終える
- キオスク表示の Chrome は Alt + F4 で閉じます。Chrome を閉じると、少しして黒い画面も閉じます（閉じないときは × で閉じてかまいません）。

■ 動かないとき
- 黒い画面に「ポートを開けませんでした」と出る: PCを再起動してから、もう一度 start.bat を開きます。
- 黒い画面がすぐ消える・赤い字が出る: 学校のPCで PowerShell が止められている可能性があります。情報担当の先生に「PowerShell のスクリプトを実行したい」と相談してください。
- Chrome が見つからない: ふだんのブラウザで開きます（Edge でも遊べます。キオスク表示にはなりません）。

この展示用パッケージは、インターネットにつながず、このPCの中（127.0.0.1）だけで動きます。
