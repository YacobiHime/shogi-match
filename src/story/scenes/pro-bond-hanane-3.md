# 会館の帰り道（二）
id: pro-bond-hanane-3
bg: street
cast: hanane
summary: また羽音と帰り道を歩く。羽音は、前は{name}の将棋が読めなかったが、今は少し分かると言う。

: 帰り道。今日は、羽音のほうから歩幅を合わせてきた。
羽音: 君の将棋、前は読めなかった。
羽音: 私は、相手の手を予想しないで読む。全部の手を並べるだけ。
羽音: でも君の手は、並べた中のどれでもないことがある。
羽音(gentle): 今は少しだけ分かる。……指す前に、一回止まるでしょ。
羽音: あれ、悪くないと思う。私には、あの止まり方はできないから。
: 駅の改札の前で、羽音は小さく手を振った。 [羽音:うなずく]
