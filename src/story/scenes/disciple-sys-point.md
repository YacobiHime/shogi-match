# 降級点

bg: night
voices: {disciple} 真壁
vars: disciple
summary: {disciple}に降級点が付いた夜。一門の先輩の真壁が、降級点の決まりと戻り方を話す。

: 例会の帰り道。{disciple}は黙ったまま歩いていた。 [tone:dim]
真壁: 降級点か。俺も付いたことがある。
真壁: 勝ち越せば消える。付いたまま、もう一度負けが込むと、クラスが1つ下がる。
{disciple}: ……下がったら、名札も左に戻るんですよね。
真壁: 戻る。でも俺は戻ってから、前より速く上がった。
- 次の例会は、1局目だけに集中しよう {one}
  {disciple}: ……1局目だけ。それなら、できそうです。
- 今週は将棋を休んで、気持ちを戻そう {rest}
  {disciple}: はい。少しだけ、休みます。
- 負けた将棋を、一緒に並べよう {review}
  {disciple}: お願いします。どこで崩れたか、知りたいです。
: 家に着くころ、{disciple}は少しだけ顔を上げていた。 [tone:none]
