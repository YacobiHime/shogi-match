# 演出の見本

cast: hanane momoka
summary: 放課後の空き教室で、羽音と百花が演出の使い方を見せてくれる見本の場面。物語の目録には載らない。

// 書き手のメモ: この台本は docs/novel-authoring-guide.md の見本です。試し読みのページ(npm run novel-editor)でも最初に読み込まれます。
// 百花は、はじめは舞台にいない(あとで[enter]するので、castにいても最初は出ない)。

: 放課後の空き教室。羽音がひとりで盤を見ている。 [間:400]
羽音: ……あ、来た。 [ぴょん] [sfx:pop]
[sfx:door]
百花: お待たせー！ 今日は何するの？ [enter:right] [音符]
羽音(smile): 動きの見本。百花、驚いてみて。 [百花:かしげる]
百花(worried): え、えっ！？ いきなり！？ [揺れる] [！] [羽音:うなずく]
羽音(gentle): うまいね。じゃあ次は、昔の話。 [回想] [羽音:おじぎ]
: ――はじめて三人で指した日のこと。 [ゆっくり] [百花:きらきら]
[暗転] [回想おわり] [bg:night]
: その夜。 [sfx:bell]
百花(wry): 結局、遅くなっちゃったね…… [汗] [しょんぼり]
羽音: 楽しかったでしょ。 [大きく] [百花:大喜び]
百花: ……うん！ また明日ね！ [exit] [ハート]
