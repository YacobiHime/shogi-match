# 香一本の差
id: disciple-sys-teai
bg: hall
voices: {disciple} 早瀬
vars: disciple
summary: 例会ではじめて香落ちの局がある日。一門の先輩の早瀬が、手合いの決まりを話す。

: 例会の前。対戦表の{disciple}の局に「香落ち」と書いてあった。
{disciple}: 香落ちって……駒を落とすんですか。
早瀬: クラスの差で手合いが付くんだ。1つ差なら平手と香落ちを交互、2つ差なら香落ち。
早瀬: 香を落とすのは上の人。上手って言う。下の人は下手で、先手の側に座る。
早瀬: 指すのは上手が先。香が1本ないぶん、上手は強く来るよ。勝ちは勝ちだ。
- 香一本の差を、しっかり活かそう {use}
  {disciple}: 端が薄い……そこを狙います。
- 上手は強く来る。受けを大事に {guard}
  {disciple}: はい。あわてずに、受けてから。
- 平手も香落ちも、同じ一局だ {same}
  {disciple}: ……同じ一局。そう思うと、落ち着きます。
: 早瀬は、昔の自分の香落ちの棋譜の話を、少しだけしてくれた。
