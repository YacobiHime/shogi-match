# やこび姫の助言の強化（設計 2026-10-27、未実装）

ユーザーの依頼：「やこび姫の助言を大幅に強化しましょう。追加する助言や発動条件などを提案して」。

この文書は、いまの助言を棚卸しし、足りないところを挙げ、足す助言（N1〜N12）を、台詞・発動条件・元になる読み・出す優先度まで決めて提案する。作戦の助言とA〜Eの強化（`docs/coach-plan-advice-design.md`）の続きに当たる。

設計の根拠は`docs/nintendo-design/`の`Game_Nintendo_Design.md`（G:）と`UI_Nintendo_Design.md`（U:）。

## 0. いまの助言（棚卸し）

| --- | --- | --- | --- |
| 形勢 | 「良い流れだね！」「駒得してるね！ 駒を交換して、局面を単純にしていこう！」 | CPUが指したあと | 評価値と駒の損得（`getCoachAdvice`） |
| 詰み | 「7手詰めだね、頑張って！」「もう受けが無いね…でも、諦めずに指し続けよう！」 | プレイヤーの手番の読み | 助言の読み（`mateWinAdvice`・`noDefenseAdvice`） |

## 1. 足りないもの

1. **「何か」を言わない知らせがある。** 「何かあるよ、気を付けて！」「詰みがありそうな気がするな～？」は、何があるのか（チャンスなのか危険なのか）が分からない。いちばん大事な場面ほど、言葉がぼやけている。
2. **終盤の方針がない。** 将棋の終盤でいちばん大事な「攻めるか、受けるか」（どちらの玉が先に詰むか）を言わない。詰みがあるときだけ「N手詰め」と言う。
3. **チャンスを知らせない。** 相手（CPU）が悪手を指しても、自分が詰みや駒得を見逃しても、何も言わない。低いレベルのCPUはわざと悪手を指す（G:4-9 反応できて倒せる）のに、それに気づかせていない。
4. **盤を指ささない。** 助言はすべて文字で、盤の上には何も出ない（U:6-1「テキストは最後の手段」に反する）。「相手の狙いは△2八角成」と言われても、どの駒か盤で探す必要がある。
5. **閃きが答えをいきなり見せる。** 押すと最善手の矢印が出る。自分で気づく楽しみ（G:6-3 攻略の自由、G:2-2 解消の気持ちよさ）を、いちばん最初に取ってしまう。
6. **対局をまたいだ記憶がない。** 前の対局の弱点（詰みの見逃し・タダ取られなど、`play-insight.mjs`の`weaknesses`）を、次の対局の助言に使っていない。上達したことも伝えていない（G:6-1 上達が見えること）。
7. **大会の物語が対局中に薄い。** 大会の1局の始めの一言のあと、やこび姫は相手の棋風や賭けているもの（「勝てば竜王」）に触れない。

## 2. 方針

- **1つの局面で1つだけ言う。** 今の`showCoachAdvice`（6秒は見せる・優先度の高いものが先）のまま。新しい助言は優先度の表（5章）に入れる。
- **答えは言わず、方向を言う。** 「タダで取れる駒があるよ」までにして、どの駒かは言わない。答えは閃きで見る（G:6-3、U:6-1）。
- **AIの読みと同じ意見のときだけ言う。** 格言や一般論（「居玉は避けよ」）も、AIの最善手がそれに沿うときだけ言う。読みと食い違う助言はしない（G:12の1 将棋として正しいか）。
- **責めない。見逃しはチャンスとして言う。** 「詰みがあったよ」は「次は見つけよう」につなげ、問題集の「あなたの対局」の棚へ案内する（U:4-3、G:7-2）。
- **しゃべりすぎない。** 「教える」助言（N1・N3・N6）は4手に1回まで、同じ種類は今までどおり8手のあいだ繰り返さない（G:9-1 いただく時間）。
- **読みはなるべく足さない。** 今すでに読んでいる結果（助言の読みの上位5手と読み筋、詰めろの確かめ、悪手判定の読み、CPU本体の読み、閃きの読み）から言う。足すのはN3の詰めろの確かめ1回だけ（`AGENTS.md`のCPUの項。CPUが指す前に読みを積まない）。

## 3. 提案

### N1. 「何かあるよ」を、中身で言う（最善手の翻訳）

今の「何かあるよ、気を付けて！」（評価の崖）と「詰みがありそうな気がするな～？」を、**最善手の種類**で言い分ける。作戦の助言（飛車を振る手を作戦の名前に翻訳）と同じ考え方で、最善手を言葉に翻訳する。

| 最善手の種類（見分け方） | 台詞の例 |
| --- | --- |
| 相手の駒をタダで取る（取った駒に取り返しがない。`exchange-eval.mjs`） | 「タダで取れる駒があるよ！ 探してみて」 |
| 駒を取る（交換になる） | 「駒を取り合う勝負どころだよ。どの駒で取るか、よく読もう！」 |
| 王手（詰みではない） | 「王手から迫れそうだよ！」 |
| 持ち駒を打つ（駒の種類を言う） | 「持ち駒の桂が光る場面だよ！」 |
| 手筋の形（`detectTesuji`を最善手に使う） | 「ふんどしの桂の形があるよ！」「叩きの歩が効きそう！」 |
| 取られそうな駒を逃がす（今の取られるマスの見分け） | 「大事な駒がねらわれてるよ。先に逃がそう！」 |
| 玉の手・玉のまわりの金銀の手 | 「守りの一手が大事な場面だよ。玉のまわりを見てみよう」 |
| 飛車・角の働きが大きく増える（動ける升が3升以上増える） | 「眠ってる角を働かせる手がありそう！」 |

- **出る条件**：今の評価の崖（2〜5位が最善より700点以上悪い）か、最善が2位より300点以上良いとき。詳しい助言のみ。
- **元になる読み**：助言の読みの上位5手と読み筋（今のまま）。**読みは足さない。**
- **優先度**：70（今の評価の崖と同じ）。チャンスの種類（取る・王手・打つ・手筋）は「注目」、危険の種類（逃がす・守る）は今の知らせと同じ（U:5-3）。
- 合わせて、手が止まったときの一言（`idle-coach-advice.mjs`）も、同じ翻訳を使って「持ち駒は何があるかな？」の一般論から、この局面の中身に置き換える。

### N2. 盤で指し示す

助言の言葉と一緒に、**盤の上にその場所を出す**（U:6-1 テキストは最後の手段、U:7-2 動きは情報のため）。

- **相手の狙い**（今の`threatAdvice`）：相手の狙いの手を、**点線の矢印**で出す。色は相手の利きの色（先手は青・後手は赤。「駒の利き」と同じ）にして、AIの候補手の赤い実線の矢印と見分ける。プレイヤーが指したら消す。
- **悪手の理由**：取られる駒の升に赤い輪（今の利きメガネの`risk-ring`と同じ「取られて損をする」の意味）を、次の手を指すまで出す。
- N1の「タダで取れる駒」は、答えになるので盤には出さない（閃きの2段目で出す。N7）。
- 盤の色の表（`AGENTS.md`）に「相手の狙いの点線の矢印」を足す。升の強調ではないので黄色の決まりには触れない。

### N3. 終盤の「攻めるか、受けるか」

終盤（61手目から、または玉のまわりで駒の取り合いが始まったとき）で、**どちらの玉が先に詰むか**から方針を言う（G:2-2 終盤は溜めが最も大きい）。

| 自玉 | 最善手 | 台詞の例 |
| --- | --- | --- |
| 詰めろ（今の詰めろの確かめ） | 王手 | 「自玉に詰めろがかかってる。王手で迫りながら、しのごう！」 |
| 詰めろ | 王手でない | 「自玉に詰めろがかかってるよ。まずは受けよう！」 |
| 詰めろでない | 相手玉に詰めろをかける手 | 「自玉はまだ安全！ 相手玉に詰めろをかけて、攻め合いで勝とう！」 |
| 詰めろでない | 守りの手 | 「相手の攻めのほうが速いよ。一手かけて守ろう」 |

- **追加の読み**：「最善手が相手玉に詰めろをかけるか」を確かめるために、最善手を指したあと手番を入れ替えた局面で、詰めろの確かめ（今と同じ7手までの連続王手、3万局面）を**1回**。終盤で、自玉が詰めろでなく、最善手が王手でないときだけ。
- 詰み（勝ち・負け）のときは今の詰みの一言を優先する。
- 優先度：80（相手の狙いより上、悪手の指摘より下）。

### N4. 見逃しの知らせ（自分の手のあと）

指した手で、**あった詰みやタダの駒を逃した**ときに、責めずに知らせる。

- **詰みの見逃し**：指す前の読みが勝ちの詰み（N手）で、指したあとは詰みでない（または手数が延びた）。
  - 「いま、5手詰めがあったよ！ 対局のあとで、問題集の『あなたの対局』で解いてみよう」（`docs/missed-mate-problems-design.md`の棚につながる）。
- **タダの駒の見逃し**：指す前の最善手が相手の駒（銀以上）をタダで取る手で、指した手がそれより300点以上悪い。
  - 「△の銀がタダで取れたよ。次は、取れる駒がないか先に探してみよう！」
- **元になる読み**：悪手判定の読み（指す前と指したあと。今のまま）。指す前の読み筋の1手目を残すようにする。読みは足さない。
- 悪手の指摘と重なるときは、見逃しのほうを言う（何を逃したかのほうが具体的なため）。優先度90。

### N5. 相手のミス（チャンスの知らせ）

CPUが悪手を指したら、**チャンスだと知らせる**（G:4-9 反応できて倒せるCPU、G:2-1 リスクとリターンを見せる）。

- **出る条件**：CPUの選んだ手が、CPU本体の読みの最善より300点以上悪く、プレイヤーから見た形勢が良くなったとき。1局に3回まで。
- **台詞**：「チャンス！ 相手の今の手で、こっちが良くなったよ。何が変わったか探してみて！」。取れる駒ができたときは「相手の駒が浮いたよ！」。答え（手）は言わない。
- **元になる読み**：CPU本体の読み（今のまま）。読みは足さない。
- 応援のみ（`encourage`）でも出す。優先度75。

### N6. 序盤の原則（格言）

序盤の大事な原則を、**AIも同じ意見のときだけ**、格言の形で1局に1回ずつ言う。

| 格言 | 出る条件 | 台詞の例 |
| --- | --- | --- |
| 居玉は避けよ | 24手目を過ぎて玉が初めの升のままで、駒の取り合いが始まり、AIの最善手が玉を動かす手 | 「『居玉は避けよ』だよ。玉を横に動かして囲おう！」 |
| 玉飛接近すべからず | 40手目まで、玉と飛車が同じ段で隣り合い、AIの最善手が玉か飛車を離す手 | 「『玉飛接近すべからず』。玉と飛車は離しておこう」 |
| 桂の高跳び歩の餌食 | 指した桂が5段目より先にいて、歩で取られる（取られるマスの見分け） | 「『桂の高跳び歩の餌食』。その桂、歩でねらわれちゃうよ」 |

- 作戦カードの案内中（囲いを組んでいる途中）は出さない（案内と重なるため）。
- 言った格言は、教室の格言帳に入れる（「格言帳に入ったよ」。G:5-1 集めたものに使い道。格言帳は`tutorial-progress.mjs`）。
- 優先度40（作戦の提案と同じ帯）。読みは足さない。

### N7. 閃きを3段階にする

閃きを押すと、いきなり矢印ではなく、**言葉 → 動かす駒 → 矢印**の順に出す（G:6-3 自分で気づく楽しみ、U:6-1 説明しないで気づかせる）。

1. **1回目**：N1の翻訳で、最善手の種類だけ言う。「持ち駒の桂を使う手があるよ」「玉の逃げ道をふさぐ手だよ」。
2. **2回目**：動かす駒（打つなら持ち駒）を緑で光らせる（「大事なマス」と同じ緑）。
3. **3回目**：今の矢印3本と「最善手は○○だよ！」。

- **回数の数え方（決めること1）**：1回の閃きで3段目まで見られる（おすすめ）。指したら次の局面でまた1段目から。閃きの回数の意味（ご褒美・ハンデ）は今のまま。
- 設定に「閃きの出し方：段階／すぐ答え」を置き、慣れた人は今までどおりにできる（U:4-1 プロモード）。
- 元になる読み：閃きの読み（今のまま）。

### N8. あなたの弱点を覚えている（対局をまたぐ）

前の対局の弱点（`play-insight.mjs`の`weaknesses`：詰みの見逃し・終盤の逆転負け・タダ取られ・序盤の不利）を、次の対局で使う。

- **始めの一言**（最初の手番）：「前の対局で、詰みを見逃してたね。今日は王手の続く手を探してみよう！」「タダで取られることが多かったね。動かす前に、取られないか確かめよう（『駒の利き』も使ってね）」。
- **同じ場面が来たら強める**：弱点が「詰み」で勝ちの詰みがあるときは、詰みの一言を「前に逃した形に似てるよ！」付きにする。
- **乗り越えたらほめる**（G:6-1 上達が見える、G:5-8 情報としての称賛）：弱点が「詰み」の人がこの対局で詰ませたら、「前は逃してた詰み、今日は見つけたね！」。
- 応援のみでも出す。読みは足さない。

### N9. 大会の物語（対局中）

大会の1局の途中でも、相手と賭けているものに触れる（`AGENTS.md`の柱：主役は大会、G:8-1 キャラ立ち）。

| 場面 | 台詞の例 |
| --- | --- |
| 相手が「逆転の名手」で、プレイヤーが1000点以上勝っている | 「中村さんは逆転の名手。最後まで気を抜かないで！」 |
| 相手が「終盤が苦手」で、終盤に入って互角 | 「中村さんは終盤が苦手。ここからがチャンスだよ！」 |
| 勝てば節目（昇級・挑戦・タイトル）で、勝勢の終盤 | 「勝てば竜王！ 最後の詰みまで、丁寧にいこう」 |
| カド番・最終局の終盤で互角 | 「ここが正念場。一手ずつ、落ち着いて！」 |
| 羽音との対局で逆転したとき | 「羽音ちゃん、悔しそう…でもまだ油断しないで！」 |

- 1局に種類ごと1回。優先度30（形勢の一言より上、ほかの助言より下）。読みは足さない。

### N10. ほめ言葉を増やす

| ほめる場面 | 見分け方 | 台詞の例 |
| --- | --- | --- |
| AIと同じ手が続いた | 指した手が、助言の読みの最善手と同じ。3手・5手続いたら | 「AIと同じ手が3手続いたね！ 冴えてる！」 |
| 狙いを受けた | 「相手の狙い」を言った次の手で、その狙いが消えた（次の読みで同じ狙いが出ない） | 「相手の狙いを、ちゃんと受けたね！」 |
| 自分で詰ませた | 閃きを使わずに詰ませた | 「自分の力で7手詰め！ お見事！」 |
| チャンスを生かした（N5のあと） | N5のあと、最善手か評価を保つ手を指した | 「チャンスを逃さなかったね！」 |

- 今の順番（神の一手 → 逆転 → 詰めろの受け → 手筋 → …）の中に入れる。読みは足さない。

### N11. 吹き出しを押すと「もう一言」

- 吹き出しを押すと、その助言の**理由を1行**足す（「なぜ？」）。例：「タダで取れる駒があるよ！」→押す→「相手の駒で、どの駒にも守られていない駒を探してみて」。大会の入口の「もっと聞く」と同じ形（U:2-2 同じ操作）。
- やこび姫の顔を押すと、**この対局のさっきの話**（直近3つ）を出す。6秒で次の助言に替わって読み逃した台詞を読み返せる。

## 4. 段階（おすすめの順番）

| 段階 | 中身 | 理由 |
| --- | --- | --- |
| 1 | N1 中身で言う、N4 見逃し、N5 相手のミス、N8 弱点の記憶、N10 ほめる | 読みを足さずに作れて、「何があるか」「何を逃したか」「チャンス」「上達」をすぐ伝えられる（1章の1・3・6） |

## 5. 優先度（1つの局面で出す順）

上から先に出す（今の表に新しいものを入れた形）。

1. 詰み（勝ち・負け）・王手（100）
2. 悪手の指摘と理由、**N4 見逃し**（90）
3. **N3 終盤の方針**（80）
4. 相手の狙い、**N5 相手のミス**（75）
5. **N1 中身で言う**（評価の崖の置き換え。70）
6. ほめる（**N10**を含む。60）
7. 作戦の提案、**N6 格言**（40〜50）
8. **N9 大会の物語**（30）

## 6. 機能設計メモ（`Game_Nintendo_Design.md`の14章の形）

### 機能名：やこび姫の助言の強化

- 一言で：やこび姫が「何があるか」「攻めるか受けるか」「何を逃したか」を、答えを言わずに教えてくれる。
- 解く課題（2-5）：ぼやけた知らせ・終盤の方針のなさ・チャンスの見落とし・文字だけの助言・答えをいきなり見せる閃き・記憶のなさ（1章）を、「最善手を言葉に翻訳する」1つの仕組み（N1）を中心に解く。翻訳は、評価の崖・手が止まったとき・閃きの1段目・格言の確かめで共通に使う。
- リスクとリターン（2-1）：助言は方向だけなので、自分で探す手間（リスク）と、見つけたときの気持ちよさ（リターン）が残る。答えが欲しければ閃きの3段目まで進める。
- 溜めと解放（2-2）：「タダで取れる駒があるよ」で探し始め（溜め）、自分で見つけて取る（解放）。終盤の「攻め合いで勝とう」から詰ませるまで。
- 初めての人の最初の1分：今までと同じ吹き出しに、少し具体的な一言が出る。操作は増えない。
- 上級者の深さ：「詳しい助言」を切れば今までどおり静か。閃きは「すぐ答え」にできる。
- 失敗したとき（7-1）：見逃しは責めずに知らせ、問題集の「あなたの対局」で解き直せる。
- ご褒美と使い道（5-1）：格言帳の格言、弱点を乗り越えたときのほめ言葉。
- ほめる瞬間（5-4）：AIと同じ手の連続、狙いを受けた、自分で詰ませた、チャンスを生かした、弱点を乗り越えた。
- 捨てるもの：助言で手そのもの（「▲2四歩を指そう」）を言うこと（閃きの3段目だけ）。読みを増やしてまで言うこと（N3の1回だけ）。1局面に2つ以上の台詞。
- 確かめ方：7章。

## 7. 確かめ方

- **純粋な処理のテスト**：最善手の翻訳（種類ごと、先手・後手）、見逃しの判定、相手のミスの判定、格言の条件、弱点の始めの一言と乗り越え、優先度の順番。
- **出る回数の測定**（今の`scripts/coach-plan-advice-report.mjs`と同じ形）：図鑑の代表局と低いレベルの自動対局で、各局面の読みから台詞を作り、1局あたりの回数を数える。目安は、N1が1局に3〜6回、N4・N5が低いレベルの相手で1局に1〜3回、全部の助言を合わせて「4手に1回より少し少ない」くらい。多すぎたら条件の点差を上げる。
- **ブラウザ**：3つの大きさで、吹き出し・点線の矢印・閃きの段階・もう一言を確かめる。
- **人に触ってもらう**（10-2）：初心者と、少し指せる人に詳しい助言で1局ずつ指してもらい、助言を読んだか、探したか、うるさく感じたかを後ろから見る。

## 8. 決めてほしいこと

1. **閃きの3段階（N7）**：1回の閃きで3段目まで見られる（おすすめ）／段階ごとに1回使う／今のまま（すぐ矢印）。
2. **盤に相手の狙いを描く（N2）**：点線の矢印（相手の利きの色）で出す（おすすめ）／出さない。
3. **始める範囲**：段階1から（おすすめ）／全部まとめて／選んだものだけ。
4. **しゃべる量**：「教える」助言は4手に1回まで（おすすめ）／もっと多く／もっと少なく。
