# 対局中の表示補助（2026-10-23）

- **一言で**：ひふみんアイを閃き・待ったの隣から使い、操作列が狭いときは駒の利き・駒の損得と一緒に「表示補助」へ折り畳む。
- **解く課題**：頻繁に使う盤の反転が見出しのメニューの中にある。ボタンを増やして小さくすると押し間違える。
- **利用場面と主役**：対局・検討中。盤を主役に保ち、表示の切り替えは同じ操作列で行う。
- **操作**：広い場合は3つの切り替えを直接表示。狭い場合は「表示補助」を押すと、その上に3つの大きなボタンが開く。切り替えを続けて試せるよう、ボタンを押しても閉じない。外側を押す・Esc・戻るで閉じる。折り畳みには有効な項目数を表示し、各切り替えは`aria-pressed`でも状態を伝える。
- **大きさ**：実際の操作列の幅と文字サイズ、同時に出ている操作数で判断する。各ボタンの最小幅5.5em・高さ44px以上を維持し、足りないときは3つまとめて折り畳む。開いた欄は盤の上に重ね、盤面を縮めない。
- **失敗したとき**：表示の切り替えはいつでも戻せる。確認ダイアログは出さない。狭い／広い表示が変わっても反転・利き・損得の設定は保持する。
- **変更しないもの**：棋譜・対局結果・助言の回数や盤の向きの保存方法。見出しと解析の「その他」にある既存の反転も同じ状態を使う。
- **原則**：`UI_Nintendo_Design.md` 3-2（浅い導線）・4-1（盤面優先）、`UI_Nintendo_Implementation.md` 7章（押せる大きさと分かる状態）、`Game_Nintendo_Implementation.md` 4章（頻繁な操作を待たせない）。
- **確かめ方**：PC・タブレット縦／横・スマホ縦／横で幅・高さ・重なり・はみ出しを確認。折り畳みと直接表示の両方で反転・利き・損得が切り替わり、画面の大きさを変えても状態を保持する。Escと外側で閉じること、検討中も使えることを確認する。

## 検証結果

- 2560×1440・1920×1080・1366×768・820×1180・390×844・844×390・320×568で、直接表示と折り畳みを確認。操作列が広いタブレット縦では3つを直接表示し、情報欄が狭いPCでは折り畳む。ウィンドウ全体の幅ではなく実際に使える幅で判断する。
- 3つの切り替えが動き、有効数が3になり、画面サイズ変更後も状態を保持。Esc・欄外で閉じることを確認。全ボタンが高さ44px以上で、開いた欄も画面内に収まる。
- 投了後の棋譜解析でもPC・スマホ縦・横で切り替えを確認。全1,580テスト・型チェック・公開用ビルド成功。
