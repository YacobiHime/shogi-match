# 竜王戦の仕組み（調査メモ）

調査日: 2026-10-09

大会モードで竜王戦を実装するための調査。出典は、日本将棋連盟の公式ページと、Wikipediaの「竜王戦」。
両者の記述が食い違う点や、ページに書かれていない点は、その旨を書く。実際の運用は期ごとに細部が変わるため、
このゲームでは制度の要点を簡略化して再現する（実際の規定そのものではない）。

出典:

- [竜王ランキング戦・決勝トーナメントについて（日本将棋連盟）](https://www.shogi.or.jp/match/ryuuou/rules/)
- [竜王戦（日本将棋連盟）](https://www.shogi.or.jp/match/ryuuou/)
- [竜王戦（Wikipedia）](https://ja.wikipedia.org/wiki/%E7%AB%9C%E7%8E%8B%E6%88%A6)
- [竜王戦ランキング戦のしくみ（将棋情報局）](https://book.mynavi.jp/shogi/detail/id=90106)

## 1. 全体の流れ

1988年（昭和63年）に第1期（優勝は島朗）。毎年、次の4段階で竜王に挑戦する者と竜王を決める。

| 段階 | 時期（目安） | 内容 |
| --- | --- | --- |
| ランキング戦（予選） | 前年11〜12月〜6月 | 全棋士などが6つの組に分かれ、組ごとのトーナメント |
| 決勝トーナメント（本戦） | 6月下旬〜 | 各組の上位11名のトーナメント |
| 挑戦者決定三番勝負 | 7月下旬〜9月上旬 | 決勝トーナメントの決勝だけ三番勝負。2勝した者が挑戦者 |
| 竜王戦七番勝負 | 10〜12月 | 竜王と挑戦者。4勝で竜王 |

## 2. 参加者

- 現役棋士全員、女流棋士4名、奨励会員1名、アマチュア5名（公式ページ）。
- 竜王戦独自のランキングで、棋士を1〜6組に分ける。
- 女流棋士・奨励会員・アマチュアは、6組から出場する。6組で昇級すると、次期は5組で出場する。
- 女流棋士とアマチュアは、敗者復活戦（昇級者決定戦）には出られない（公式ページ）。
- 2021年から、ランキング戦で優勝した女流棋士・アマチュアには、棋士編入試験の受験資格がある（Wikipedia）。

## 3. ランキング戦（1〜6組）

### 組の人数

| 組 | 定員 | 決勝トーナメントへ | 昇級 | 降級 |
| --- | --- | --- | --- | --- |
| 1組 | 原則16名 | 5名（優勝、2〜5位） | なし | 4名 |
| 2組 | 原則16名 | 2名（優勝、2位） | 1組へ4名 | 4名 |
| 3組 | 原則16名 | 1名（優勝） | 2組へ4名 | 4名 |
| 4組 | 原則32名 | 1名（優勝） | 3組へ4名 | 4名 |
| 5組 | 原則32名 | 1名（優勝） | 4組へ4名 | 4名 |
| 6組 | 定員なし（1〜5組以外の全員、約70名。女流・奨励会・アマを含む） | 1名（優勝） | 5組へ4名 | なし |

### 形式

- 各組とも、1回戦から勝ち抜くトーナメント。持ち時間は各5時間（チェスクロック）。
- 組み合わせは、非公表の順位に基づき、上位者と下位者が当たるように組む。前期に降級してきた4名は、準決勝まで当たらない位置に置く（Wikipedia）。
- ランキング戦で敗れた者は、敗者復活の戦いに回る。決勝戦の敗者は回らない。
  - 1組: 出場者決定戦。準決勝敗者2名で3位、2回戦敗者4名で4位、1回戦敗者8名で5位を決める。この3〜5位が、決勝トーナメントに進む。
  - 2〜6組: 昇級者決定戦。敗者を2つのブロックに分け、各ブロックの勝者2名が3位として昇級する。
  - 4・5組: 1回戦で負け、昇級者決定戦の1回戦でも負けた者は、残留決定戦（各3時間）に回る。
- 昇級の4名は、ランキング戦の決勝進出2名（優勝・準優勝）と、昇級者決定戦の優勝2名。
- 2敗失格制（Wikipedia）。ランキング戦と敗者復活戦の両方で敗れると、昇級の権利を失い、残留か降級になる。
  公式の規定ページには、この言葉は書かれていない（要確認）。

## 4. 決勝トーナメント（本戦）

- 出場者は11名: 1組から5名、2組から2名、3・4・5・6組から各1名。持ち時間は各5時間。
- 組み合わせは、ランキング戦の成績に基づいて自動的に決まる。上位の組ほど、また1・2組では組内の順位が上位なほど、挑戦者決定戦に近い位置に入る。
- 挑戦者決定戦（三番勝負）に進むまでに必要な勝数（Wikipedia）:

| 出場者 | 必要な勝数 |
| --- | --- |
| 1組優勝 | 1勝 |
| 1組2位・3位 | 2勝（1組優勝とは、挑戦者決定戦まで当たらない） |
| 1組4位 | 2勝（1組優勝に勝つ必要がある） |
| 1組5位 | 3勝（1組優勝に勝つ必要がある） |
| 2組優勝 | 2勝 |
| 2組2位 | 3勝 |
| 3組優勝 | 3勝 |
| 4組優勝 | 4勝 |
| 5組優勝・6組優勝 | 5勝 |

- 上の表は、11名のトーナメントとして整合する（各出場者の深さ`w+1`について、2^-(w+1)の和が1になる）。
  1組優勝は準決勝から、1組4位・5位は1組優勝と同じ側の山、1組2位・3位は反対側の山に入る。
  実際の対戦表の細部は、期ごとの組み合わせ表を確認する必要がある。
- 3組以下の出場者が挑戦者になった場合、七番勝負に敗れても、次期は1組に昇級する。

## 5. 挑戦者決定三番勝負

- 決勝トーナメントの決勝だけが三番勝負で、2勝した者が挑戦者になる。
- 先後は、第1局は振り駒、第2局は入れ替え、第3局は再び振り駒（Wikipedia）。

## 6. 七番勝負

- 竜王と挑戦者が対戦し、先に4勝した者が竜王になる。持ち時間は各8時間（チェスクロック）、2日制で、1日目の終わりに封じ手がある。
- 10月〜12月ごろ、全国の旅館やホテル、寺社などで行う。第39期（2026年）は、10月9・10日の第1局から、12月16・17日の第7局まで。
- 先後の決め方は、公式ページには書かれていない（要確認）。

## 7. 永世竜王

- 竜王を連続5期、または通算7期以上保持した棋士に与えられる（Wikipedia）。
- 資格者（2025年11月時点）: 渡辺明（連続5期）、羽生善治（通算7期）、藤井聡太（連続5期）。

## 8. 竜王戦と昇段（Wikipedia）

- 六段: 竜王戦2組への昇級（四段からの飛び付き昇級もある）
- 七段: 竜王戦1組への昇級、または竜王への挑戦
- 八段: 竜王位1期の獲得

## 9. このゲームでの再現

実装した内容は`docs/tournament-design.md`にある。調査の段階で挙げた論点は、次のように決めた。

1. 他の棋士同士の対局: 全員分を自動で決めて、トーナメント表に出す。
2. 規模の縮小: 5段階の規模で、組の人数、決勝トーナメントの人数、昇級・降級の人数を割合で減らす。番勝負の数は変えない。
3. 敗者復活戦: エントリー設定で入り切りを選べる。
4. 開始地点: 6組から。結果は1期ごとに保存し、昇級・降級で組が変わる。竜王になれば防衛戦、連続5期か通算7期で永世竜王。
5. 相手の強さ: 組が上がるほど強くし、難易度（10段階）で全体を上下する。初期値は、レーティングに合わせたおすすめ。
6. 持ち時間: このゲームには持ち時間の機能がないので、使わない。
7. 研修会入会試験: 竜王戦に置き換えて、削除した。
