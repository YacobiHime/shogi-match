# CPU難易度の調整方針

## 比較基準

ぴよ将棋は40段階で、公式説明では最低レベルが15級、最高レベルがアマ七段程度とされている。
また、低いレベルでも駒をただで損する手をできるだけ指さない範囲を狙いつつ、格上に勝つ場合も
あるよう調整していると説明されている。

- ぴよ将棋公式: https://www.studiok-i.net/piyo_shogi/
- ぴよ将棋公式の機能説明: https://www.studiok-i.net/ios/piyo_shogi.html

本作は異なるエンジンを使うため、nodesだけをぴよ将棋のレベルへ直接換算することはできない。
そこで、次の3要素を独立して段階化する。

1. 探索量（局面を読む精度）
2. MultiPVの候補数と選択順位（最善手を選ぶ頻度）
3. 最善手から許容する評価値損失（大きすぎる悪手の抑制）

## 低難易度の方針

- 入門は駒の動かし方を覚える人向けとし、CPUの指し手には評価探索を使わない。
- 王手放置などの反則はせず、現在の合法手からランダムに1手を選ぶ。
- 駒得、手筋、詰み、定跡は意図的に読まないため、初心者らしい見落としや手戻りが起こる。
- 入門でも助言用探索はプレイヤーへの解説のためにだけ使用し、CPUの指し手には影響させない。
- 初級、易しい、やや易しいと進むごとに候補数と許容損失を徐々に狭める。

## 中級以上の方針

- ふつうは25,000 nodes、6候補、最大500点差とする。
- やや強い以降は探索量を増やし、候補順位と許容損失を狭める。
- 藤井聡太並み（推定）は第1候補だけを選び、意図的な悪手を混ぜない。

## 作戦指定

居飛車、四間飛車などの作戦手を唯一の探索候補として強制しない。
通常探索の安全な候補に作戦手が含まれている場合だけ優先し、両取り、王手、詰みなどへの対応を
作戦指定より優先する。

## 今後の校正

名称と段級位は暫定的な目安である。固定局面テストに加え、各難易度間の自動対局を複数局行い、
隣接レベル間の勝率と一手当たり平均評価損失を記録して再調整する。
