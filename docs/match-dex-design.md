# 対局中の図鑑（2026-10-23）

### 機能名：対局中に図鑑を開く

- 目的（コンセプトとの関係）：指している最中に「この囲いの形は？」「この駒はどう動く？」「この言葉の意味は？」と思ったとき、その場で確かめられるようにする。対局を終えたりホームへ戻ったりしなくてよい。分からないことを、必要になった瞬間に1つだけ調べられる（`UI_Nintendo_Design.md` 6-1、`UI_Nintendo.md` 4-2）。
- 利用場面：対局中・検討中（通常・学習・大会・教室の対局・棋力測定）。自分の手番で迷ったときに数十秒。
- 画面の主役：対局画面では盤のまま。ボタンは見出しの操作（投了・中断・設定）の並びに置き、盤と競合させない（4-1の優先度5）。図鑑の棚では5つの図鑑の絵。
- 情報の優先順位：
  1. 盤（変えない）
  2. 見出しの「図鑑」ボタン（本の絵＋「図鑑」の字、琥珀の縁）
  3. 図鑑の棚の5つの絵と名前
  4. 棚の補足（駒の動き・うまい指し方・戦法と囲い・棋士とタイトル・ことばの意味）
  5. 「見終わったら、この対局に戻ります。」の1行
- 操作の流れ（手数）：「図鑑」→ 図鑑を選ぶ（2回）。戻るのは図鑑の「← 対局へ戻る」かブラウザの戻る（1回）で、同じ局面に戻る。
- 確認ダイアログ：出さない。図鑑を開いても対局は消えず、いつでも戻れるため（`UI_Nintendo_Design.md` 5-2）。
- 使うメッセージ分類：なし（画面の切り替えだけ）。
- 初めて使う人への伝え方：ホームの「しらべる」と同じ5つの絵と名前・同じ並びにする（`UI_Nintendo.md` 2-2 同じものは同じ見た目）。ボタンは本の絵と「図鑑」の字で、メニューの中にしまわない。画面の幅が狭くて投了・中断をメニューにしまうときも出す。
- 快の要素：図鑑はホームから開くときと同じ0.2秒の浮かび上がりで開く。
- 見ている人への配慮：図鑑を開いているあいだ、対局画面は残したまま隠す（`visibility: hidden`）。閉じると直前の一手の強調も含めて同じ盤に戻る。
- 作らないと決めたこと：
  - 対局から開いた図鑑では、将棋界図鑑の代表局のAI解析を出さない。図鑑の解析は対局用のエンジンを借りるが、同じエンジンは一度に1つの探索しかできず、CPUの手番の探索と重なるため（`AGENTS.md`のCPUの項）。
  - 定跡図鑑の戦法占いからは、新しい対局を始めない（「この作戦で指す」「完成形から指してみる」を出さず、「図鑑で見る」だけ）。指している対局が消えるため。
  - 図鑑を見ているあいだ、CPUの思考は止めない。対局の流れの処理を変えない（UIの変更とゲームロジックの変更を混ぜない。`UI_Nintendo_Implementation.md` 1章）。
  - 局面に合わせて図鑑の項目を自動で選ぶこと（いま組んでいる囲いを開くなど）。まずは開ける道を作り、使われ方を見てから考える。
- 検証方法：390×844・820×1180・1366×768で、ボタンの高さが44px以上で見出しに収まること、棚の最初の図鑑にフォーカスが移ること、図鑑を開くと画面の中央が図鑑になる（対局の部品が上に出ない）こと、戻るボタンが「対局へ戻る」で、押す・ブラウザの戻るの両方で対局画面に戻ることを確かめる。
- 根拠：`UI_Nintendo_Design.md` 3-2（浅い導線）・4-1（盤面優先）・5-2（確認の方針）・6-1（必要な瞬間に1つ）、`UI_Nintendo_Implementation.md` 3-4（操作ボタン）・7-4（44px）、`UI_Nintendo.md` 2-2・4-2。

## 検証結果

- 390×844・820×1180・1366×768で、自由対局を始めて確かめた。「図鑑」ボタンは高さ44〜47pxで見出しに収まり、スマホ縦ではメニューにしまった投了・中断の代わりに見出しに残る。
- 棚を開くと最初の「駒図鑑」にフォーカスが移る。定跡図鑑・駒図鑑・将棋界図鑑を開くと、戻るボタンは「対局へ戻る」で、画面の中央は図鑑。押す・ブラウザの戻るのどちらでも対局画面に戻る。将棋界図鑑にAI解析の欄は出ない。
