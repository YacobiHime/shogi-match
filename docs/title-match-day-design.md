# タイトル戦の二日制：1日目のまとめ・封じ手の開封・勝負メシ・観戦記

竜王戦・名人戦の七番勝負（二日制）の封じ手は、これまで「封じ手」の札を1.8秒出して「2日目」に変えるだけだった（`docs/match-stage-design.md`）。
封じ手を、1日目を見渡して息をつき、2日目へ溜めをつくる場面にする。終局後には、その1局を新聞の観戦記にして残す。

- 決めた日：2026-10-23（ユーザーの「おまかせ」。提案のおすすめのとおり、1日目のまとめ・勝負メシ・観戦記、封じ手予想あり、考えた時間の記録あり）
- 対象：タイトル戦（舞台の重さが`title`の局。`describeMatchStage`の`twoDay`）だけ。ふつうの局と大一番は変えない。

## 0. 見立て

- 封じ手は、現実のタイトル戦でいちばん「間」がある瞬間。控室では形勢と封じ手の予想が語られ、翌朝、立会人が封筒を開ける。
- いまの画面には、その「間」に見るものがない。形勢は中継の勝率バーで分かるが、1日目の流れ（どこで傾いたか）や、控室の声は見えない。
- そこで、封じ手のあとに「1日目のまとめ」を開けるようにし、2日目の始めに「封じ手の開封」の札を出す（ギュッとしてパッと解消。D:2-2）。
- 昼の休憩で勝負メシを選び、終局後に観戦記として残す。勝負メシは強さに関係しない世界の味付け（D:8-4 メニューは世界を語る）で、観戦記は期を越えて残る自分の物語（D:5-3 見返りの種類）。

## 1. 1日目のまとめ

### 機能設計メモ

- 一言で：封じ手のところで、1日目の形勢と流れと控室の声が一目で分かる。
- 解く課題：封じ手が札だけで終わり、どちらが良いのか・どう進んだのかが分からない。
- リスクとリターン：なし（見るだけ）。
- 溜めと解放：1日目の勝率の線を見て、2日目に向けて気持ちを溜める。開封の札で解放する。
- 初めての人の最初の1分：封じ手の札のあと、対局の札の「2日目」が「2日目・まとめ」のボタンになり、押すとシートが開く。
- 上級者の深さ：勝率の線・駒の損得・考えた時間の配分を見て、2日目の方針を立てる。
- 失敗したとき：なし。
- ご褒美と使い道：まとめの中身は、終局後の観戦記に使う。
- ほめる瞬間：封じ手が控室の予想と同じなら「控室の予想どおり」（開封の札）。
- 捨てるもの：シートを自動で開くこと（待たせる。D:3-3）。対局を止めること。プレイヤーの次の手を勧めること（控室の一言と同じ決まり）。
- 確かめ方：3つの画面の大きさで、シートが1画面に収まり、閉じると盤に戻ること。

### 1-1. 中身（上から優先順）

1. **形勢**：中継と同じ勝率（あなた ○%）と、1日目の勝率の線（プレイヤーの手番ごとの記録。0〜封じ手まで）。助言が「なし」で読みがないときは、勝率の行を出さない。
2. **戦型と駒の損得**：先手・後手の戦型（対局の札と同じ言葉）、駒の損得（対局の「駒の損得」と同じ点数で、「あなた +3」）と持ち駒の数。
3. **考えた時間**：プレイヤーの考えた時間の合計と、いちばん長く考えた手（「29手目 ▲4五歩・4分」）。
4. **控室の声**：3人の短い一言。
   - 立会人：名簿の年長の棋士（50歳以上で、タイトルの通算がいちばん多い人。相手は除く）。1日目の全体の感想（互角／やや指しやすい／はっきり良い）。
   - 解説：推しの棋士、いなければ羽音、それもいなければ名簿の上位の棋士（相手は除く）。戦型と駒の損得、ここ十数手の流れ。
   - 観戦記者：架空の記者。長考と勝負メシ。
   - 言うのは盤の事実だけ。どちらの次の手も勧めない。形勢は「先手」「後手」で言う（対局者を「良い・悪い」と判定しない。U:8）。
5. **封じ手予想**：控室の第1候補（封じ手の前の局面での助言の読みの最善手）。読みがなければ出さない。

### 1-2. 封じ手と開封の流れ

- 封じ手の札（今の札。1.8秒）に「控室の予想は○○」を添える（予想があるときだけ。プレイヤーはもう指しているので、答え合わせ）。
- 封じ手の札が消えたら（時間か、盤を触る）、続けて「封じ手の開封」の札を1.8秒出す：「2日目の朝 / 立会人の○○さんが封筒を開けた / 封じ手は▲4五歩」。予想と同じなら「控室の予想どおり！」、違えば「控室もうなる一手」。
- 盤の操作と相手の手は止めない（今の札と同じ）。
- 対局の札の「2日目」の札をボタンにし（「2日目・まとめ」）、押すと1日目のまとめのシートを開く。終局まで何度でも開ける。シートを開いているあいだは秒読みを止める。

## 2. 勝負メシ

### 機能設計メモ

- 一言で：タイトル戦の昼休みに、対局場の名物から勝負メシを選ぶ。
- 解く課題：タイトル戦の「旅をしている」感じが、対局場の名前だけで薄い。
- リスクとリターン：なし（強さには関係しない）。
- 溜めと解放：なし。小さな楽しみ。
- 初めての人の最初の1分：20手を越えた最初の自分の手番で、補助の欄に「お昼の休憩 / 勝負メシはどれにする？」と3つのボタンが出る。
- 上級者の深さ：対局場ごとに献立が違う（14か所×3品）。観戦記に残る。
- 失敗したとき：選ばずに指し続けてもよい。封じ手までに選ばなければ、1品目に決まる（「おまかせ」）。
- ご褒美と使い道：観戦記と1日目のまとめに載る。相手の勝負メシも中継の1行で知らせる（「昼食休憩：○○さんは天ぷらそばを注文」）。
- ほめる瞬間：なし。
- 捨てるもの：強さや助言への効果（勝負メシで有利になると、選ぶのが義務になる。D:5-8）。盤を隠す大きな札。
- 確かめ方：3つの画面の大きさで、札が盤を隠さないこと。

## 3. 観戦記

### 機能設計メモ

- 一言で：タイトル戦の1局が終わると、新聞の観戦記ふうの記事ができる。
- 解く課題：タイトル戦の1局が、勝ち負けの記録だけで終わる。
- リスクとリターン：なし。
- 溜めと解放：1日目の流れ → 2日目の分かれ目 → 終局、を記事で振り返る。
- 初めての人の最初の1分：タイトル戦の結果の窓に「観戦記を読む」が出る。
- 上級者の深さ：やこびノートの「大会」の項目に、これまでの観戦記が並ぶ（新しい順に30局まで）。
- 失敗したとき：負けた局も観戦記にする。言葉は責めない（「次の局へ、静かに闘志を燃やしていた」）。
- ご褒美と使い道：期を越えて残る。
- ほめる瞬間：勝った局の見出し。
- 捨てるもの：長い文章（5段落まで。D:8-2）。タイトル戦以外の局の観戦記（特別さが薄れる）。
- 確かめ方：勝ち・負け・封じ手の前の終局（短手数）で、文が破綻しないこと。

### 3-1. 記事の形

- 見出し：結果と分かれ目から（「挑戦者・やこび、封じ手から一気の寄せ」など）。
- 1段落目：対局場と、どちらが先手か、戦型。
- 2段落目：1日目の流れと勝負メシ、封じ手と控室の予想。
- 3段落目：2日目の分かれ目（封じ手のあとで勝率がいちばん大きく動いた手）。
- 4段落目：終局（手数・勝ち方）と、番勝負の星。
- 保存は`localStorage`のキー`yacobihime:shogi-match:kansenki:v1`（新しい順に30局）。読めなくても対局は続けられる。

## 4. 記録すること（対局の保存に足す）

大会の対局の保存（`ryuoGame`）に、タイトル戦だけ`day`を足す。リロードしても戻る。

| 項目 | 中身 |
| --- | --- |
| `rates` | `[手数, 勝率%]`の並び。助言の読みの評価値から、中継と同じ式で、プレイヤーの手番ごとに1つ |
| `think` | `[手数, ミリ秒]`の並び。プレイヤーが指した手の考えた時間（手番が来てから指すまで。1手10分で頭打ち。画面を隠しているあいだは数えない） |
| `meal` | 選んだ勝負メシ |
| `seal` | 封じ手（`{ ply, move, predicted, material, black, white }`。`predicted`は控室の予想（なければ空）、`material`はそのときの駒の損得、`black`・`white`は戦型） |

## 7. 実装（2026-10-23）

- **純粋な処理**：`src/core/title-day.mjs`（記録`emptyDay`・`normalizeDay`・`noteDayRate`・`noteDayThink`・`trimDay`、まとめ`daySummary`・`ratePoints`、控室の顔ぶれ`roomMembers`と声`roomVoices`、開封`unsealCard`、勝負メシ`lunchMenu`・`opponentMeal`、観戦記`turningPoint`・`writeKansenki`・`loadKansenki`・`saveKansenki`）。テストは`title-day.test.mjs`。
- **画面**：`src/ShogiMatchGame.vue`の`titleDay`（`ryuoGame.day`）・`sealTitleDay`・`unsealView`・`lunchOffer`・`daySummaryView`・`writeTitleKansenki`。シートは`src/TitleDaySheet.vue`（`mode`が`summary`か`kansenki`）。やこびノートの「大会」の項目に「観戦記」を足した（新しい順に3局、「すべて見る」で全部）。
- **封じ手予想**：助言の読み（`updateDedicatedCoachAdvice`）の最善手を`roomPick`に覚えておき、封じ手の1手前の局面のものを予想にする。新しい探索は足さない。助言が「なし」のとき（読みがないとき）は予想を出さない。
- **設計から変えたこと**：
  - 封じ手の札の「控室の予想」は、予想があるときだけ出す。
  - 駒の損得の言い方は、対局の「駒の損得」と同じ点数（歩が90）で、150点未満を「ほとんどない」、800点以上を「大きく」とした。
  - 立会人の名前には「さん」を付けない（「立会人の鈴木直樹九段が封筒を開けた」）。
- **確かめたこと**：390×844・820×1180・1366×768で、竜王戦の防衛戦の七番勝負第1局を、手を流し込んで進めた。22手目で勝負メシの札（3品）が出て、選ぶと中継の1行に相手の勝負メシが出ること、41手目の封じ手で封じ手の札、続けて開封の札（「封じ手は▲6九金」）が出ること、「2日目・まとめ」で1日目のまとめ（勝率の線・控室の3人の声・封じ手）が1画面に収まること、終局後に結果の窓の「観戦記を読む」で観戦記が開くことを確かめた。封じ手予想（読みの最善手）と考えた時間は、手を流し込んだので出ていない（自動テストだけ）。やこびノートの観戦記の一覧は、型チェックと自動テストだけで確かめた。実際に指して封じ手まで進めた確認は、まだしていない。
