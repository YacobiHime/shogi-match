# ホームの「強くなる道」 設計

「ホームで何を選べばいいか分からない」という声を受けた設計です（2026-10-18）。
`docs/nintendo-design/`の`Game_Nintendo_Design.md`（D）と`UI_Nintendo_Design.md`（U）に基づきます。

## 1. いまの問題

| 見つけたこと | 外れている指針 |
|---|---|
| ホームに入口が10個（自由対局・大会・終盤戦・教室・問題集・図鑑5つ）、同じ大きさで並んでいて、どれから遊ぶかが分からない | 同じ種類の選択肢は3つ程度（U:2-1）。主役を大きさ・濃さ・位置で示す（U:4） |
| 「つぎはこれ」が案内するのは教室と対局だけ。通常対局を3局指すと、ずっと「対局する」になり、問題集・大会へ案内しない | 次に学ぶ1つを示す（D:6-1）。目の前に吊られたごほうび（D:5-2） |
| いま全体のどこにいて、次に何があるかが見えない | 上達が見える（D:6-1）。でこぼこの山場が見える（D:4-4） |

## 2. 設計メモ（Game_Nintendo_Design.mdの14章の形）

- **一言で**：やこび姫と強くなる5つの段を、ホームの「つぎはこれ」の上に1本の道で見せる。いまの段の行き先を「つぎはこれ」にし、まだ早い入口はそっと薄くする。
- **解く課題**：どれを選べばいいか分からない／教室のあとに何をするか分からない／大会や問題集の出番が分からない、を1つの道で解く（D:2-5）。
- **リスクとリターン**：段を進むと、次の段の入口が明るくなる（鍵はかけない）。
- **溜めと解放**：段を終えると、道の印に丸が付き、「つぎはこれ」が次の段へ変わる。
- **初めての人の最初の1分**：道の1段目「駒を覚える」が光り、「つぎはこれ」は将棋教室。ほかの入口のうち、まだ早いもの（大会・終盤戦・問題集）は薄く、「1局指したら」のように添える。
- **上級者の深さ**：はじめての案内で「ルールは分かる」「ふだん指している」を選んだ人は、途中の段から始まる。薄くした入口も押せばそのまま遊べる（自由の余地を残す。U:6-1・D:4-1）。
- **失敗したとき**：道の段は戻らない（負けても段は下がらない）。
- **ご褒美と使い道**：段を終えるたびに「つぎはこれ」が新しい遊びへ案内する。最後の段は級・段を上げる道で、次の級までの残りを出す（D:5-2、5-5）。
- **ほめる瞬間**：やこび姫の吹き出しで、いまの段に合わせて一言かける（「駒の動き、覚えたね！ CPUと指してみよう」など）。
- **捨てるもの**：アプリの使い方を説明するチュートリアル（長い説明書は読まれない。D:6-2、U:6-1）。入口の鍵（慣れた人の自由をふさぐ）。段ごとのご褒美の画面（「つぎはこれ」が変わることで足りる）。
- **確かめ方**：将棋を知らない人に、説明なしでホームから遊んでもらい、最初に押す場所と、2回目にホームへ戻ったときに迷わないかを見る（D:10-2）。

## 3. 5つの段

段は、保存してある記録だけで決める（新しい保存は増やさない）。前の段を終えていなくても、後の段の条件を満たしていれば、その段も終えたことにする（遊び方の順番を押しつけない）。

| 段 | 名前 | 終えた条件 | 「つぎはこれ」 | おすすめの入口 |
|---|---|---|---|---|
| 1 | 駒を覚える | 教室の第1巻を終える（`v1-c2-boss`をクリアかスキップ）、または通常対局を3局以上指した、またははじめての案内で「ルールは分かる」「ふだん指している」を選んだ | 将棋教室ではじめる／将棋教室のつづき | 将棋教室 |
| 2 | 初めての対局 | CPUとの通常対局（レーティングの対象）を1局以上指した | はじめての対局（振り駒ですぐ始める） | 自由対局 |
| 3 | 詰みを覚える | 教室の第2巻を終える（`v2-c3-boss`）、または問題集を10問以上解いた、または案内で「ふだん指している」を選んで1局以上指した | 教室で詰みを覚えよう（教室の第2巻が終わっていれば問題集） | 将棋教室・問題集 |
| 4 | 竜王戦に出る | 竜王戦で1局以上指した、または1期以上を終えた | 竜王戦に出よう（大会の画面を開く） | 大会 |
| 5 | 大会で勝ち上がる（2026-10-22に「級・段を上げる」から改名。`docs/first-play-design.md`の6-3） | （終わりなし） | 対局する（次の級・段までの残りを添える）。大会への誘い（6-2）と竜王戦のつづきが中心 | 自由対局・終盤戦 |

- 中断した対局があるときは、今までどおり「対局を再開」を最優先にする。
- 入口を薄くするのは、その入口の段が、いまの段の2つ以上先のときだけ（すぐ次の段は薄くしない）。薄くした入口の説明は「1局指したら」「詰みを覚えたら」のように変える。しらべる（図鑑）はいつも薄くしない。
- 入口と段の対応：将棋教室＝1、自由対局＝2、問題集・終盤戦＝3、大会＝4。

## 4. 画面

- 道は「つぎはこれ」の札の中の上に、5つの丸を線でつないで並べる。終えた段は丸に✓、いまの段は大きく光らせる。段の名前は出さない（「つぎはこれ」の大きな見出しと重なり、見出しが2行になって1画面に収まらなくなるため）。名前は読み上げの文（「強くなる道 2/5：初めての対局」）に残す。
- いまの段のおすすめの入口には「おすすめ」の小さな札を付ける。
- 実装：段の判定は`src/core/home-roadmap.mjs`（画面から独立した純粋な処理）、画面は`src/ShogiMatchGame.vue`のホーム（`homeRoadmap`・`homeNext`）。問題集の解いた記録は、対局画面から重い`problem-set.mjs`を読まないよう、`src/core/problem-progress.mjs`に分けて読む。


## ホームのモード名に添える補足文を削除（2026-11-05、実装・自動テスト済み）

目的はホームを簡潔にすること。自由対局・大会・終盤戦・物語・将棋教室・問題集・脳トレ・図鑑のタイルから「設定を選んで1局」などの補足文を削除し、アイコンとモード名で選べるようにする（UD:2 明快、UD:4 情報の優先順位）。おすすめの印や「つぎはこれ」の説明、各モード内の説明は維持する。ブラウザの自動操作でPC・スマホ・タブレットのタイルを確認する。実際に遊んでの確認は未確認。


## 補足文を削除した後の位置調整（2026-11-05、実装・自動テスト済み）

ホームに限り補足文の空き行を廃止する。PC・横画面はアイコンと名前の1行を上下中央、スマホ・タブレットの縦画面はアイコンと名前の2行をまとまりとして上下中央に配置する。図鑑も補足文の空き列を除いた3列にする。大会の選択画面など補足文のある別画面は変更しない（UD:2 明快、U:7-5 画面の大きさと向き）。ブラウザの自動操作で文字・アイコンの中心と上下の余白を確認する。実際に触っての確認は未確認。


## ホームの押せるボタンの明るさ（2026-11-05、実装・自動テスト済み）

大会・終盤戦・問題集などを習熟段階に応じて半透明にしていた表示を廃止する。どれも押せるため、同じ明るさで表示し、操作できないボタンとの誤認を防ぐ（UD:2 明快、U:3-4 押せない状態との区別）。おすすめの縁と札は維持し、推奨先の判断自体は変更しない。ブラウザの自動操作でPC・スマホ・タブレットの全タイルの不透明度を確認する。実際に触っての確認は未確認。


## 5. スマホのブラウザで1画面に収める（2026-11-14、設計とモックアップ。ユーザーの指摘「ホーム画面のUIもスマホのブラウザで開くとスクロールしなきゃいけなくなる」）

読んだ指針: `UI_Nintendo_Design.md`（2 判断の優先順位、3-2 導線のルール）、`UI_Nintendo_Implementation.md`（7-4 操作しやすさ（押せる大きさは44px）、7-5 画面の大きさと向き（1画面に収め、ページをスクロールさせない。収まらないときは並びを変える→タブで分ける→補足の文を省くの順））、`Game_Nintendo_Design.md`（3-3 遅さは罪、すぐに遊ばせる）。

### 5-1. 今の問題（測ったこと）

スマホのブラウザは、住所の帯と下のツールバーの分だけ、見える高さが端末の高さより短い。見える大きさでホームを開き、ホームの欄（`.shogi-home`）の中身の高さを測った（ビルドした画面。はじめて遊ぶ人の保存：つぎはこれ・コツの小さな入口・記録の帯・3つの区分・引き継ぎの行）。

| 大きさ（見える部分） | 例 | 中身の高さ | 溢れ |
| --- | --- | --- | --- |
| 375×553 | iPhone SEのSafari | 625px | 72px |
| 360×640 | 小さいAndroid | 666px | 26px |
| 390×664 | iPhone 14のSafari | 684px | 20px |
| 412×780 | AndroidのChrome | 884px | 104px（文字が大きくなる分、背の高さが足りない） |
| 390×844 | ツールバーなしの全画面 | 884px | 40px |
| 844×340・820×1180・1366×768 | 横向き・タブレット・PC | 収まる | — |

縦に積んでいるもの（390×664で測った高さ）：

| もの | 高さ |
| --- | --- |
| タイトルとやこび姫の吹き出し | 79px |
| つぎはこれ | 156px |
| すぐ使えるコツの小さな入口（つぎはこれの下の1行） | 44px |
| 名前と記録の帯 | 44px |
| あそぶ・まなぶ・しらべるの3つの区分 | 255px |
| 引き継ぎ・データリセットの行 | 44px |
| すき間と上下の余白 | 約60px |

- 前に1画面に収めたあと（10-18）に、コツの小さな入口（10-31）と引き継ぎ・同期の行（11-11・11-13）が足され、44pxずつ2行増えた。
- 同期の一言（「読み込んだ」など）は、引き継ぎの行の中に1行増えて出るので、出ている数秒だけさらに長くなる。

### 5-2. 機能設計メモ（Game_Nintendo_Design.mdの14章の形）

### 機能名：スマホで1画面のホーム

- **一言で**：スマホのブラウザで開いても、ホームの全部の入口が1画面に見え、スクロールしないで選べる。
- **解く課題**：
  1. 下の区分（しらべる）と引き継ぎが画面の外に出て、あることに気づかない（UD:2 迷わない）。
  2. 指が少し動くと画面がずれ、押したいタイルの位置が変わる（U:7-5）。
  3. この先、ホームに1行足すたびに溢れる（足し方の決まりがない）。
- **リスクとリターン**：入口は1つも消さない。押せる大きさ（44px）も保つ。
- **溜めと解放**：（画面の配置なので、なし）
- **初めての人の最初の1分**：開いた画面に、つぎはこれの「はじめる」と、あそぶ・まなぶ・しらべるの全部のタイルが入っている。
- **上級者の深さ**：引き継ぎ・同期は記録の帯の横に残し、状態（同期のずれ）は印で見える。
- **失敗したとき**：見える高さが540pxより低い画面（アプリの中のブラウザなど）は、今の文字の縮め方で詰め、それでも入らなければ欄の中だけスクロールする（今と同じ）。
- **ご褒美と使い道**：（なし）
- **ほめる瞬間**：やこび姫の吹き出しは残す（5章の前の「ほめる瞬間」）。
- **捨てるもの**：
  - 引き継ぎのボタンの下の小さな状態の文字（「☁ 同期済み」など）。印に変え、文は引き継ぎのシートに出す。
  - 引き継ぎの行という1行（ボタンは記録の帯の横へ、データリセットは引き継ぎのシートの中へ）。
  - コツの小さな入口の1行（つぎはこれの札の中へ）。
- **確かめ方**：5-1の表の大きさ全部と、ホームの状態の全部（5-3の6）で、中身の高さが見える高さ以下になるかを測る。スマホを持つ人に開いてもらい、しらべるのタイルと引き継ぎを、スクロールせずに見つけられるかを見る。

### 5-3. 決めたこと

1. **目標**：縦向きで、見える高さが540px以上・幅が320px以上なら、ホームのどの状態でもスクロールしない（5-1の表の全部）。横向き・タブレット・PCは今の配置のまま。
2. **引き継ぎのボタンを、記録の帯の横に置く**（U:7-5の「並びを変える」）。
   - 記録の帯の行を「名前・記録の帯・引き継ぎ」の3つにする。帯は残りの幅を使う。引き継ぎは雲の絵と「引き継ぎ」の2語の丸いボタン（44px）。
   - 同期の状態は、ボタンの右上の小さな印にする。
     - 同期済み：緑の点。
     - どちらを使うか決める：琥珀の「!」。
     - ログアウト中：印なし。
   - 読み上げの文には状態を入れる（「引き継ぎ・同期。同期済み」）。
   - 同期の一言は、行を増やさず、記録の帯のすぐ下（「あそぶ」の見出しとタイルの上の端）に重ねて数秒出す札にする。帯の上に出すと「はじめる」の下の端にかかるため（モックアップで確かめた）。札は押せない（`pointer-events: none`）ので、下のタイルはそのまま押せる。
   - 広い画面（PC・横向き）でも同じ並びにして、どの画面でも同じ場所にする。
3. **データリセットは引き継ぎのシートの中へ**。
   - データリセットは記録の出し入れの仲間で、めったに押さない。引き継ぎのシートのいちばん下に「記録を消す（データリセット）」の行を置き、押すと今のデータリセットの選ぶ窓を開く。
   - `exhibit`の属性で出す・出さないは今のまま。
   - よく使う画面ではないので、1段奥でよい（UD:3-2）。
4. **小さな2つ目の入口（コツ・香落ちで挑む・竜王戦の対策と続き）は、つぎはこれの札の中へ**。
   - 札の下の「▶ はじめる」の行を「▶ はじめる」と2つ目の入口の横並びにする。
   - 2つ目の入口は札とは別のボタン（札の上に重ねて置く。札のボタンの中にボタンを入れない）で、文字は今と同じ下線の小さな文字、押せる高さは44px。
   - 2つ目の入口がないときは、「はじめる」が今と同じく横いっぱい。
5. **詰めるのはここまで**。
   - 文字の大きさ・タイルの高さ（44px以上）・やこび姫の吹き出し・つぎはこれの説明の2行は変えない（補足の文を省くのは最後の手。U:7-5）。
   - 5-1の測り方での見込み：375×553で約534px（19px余る）、390×664で約593px、412×780で約790px。
     - 412×780は、文字が大きい分まだ10pxほど足りない。背の低い縦向きの決まり（今の`max-height: 700px`）を`max-height: 800px`まで広げ、すき間だけ詰める（文字は縮めない）。
6. **確かめる状態**（自動の確かめに入れる）：
   - はじめての保存（コツの入口あり）。
   - 竜王戦の期の途中（対策と続き）。
   - 立て直し（香落ちで挑む）。
   - 対局を再開。
   - 同期の「どちらを使う」の印。
   - 同期の一言が出ている間。
   - データリセットを出す・出さない。
7. **これからの決まり**：ホームに行を足すときは、5-1の表の大きさで中身の高さを測り、溢れるなら既にある行の中に入れる（新しい1行にしない）。確かめの道具は`scripts/home-fit-check.mjs`（実装のときに作る）。
