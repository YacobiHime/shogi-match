# 棋力スカウター（大会の相手の戦闘力を測る）

ユーザーの依頼（2026-11-08）：「大会等で、スカウターで相手の戦闘力を測って自分と比べられるようにしたい。」

## 1. 機能設計メモ

- 一言で：次の相手の札の「スカウター」を押すと、琥珀色のレンズの中で相手と自分の戦闘力が桁を上げながら測られ、勝つ見込みとやこび姫の一言が出る。
- 解く課題：①「格上・格下」の札だけでは、どれくらい強いのかが分からない。②強さの数字（Lv）が地味で、相手の前に立つ緊張がない（D:8-1 パラメーターでキャラ立ち）。③強くなっても、自分の数字が大きくなる手ごたえがない（D:6-1 上達そのものが楽しさ）。
- リスクとリターン：測ってみて格上なら、難易度を下げる・対策をする・覚悟して挑む、を選べる（D:2-1）。
- 溜めと解放：数が跳ねながら上がる1.3秒が溜め、止まって「勝つ見込み○%」が出るのが解放（D:2-2）。相手が10倍以上だとレンズにひびが入って「計測の限界」と出る。
- 初めての人の最初の1分：次の相手の札の橙のボタンを押すと、すぐ測り始め、押せば飛ばせる。はじめたばかりでも数百、強い棋士は何十万・何億と大きな数が出る。
- 上級者の深さ：戦闘力の比がそのまま勝ちやすさの比（イロ式。1Lv=60点）なので、数字に意味がある。2Lvで約2倍。
- 失敗したとき：失敗はない（見るだけ）。
- ご褒美と使い道：自分の戦闘力は、レーティングが上がるほど大きくなる（強くなった実感）。
- ほめる瞬間：格下の相手でも「油断せずに」と言い、上から目線にしない。
- 捨てるもの：測った記録の保存、対局中のスカウター（次の候補）、序盤・中盤・終盤の内訳。
- 確かめ方：大会の何人かの相手を測ってもらい、数字の大きさと勝つ見込みが実感と合うかを見てもらう。

## 2. 決めたこと

- **戦闘力の式**：`500 × 10^(Lv × 60 / 400)`（`src/core/power-scouter.mjs`の`battlePower`）。1Lvで約1.41倍、2Lvで約2倍。Lv0で500、Lv20で約50万、Lv49で約100億。数は万・億で書く（`powerText`）。
- **比べ方**：相手は期の世界の物差しのLv、自分はレーティングのLv（大会の画面に渡している`userLevel`。「格上」の札と同じ物差し）。勝つ見込みは「自分 ÷（自分＋相手）」で、1〜99%に収める。
- **見立ての段**（相手÷自分）：10倍以上「計測の限界」（レンズにひび）、2倍以上「格上」、1.25倍以上「やや格上」、0.8〜1.25「互角」、0.4〜0.8「やや格下」、それより下「格下」。それぞれにやこび姫の一言（`SCOUTER_TEXT`）。
- **置く場所**：竜王戦・名人戦・奨励会・研修会の次の相手の札の札の並び、団体戦の次の試合の盤の一覧の下、棋士の1年の次の対局の「対 ○○」の横。分身の期（観戦）は自分が指さないので出さない。将棋まつりの指導対局も出さない。
- **見せ方**：画面いっぱいに暗くした上に琥珀色のレンズ（走査線）。測っている1.3秒は数が跳ね、上がっていく小さな音（効果音のオン/オフに従う。`waza-audio.ts`を使う）。押すと飛ばせる。動きを減らす設定では、すぐ結果を出す（U 6）。戻る操作で閉じる。
- **名前**：「棋力スカウター」。見た目はこのゲームの琥珀色の道具として作り、特定の作品の見た目は写さない。
