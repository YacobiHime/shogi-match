# Game_Nintendo_Design ― 桜井政博・任天堂のゲーム論に基づく設計の指針

機能や遊びを**設計するとき**に参照する文書です。何を作るか、なぜ面白いのか、何を優先し何を捨てるかを決める段階で使います。

- 実装時のルール（演出の段階、時間の初期値、置き場所、避けること）は`Game_Nintendo_Implementation.md`にあります。
- 画面・操作・文言などUIの指針は`UI_Nintendo.md`（根拠）、`UI_Nintendo_Design.md`、`UI_Nintendo_Implementation.md`にあります。この文書はUIではなく、**遊び・動機・難易度・ご褒美・教え方**を扱います。

## 0. この文書について

### 0-1. 範囲と資料

- 中心は桜井政博氏（『星のカービィ』『大乱闘スマッシュブラザーズ』）と、任天堂の開発者（宮本茂氏、岩田聡氏、手塚卓志氏など）のゲーム論です。

  - 動画の日本語の題名は、視聴メモ [G2] の一覧で確かめました。
  - 各回の中身は、回ごとの要約サイト [G3]〜[G9]（英語、個人）で確かめました。個人の要約なので、細部を引用するときは動画で確認してください。
- 任天堂公式サイト（社長が訊くなど）のページは、作成時の環境から直接開けませんでした。検索結果に表示された本文の抜粋で確かめた内容に限って載せています。

### 0-2. 表記

- `[G1]`などは、末尾「15. 出典一覧」の番号です。`→N:4-4`は`UI_Nintendo.md`の章番号です。

## 2. 核：何が面白いのか

### 2-1. ゲーム性とは「リスクとリターン」の駆け引き

- 桜井氏は、ゲーム性の本質を「リスクを冒してリターンを得る」駆け引きと定義しています。攻略とは「リスクを抑えてリターンを得る工夫」です [G3]『リスクとリターン』[G11]。
- CEDEC 2012の基調講演でも、ゲームデザインで最も重視するのはリスクとリターンだと述べています。リスクは「プレイヤーに押し寄せる脅威や危険性」、リターンは「その脅威を排除することやその過程」です。アイデアを溜めているのではなく、必要に応じてロジカルに組み立てているとも話しています [G18]。
- 例として挙げているのは次の作品です [G3]。
  - 『スペースインベーダー』：砲台は敵の真下に入らないと当たらない（リスクなし・リターンなし）。近づくほど撃たれやすく、倒しやすい。リターンは死の淵の近くにある。
  - 『スーパーマリオブラザーズ』：敵を踏むには、敵に最も近づいた瞬間に跳ぶ必要がある。
  - 落ちものパズル：積み上がった高さがリスク、消すことがリターン。危険を溜めたほど消したときが気持ちいい。苦手なジャンルの『メテオス』でも、この見方で基本ルールを5分で作れた [G3][G18]。
- 将棋・チェスについて、桜井氏は「駆け引きは兵力の大小ではなく、利きの範囲と配置から生まれる」と述べています [G3]『戦略シミュレーションのゲーム性』。
- ただし、リスクとリターンは面白さの一側面にすぎず、当てはまらない遊びもあるとも強調しています [G11]。

→ 補足：将棋は、駒を前に出すほど取られやすく、攻めが届く、というリスクとリターンでできた遊びです。初心者にはこの駆け引きが見えないので、「どこが危ないか」「何が取れるか」を見せることが、遊びの中心を見せることになります。

### 2-2. 「ギュッとしてパッと解消」― 緊張と緩和

- 面白さの核は、ストレスをかけてから一気に解消することです。ストレスそのものは楽しくありません。雑草を抜くように全部取り除くのではなく、越えるべき壁を置き、越えたときに解放します [G3]『ギュッとしてパッと解消』。
- 解消のあとに経験値・装備・選択肢の広がりなどのご褒美があると、ゲーム性はさらに上がります [G3]。
- 『はたして敵は必要なのか』では、「ストレス → 解消 → 成長 → 前進」の連鎖があれば、敵そのものは必須ではないと結論づけています [G3]。
- 桜井氏は、ゲームを「ストレスを与え続ける遊び」とも表現しています [G13]。

→ 補足：将棋では、王手・詰めろ・駒損の局面がストレス、受け切り・詰み・駒得が解消です。終盤ほど溜めが大きくなるので、解消の瞬間（詰み、逆転の一手）を最も強く演出する価値があります。

### 2-3. ゲーム性の外にある面白さ

- 桜井氏は、ゲーム性以外の面白さとして7つを挙げています [G3]『ゲーム性以外の面白さ』。
  1. 操作の手触り
  2. 物語や冒険
  3. 映画のような演出
  4. キャラクターや原作の魅力
  5. 現実のモチーフの再現
  6. ものづくり・組み立て
  7. リズム
- 現実のモチーフは少ない手がかりでも効きます。電車のゲームでは、ドアの開閉音や駅の足音だけで画面の外の世界を感じさせられます [G3]。

→ 補足：将棋ゲームでは「駒音」「実在の棋戦の手続き（振り駒・封じ手・タイトル戦）」が現実のモチーフに当たります。囲いを組む・定跡を完成させるのは「ものづくり」の楽しさです。

### 2-4. ゲーム性を上げると、一般性が下がる

- 駆け引きを鋭くするほど、初めての人には難しくなります。桜井氏はこれをトレードオフとして扱います [G3]『ゲーム性を上げると、一般性が下がる』。
- 初代『星のカービィ』は、危険が最大になる前に敵を吸い込めること、6回まで耐えられる体力、いつでも飛べることで、わざとリスクを軽くしています。初心者へのやさしさが作品の役割だったからです [G3]。
- 『星のカービィ 夢の泉の物語』では、初心者は吸い込みだけで進め、上級者はコピー能力を使いこなす、という形で両方を満たしました [G9]。

### 2-5. アイデアとは、複数の問題を一気に解決するもの

- 宮本茂氏の考えとして、岩田聡氏が広めた言葉です。糸井重里氏は、任天堂公式のインタビューで、岩田氏がほぼ日でこの言葉を紹介したと振り返っています [G23]。ほぼ日の書籍『岩田さん』（2019年）にも、この言葉が章の見出しとして収められています [G43]。
- → 補足：1つの機能で複数の課題（例：図鑑を開く理由、対局で戦法を試す理由、定跡を覚える理由）が同時に解けるなら、それは良いアイデアです。課題ごとに機能を足していくと、画面が増えて「簡単そう」に見えなくなります（→N:1-4, 2-1）。

### 2-6. 足し算ではなく掛け算で遊びを作る

- 『ゼルダの伝説 ブレス オブ ザ ワイルド』のGDC 2017講演では、決められた仕掛けを足していく「足し算の設計」から、物どうしが互いに作用する「掛け算の設計」へ移ったと説明されています。炎・氷・風などの状態を扱う「化学エンジン」がその土台です [G26]。
- 同作のCEDEC 2017講演では、三角形の山が「頂上へ登るか、迂回するか」という選択を生むこと、重要な建物に「引力」を持たせて自然に向かわせることが紹介されました [G25]。

→ 補足：将棋はもともと掛け算の遊びです（駒の利きが重なり合う）。機能を作るときは、新しいルールを足すより、既にある要素（利き、囲い、戦法、棋士の棋風）どうしの組み合わせで新しい場面を作れないかを先に考えます。

## 3. 手応え：触って気持ちいいか

### 3-1. 無反応をなくす

- すべての入力に、目に見える反応を返します。反応が弱い・ないと、プレイヤーは自分が操作したのかどうか分かりません。ゲームは双方向のコミュニケーションなので、常に応える必要があります [G4]『ノーリアクションを排除せよ』。
- 桜井氏は、遅延そのものにも強い不満を述べています [G10]『遅延を撲滅してほしい』。

### 3-2. 大事なところはストップ

- 大事な瞬間に一瞬だけ動きを止めると、手応えがまったく変わります。対象は次の3つです [G2]『大事なところはストップ!』[G5]。
  - 攻撃が当たった「してやった」感（ヒットストップ）
  - ボスを倒した「やった!」と余韻（ボスストップ。『星のカービィ 夢の泉の物語』では、ボスが倒れるときに画面が光る）
  - やられたときの「しまった」感
- 止め・振動・スローを組み合わせ、プレイヤーが「あれ？」と戸惑わないようにします [G2]。
- 桜井氏のファミ通コラム（Vol.490〜491）では、ヒットストップの長さは攻撃の強さで変え、上限を設けること、乱戦では長く止めすぎないことが説明されています [G15]。
- 『8つのヒットストップ仕様』では、揺れるのは見た目だけで当たり判定は揺らさないこと、揺れの幅はだんだん小さくすること、揺れの大きさを攻撃の強さとカメラの距離で変えることなどが挙げられています [G5]。
- エフェクトでは、明るく光らせるだけだと画面が白っぽくなって目立たないので、暗い色を混ぜてコントラストを保つこと（『モヤっとさせるな』）、画面の揺れは強く始めて徐々に収めること（『画面振動』）が勧められています [G8]。

→ 補足：将棋は1手ごとに時間が止まる遊びですが、「この1手は特別だ」という瞬間（神の一手、詰み、大駒を取る手）を、通常の手と同じ速さで流すと手応えが薄れます。止める長さは、手の重要度に比例させます（実装は`Game_Nintendo_Implementation.md`の3章）。

### 3-3. 遅さは罪、すぐに遊ばせる

- 遊んでいない時間（長い待ち、操作できない間、遅い進行）が問題です。ロードは避けられなくても、削れる時間は削ります [G5]『遅さは罪』。
- 画面遷移の遅いフェード、長い暗転、操作が戻るまでの間は、プレイヤーの時間を奪います。「少しせっかち」がちょうどよいとされます [G5]『画面遷移は素早く』。
- 最初の3分で面白さが伝わらないと、プレイヤーはやめてしまいます。物語の前置きより先に操作させます [G4]『とにかくゲームさせてみて』[G13]。
- 盛り上がる場面を最初に持ってきます。桜井氏は「まず、ゲームの操作をさせる！できれば敵軍の本気を見せる」と述べています。『新・光神話パルテナの鏡』では、最終ボスのメデューサが1分以内に登場します [G4][G14]『最初にクライマックスを』。

### 3-4. 音は心に直接届く

- 「名作に音が悪いものなし」。好きなゲームを思い出すと、まず音楽や効果音が浮かぶほど、音は映像や遊びより直接心に届きます [G7]『名作に音が悪いものなし』。
- 効果音は重要度で音量のバランスを取ります。プレイヤーに近い出来事ほど大きくします [G7]『重要度で効果音バランスを取る』。
- 音は誇張（フィクション）と現実味（ノンフィクション）の釣り合いで作ります。現実のパンチの音では物足りず、現実味のある音は情報を足します [G7]『音はフィクション、ノンフィクション』。

→ 補足：駒音は将棋の「現実のモチーフ」の中心です。手の重要度ごとに音を変えると、画面を見ていなくても局面の重さが伝わります。

## 4. 難しさ：誰が遊べて、誰が燃えるか

### 4-1. 初心者にはやさしく、気持ちよく

- 桜井氏は、アーケードで格闘ゲームの派手なコンボを決めた相手が、普通の女性だったと気づいて虚しくなった経験を語っています。以来、気軽な対戦では本気を出しすぎないそうです [G4]『初心者にはやさしく、気持ちよく』。
- 始めたばかりの人には敷居を下げます。ただし手を引きすぎると逆効果なので、自由の余地は残します [G4]。
- 宮本茂氏・岩田聡氏の任天堂は、ゲームをしない人を含めた「全人口」に向けた開発を掲げていました（GDC 2006の岩田氏講演「Disrupting Development」）[G42]。『Wii Sports』では、普段スポーツをしない人、たとえば「お母さん」でも触りそうな種目としてボウリングを加えています [G28]。

### 4-2. 難易度選択を、リスクとリターンにする（悪魔の釜）

- 『新・光神話パルテナの鏡』では、かんたん・ふつう・むずかしいの代わりに、ステージ前に「悪魔の釜」でホンキ度を決めます。基準は2.0です [G3][G16][G17]。
  - ゲーム内のお金（ハート）を注ぎ込むほどホンキ度が上がり、敵は強くなるが、ご褒美も良くなる。
  - ミスするとハートがこぼれ、ホンキ度が下がって続きは易しくなる。その代わり、ご褒美も手に入りにくくなる。
  - 失敗すると難しさが下がるので詰まりにくく、「かんたんモードにしますか？」と聞く必要がない。
- 桜井氏はこれを「自分に対する賭け」と表現しています [G16]。
- 一方、反省点として、常に気の抜けない緊張、広すぎるステージ、ホンキ度を下げると易しくなることが伝わりにくかった点を挙げています [G3]。

### 4-3. クリアできないよりマシ ― 安全網

- 勝つか負けるかの瀬戸際に一番の快感がありますが、何十時間も遊んだあとに先へ進めないのは深刻な問題です [G3]『クリアできないよりマシ』。
- 安全網の例は次のとおりです [G3]。
  - 何度も負けたら難易度を下げる提案をする
  - クリア扱いでステージを飛ばせる
  - 途中で難易度を変えられる
- 結論は「恥ずかしくないと感じる範囲で、安全網を用意する」です [G3]。

### 4-4. 単調な坂は山登りにならない

- 自分の強さと敵の強さが一直線に上がっていく設計は、ただの作業です。景色が変わらず、休む場所も等間隔だからです [G3]『単調な坂は山登りにならない』。
- 良い難易度の曲線はでこぼこです。ボスのような高い壁と、楽な平地を交互に置きます。敵をすき間なく並べず、空白と「おいしい場所」を置くと、探索が楽しくなります [G3]。
- 手塚卓志氏は『New スーパールイージ U』で、難易度が高いなら長いコースは疲れるので、コースを短くする必要があったと語っています [G29]。

### 4-5. ズルを許す

- 敵が勝手に倒れ続ける場所での稼ぎ、メタルスライム狩りなど、バランスを崩す抜け道は、デバッグでは消されがちです。しかし、それがゲームで一番の思い出になることも多いとされます [G3]『ズルを許す』[G13]。
- 結論は「内部のパラメーターは書き換えさせないが、ゲーム内でのある程度のズルは許す。完全に平らな道は楽しくない」です。対戦でのズルは別です [G3][G10]。

→ 補足：将棋では、CPUが同じ手に何度も引っかかる、得意な戦法でいつも勝てる、といった「ハメ」がこれに当たります。対局の正しさ（ルール・判定）は守ったうえで、プレイヤーの見つけた勝ち筋は、すぐには塞ぎません。

### 4-6. ハンデで差を縮める

- 『マリオカート』は、順位が低いほど速さの補正とアイテムの優遇を受けます [G5]『ハンデブースト』。
- 『スマブラ』は、うまさを反映することを優先し、こびない形で差を縮めています。先頭の人はスマッシュボールを取りにくく、負けている人は最後の切りふだのゲージが早くたまります [G5]。
- 最も効果が大きいのは、家で子どもや初心者相手にわざと攻撃を受けるような「人間のハンデ」だと述べています [G5]。

→ 補足：将棋の駒落ちは、何百年も使われてきた「こびないハンデ」です。

### 4-7. 平均と平凡は同じ ― 個性はとがらせる

- 弱点を補い、強みを削ると、すべてが平均に近づきます。それが最もつまらない結果です。弱点も強みと同じくらい大きくすると、個性が残ります [G5]『平均と平凡は同じ』[G3]『長所を伸ばし、短所も伸ばす』。
- 『大乱闘スマッシュブラザーズ SPECIAL』のオンライン勝率は、87体のファイターで最高51.43%、最低47.118%でした。勝率は狭い幅に収めつつ、長所と短所は大きく残しています [G5]。

→ 補足：竜王戦の棋士の棋風（攻め将棋・受け将棋、終盤の得意・苦手）は、勝率をそろえたうえで、とがらせたほうが面白くなります。

### 4-8. どれぐらい良いことをした？

- 難易度・ご褒美・罰は、プレイヤーの行為がどれだけ良かったかに見合わせます。『スマブラ』では、隙の大きいスマッシュ攻撃を当てたほうが、素早い弱攻撃より大きな威力と吹っ飛ばしを持ちます [G3]『どれぐらい良いことをした?』。
- ただし、きっちり比例させすぎると刺激がなくなります。「倒しにくいが見返りが大きい敵」のような大胆さも必要です [G3]。

→ 補足：好手・神の一手の称賛や演出の大きさは、手の難しさ（見つけにくさ、捨て駒、形勢への影響）に見合わせます。`src/core/god-move.mjs`の判定がこの考え方に当たります。

### 4-9. コンピューター相手は「反応できて、倒せる」

- コンピューターの相手には、プレイヤーが反応できる振る舞いが必要です。そうでないと不公平に感じます [G4]『コンピュータープレイヤー』。
- 体力が減ったら怒る、得意な技を多く使う、などの振る舞いで個性を出します。『スマブラSP』のCPUには反応の遅れがあり、左右の操作が反転すると一瞬混乱します [G4]。
- CPUは攻撃的だが倒せるように調整します。完璧に避けるCPUは楽しくないからです。目的は常に楽しませることです [G4]。

### 4-10. 作り手は基準にならない

- 何度も遊んだ作り手には、難しいゲームも簡単に感じます。作り手がやっと勝てるなら、それは難しすぎます [G3]『ハンデをつけてバランス調整』。
- 慣れていない人に遊んでもらうのが最善ですが、時間や慣れの問題があります。片手で遊ぶ、体力を減らすなど、作り手が自分にハンデを付けて調整する方法を勧めています [G3]。
- 結論は「自分を基準にしない。思っているより難易度を下げるのが、たいてい正しい」です [G3]。

## 5. 動機：なぜ続けたくなるか

### 5-1. ごほうび要素はまっ先に考える

- 基本の構造ができたら、早い段階でご褒美を考えます。進むことだけでは、今の動機としては弱いからです [G3]『ごほうび要素はまっ先に』。
- ご褒美は、使い道が魅力的でなければ働きません。集める・揃える・解放することは、使うこととセットで設計します [G3]。
- 例：『スマブラSP』のスピリッツがすべて最初から手に入るなら、集める喜びはありません [G3]。

### 5-2. 目の前に吊られたごほうび

- 遊んでいる最中にご褒美が見えていると、前に進む力が最も強くなります [G4]『目の前に吊られたごほうび』。
- 『イース』（PCエンジン版）は、画面の下に今の経験値と次のレベルまでの量を表示し、「あと1つ」とがんばらせます。『ファザナドゥ』は、店の品物を少なく高くして、小銭を貯めて装備を買ったときの強化を鋭く感じさせます [G4]。

### 5-3. 見返りを想定する ― ご褒美の種類

- プレイヤーには目指すものが必要なので、ご褒美の仕組みは最初から計画します。最も効くのは、お金・レベル・技などでキャラクターが強くなることです [G4]『見返りを想定する』。
- 『スマブラ』は対戦の公平さのためにキャラクターを育てられないので、ファイターの解放、フィギュア、シール、スピリッツ、音楽、ゲーム内通貨、条件を満たすとパネルが開く「挑戦（クリアゲッター）」などで見返りを作りました [G4]。
- 『カービィのエアライド』のクリアゲッターは、気軽な人にも進んでいる感覚を与えました [G9]。『スマブラDX』のフィギュアは、参戦できるキャラクターが限られる中で、任天堂の歴史を伝えるために加えられました [G9]。
- ご褒美が多すぎると迷わせますが、進歩のないゲームは味気ないとされます [G4]。

### 5-4. ほめてやれ！

- 期待どおりのご褒美を渡すだけでなく、良いプレイそのものをほめます [G4]『ほめてやれ!』。
  - 『スマブラ』：遠くへ吹っ飛ばしたときや、ぎりぎりで崖をつかんだときに観客が沸く。『スマブラSP』では、撃墜した瞬間に紙吹雪が舞う。
  - 『カービィのエアライド』：クリアのダンスに合わせて手拍子が入る。
- ありふれた出来事も、プレイヤーの気持ちに合わせて演出します [G4]。

### 5-5. スコアの見せ方

- ただの数字では、多くのプレイヤーは燃えません。身近な尺度に置き換えます。例：『脳トレ』の脳年齢、『Wii Fit』の体年齢、『スマブラ』の世界戦闘力 [G4]『スコアの見せ方』。

→ 補足：レーティングを「級・段」に置き換える、のがこれに当たります（このゲームは実装済み）。

### 5-6. ランキングの功罪

- ランキングは目標になり、腕の近い相手と組む助けにもなります。一方、低い順位は恥ずかしさを残します。「400位」「1万位」では、ほとんどやる気が出ません [G3]『ランキングの功罪』。
- 『スマブラ』の世界戦闘力は、世界中のプレイヤーに対する強さを大きな数で示します。分母が大きいので「100万位」とは出ず、最上位も表示しないので、ズルも防げます。最上位の人には「VIPルーム」で満足を与えます [G3]。

### 5-7. 作業ゲームを面白くするには ― 実りがある

- 駆け引きの少ない作業系のゲームでも夢中になれるものには、3つの共通点があります。現実のモチーフ、何かが実ること、静かに淡々と遊べること [G3]『作業ゲームを面白くするには』。
- 「実りがある」ことを最初に設計します。お金を稼いで道具を買い、作業が楽になる、という流れがないと、ゲームの寿命は大きく縮みます [G3]。

### 5-8. 外からのご褒美の注意点（一般理論）

- 金銭や賞品のような外からの報酬は、もともと楽しんでいた活動への内側からの意欲を下げることがあります（アンダーマイニング効果）。報酬がなくなると関心も下がります [G37]。
- 一方、支配されていると感じさせない、情報を伝える言葉の称賛は、意欲を高めると予測されています。報酬が能力を反映する場合も意欲が高まるとされます [G37]。
- 自己決定理論では、人の意欲を支える基本的な欲求として、自律性（自分で選んでいる）、有能感（できるようになっている）、関係性（人とつながっている）を挙げています。支配的な環境より、自律を支える環境のほうが意欲が続くとされます [G36]。

→ 補足：ほめるときは「すごい！」だけでなく「何が良かったか」を伝えると、情報としての称賛になります。ご褒美で遊びを「やらされる」形にしないことが大切です。

## 6. 学び：どう上達させるか

### 6-1. 上達そのものが楽しさになる

- ラフ・コスターの『A Theory of Fun』は、脳が新しいことを学ぶと報酬を与えるのでゲームは楽しい、という考えで知られます。単純すぎても複雑すぎても楽しくならず、三目並べのように覚え尽くせる遊びはすぐ退屈になる、とされます [G35]。
- フロー理論（チクセントミハイ）では、深い没入が起きる条件として、課題と技能の釣り合い、明確な目標、すぐ返ってくるフィードバックが挙げられています [G38]。
- ゲームニクス理論の「段階的な学習効果」「いつの間にか上達している」も同じ方向です（→N:4-1）。

→ 補足：将棋は覚え尽くせない遊びなので、退屈より「どこを学べばいいか分からない」ことが問題になりやすいです。次に学ぶ1つを示し、上達を見せることが、このゲームの楽しさの中心になります。

### 6-2. 自然なチュートリアル

- 無機質な練習場より、本番の戦闘の中で覚えさせるほうが、ワクワクも生まれます。操作説明が必要なら、世界観に合わせて「やらされている」感じをなくします [G4]『自然なチュートリアル』。
- 長い文字の説明書と、無機質な練習場の両方を避けます。『スマブラ』のデモ映像は、遊びながらテクニックを教える案が何度も失敗した末に生まれたものです [G5]『How to Play』。
- 言語が読めなくても遊べるようにします。最悪の場合でも、ボタンを連打すれば本編が始まるようにしておく、という考え方です [G6]『言語がなくてもわかるように』。
- 必要な瞬間に必要なことだけ教える、テキストは最後の手段、という任天堂の考え方は`UI_Nintendo.md`にあります（→N:4-2, 4-3）。

### 6-3. 強制感と攻略の自由

- 「目を撃って、ひるんだら斬る」のように攻略法が1つに決まったボスは、チュートリアルのように感じられます。桜井氏はプレイヤーとしては自由を好みます [G3]『強制感と攻略バランス』。
- 試行錯誤で攻略法を見つけるのも、多彩な手段を試すのもゲームです。どちらが正しいということはなく、作り手が狙いを決める必要があります [G3]。

### 6-4. 学習アプリの事例

- **Duolingo Chess（2025年）**：駒の動かし方から始め、「ビショップをここへ」という誘導つきの課題から、「2手で詰ませる手を探せ」のような自由な課題へ、少しずつ難しくします。定跡は暗記させず、問題を解き戦術を指して学びます。コースの約75%が問題形式で、残りはコーチ役のオスカーとの短い対局と通常の対局です。間隔をあけた復習で、前に学んだ戦術を思い出させます [G31]。
- **どうぶつしょうぎ（2008年考案）**：女流棋士の北尾まどか氏が、駒の名前や動かし方を知らない子どもでも遊べるように考案しました。3×4マスの盤と8枚の駒を使い、駒に動ける方向の印を付けています [G39]。
- **世界のアソビ大全51**：5五将棋を「普通の将棋のクライマックスから遊べる、マリオでいえばいきなりクッパとの戦いから楽しめるようなルール」と紹介されています [G30]。

→ 補足：盤を小さくする・駒を減らす・終盤から始める、は「最初にクライマックスを」「初心者にはやさしく」を将棋で実現する定番の方法です。

### 6-5. チェス・将棋アプリの事例

- **Chess.comの手の分類**：「Brilliant（!!）」は、良い駒の犠牲を見つけた手で、最善かほぼ最善のものに付きます。指したあとに悪い局面になる場合や、すでに完全に勝っている場合は付きません。レーティングの低い人には、駒の犠牲の判定を甘くしています。終局直後は速い解析で分類し、詳しい振り返りで分類が変わることもあります [G33]。
- **Lichessの問題**：問題にも対局と同じGlicko-2の評価を使い、1回の挑戦を「問題との対局」として扱います。テーマを選んで解く問題は、テーマがヒントになるので評価の変動を小さくしています [G34]。
- **将棋ウォーズ**：対局で使った囲い・戦法・手筋を200種類以上コレクションでき、派手な演出が特徴として紹介されています [G40]。

→ 補足：手の分類は「どれぐらい良いことをした？」（4-8）を数値で決める仕組みです。このゲームの神の一手の基準（`src/core/god-move.mjs`）も、見つけにくさ・捨て駒・形勢を加味しています。コレクションは「ごほうびはまっ先に」（5-1）の将棋での実例です。

## 7. 負け：失敗が嫌にならないか

### 7-1. リトライは迅速に

- やられてから操作が戻るまでの時間が、いらだちの溜まる時間です。冷める前に、できるだけ早く操作を戻します [G3]『リトライは迅速に』。
- やられたことは伝わる必要があります。演出は派手でも短く、1秒〜数秒にとどめます [G3]。
- 復活直後に攻撃されないようにします。操作する前に何度もやられると、ゲームを嫌いになります。ただし、その場で無限に復活できると考えなくなるので、それも避けます [G3]。

### 7-2. 勝った人も負けた人も楽しい

- 海外の研究として、対戦型FPSでは勝ったときに不安、負けたときに安堵を感じる、という結果が紹介されています。桜井氏は、すぐに次を始められれば負けを引きずらないこと、勝っても次に負けるかもしれないので勝利そのものはご褒美になりにくいことを挙げています [G3]『やられるとスッキリする?』。
- 最良なのは、勝った人も負けた人も楽しいことです。対戦は相手を打ち負かすことだけではありません [G3]。
- 『マリオ』は、失敗したときに自分が悪いと思えるバランスで作られており、それが「もう1回」につながるとされます（→N:4-4）。

### 7-3. やり直しに見合う魅力はあるか

- 繰り返し遊ぶ仕組みを真似ても、続ける理由がなければ働きません。主な理由は「先を見たい」という気持ちです。同じ場所を繰り返すとき、プレイヤーに何が見えているかを考えます [G3]『やり直しに見合う魅力はあるか?』。

→ 補足：将棋の負けは、1局が長いぶん重くなりがちです。「負けた局面からもう一度」「敗因の1手だけ見る」のように、やり直しの単位を小さくすると、負けが次の挑戦に変わります。

## 8. 人と世界：キャラクターと観る楽しみ

### 8-1. パラメーターでキャラ立ちを

- キャラクターは、中立の基準から外れた「とがった」能力を持たせると立ちます。特徴は一言で言えるくらい鋭くします [G4]『パラメーターでキャラ立ちを』。
- 『星のカービィ』のゴルドーは、無敵で攻撃しないので単独では退屈ですが、ほかの敵と組み合わせると意味が生まれます [G4]。
- まずでこぼこに作り、問題をあとで直すよう勧めています [G4]。

### 8-2. ゲームのシナリオは特異

- ゲームのシナリオには、他の媒体と違う点が4つあるとされます [G4]『ゲームのシナリオは特異』。
  1. 長いムービーは遊びの邪魔になり、いらだたせる
  2. プレイヤーは主人公の目で見るので、他のキャラクターの長い過去話は合わない
  3. 勝ったのに負けたように感じさせる展開は不公平
  4. 仲間の死や離脱は扱いにくい
- 遊びから始めて、物語はその後に渡します [G4]。

### 8-3. 応援する楽しみ

- 観戦は、どちらかに肩入れすると面白くなります。『スマブラ』の観戦モードでは、リプレイにポイントを賭けられます。予想の意味は小さくても、誰かを応援する小さな理由になります [G4]『応援する楽しみ』。
- 任天堂の「将棋3席」の考え方（遊んでいる人だけでなく、見ている人も楽しい）は`UI_Nintendo.md`にあります（→N:6-1）。

### 8-4. メニューは世界を語る

- 同じ遊びでも、UIやフォントで、かっこよく・かわいく・怖く感じさせられます。フォントとUIは世界観の包装紙です [G6]『メニューは世界を語る』。

## 9. 時間と暮らし：どのくらい、どこで遊ぶか

### 9-1. いただく時間を意識する

- プレイヤーは時間をコストとして量ります。面白くても300時間かかるゲームは、買う前にためらわれます。長く遊ぶのは楽しさの結果であるべきで、水増しではいけません [G4]『いただく時間を意識する』。
- ゲームはSNSや手軽な娯楽に比べて始める敷居が高いので、その敷居を越える魅力が要ります [G4]。

### 9-2. 遊びを暮らしに合わせる

- 『どうぶつの森』のディレクター江口勝也氏は、仕事が忙しく家族と一緒にゲームを遊べなかった寂しさから、時間をずらして遊べる仕組みを考えたと語っています。昼に子どもが残した手がかりを、夜に帰った親が使って先へ進む、というリレーの構想でした [G27]。
- 宮本茂氏は、自分の趣味をゲームにしてきました。庭いじりから『ピクミン』、犬を飼い始めて『Nintendogs』、健康への関心から『Wii Fit』です [G19]。
- Duolingoの連続記録（ストリーク）は、短い時間でも毎日続ける習慣づけのために作られています。連続が2日から3日になると50%の増加ですが、200日から201日は0.5%なので、初めのうちは伸びるたびに達成感が大きく、長くなると「失いたくない」気持ちが主な動機になる、と説明されています。1日休んでも記録が途切れない「ストリークフリーズ」は、少しの「ゆとり」が厳しい決まりより意欲を保つという研究に基づくとされます [G32]。

→ 補足：毎日の習慣は強い動機になりますが、途切れたときに責める作りにすると、遊びが義務になります（5-8の自律性）。休んでも責めない仕組みとセットで考えます。

## 10. 作り方：どう確かめるか

### 10-1. 小さな試作を並行し、楽しさが固まってから作る

- 岩田聡氏はGDC 2009の基調講演で、宮本茂氏の開発手法を紹介しました [G19]。
  - アイデアを1〜2人の小さなチームで試作し、複数を並行して進める。
  - 試作の期間は区切らず、2年に及ぶこともある。
  - 遊びの核の楽しさが固まったものだけを本制作に移す。お蔵入りの試作を後で再挑戦することもある。
  - 制作前に楽しさが固まるので、完成形を想像しやすく、開発期間も読みやすくなる。
- 『スプラトゥーン』は、2013年初めに集められた10人が、半年で約70の企画と数本の試作を作るところから始まりました。野上恒氏は、「勝つためにインクを塗ると、相手に居場所を知られてしまう」というジレンマが、面白くなりそうだと感じた点だったと述べています [G24]。
- 同作では「主人公はイカ」「少しヘンな世界」という大きな器だけを先に決め、スタッフが中身を膨らませました。新規のプレイヤーが多いと予想して、初めはモードを絞り、長い時間をかけて増やす方針をとりました [G24]。

### 10-2. 遊ぶ人を後ろから見る

- 宮本氏は、開発と関係のない社内の人を「さらって」試作を遊ばせ、すぐに分かるかどうかを後ろから見ます。20年続けている習慣だとされます [G20]。
- 岩田氏によれば、宮本氏は質問もせず、何に退屈し、何を楽しみ、何に引き込まれるかを、反応を見るだけで確かめます [G21]。
- 『ドンキーコング バナンザ』では、宮本氏が先へ進まず1か所で壊したり掘ったりし続けたことを、プロデューサーは「プレイヤーが興味を持てるものがたくさんある証拠」と受け止めています [G41]。

### 10-3. ちゃぶ台返し

- 宮本氏は、開発の途中でもプロジェクトを根本から揺さぶることがあり、これは「ちゃぶ台返し」と呼ばれます。岩田氏は、壊れたものはないので一からやり直す必要はないと説明する一方、時間がかかることも認めています [G22]。

### 10-4. 分解・考察・再構築

- 独自のものを作るには、面白い要素を部品に分け、なぜ面白いかを考え、自分の形に組み直します [G4]『分解、考察、再構築』。
- 例：レースゲームのドリフトは危険と見返りのある技なので、ドリフト全体を速くするのではなく、ブレーキで溜めてドリフトし、カーブの終わりで解放すると加速する、という形に組み直しました。これが『カービィのエアライド』になりました [G4]。
- 既存の仕組みをなぜ面白いのかを考え直すと、真似より独自のゲームになります [G3]『ギュッとしてパッと解消』。

### 10-5. 「〜みたいなゲーム」で終わらせない

- 新しいゲームを「〜みたい」と説明すると、元の作品を遊べばよくなります。比較の対象は世代によっても違います [G4]『あるものでしかわからない』。
- 好きな作品を手本にするのは良いことですが、元の作品にない魅力をいくつも持たせる必要があります [G4]『同じような作品』。

## 11. この将棋ゲームへの適用

原則ごとに、いまの機能と、設計を考えるときの問いを並べます。「いまの機能」は2026-10時点の実装です。「設計の問い」はすべて「→ 補足」に当たる応用です。

| 原則 | いまの機能 | 設計の問い |
|---|---|---|
| リスクとリターン（2-1） | やこび姫の助言（悪手・詰めろ・取られそうな駒）、駒の利きの表示 | 初心者に「どこが危なく、何が取れるか」が盤上で見えているか |
| 緊張と緩和（2-2） | 王手の表示、終局の演出 | 溜め（終盤の攻防）に見合う解放（詰み・逆転）の瞬間を作れているか |
| 掛け算（2-6） | 戦法×囲い×棋士の棋風、序盤傾向の設定 | 新しいルールを足す前に、既存要素の組み合わせで新しい場面を作れないか |
| 無反応をなくす（3-1） | 駒の着地アニメ、駒音2種 | 選択・移動・取る・成る・王手・詰みのすべてに、区別できる反応があるか |
| 大事なところはストップ（3-2） | 神の一手の判定（1局3手まで） | 特別な手が、普通の手と同じ速さで流れていないか |
| 遅さは罪（3-3） | 「つぎはこれ」1つ、CPU思考中のゲージ | 開いてから最初の1手まで、負けてから次の1手までの時間は最小か |
| 初心者にはやさしく（4-1） | Lv0〜10のロジックAI、将棋教室、はじめての案内 | 初めての人が、最初の数分で「指せた」「勝てた」と感じられるか |
| 悪魔の釜（4-2） | 難易度はLvで選ぶ | 強い相手を選ぶことに見返り（称号・記録）があるか。負けたら易しくする提案が恥ずかしくないか |
| 安全網（4-3） | 閃き・待ったの回数を選べる | 何度負けても先へ進めない場面がないか（教室・大会） |
| でこぼこ（4-4） | 竜王戦の組と番勝負、教室の巻と章 | 難しさが一直線に上がるだけになっていないか。山場と平地があるか |
| 平均と平凡（4-7） | 棋士の棋風と得意・苦手 | 棋士の個性を一言で言えるか。勝率はそろえつつ、とがっているか |
| 反応できて倒せるCPU（4-9） | 詰みを見逃す確率、棋風による手の選び方 | CPUの負け方が「人間らしいミス」に見えるか。理不尽な強さに見えないか |
| ごほうびはまっ先に（5-1） | 称号、レーティング、教室の★、問題集の記録 | 集めたものに使い道（見た目の変更、新しい相手、台詞）があるか |
| 吊られたごほうび（5-2） | 次の級までの残り | 対局中・対局直後に、次の目標と残りが見えているか |
| ほめてやれ（5-4） | 好手・神の一手の称賛、終局の紙吹雪 | 何が良かったかを伝えているか。ありふれた良い手も拾えているか |
| 自然なチュートリアル（6-2） | 必要な瞬間の助言、教室のレッスン | 説明を読む前に盤で触れているか。誘導から自由へ段階的に移っているか |
| リトライは迅速に（7-1） | 対局の振り返り、感想戦 | 負けてから「もう一度」までの手数と時間は最小か。やり直しの単位は小さいか |
| 勝者も敗者も楽しい（7-2） | 振り返り、敗着の説明 | 負けた後の画面が、責めずに次の一手を示しているか |
| キャラ立ち（8-1） | やこび姫の表情・台詞、棋士名鑑 | やこび姫と棋士たちの性格が、台詞と振る舞いで一貫しているか |
| 応援する楽しみ（8-3） | 竜王戦の自動対局、棋士名鑑 | 他の棋士の対局に肩入れする理由（推しの棋士、予想）があるか |
| いただく時間（9-1） | 中断と再開 | 1局が長い将棋で、短い時間でも遊べる単位（問題、終盤からの対局）があるか |

## 12. 判断に迷ったとき

設計で迷ったときは、上から順に優先します。

1. **将棋として正しいか**：ルール・判定・解析の正しさを、演出やご褒美のために曲げない。
2. **遊びの中心が見えるか**：駆け引き（どこが危ないか、何が取れるか）が伝わる（2-1）。
3. **待たせないか**：遊ぶまで、やり直すまでの時間を削る（3-3, 7-1）。
4. **初めての人が置いていかれないか**：一般性を下げすぎない。上級者向けの深さは別に用意する（2-4, 4-1）。
5. **気持ちいいか**：反応・止め・音・ほめ言葉（3章, 5-4）。
6. **続けたくなるか**：ご褒美・記録・次の目標（5章）。ただし義務にしない（5-8, 9-2）。

- 新しい機能を足す前に、「既存の機能の組み合わせで解けないか」「1つの機能で複数の課題を解けないか」を確かめます（2-5, 2-6）。
- 自分（作り手）が遊んで簡単だと感じても、それを基準にしません（4-10）。

## 13. 設計レビューのチェックリスト

### 13-1. 核

- [ ] この機能の面白さを一言で言えるか [2-1, 10-5]
- [ ] リスクとリターン（何を賭けて、何が得られるか）がプレイヤーに見えるか [2-1]
- [ ] 溜め（ストレス）と解放があり、解放のあとに成長や前進があるか [2-2]
- [ ] 1つの機能で、複数の課題を同時に解いているか [2-5]
- [ ] 足し算（新しいルール）より、掛け算（既存要素の組み合わせ）を先に検討したか [2-6]

### 13-2. 手応え

- [ ] すべての操作に、目に見える反応があるか [3-1]
- [ ] 特別な瞬間（神の一手、詰み、逆転）に、止め・音・ほめ言葉があるか [3-2, 5-4]
- [ ] 遊び始めるまで、やり直すまでの時間を最小にしたか [3-3, 7-1]
- [ ] 音だけでも、出来事の重さが伝わるか [3-4]

### 13-3. 難しさ

- [ ] 初めての人が、最初の数分で手応えを得られるか [3-3, 4-1]
- [ ] 上級者向けの深さを、初心者の道をふさがない形で用意しているか [2-4]
- [ ] 難易度を選ぶこと自体に、リスクとリターンがあるか [4-2]
- [ ] 何度失敗しても進めない場所に、恥ずかしくない安全網があるか [4-3]
- [ ] 難しさの曲線に、山場と平地があるか [4-4]
- [ ] プレイヤーが見つけた勝ち筋（ズル）を、正しさを守る範囲で残しているか [4-5]
- [ ] 個性（棋士・戦法）を平均に寄せすぎていないか [4-7]
- [ ] 見返りの大きさが、行為の良さ・難しさに見合っているか [4-8]
- [ ] CPUの振る舞いは、反応できて倒せるものか [4-9]
- [ ] 作り手以外（慣れていない人）で難しさを確かめたか [4-10, 10-2]

### 13-4. 動機

- [ ] ご褒美を、遊びの骨組みと同時に設計したか。使い道があるか [5-1]
- [ ] 遊んでいる最中に、次の目標とそこまでの残りが見えるか [5-2]
- [ ] ご褒美の種類と量が、迷わせない範囲か [5-3]
- [ ] 良いプレイを、何が良かったか分かる形でほめているか [5-4, 5-8]
- [ ] 数字を、身近な尺度に置き換えているか [5-5]
- [ ] 順位や記録が、低い人に恥をかかせていないか [5-6]
- [ ] 外からのご褒美で、遊びを「やらされる」形にしていないか [5-8]

### 13-5. 学び

- [ ] 説明を読む前に、盤で触れられるか [6-2]
- [ ] 誘導つきの課題から、自由な課題へ段階的に移っているか [6-3, 6-4]
- [ ] 前に学んだことを、間をあけてもう一度使わせているか [6-4]
- [ ] 上達したことが、プレイヤーに見えるか [6-1]

### 13-6. 負け

- [ ] 負けてから次の挑戦までが短いか。やり直しの単位は小さいか [7-1, 7-3]
- [ ] 負けの演出は短く、責めていないか [7-1, 7-2]
- [ ] 負けた原因が、自分で納得できる形で示されるか [7-2]

### 13-7. 人と世界・時間

- [ ] キャラクターの個性を一言で言え、台詞と振る舞いで一貫しているか [8-1]
- [ ] 長い説明や会話で、遊びを止めていないか [8-2]
- [ ] 見ている人・応援する人にも楽しさがあるか [8-3]
- [ ] プレイ時間を水増ししていないか。短い時間でも遊べる単位があるか [9-1]
- [ ] 習慣の仕組みが、途切れたときに責める作りになっていないか [9-2]

### 13-8. 作り方

- [ ] 本格的に作る前に、小さな試作で遊びの核を確かめたか [10-1]
- [ ] 作った人以外に、説明なしで遊んでもらい、反応を見たか [10-2]
- [ ] 「〜みたい」で説明できてしまわない、独自の魅力があるか [10-5]
