# 棋士の世界を1つにする・やこびノートの大会と棋士名鑑・コレクションの作り直し

2026-10-22の設計。まだ実装していない。ユーザーが決めた次の4つで作る。

1. やこびノートの項目は「大会」と「棋士名鑑」に分ける。
2. 2つある棋士の世界は、1つの世界に作り直す。
3. 着せ替えは、コレクションの中の別のページにする。
4. 集めた戦法・囲いは、完成形の小さな盤のカードで見せる。

## 1. 今の問題

### 1-1. やこびノートに名人戦がない

- 項目は「まとめ・成績・戦法・竜王戦・コレクション・設定」の6つ。
- 「竜王戦」には、竜王戦の歩み（組の階段・参加期数・これまでの成績）と、棋士名鑑が入っている。
- 名人戦の歩みと賞状帳は、ノートのどこにもない。
- 棋士名鑑は「竜王戦」の下に隠れていて、竜王戦の組でしか探せない。

### 1-2. 棋士の世界が2つある（いちばん大きい問題）

- **名簿（`ryuo-roster.mjs`、キー`yacobihime:shogi-match:ryuo-roster`）**
  - 棋士ごとに次のものを持つ: 竜王戦の組、順位戦のクラス（`member.junni`）、タイトル、通算成績、プレイヤーとの対戦成績（`vsUser`）。
  - 竜王戦の期が終わるたびに、「棋界の1年」（`ryuo-league.mjs`の`playLeagueYear`）が順位戦と名人戦を含む7つのタイトル戦を自動で進める。
- **名人戦のキャリア（`meijin.mjs`、キー`yacobihime:shogi-match:meijin-career`）**
  - 名人戦モードの順位戦の世界（`league`: クラスごとの順位の並び・降級点・名人）を、名簿とは別に持つ。
  - 最初の期は名簿の`junni`から作る。そのあとは、期の始めに名簿と照らし合わせ、引退した棋士を外して新四段を足すだけ。
- このため、次のような食い違いが起きる。
  - 名人戦でプレイヤーや羽音が名人になっても、名鑑の「タイトル保持者」の名人は名簿の名人のまま。
  - 名人戦で昇級した棋士が、名鑑では元のクラスのまま。
  - 竜王戦の期が終わると、名簿の順位戦が勝手に1期進む。名人戦の世界とは別に進むので、名人が2人いるように見える。
  - 名人戦の対局は、名簿のプレイヤーとの対戦成績に数えない。

### 1-3. 棋士名鑑が読みにくい

- 一覧は名前・段位・棋風の文字だけで、顔（判子）がない。
- あなたとの対戦成績は、開かないと分からない。
- 開くと、その場で長く伸びる（`<details>`）。1つの組に数十人いるので、どこを見ていたか分からなくなる。

### 1-4. コレクションが読みにくい

- 印は121個。0個のときは、灰色の文字の札が全部並び、スマホでは約2100pxの縦スクロールになる。
- 着せ替え（使うもの）と印（集めるもの）が、同じ画面に混ざっている。
- 次に取れそうな印が分からない。
- 「Lvの壁」は1〜40の数字が並ぶだけ。

## 2. 棋士の世界を1つにする（データ）

### 2-1. 考え方

- **棋士の世界は名簿1つにまとめる。**
  - 順位戦の世界（クラスごとの順位の並び・降級点・名人）は、名簿の中に`junni`として持つ。
  - 名人戦のキャリアには、プレイヤー自身の歩み（期数・最高クラス・名人の期数・永世名人・これまでの成績・設定）だけを残す。
- **書き込む関数は1か所にする。**
  - 順位戦の世界を変えるのは、`junni-world.mjs`（新設）の関数だけにする。
  - 棋士の`member.junni`と、名簿の名人（`roster.titles.meijin`）は、その関数が順位戦の世界から写す控えにする。
  - 名鑑・対局相手の紹介・昇段の規定は、この控えを読むだけで、自分では書き換えない。
- **順位戦は「名人戦の期」でしか進まない。** 進め方は次の2つで、どちらも同じ`advanceJunni`を使う。
  1. プレイヤーが名人戦を指す。プレイヤーのクラスは実際の成績で決め、ほかのクラスは自動で決める（今の`advanceLeague`）。
  2. プレイヤーが名人戦に一度も出ていない間は、棋界の1年（竜王戦の期の終わり）が、名人戦の1期を自動で進める。順位戦と名人戦七番勝負を含み、プレイヤーはいない。
- 名人戦に初めて出たら、棋界の1年は順位戦を進めなくなる。名人戦の暦は竜王戦とは別（`docs/meijin-design.md`の13章の案B）なので、名人戦を指さない間は、順位戦の世界はその期のまま止まる。
- 竜王以外の6つのタイトル（王位・叡王・王座・棋王・王将・棋聖）は、今までどおり棋界の1年で決める。名人は棋界の1年のタイトル戦から外す。

### 2-2. 名簿の`junni`

```js
roster.junni = {
  no: 12,                 // 何期目の順位戦まで終えたか(名人戦の期の番号)
  holder: 'p17' | 'user' | null,  // 名人
  classes: { A: [...], B1: [...], B2: [...], C1: [...], C2: [...] }, // 順位の並び(上が1位)。'user'はプレイヤー
  points: { [id]: 0..3 }, // 降級点
  even: { [id]: true },   // 前の期に指し分け以上(降級点を消す条件)
  free: [...],            // フリークラス(順位戦に出ない)
  userJoined: false,      // プレイヤーが名人戦に出たか(出たら、棋界の1年は順位戦を進めない)
};
```

### 2-3. 世界を変える場面

| 場面 | すること | 関数 |
|---|---|---|
| 名簿を作る | 強い順にクラスへ並べる（今の`seedJunni`と同じ）。名人は過去の履歴の最後の名人 | `createJunni(roster)` |
| 名人戦の期を始める | プレイヤーがまだいなければC級2組の最後に入れ、`userJoined`を真にする。期は世界の写しで指す（今と同じ） | `joinJunni(roster)` |
| 名人戦の期が終わる | `advanceJunni`で次の期の世界を作り、名簿へ書き戻す。名人が替わったら、名簿のタイトル・獲得期数・タイトルの履歴・段位（九段）も直す | `applyMeijinSeasonToRoster(roster, season)` |
| 棋界の1年（`userJoined`が偽のときだけ） | 名人戦の1期を自動で進める（全クラスを自動、A級1位と名人の七番勝負も自動） | `autoJunniSeason(roster, rng)` |
| 引退・新四段（竜王戦の期の終わり） | 引退した棋士をクラスから外し、新四段をC級2組の最後に足す。名人が引退したら名人は空き | `syncJunni(roster)` |
| 名人戦の期の途中に、棋界の1年が来た | 期の写しはそのまま指す。期の終わりに`advanceJunni`の結果へ`syncJunni`をもう一度かける | `applyMeijinSeasonToRoster`の中 |

- 名人戦の期（`meijin-season`）は、今と同じく、期の始めの世界の写し（`league`・`players`・`ratings`）で指す。期の途中で名簿が変わっても、期の中身は変えない。

### 2-4. プレイヤーとの対戦成績

- `roster.vsUser[id]`に、大会ごとの内訳を足す。

  ```js
  { wins, losses, streak, lastNo, lastWin, byEvent: { ryuo: { wins, losses }, meijin: { wins, losses } } }
  ```

- 名人戦の対局も、終局で`vsUser`に数える（今は竜王戦だけ）。名鑑とVS画面の「対戦成績」は、両方を合わせた数にする。

### 2-5. 保存の移しかえ

- 名簿の版を3から4に上げる（`ROSTER_VERSION = 4`）。読み込むときに、版3の名簿を次の順で移す。
  1. 名人戦のキャリアに`league`があれば、それを名簿の`junni`にする（`userJoined`は真）。名人は`league.holder`にし、名簿の名人と食い違えば、名人戦のほうを正にする。
  2. なければ、名簿の`member.junni`と`roster.titles.meijin`から`junni`を作る（`userJoined`は偽）。
  3. 名人戦のキャリアからは`league`を消し、版を2に上げる。
- 進行中の名人戦の期（`meijin-season`）は、そのまま続けられる（期は写しで指すため）。
- テストでは、版3の名簿と名人戦のキャリアの組み合わせ（名人戦なし・進行中・終えた期あり・名人がプレイヤー）を移し、次のことを確かめる。
  - クラスの人数
  - 名人が1人であること
  - プレイヤーがどのクラスにも1回だけいること

### 2-6. ほかへの影響

- `createMeijinSeason`・`describeMeijinSeason`は、`career.league`の代わりに`roster.junni`を受け取る。
- 名人戦の入口の「名人 ○○」・五重塔・羽音の位置は、`roster.junni`から読む。
- 竜王戦の名鑑・VS画面・相手の紹介のクラスは、控えの`member.junni`を読む（変えない）。
- 後で作る棋士モードは、この1つの世界の上に作る（名人戦の設計の方針どおり）。

## 3. やこびノート: 大会と棋士名鑑

### 3-1. 項目

- 項目は「まとめ・成績・戦法・**大会**・**棋士名鑑**・コレクション・設定」の7つにする。
- スマホでは、上の切り替えを4列2段にする。「棋士名鑑」は短く「名鑑」と書く。
- 前に「竜王戦」の項目を開いていた人は、「大会」を開く（保存した項目の`ryuo`を`tournament`に読み替える）。

### 3-2. 大会

上から次の3つのカードを並べる。

- **竜王戦**
  - 今と同じ: 組の階段、現在・参加・挑戦者・竜王の札、連続と最長、これまでの成績（新しい5期）。
- **名人戦**
  - 五重塔の小さな階段（C級2組〜A級・名人。自分の階に「あなた」）。
  - 札: 現在（例「C級1組 3位」）・参加・最高・名人の期数。
  - これまでの成績（新しい5期。クラス・成績・順位・昇級／残留／降級点）。
  - 出ていなければ「タイトル画面の『大会』から、名人戦に参加できます」。
- **賞状帳**
  - 新しい3枚を1行ずつ（格の色の判子・「第N期 竜王戦 ○○」）と「すべて見る（N枚）」。
  - 押すと、大会の画面と同じ賞状（`SeasonAward.vue`、動かさない）を開く。

### 3-3. 棋士名鑑（機能設計メモ）

#### 機能名：棋士名鑑

- **一言で：** 対局する相手を、顔と肩書きで覚え、「次に当たったら」を楽しみにする。
  - 推しを作る楽しみ（G:8-3）。
  - パラメーターでキャラ立ちさせる（G:8-1）。
- **解く課題：**
  1. 名人戦の世界が見えない。
  2. 竜王戦の組でしか探せない。
  3. 一覧が文字だけで、誰が誰か覚えられない。
  4. 開くと長く伸びて、位置を見失う。
- **初めての人の最初の1分：**
  - いちばん上に「タイトル保持者」が8人、顔の判子と肩書きで並ぶ。
  - その下に「あなたのまわり」（同じ組・同じクラスの棋士と、羽音）。
  - 1人押すと、くわしい情報が重なって開く。
- **上級者の深さ：**
  - 絞り込み: タイトル／竜王戦の組（1〜6組）／順位戦（A級〜C級2組・フリークラス）／注目（推し・ライバル・対戦した棋士）。
  - 並べ替え: 順位（組・クラスの中の並び）・レーティング・対戦成績。
- **ほめる瞬間：** あなたが勝ち越している棋士に、小さな「勝ち越し」の印を付ける。
- **ご褒美と使い道：** 推しにすると、竜王戦の画面でやこび姫が様子を知らせる（今と同じ）。名人戦の画面にも同じ知らせを出す。
- **捨てるもの：**
  - 名鑑の中の検索の文字入力は作らない。
  - 全棋士の表（表計算のような一覧）も作らない。
- **確かめ方：** 竜王戦で負けた相手を、名鑑で探して開くまでの操作数を数える（3回以内）。

#### 画面

- **上：** 絞り込みの切り替え（「あなたのまわり」「タイトル」「竜王戦」「順位戦」「注目」）。「竜王戦」「順位戦」を選ぶと、その下に組とクラスの小さな切り替えが出る。
- **一覧の1行：**
  - 顔の判子（名前の1文字。色は棋風。羽音は絵）
  - 名前と段位
  - 肩書き（タイトル）
  - 「竜王戦 3組・順位戦 B級2組 4位」の1行
  - 右端にあなたとの対戦成績（例「2勝1敗」）。勝ち越しは琥珀。
  - 推しの★・ライバルの◆
- **くわしい情報：** 画面に重ねるシート（スマホは下から、PCは右から）。
  - 今の`PlayerAbilityPanel`（能力・特殊能力・使用率）と経歴。
  - あなたとの対戦（竜王戦・名人戦の内訳と最後の対局）。
  - 「推しにする」。
  - 閉じると、一覧の同じ位置に戻る（U:7-5）。
- **PCの配置：** 左に一覧、右にくわしい情報を並べる（重ねない）。
- **入口：** ノートの「棋士名鑑」に加えて、大会の画面の次の相手の札の「くわしく」からも同じシートを開く（今と同じ部品）。

## 4. コレクション（機能設計メモ）

### 機能名：コレクション（印のアルバムと着せ替え）

- **一言で：** 指した将棋が、アルバムの1枚になる。埋まっていくページと、次の着せ替えまでのゲージで「あと少し」を見せる（G:5-2）。
- **解く課題：**
  1. 灰色の札の壁。
  2. 着せ替えと印が混ざっている。
  3. 次に何を取ればいいか分からない。
  4. Lvの壁が数字だけ。
- **リスクとリターン：** まだ組んだことのない戦法を、作戦カードで選んで指してみる。慣れない形は負けやすいが、印と着せ替えが手に入る。
- **初めての人の最初の1分：** いちばん上に「印 0 / 121」と「次の着せ替え（暖色木目）まで あと3個」のゲージと、その着せ替えの小さな絵。その下の「次に取れそう」に、作戦カードで使える戦法・囲いが3つ並び、押すと作戦カードのくわしい画面が開く。
- **上級者の深さ：** 組んだ回数（×N）、初めて組んだ日、Lv40までの壁、神の一手の回数、竜王戦の予想の的中。
- **ご褒美と使い道：** 印の数で、盤と駒の着せ替えが使えるようになる（今と同じ。`THEME_UNLOCKS`）。
- **ほめる瞬間：** 対局で新しい印を取ったときの知らせ（今と同じ）。そのあと初めてコレクションを開いたときは、新しいカードに「NEW」を付けて光らせる（1回だけ）。
- **捨てるもの：**
  - 印の交換・売買。
  - 印の数のランキング。
  - まだのカードの中身（完成形）を隠すこと。存在と形は見せる。どう組むか分かるほうが、挑戦したくなるため。
- **確かめ方：** 初めて開いた人が「次に取れそう」のカードを押して、作戦カードを選んで対局を始めるかを見る。

### 4-1. 画面

- **いちばん上（いつも出す）：**
  - 印の合計と、次の着せ替えまでのゲージ（例「暖色木目まで あと3個」）。
  - 切り替え「印のアルバム｜着せ替え」。
- **印のアルバム：**
  - ページを上の小さな切り替えで選ぶ: 「居飛車」「振り飛車」「囲い」「手筋」「Lvの壁」「記念」。ページごとに「12 / 40」と出す。
  - 長い1本のスクロールにしない。
  - 最初に開くページは、前に開いたページ（なければ居飛車）。
- **戦法・囲いのカード：**
  - 完成形の小さな盤（`FormationThumb.vue`。作戦カードと同じ）と名前。
  - 取ったカード: 色つきで「×3」。
  - まだのカード: 盤を薄くし、名前を灰色にする。
  - 次に取れそうなカード: 作戦カードで使える（`opening-unlocks.mjs`で解放済み）のにまだ組んでいないもの。「挑戦できる」の札を付け、ページの先頭に並べる。
  - 押すと、作戦カードのくわしい画面（手順の再生つき）を開く。「この作戦で指す」で対局準備へ。
  - スマホは3列、タブレットは4列、PCは6列。
- **手筋：** 手筋図鑑の小さな図と名前のカード（取ったものは色つき）。押すと手筋図鑑のその手筋へ。
- **Lvの壁：**
  - Lv1〜40を、10段ずつ4本の階段（初級〜達人）にする。
  - 勝ったLvは琥珀に光り、次に勝つと印が増える一番低いLvを「次の壁」として縁取る。
  - おすすめの強さの範囲には印を付ける。
- **記念：** 神の一手の回数、竜王戦の予想の的中、賞状の枚数。印の数には入れない。
- **着せ替え：** 今の盤・駒の選び方をそのまま移す。まだのものに「印あと○個」。

### 4-2. データ

- `collection.mjs`の保存はそのまま使う。
- 足すもの:
  - 初めて取った日（`formations[label].firstAt`）
  - まだ見ていない印の一覧（`unseen`）。コレクションを開いたら消す。
- 「次に取れそう」は`opening-unlocks.mjs`の解放の状態から、画面で決める（保存しない）。

## 5. 作る順番

1. **段階1：1つの世界（データ）**
   - `junni-world.mjs`と名簿の版4、保存の移しかえとテスト。
   - 名人戦の期と棋界の1年を、`roster.junni`で読み書きするように直す。
   - 名人戦の対局を`vsUser`に数える。
   - 画面の見た目は変えない（名人の食い違いが直ることを確かめる）。
2. **段階2：やこびノートの大会と棋士名鑑**
   - 項目の作り直し。
   - 大会（竜王戦・名人戦・賞状帳）。
   - 棋士名鑑（絞り込み・顔の判子・対戦成績・重ねるシート）。
3. **段階3：コレクション**

各段階で、テスト・型・ビルド、3つの大きさのブラウザ確認、文書の更新、コミットをする。

## 6. 決めてほしいこと（実装の前に）

1. 棋界の1年は、プレイヤーが名人戦に出たあとは順位戦を進めない（順位戦は名人戦を指したときだけ進む）。この形でよいか。
   - 名人戦を指さない間は、順位戦のクラスと名人は止まったままになる。
2. 名人戦に出る前の名人戦の自動の1期で、羽音もほかの棋士と同じように昇級していく。プレイヤーが後から名人戦に出ると、羽音が上のクラスにいることがある。これでよいか。
   - 今は、プレイヤーと羽音はC級2組から一緒に始まる。
