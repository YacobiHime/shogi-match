# 大会モードの設計

最終更新: 2026-10-09

対局の種類に「大会」を加え、実際の棋士のように、予選から大会を勝ち上がって称号を得られるようにする。
最終的に目指す全体像と、いま実装した範囲をここに記録する。実装の正本は`src/core/tournament.mjs`（進行と判定）、
`src/core/player-profile.mjs`（称号と成績の保存）、`src/ShogiMatchGame.vue`（画面）である。

## 目指す全体像

プロ棋士になる過程と、プロの棋戦を、段階を追って遊べるようにする。

1. 研修会の入会試験（実装済み）
2. 研修会での昇級（F2→F1→E2…→A）
3. 奨励会の入会試験、奨励会の級位・初段・三段（三段リーグ）
4. 四段（プロ入り）
5. プロの棋戦: 順位戦（C級2組から）、竜王戦（ランキング戦の予選から）、名人戦、ほか八大タイトル
6. 取った称号や成績を、プロフィールに表示する

設定で、大会の長さ（対局数）を短くしたり、相手の強さを調整できるようにする。

## 実装済み（第1段階）

- タイトル画面に「大会」ボタンを置き、専用の画面（`src/ShogiTournament.vue`）から始める。対局設定には出さない。
  - 大会: 研修会入会試験
  - 対局数: 1局（短縮）・3局・5局
  - 相手の強さ: 基準のレベル（既定はLv.26）。局が進むほど、基準より2レベルずつ強くなる。
  - 対局設定を通さずに1局目を始める。結果の画面から、プロフィール・大会の画面・ホームへ移れる。
  - 画面は、その大会に挑戦した結果と、これまでの称号も表示する。
- 研修会入会試験の判定（簡易版）
  - 先手と後手を1局ごとに入れ替える。
  - 半分より多く勝つと合格（1局なら1勝、3局なら2勝、5局なら3勝。引き分けは0.5勝）。
  - 合格は「研修会 F2クラス」。3局以上で全勝すると「研修会 F1クラス」。1局だけの試験ではF1は出ない。
  - 実際の試験の規定を再現したものではない。
- 1局ごとに結果と「次の対局へ」を出し、全局が終わると合格・不合格と称号を出す。
- 中断・リロード・再開をしても、大会の進行は続く（保存のスナップショットに`tournament`を含める）。
- 称号と大会の成績は、やこびノートの「プロフィール」に出す（所属は、いちばん高い称号）。
- 大会の対局は、通常対局のレーティングには数えない。

## 次の段階の方針

- 研修会のクラス（F2からAまで）を持ち、定期的な「例会」の勝敗で昇級・降級する。
- 奨励会の入会試験は、研修会の成績（Bクラス以上など）から受けられるようにする。
- 各段階の長さ（例会の局数、リーグの人数）は、設定で短縮できるようにする。
- 大会の種類を増やすときは、`TOURNAMENTS`に定義を足し、`examVerdict`に相当する判定を大会ごとに用意する。
- 実在の棋戦（順位戦・竜王戦・名人戦）は、制度の要点（リーグ・トーナメント・番勝負）を簡略化して再現する。
