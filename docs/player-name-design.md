# プレイヤー名（設計 2026-10-22、実装・自動テスト済み）

タイトル画面で、プレイヤー名を入れられるようにする。いままでは、盤の名札は「先手・後手」、対局準備と竜王戦のVS画面は「あなた」、竜王戦のトーナメント表も「あなた」だった。

### 機能名：プレイヤー名

- 一言で：自分の名前が盤の名札と竜王戦の表に載る。
- 解く課題：盤の名札が「先手」のままで、だれが指しているか分かりにくい／竜王戦の表で、架空の棋士の名前の中に自分だけ「あなた」と並ぶ（一人の棋士として参加する気分が薄い）。
- リスクとリターン：なし（入れなくても遊べる）。
- 溜めと解放：なし。
- 初めての人の最初の1分：タイトル画面の記録の帯の左に、点線の「名前を入れる」。押すと名前の札が開き、入れて「この名前にする」。入れなくてもよい。
- 上級者の深さ：なし。
- 失敗したとき：空にして決めれば「あなた」に戻る。何度でも変えられる。
- ご褒美と使い道：盤の名札・対局準備の自分の側・竜王戦のトーナメント表とVS画面に名前が出る。
- ほめる瞬間：なし。
- 捨てるもの：アカウントやオンラインでの名前の共有（端末に保存するだけ）。会話の中の「あなた」の書き換え（やこび姫の台詞や解説の「あなた」は呼びかけなので、そのまま）。番付の「あなた」の札（「ここにいる」という印で、長い名前は入らない）。
- 確かめ方：ブラウザで、名前を入れて、盤の名札・対局準備・竜王戦の表とVS画面に出ることを見る。

## 決めたこと

- 保存：`localStorage`の`yacobihime:shogi-match:player-name:v1`（`src/core/player-name.mjs`）。前後の空白を除き、制御文字を消し、続く空白を1つにして、10文字まで。空なら保存を消す。展示の「最初から」は、このゲームの鍵をすべて消すので、名前も消える。
- タイトル画面：記録の帯（やこびノート）の左に、名前のボタンを置く（帯は1つのボタンなので、中には入れられない）。入れていないときは点線の縁で「名前を入れる」。スマホの幅では、名前のボタンを幅の40%までにし、帯の「やこびノート」を「ノート」に縮める。長い名前は「…」で切る。
- 名前の札：見出し「プレイヤー名」、説明、入力欄（44px以上、文字は16px以上でスマホで拡大されない）、「この名前にする」「やめる」。Enterでも決まる。外側を押すかブラウザの戻る操作で閉じる（`navigateBack`・`canGoBack`）。
- 出す場所：
  - CPUとの対局の、プレイヤー側の盤の名札（入れていなければ、今までどおり先手・後手の表示名）。二人で指す対局は今までどおり。
  - 対局準備の、自分の側の名前（入れていなければ「あなた」）。
  - 竜王戦：新しい期のトーナメント表の自分の名前（`createSeason`の`userName`）。進めている期があるときに名前を変えたら、その期の表の名前も替える。VS画面の自分の名前。
- 根拠：U:3-2（タイトルから1回の操作で開く）、U:5-2（ボタンは動詞）、U:7-4（押せる大きさ44px）、G:2-4（初心者の道をふさがない。入れなくても遊べる）。
