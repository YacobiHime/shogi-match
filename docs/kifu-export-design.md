# 対局中の棋譜の書き出し（2026-11-17）

依頼：対局中に現在の局面までの棋譜を書き出す。入口は右上の三本線メニューの設定の一種。

## 1. 機能設計メモ

- 一言で：指している途中の一局を、ほかの将棋ソフトでも並べられる形で残す。
- 解く課題：終局せずに棋譜を保存する。検討中も、表示中の局面より先の手や別の分岐を混ぜない。
- リスクとリターン：書き出しで対局は変えず、棋譜ファイルを得る。取り消せない操作ではないため確認の窓は出さない（U:3-1）。
- 溜めと解放：メニューを開いて押すと保存が始まり、何手目までを書き出したかを伝える（D:3-1）。
- 初めての人の最初の1分：対局画面の右上「メニュー／設定」→「棋譜を書き出す」。端末のダウンロード先へ保存する。
- 上級者の深さ：駒落ち・任意局面・検討中の分岐も、開始局面と現在までの経路を保つ。
- 失敗したとき：メニュー内の案内からもう一度押せる。現在の対局はそのまま。
- ご褒美と使い道：KIFをほかの将棋ソフトへ読み込んで振り返れる。
- ほめる瞬間：通常のファイル保存なので褒めず、書き出した手数を短く知らせる。
- 捨てるもの：対局中の形式選択・新しいシート・共有サービスへの送信。盤の操作列には足さない（UD:2 明快・軽快）。
- 確かめ方：書き出したKIFを読み直して局面が一致すること、途中の手や分岐の範囲、元の棋譜が変わらないこと。ブラウザでメニューからダウンロードして、3サイズと背の低い横画面で操作できること。

## 2. 形式と画面

- KIF形式・UTF-8、拡張子はUTF-8の棋譜に使う`.kifu`。ファイル名に書き出した日時と手数を入れる。
- 先手・後手の名前は盤の名札とそろえる。開始局面、現在までの指し手、元の棋譜にある消費時間とコメントを引き継ぐ。終局していない棋譜に投了などの終局結果を加えない。
- 対局・検討中のメニューに「棋譜を書き出す」。CPUの思考中も使え、押した瞬間の確定済みの手までを同期的に複製する。
- 成功・失敗の一言はメニュー内の`role=status`へ。書き出してもメニューの設定や対局を変えない。
- 短い画面では設定メニューの中をスクロールし、各ボタンの大きさを保つ（U:7-4・7-5）。
