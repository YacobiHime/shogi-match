# 天鷺羽音（あまさぎ はのん）の人物設定

この文書は、天鷺羽音の人物と口調を、このゲームのために残したものです。羽音の台詞を書くとき・直すときは、ここの「口調」に合わせます。

- 元にした文書：ノベルのリポジトリ（`YacobiHime/novel`）の`design/characters.md`と`docs/characters.md`（2026-09-16の版）。
- ノベルはミステリーなので、事件・暗号・黒幕（黒姫真理）・犯罪組織・主人公（戸鎖続）との出会いの筋は入れていません。羽音の性格・好み・口調は、ノベルのまま残しています。
- ゲームの中の立場（竜王戦に出る新四段のライバル、名簿・強さ・特徴・出る場面）は`docs/hanane-rival-design.md`にあります。この文書と食い違うときは、立場と強さはあちら、性格と口調はこちらに合わせます。

## 1. 立場

| 項目 | ノベル | このゲーム |
| --- | --- | --- |
| 身分 | 燈ヶ丘高校2年生。ヒロイン | 高校に通いながら、三段リーグを突破した新四段のプロ棋士（17歳）。プレイヤーのライバル |
| 将棋 | 天鷺名人の娘で、本気で将棋はしていないが、かなり強い | 父親譲りの読みで、竜王戦・名人戦を勝ち上がる。序盤から終盤にかけて強さを増し、力戦に強い |
| 家族 | 父は将棋の天鷺善彦名人 | 同じ。善彦は史上最強と言われる名人で、竜王を含む多くのタイトルを持つ |

- ノベルでは「本気で将棋をしていない」が、ゲームでは棋士として指す。ここだけはゲームに合わせて書き換えた。性格の「自分の頭を、自分が面白いと思うことに使いたい」は、ゲームでは「将棋を、いちばん面白い問題として本気で指している」と読みかえる。

## 2. 性格

- 調子に乗ったり油断したりしやすいが、感情的になることは少なく、他人を馬鹿にしない。
- 他人の気持ちがよく分からないが、それでいいと思っている。ただ、大切な友達の気持ちは分かりたいと思うようになる（ノベルでは親友の桜乃百花との出来事から）。
- 不器用で、友達が落ち込んでいるときは、とにかく一緒にいようとする。
- 実は寂しがり。独りになることを恐れている。
- 難しい問題を解くのが楽しい。大切な友人と一緒にいたい。
- 重要な場面での決断・判断がとても優れている。
- 自分の頭を、自分が面白いと思うことに使いたいと思っている。
- 欲しいもの：自分が本当に面白いと思える問題を追究すること。

## 3. 好みと特技

- 果物が好き。マヨネーズとソースが大嫌いで、体が受け付けないらしい。
- 数学が好き。級数や複素解析が好みで、数学を使うこと全般が得意。物理の計算にも強い。難しい問題を解く・最新の理論を理解する・規則性を見つけるのが好き。
- 学校では、資料がたくさん置いてある空き教室を占領して居着いている。
- 能力（ノベルの設定）：圧倒的な処理速度があり、計算や思考がとても速い。言語理解119・知覚推理127・処理速度156・ワーキングメモリ150（IQ138）。ゲームの能力値は、名鑑の8つの能力（`docs/player-abilities-design.md`）で別に持つ。
- ゲームでは、数学好きの設定を出すためだけに「確率」「規則性」を台詞に入れない（`docs/hanane-rival-design.md`の1-3）。

## 4. 口調

- 一人称：私
- 二人称：名前の呼び捨て（「○○先生」のような役職は付ける）か「君」。ゲームのプレイヤーは「君」と呼ぶ。
- 三人称：彼女、彼
- 敬語：ノベルでは「目上の相手以外には敬語を使わない」。**ゲームでは、目上の相手にも敬語を使わない**（2026-10-24のユーザーの指定。`AGENTS.md`）。「です・ます」「よろしくお願いします」「ありがとうございました」「負けました」も言わない。
- 使う言葉：
  - 感動詞：「へえ」「ふぅん」「なるほど」「すごい」「ああ」「まぁ」「え」
  - 接続助詞：「けど」「から」「たら」「ても」「なのに」
  - 終助詞：「よ」（「〜だ」で終わるときはたいてい付ける）「でしょ」「ね」
  - 副助詞：「〜だって」
  - 独立語：「そういうこと」「はじめまして」「それに」「そっか」「確かに」「どう？」
- 特徴：
  - 基本は淡々としているが、素っ気なく聞こえない程度に親しみを込めて話す。飾らない、率直な物言い。
  - 断定を避け、「〜でしょ」「〜よね」「どう？」のように相手に確かめる・同意を求める言い方をよく使う。核心を突くときも、命令ではなく問いかけの形にすることが多い。
  - 文末を省いたり、要点だけを短く言ったりする（「あ、起きた」「ごめん…。」）。饒舌ではない。
  - 誰かを気遣うときも大げさにならず、さらっと軽く言う（「安心して。」「良いの？」）。
  - 感嘆符（！）は、ふだんは使わない。ノベルでは本気で怒ったときだけ使う（「ふざけるな！」）。ゲームの台詞では使わない（`docs/hanane-rival-design.md`の1-3）。
  - 「……」は、言いよどむ・考えるときにだけ使う。文の頭に毎回付けない。

### 4-1. 台詞の例（ノベルから。ミステリーの筋に関わるものは除いた）

ふだん：
- 「羽音です、はじめまして。」（ノベルの言い方。ゲームでは敬語を使わないので「天鷺羽音。はじめまして。」にする）
- 「勉強教えるのとかやったことないけど…」
- 「わからないとこあったら聞いて。」
- 「え、本気...？」
- 「特にないけど…」
- 「何かあった？」
- 「どう？当たってる？」
- 「安心して。」
- 「君は、私と同じで少し変わってるね。」
- 「その方が合理的だ。」
- 「もしかして、気になるの？」
- 「大方、私に気を遣わせないように無理したってところでしょ。」
- 「誤魔化さなくていいよ。」

親しい相手に：
- 「ごめん……」
- 「なんで私に相談しなかった……」
- 「さっき裏庭で採れたんだ、一緒に食べよう。」
- 「悪いけど、私苦手なんだ…マヨネーズ。」
- 「私より上がいることなんて分かってる。だから、私の計算能力と探究心で生きていける分野を探すんだ。」
- 「人の気持ちなんて分からないままでいいと思ってた。でも、大切な友達の気持ちは分かりたい。」（ノベルでは「百花の気持ちは分かりたい。私の大切な友達だから。」）

感情的になったとき（ゲームではめったに出さない）：
- 「ああ、そう受け取ってもらって構わない。」
- 「それとも、彼に非があるとでも言うつもりかな？」

### 4-2. ゲームの台詞での使い方

- 例の台詞はそのまま場面へ割り当てず、口ぐせと話し方の型を借りる。
- 将棋の場面では、「へえ」「なるほど」で相手の手を認め、「〜だね」「〜だよ」「〜でしょ」で短く言い切らずに伝える。
- 負けても取り乱さない。悔しさは「悔しいけど」と短く言い、「次は勝つから」と不器用な負けず嫌いを見せる。
- 台詞の置き場所：対局前後の一言`src/core/ryuo-story.mjs`の`HANANE_LINES`、対局中の一言`src/core/match-presence.mjs`の`LINES.hanane`、中継の解説`src/core/relay-commentary.mjs`の`ha`と心の声`THOUGHTS.hanane`、勝負メシの一言と封じ手の休憩の解説`src/core/title-day.mjs`、奨励会の一言`src/core/shoreikai-speech.mjs`の`HANANE_SHOREIKAI_LINES`。
