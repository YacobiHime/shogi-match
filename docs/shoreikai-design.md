# 奨励会：入会試験からプロ（四段）まで

大会の選択にある「奨励会」のタイル（いまは準備中）を、入会試験に受かって奨励会に入り、級・段を上がって三段リーグを抜け、四段（プロ棋士）になるまでの大会にする。

- 状態：設計（2026-10-23）。決めたことは12章、足した遊びは13章。
- このゲームの柱（`AGENTS.md`）：主役は大会と物語。奨励会は「プロになるまでの物語」で、四段になったら竜王戦・名人戦へ戻る道として勧める。
- `docs/nintendo-design/Game_Nintendo_Design.md`の1章で、長期の目標に「研修会→奨励会→プロの道のり」を挙げている。研修会はこの設計に入れない（11章）。
- 名人戦の設計（`docs/meijin-design.md`の13章）で、「奨励会入会試験から始める、棋士として1年を過ごすモード」を後で作るとした。この設計は、そのうち「プロになるまで」を大会として先に作る。処理は保存と暦に依存しない形にし、後の棋士モードから呼べるようにする（名人戦と同じ方針）。

## 0. 見立て

- 竜王戦と名人戦は「プロになってから」の大会。プレイヤーがどうやってプロになったかの物語がない。
- 奨励会は、現実の将棋でいちばん厳しく、いちばんドラマのある場所（年齢制限、三段リーグの最終日、次点）。昇級・昇段の規定がはっきりしているので、「あと何勝で昇級」という目の前のごほうび（D:5-2）を作りやすい。
- ただし、実物の規定のままだと四段まで数百局かかる（2章）。規模を選べるようにし、いただく時間（D:9-1）に見合う長さにする。
- 強さは竜王戦と同じく、棋士（奨励会員）の強さをレーティングで持ち、実際に指す相手のLvは難易度で決める。初心者でも、選んだ難易度で勝率6〜8割の相手と指せる（D:4-1）。

## 1. 実物の制度（調べたこと）

出典：日本将棋連盟の「奨励会規定」と「2026年度奨励会入会試験のご案内」（11章の後ろの出典）。規定は改定されることがあるので、数字はゲームの初期値として使い、表に残す。

| 項目 | 実物 |
| --- | --- |
| 受験資格 | 満19歳以下。四段以上の棋士（師匠）の推薦が要る |
| 入会試験（級位の受験） | 一次試験は受験者同士の対局で、4勝で通過・3敗で失格。二次試験は奨励会員との対局で、1勝で合格（3局が目安）。作文・面接もある |
| 受験級 | 6級〜1級から選んで受ける（初段の受験は、すべて奨励会員と対局し、3敗で失格） |
| 昇級（6級→1級→初段） | 6連勝、9勝3敗、11勝4敗、13勝5敗、15勝6敗 |
| 昇段（初段→二段→三段） | 8連勝、12勝4敗、14勝5敗、16勝6敗、18勝7敗 |
| 降級（二段以下） | 2勝8敗以下で降級点。降級点が消えないうちにもう一度取ると降級。3勝3敗以上で降級点が消える |
| 三段リーグ | 半年で1期、18局（同じ相手と2回は当たらない）。上位2名が四段。同じ星なら前期の順位が上の人が上 |
| 次点 | 3位は次点。次点を2回取ると、四段（フリークラス）になれる |
| 三段の降段 | 勝率2割5分以下（18局なら4勝以下）で降段点。2期続けると二段へ |
| 年齢制限 | 満21歳までに初段、満26歳の誕生日を含むリーグの終わりまでに四段。最後のリーグで勝ち越せば延長 |

## 2. 長さの見積もり

勝率を一定（6割・7割）として、4級で入り、三段リーグを抜けるまでの局数を、規定のとおりに2000回試した（勝率を一定にした簡単な試算。三段リーグのほかの三段は勝率5割。昇級点に届かないまま負けが上限を越えたら、数え直す）。

| 規模 | 昇級 | 昇段 | 三段リーグ | 勝率7割 | 勝率6割 |
| --- | --- | --- | --- | --- | --- |
| 実物どおり | 6連勝/9-3/11-4/13-5/15-6 | 8連勝/12-4/14-5/16-6/18-7 | 30名・18局・上位2名 | 約155局（リーグ約1.8期） | 約330局（約3.9期） |
| 短め | 4連勝/6-2/8-3 | 5連勝/8-3/10-4 | 16名・10局・上位2名 | 約83局（約1.9期） | 約140局（約3.4期） |
| みじかい | 3連勝/4-1/5-2 | 4連勝/6-2/7-3 | 8名・6局・上位1名 | 約58局（約2.5期） | 約86局（約4.0期） |

- 1局15分として、みじかいでも約15時間。竜王戦の1期（5〜15局）より長い、長期の目標になる。
- 1つの昇級は、みじかいで約4〜6局、実物どおりで約10〜15局。「あと何勝で昇級」が、1〜2回の遊びの中で動く長さにする（D:5-2）。
- 受験級を上げると短くなる（1級で入れば、級の昇級が1つだけ）。そのぶん入会試験の相手が強い（3章の悪魔の釜）。

## 3. 遊びの流れ

```
入口（師匠を選ぶ・受験級・設定）
  → 入会試験（一次：受験者同士 4勝で通過／3敗で不合格 → 二次：奨励会員と3局 1勝で合格）
  → 例会（1回に2局。級・段の近い奨励会員と当たる）をくり返し、昇級・昇段
  → 三段リーグ（1期ずつ。上位で四段、3位は次点）
  → 四段昇段（免状の式・賞状帳・竜王戦と名人戦への誘い）
```

### 機能設計メモ（奨励会という大会）

- 一言で：入会試験に受かり、級を上がり、三段リーグを抜けて四段（プロ）になる。
- 解く課題：プロになるまでの物語がない。竜王戦・名人戦の「自分」が、どこから来たのか分からない。
- リスクとリターン：受験級（高いほど近道だが試験の相手が強い。D:4-2 悪魔の釜）。三段リーグの1局の重さ（自力と他力）。
- 溜めと解放：昇級点まであと何勝 → 昇級の判子。三段リーグの最終局 → 四段（ギュッとしてパッと解消。D:2-2）。
- 初めての人の最初の1分：大会の選択で「奨励会」を押す → やこび姫が「プロになるには、奨励会に入って四段になるんだよ」と言い、師匠の候補3人と、おすすめの受験級が並ぶ。「受験する」ですぐ一次試験の1局目。
- 上級者の深さ：受験級を上げて近道する。三段リーグの順位と次点。年齢制限（選んだ人だけ）。
- 失敗したとき：
  - 入会試験に落ちたら、その場で受け直せる（受験級を1つ下げる提案を、選べる形で。D:4-3、7章）。
  - 負けが込むと降級点（実物のまま）。ただし降級点が付く前に、やこび姫が「あと1つ負けると降級点」と知らせる。
  - 年齢制限は、選んだ人だけ（11章）。
- ご褒美と使い道：昇級・昇段の判子（期の画面の節目と同じ言葉と音）。四段の免状（賞状帳）。称号「棋士」。四段になると、竜王戦・名人戦に「新四段」として出る言葉が変わる（物語のつながり）。
- ほめる瞬間：連勝で昇級（「6連勝で昇級！」）、三段リーグの勝ち越し、四段。
- 捨てるもの：実物の作文・面接。駒落ちの手合い（11章）。例会の自動の対局（プレイヤーの対局は自分で指す）。
- 確かめ方：みじかいで、勝率7割の人が約60局で四段に届くこと。どの画面からも「次の1局」をすぐ押せること。

## 4. 奨励会の世界（名簿）

- 竜王戦の名簿（`ryuo-roster.mjs`）とは別に、奨励会員の名簿を持つ。段級ごとに8〜12名、合わせて約70名。名前・年齢・段級・レーティング・棋風と特殊能力・得意戦法は、竜王戦の棋士と同じ作り方（`player-character.mjs`・`player-abilities.mjs`・`ryuo-repertoire.mjs`）で作る。
- 強さの目安：6級はR1150前後、三段はR1500前後（棋士の平均R1555のすぐ下）。数字は自動対局の校正で決める（`docs/rating-realism-design.md`と同じやり方）。
- 例会ごとに、ほかの奨励会員どうしの対局も自動で決め（`ryuo-simulation.mjs`と同じElo式）、昇級・昇段・降級・退会・新しい入会で、世界が動く。同期が先に昇級した、などを速報にする（`match-presence.mjs`の速報と同じ形）。
- **天鷺羽音**：プレイヤーが入会したとき、三段リーグの三段（17歳）。最初の三段リーグで四段になり、竜王戦の名簿の「新四段の羽音」につながる。その後は「四段で待ってるよ」と、ときどき声をかける（目標の背中）。
- **同期**：入会試験の受験者から、架空の同期を2人作る。同じ年に入会し、例会でも当たる。どちらが先に上がるかの競争（D:8-3 応援する理由、D:4-7 個性はとがらせる）。
- **師匠**：入口で、竜王戦の名簿の棋士から3人の候補を出して選ぶ（推薦が要るという実物の決まり）。師匠は昇級・昇段・四段のときに一言かける。師匠の得意戦法を、作戦カードの「師匠の得意」として案内する（強さには関係しない）。

## 5. 入会試験

- 受験級：6級〜1級。おすすめはプレイヤーのレーティングから出す（竜王戦のおすすめの難易度と同じ考え方）。
- 一次試験：受験者どうし。4勝で通過・3敗で不合格（最大6局）。相手は受験級の受験者。
- 二次試験：奨励会員と3局。1勝で合格。相手は受験級の1〜2つ上の奨励会員。
- 合格したら、合格の判子と、師匠とやこび姫の一言。受験級で入会する。
- 不合格なら、その場で受け直せる。受験級を1つ下げる提案を並べる（下げないで受け直すこともできる）。

## 6. 例会と昇級・昇段

- 例会1回で2局。相手は同じ段級か、1つ上下の奨励会員（実物の手合いは駒落ちがあるが、ここではすべて平手。11章）。
- 例会の前に、次の相手の札（顔・棋風・能力。竜王戦の次の相手の札と同じ部品）と、昇級までの残りを出す：「9勝3敗まで あと2勝（負けはあと1つまで）／6連勝まで あと4連勝」。
- 昇級・昇段は、規模の規定（2章）で決める。判子「昇級」「昇段」と、名札掛けの名札が動く（7章）。
- 降級点は、規模に合わせて縮める（実物どおり2勝8敗、短め2勝6敗、みじかい1勝4敗。消すのは勝ち越し）。
- 例会は2局ごとに区切りがよく、そこで中断してもよい（D:9-1）。対局の途中の中断と再開は、竜王戦と同じ。

## 7. 画面

### 機能設計メモ（名札掛け）

- 一言で：道場の名札掛けで、自分の名札が右へ（上の段級へ）掛け替えられていく。
- 解く課題：級・段の位置が、数字だけでは分かりにくい。
- 画面の主役：名札掛け（ドット絵の木の板に、段級ごとの列と名札）。自分の名札は朱、同期は青、羽音は金の縁。
- 情報の優先順位：1. 次の1局（相手と「対局する」） 2. 昇級までの残り 3. 名札掛け 4. 速報（同期・羽音） 5. 経歴。
- 操作の流れ：入口 →「対局する」の1手で例会の1局目へ。
- 快の要素：昇級で名札が外れて右の列へ掛かる動き（0.6秒）と、木の札の「カタン」の音。動きを減らす設定では、光るだけ。
- 見ている人への配慮：名札掛けは遠くからでも自分の位置が分かる色にする。
- 作らないと決めたこと：奨励会員全員の詳しい成績表（名鑑で見る）。
- 確かめ方：3つの画面の大きさで、名札掛けと「対局する」が1画面に収まる。

### 7-1. 画面の並び

- **入口**：題字「奨励会」と名札掛け（まだ自分の名札はない）。下の枠に、やこび姫の一言・師匠の候補3人・受験級（おすすめつき）・設定の要約・「受験する」。
- **入会試験**：一次・二次の星取り（○●と、あと何勝・何敗）。次の相手の札。
- **例会の画面**：名札掛け、昇級までの残り、次の相手の札、「対局する」。上の帯に、いまの段級と年齢（年齢制限があるときだけ）。
- **三段リーグの画面**：リーグ表（名人戦の`MeijinLeagueTable.vue`を使い、上位2名と次点の線を引く）と、自力・他力（`meijin.mjs`の`promotionOutlook`と同じ考え方）。最終局は「勝てば四段」。
- **四段の式**：免状ふうの賞状（`SeasonAward.vue`）、師匠・羽音・やこび姫の一言、「竜王戦へ」「名人戦へ」のボタン。

### 7-2. 対局中

- 竜王戦・名人戦と同じ対局の札・相手の顔と一言・中継・速報を使う（`match-stage.mjs`・`match-presence.mjs`に`event: 'shoreikai'`を足す）。
- 賭けているもの：「勝てば昇級」「あと2勝で昇級」「勝てば四段」など。
- 重さ：ふつうの例会はplain、入会試験の最後の1局・昇級がかかる1局・三段リーグの最終日はbig、四段がかかる1局は大きな開幕の札。
- 背景：道場（畳と名札掛け）。三段リーグは夕方の東京・将棋会館。

## 8. 設定（エントリー）

竜王戦・名人戦と同じ「項目: 値 [変更]」の行。

| 項目 | 選択肢 | 既定 |
| --- | --- | --- |
| 難易度 | 14段階（竜王戦と同じ。おすすめは勝率6〜8割） | おすすめ |
| 規模 | 実物どおり／短め／みじかい | みじかい |
| 年齢制限 | なし／あり | なし |
| やこび姫の助言・閃き・待った | 竜王戦と同じ | 竜王戦と同じ |

## 10. 作る順番

1. **段階1：規定と世界（`src/core/shoreikai.mjs`）とテスト**。名簿の生成、入会試験、昇級・昇段・降級点、例会の進行（ほかの奨励会員の自動対局）、三段リーグ（組み合わせ・順位表・次点・降段点）、キャリアと保存。規模ごとの局数をテストで確かめる。
2. **段階2：画面**。大会の選択のタイル、入口（師匠・受験級・設定）、入会試験、例会の画面と名札掛け、三段リーグの表、四段の式。
3. **段階3：対局との連携**。対局の札・賭けているもの・判子・速報・やこび姫と師匠の一言、レーティングとノートへの記録。
4. **段階4：物語のつながり**。羽音と同期の台詞、やこびノートの「大会」に奨励会の経歴、四段の賞状、竜王戦・名人戦への誘い。

各段階で、純粋な処理とテスト → 画面 → 3つの画面の大きさでの確認 → 文書 → コミットの順に進める。

## 11. 決めること（おすすめつき）

1. **規模の既定**：みじかい（勝率7割で約60局）／短め（約80局）／実物どおり（約155局）。おすすめは**みじかい**。
2. **年齢制限**：既定「なし」で、選んだ人だけ「あり」にする（おすすめ）／いつも「あり」／作らない。
3. **師匠**：竜王戦の名簿の棋士から3人の候補を出して選ぶ（おすすめ）／選ばない（師匠なし）。
4. **同期のライバル**：架空の同期を2人作る（おすすめ）／作らない。
5. **羽音**：入会時に三段で、最初の三段リーグで四段になる（竜王戦の名簿の新四段につながる。おすすめ）／奨励会には出さない。
6. **手合い**：すべて平手（おすすめ。実物は段級の差で駒落ちがある）／実物どおり駒落ちを入れる。
7. **研修会**：今回は作らず、タイルは準備中のまま（おすすめ）／入会試験に落ちた人の道として一緒に作る。
8. **四段のあと**：竜王戦・名人戦は今までどおり誰でも出られる（おすすめ。前の保存の人を締め出さない）／四段にならないと名人戦（順位戦）に出られないようにする。

## 13. 足した遊び（ユーザーの「面白くするためのアイディアは組み込んでよい」による）

- **三段リーグ最終日の結果発表**：最後の1局を終えると、上位を争う三段の最終局の結果を1人ずつ明かし（0.8秒ずつ。押すと飛ばせる）、最後に四段が決まる。自分が勝っても、ほかの人の結果しだいで決まる「他力」のドキドキを、いちばん強い溜めと解放にする（D:2-2）。
- **棋士番号**：四段になると、棋士番号（「第347号」など）をもらう。免状と、やこびノートに残る。現実のモチーフで、プロになった実感を足す（D:8-4）。
- **今日の成績の判子**：例会の2局の○●を、例会の帳面に判子で残す。連勝中は「○連勝中」と出す（いま何が起きているかが分かる。D:5-2）。
- **同期対決**：例会で同期と同じ段級になったら、優先して当てる。勝てば同期より先に上がれる（応援する理由とライバル。D:8-3）。
- **降級点の予告**：降級点の1つ手前で、やこび姫が「あと1つ負けると降級点。でも、1つ勝てば消えるよ」と言う（責めない、次にすることを伝える。D:7）。
- **師匠の一言**：入会・昇級（3回ごと）・昇段・三段リーグ入り・四段のとき、師匠が一言かける。四段の式では、師匠から扇子をもらう。
- **奨励会の歩み**：やこびノートの「大会」に、いまの段級・入会からの対局数・最長連勝・段級の推移（入会、昇級の日付の代わりに例会の回）を出す。
- **名札の掛け替え**：昇級すると、名札掛けの自分の名札が上の段級の列へ移り、「カタン」と音が鳴る（`public/audio/nameplate.mp3`。動きを減らす設定では光るだけ）。

## 14. 段階1の実装（規定と世界。2026-10-23）

- **処理**：`src/core/shoreikai.mjs`（画面・保存の仕組み・暦に依存しない）。テストは`shoreikai.test.mjs`。
  - 規定：`promotionRule`（6級〜2級は昇級、1級〜二段は昇段の規定。1級から初段も昇段の規定）、`addToRecord`・`promotionReached`・`promotionProgress`（前の昇級からの成績。負けが上限を越えたら数え直す）、`addToSlump`・`slumpWarning`（降級点・消える・降級。勝ちが増えたら数え直す）。
  - 世界：`createWorld`（段級ごとに規模の人数、三段は三段リーグの定員。羽音は三段）。ほかの奨励会員は、規定の勝ち負けではなく、才能による強さの伸び（`monthlyGrowth`）が次の段級の目安を越えたら上がる（規定どおりに動かすと、勝率5割どうしでも昇級が速すぎ、低い級が空になり三段が増えすぎたため）。21歳で初段に届かなければ退会、毎月わずかに進路でやめる人、半年ごとの入会で人数を保つ。三段が定員の1.25倍を越えているあいだは、二段の人は三段に上がらない。
  - 挑戦：`createShoreikaiRun`（入会試験から）、`recordShoreikaiGame`（1局を記録し、試験・例会・三段リーグを進めて次の1局を決める）、`retryExam`、`describeShoreikai`（画面に出す形）、`nameboard`（名札掛け）、`leagueStandings`・`leagueOutlook`・`leagueSchedule`（三段リーグ）、`mentorCandidates`・`recommendedExamRank`、`loadShoreikai`・`saveShoreikai`・`closeShoreikaiRun`。
  - 例会の相手は段級が1つ上下までの奨励会員（少なければ広げる）。同じ段級に同期がいれば6割で当てる。ほかの奨励会員の例会の結果は、プレイヤーの1局目の前に決めて、速報に使う。
  - 三段リーグは、プレイヤーが三段になったら、ほかの三段の期を締めてから次の期に入る（途中の期にあとから入らない）。組み合わせは、同じ相手と当たらない組み方を40回まで試して選ぶ。羽音は最初の期で必ず四段になる。
