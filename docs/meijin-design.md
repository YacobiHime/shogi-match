## 1. 名人戦と順位戦の仕組み（調査メモ）

この環境からは日本将棋連盟などのページを開けなかったため、下は作り手の知識によるまとめ。**「要確認」の行は、実装の前に公式の規定で確かめる。** このゲームでは要点を簡略にして再現する（規定そのものではない）。

| 項目 | 内容 |
|---|---|
| 全体 | 名人戦の挑戦者は「順位戦」で決まる。棋士はA級・B級1組・B級2組・C級1組・C級2組の5つのクラスに分かれ、1年（6月〜翌3月）かけてクラスごとにリーグ戦を指す。A級の1位が、名人と七番勝負を指す |
| 竜王戦との違い | 竜王戦は、どの組からでも1期で竜王になれる（トーナメント）。名人は、C級2組から毎年1つずつ上がっても、挑戦まで最短5年かかる |
| 新四段 | C級2組から始める |
| A級 | 10名の総当たり（9局）。1位が名人挑戦。同じ勝ち数で並んだら、パラマス方式（順位の下の者から勝ち抜き）のプレーオフ。下位2名がB級1組へ降級 |
| B級1組 | 13名の総当たり（12局）。上位2名が昇級、下位2名が降級 |
| B級2組・C級1組・C級2組 | それぞれ約25・30・50名で、10局（総当たりではなく、組み合わせで当たる相手が決まる）。上位が昇級（C級2組は3名、B級2組は2名、C級1組は2名。**C級1組の枠は近年変わった可能性があり要確認**） |

| 順位 | クラスの中の順位は前期の成績で決まる。同じ勝ち数なら順位が上の者が上（昇級・降級・降級点を決める。いわゆる「頭ハネ」）。昇級してきた者・降級してきた者・新四段の順位の付け方は要確認 |

いまの裏の自動の順位戦（`ryuo-league.mjs`）は、定員をA級10・B級1組13・B級2組25・C級1組35・C級2組50、昇級をB級1組2・ほかは3、C級2組の下位2名がフリークラス、としている（降級点はない）。名人戦を作るときに、プレイヤーのいるクラスは実際に指した成績で決め、ほかのクラスは今の自動の決め方のまま、規定の数（昇級の人数・降級点）を1の表にそろえる。

## 2. ゲームでの形（何を再現し、何を縮めるか）

- 大会の選択の準備中のタイル「順位戦」「名人戦」を、1つの大会「**名人戦**」（副題「順位戦から名人へ」）にまとめる。順位戦は名人戦の予選なので、分けると「何が違うの？」と迷う（U:2）。
- プレイヤーは、C級2組の新四段として始める（2期目以降は、前期の成績で上がり下がりしたクラス）。
- 1期 = 1年。プレイヤーのクラスのリーグ戦を指し、成績で昇級・残留・降級点・降級が決まる。A級で1位になれば名人戦七番勝負。名人になったら、次の期はA級の1位を迎えて防衛戦。
- 名人までの道は長い（最短6期）。竜王戦の「1期で頂上まで行ける夢」と対になる「何年もかけて登る夢」にする（D:4-4 でこぼこ、2-2 長い溜め）。ただし1期の中にも山場（昇級争い・最終局・プレーオフ・七番勝負）を作り、1局ごとに意味があるようにする。

## 3. 機能設計メモ（Game_Nintendo_Design.mdの14章の形）

### 機能名：名人戦（順位戦から名人へ）

- **一言で**：C級2組の新四段から、毎年1つずつクラスを上がって名人をめざす。1局の勝ち負けで、昇級のライン・順位・降級点が動く、リーグ戦の駆け引き。
- **解く課題**：準備中だった順位戦と名人戦／竜王戦だけでは長く遊ぶ目標が1つしかない／裏で動いている順位戦にプレイヤーが関われない、を1つの大会で解く（D:2-5）。
- **リスクとリターン**：1期10局の中で、1敗の重さが毎局変わる（全勝なら自力で昇級、1敗でほかの結果待ち、2敗で昇級争いから遠のく）。昇級すれば相手は強くなり、段位も上がる（C級1組で五段…A級で八段）。
- **溜めと解放**：期の中は「自力／他力」の札で緊張を見せ、最終局の一斉対局で、ほかの対局の結果が1つずつ明かされて昇級が決まる（解放）。期をまたいでは、クラスを1つ上がるたびに五重塔を1階登る。
- **初めての人の最初の1分**：入口で、五重塔（1階がC級2組、5階がA級、相輪が名人）と、自分の駒が1階にいる絵、目標の1行（「10局で上位3名に入れば昇級」）、「出場する」。押すと、すぐ1回戦の相手と対局できる。
- **上級者の深さ**：順位による同星の上下（頭ハネ）、ライバルの羽音が同じC級2組から登ってくる昇級争い、A級のプレーオフ、名人の防衛と永世名人（通算5期）。
- **失敗したとき**：負けても期は続く（リーグ戦なので1敗で終わらない）。降級点は1回では落ちない安全網（D:4-3）。C級2組からは落とさない（フリークラスは作らない。5章）。
- **ご褒美と使い道**：昇級と段位、名人の称号、永世名人。昇級の判子と、五重塔を1階登る演出。やこびノートに順位戦の履歴（何期目にどのクラスで何勝）。
- **ほめる瞬間**：自力で昇級が決まった1局（その場で判子）、最終局で他力の昇級が決まった瞬間、全勝、名人獲得。
- **捨てるもの**：フリークラスへの陥落（遊びが止まる）。持ち時間・2日制（対局の長さは今の対局と同じ）。勝ち負けの表に評価値を出すこと。
- **確かめ方**：初めての人に1期（10局）遊んでもらい、毎局「いま昇級できそうか」を言えるか聞く。最終局の結果発表で、ほかの対局を見たくなるか。

## 4. 1年の流れと、竜王戦との関係（大事な決定）

いまは、竜王戦の期が終わるたびに「棋界の1年」（年間成績・順位戦の自動・ほかのタイトル戦・昇段・引退・新四段）が進む。名人戦を足すと、プレイヤーのクラスの順位戦を、その1年の順位戦として使う。

**案A（おすすめ）: 共通の1年**
- 1年の中に、竜王戦の第N期と順位戦の第N期がある（現実と同じく並行して進む）。どちらから指してもよく、「つぎはこれ」が次の1局を勧める。
- 1年が進むのは、その年にプレイヤーが出場した大会がすべて終わったとき（竜王戦だけなら今と同じ）。名人戦だけに出た年は、竜王戦は名簿の棋士だけで自動で進める（プレイヤーは不参加で、組は変わらない）。
- 1年が進むとき、プレイヤーのクラスは実際に指した成績で、ほかのクラスは今の自動の決め方で、昇級・降級を決める。名人戦の挑戦者は、A級の実際の1位。
- 竜王戦の結果の画面の「次の期へ」は、順位戦が残っていれば「順位戦があと3局。終えると次の年へ」と添えて、順位戦の画面へ案内する。
- 良い点: 名簿・推し・羽音・善彦・名鑑の成績が、2つの大会で同じ1年を生きる。現実の棋界と同じ。

**案B: 別々の暦**
- 名人戦は独自の期の番号で進み、名簿の1年は竜王戦だけで進む。名人戦の期の始めに、クラスの棋士を写して使う。
- 良い点: 作りやすい。悪い点: 名人戦の途中で名簿の1年が進むと、同じ棋士が別のクラスにいる、などの食い違いが出る。

## 5. 順位戦の期（プレイヤーのクラス）

| 項目 | 決め方（初期値） |
|---|---|
| 参加者 | 名簿のそのクラスの棋士全員（C級2組50・C級1組35・B級2組25・B級1組13・A級10）。羽音は新四段なので、プレイヤーと同じC級2組から始まる |
| プレイヤーの対局 | C級2組・C級1組・B級2組は10局（相手は、組み合わせの決まりで、同じ相手と2度当たらないように選ぶ。強さが近い相手と、順位の近い相手を混ぜる）。B級1組は12局、A級は9局の総当たり |
| ほかの棋士の対局 | プレイヤーと同じ回戦の対局を、竜王戦と同じ自動対局（`ryuo-simulation.mjs`）で決め、1局ごとに表が進む |
| 順位 | 1期目のプレイヤーは新四段の位置（C級2組の下のほう）。2期目からは前期の成績で決まる。同じ勝ち数なら順位が上の者が上 |
| 昇級 | C級2組3名・C級1組2名・B級2組2名・B級1組2名（1章の要確認の結果で直す） |
| 降級点・降級 | B級2組・C級1組・C級2組は下位の約5分の1に降級点。B級2組・C級1組は2点で降級。C級2組は降級しない（3点でフリークラスの代わりに「次の期は降級点なしの再挑戦」とする。遊びを止めない。D:4-3）。B級1組・A級は下位2名が降級。勝ち越しか2期続けて5割で、降級点を1つ消す |
| 名人挑戦 | A級の1位。同じ勝ち数で並んだら、パラマス方式のプレーオフ（プレイヤーが入れば指す。ほかは自動） |
| 段位 | 今の昇段規定（`applyDanRules`）のとおり、C級1組で五段・B級2組で六段・B級1組で七段・A級で八段・名人で九段 |
| 永世名人 | 名人を通算5期 |

### 5-1. 自力・他力（毎局の目標）

- 残りを全部勝ったら、ほかの結果にかかわらず昇級できる → 「自力」の札（琥珀）。
- 全部勝っても、ほかの棋士の結果しだい → 「他力」の札（灰）と「○○さんが1敗すれば」のように、いちばん効く他力の1行。
- 昇級の可能性がなくなった → 札は出さず、「残留を決めよう」「勝ち越して降級点を消そう」など、次の目標に替える（責めない。U:4-3）。
- 計算は、各棋士の今の勝ち数・残りの対局数・順位から、プレイヤーより上になりうる人数を数える。

### 5-2. 最終局の一斉対局（解放）

- プレイヤーの最終局が終わったら、同じ日のほかの対局の結果を、昇級争いに関わる順に1局ずつ明かす（押すと飛ばせる。1局0.6秒、合わせて5秒以内）。
- 昇級が決まった瞬間に判子。A級なら「将棋界の一番長い日」の題で、挑戦者と降級者が決まるまで。

## 6. 名人戦七番勝負・名人

- プレイヤーがA級1位 → 名人（名簿の名人。最初は天鷺善彦の六冠に名人が入っている）と七番勝負。竜王戦の③番勝負と同じ画面（`RyuoSeries.vue`）を使う。
- 名人になったら、次の年は順位戦を指さず、A級（自動）の1位を迎えて防衛戦。
- 名人の期数・永世名人は、キャリア（新しい保存`meijin-career`）と称号に残す。

## 7. 画面

竜王戦の画面の作り（上の帯1本・段階の道のり・次の一局の枠・PCの2列）をそのまま使い、地図と表だけを名人戦のものにする（覚えることを増やさない。U:2）。

| 場所 | 中身 |
|---|---|
| 入口 | ドット絵の**五重塔**の全景（1階C級2組〜5階A級、上の相輪に名人の座）。自分の駒が今のクラスの階に立つ。番付の代わりに、5つのクラスの札（自分のクラスに「あなた」）。目標の1行・やこび姫のひとこと・設定の要約・「出場する」 |
| 上の帯 | 戻る・題字「第N期 名人戦」・段階の道のり（**① 順位戦（C級2組） → ② 最終局 → ③ 名人戦七番勝負**。A級以外の年は③を薄く「A級で1位なら」） |

| 次の一局の枠 | 竜王戦と同じ部品（相手の顔・能力・得意戦法・やこび姫の1行・「対局する」）。「勝てば」の代わりに「自力／他力」の札と、勝った場合・負けた場合の順位の見込み |
| 結果 | 今期の成績（10局の○●）、昇級・残留・降級点・降級の判子、五重塔を1階登る演出、次の期の目標 |

- 竜王戦と同じく、対局から戻ると期の画面、対局を中断したら期の画面からも再開できる。
- 「つぎはこれ」は、竜王戦と同じく「続きを指す」「○○対策」を出す（`ryuo-next.mjs`を大会の種類に依存しない形に広げる）。

## 8. 規模と難易度

- **難易度**：竜王戦と同じ14段階（棋士のレーティングから、実際に指す相手のLvを決める）。
- **規模**（1期の対局数）：実物どおり（C級10局・B級1組12局・A級9局）／短め（すべて7局。B級1組・A級は順位の近い相手から）／みじかい（すべて5局）。昇級・降級の人数は変えない（少ない対局ほど、1敗が重くなる）。
- やこび姫の助言・閃き・待ったの回数は、竜王戦と同じ設定の行。

## 9. 物語（羽音と善彦）

- 天鷺羽音は新四段なので、プレイヤーと同じC級2組から始まる。毎期、昇級争いのライバルとして表に札を付け、当たるのは期の中の1局（組み合わせで必ず当てる）。羽音の昇級・降級も実際の成績で決まり、先に上がられることもある（追いかける動機。D:8-3）。
- 天鷺善彦は名人（六冠の1つ）。A級に上がると、表の上の「名人」の欄に顔が出る。

## 11. 作る順番（案）

1. **段階1：データ**。`meijin.mjs`・`meijin-career.mjs`とテスト、`ryuo-league.mjs`の規定の数。
2. **段階2：1年の進め方**。竜王戦と名人戦の共通の1年（案Aなら）。
3. **段階3：画面**。大会の選択のまとめ、入口、期の画面のリーグ表と次の一局、対局との連携、結果。
4. **段階4：演出**。五重塔の地図、自力/他力の札、最終局の一斉対局、昇級の判子、名人戦七番勝負、永世名人、「つぎはこれ」。

## 12. 決めてほしいこと

1. 順位戦と名人戦を1つの大会「名人戦」にまとめる（準備中の「順位戦」のタイルはなくす）。それとも分ける。
2. 竜王戦との1年の関係：案A（共通の1年。おすすめ）か、案B（別々の暦）。
3. 規模の初期値：実物どおり（1期10局）か、短め（7局）か。
4. 地図のモチーフ：五重塔（1階ずつ登る）でよいか。ほかの案（階段・城・竜王戦の山の続き）。
5. C級2組の降級点3点：フリークラスへ落とさない（再挑戦にする）でよいか。

## 13. 決めたこと（2026-10-22）

1. 順位戦と名人戦は、1つの大会「名人戦」（副題「順位戦から名人へ」）にまとめる。準備中の「順位戦」のタイルはなくす。
2. 竜王戦とは**別々の暦**（案B）。名人戦は自分の期の番号で進み、竜王戦の期と名簿の「棋界の1年」とは結びつけない。
   - 棋士として1年を過ごすモード（カレンダーで対局し、奨励会入会試験から始め、三段リーグにいる間はタイトル戦の予選にも混ざれる。ノベルゲーム風味の場面と物語つき）は、別のモードとして後で作る。共通の1年はそのモードで扱う。
   - そのため、名人戦の順位戦の処理（`meijin.mjs`）は、保存や暦に依存しない形にする（期の作成・組み合わせ・回戦の進行・順位表・昇級と降級点・自力/他力・プレーオフ・番勝負）。棋士モードのカレンダーからも同じ処理を呼べるようにする。
3. 規模は設定で調整できる（実物どおり／短め／みじかい）。初期値は実物どおり。
4. 地図は五重塔。
5. C級2組の降級点3点は、フリークラスへ落とさず、降級点を消して再挑戦にする。

### 13-1. 別々の暦の決め方（案B）

- （2026-10-22に変えた: 順位戦の世界は名簿の`roster.junni`に1つだけ持ち、名人戦のキャリアには持たない。`docs/player-world-note-design.md`の2章）名人戦の「順位戦の世界」（全クラスの棋士・順位・降級点・名人）を、名人戦のキャリアに持つ（`meijin-career`の`league`）。名簿（`ryuo-roster`）の`junni`とは別に持ち、名簿の裏の自動の順位戦はそのまま動かす（竜王戦の名鑑などに出る順位戦の記録は、竜王戦の暦のもの）。
- 最初の名人戦では、名簿の今の`junni`から順位戦の世界を作る。プレイヤーはC級2組の最後の順位（新四段）に入る。羽音は新四段なので、C級2組に入れる。名人は名簿の名人（最初は天鷺善彦）。
- 期の始めに、名簿と照らし合わせる: 名簿から消えた棋士（引退）は外し、名簿にいて順位戦の世界にいない棋士（新四段）はC級2組の最後に足す。棋士の強さ・能力・使用率は、その時の名簿のものを写す。
- 期の終わりに、プレイヤーのクラスは実際の成績で、ほかのクラスは自動（クラスの平均との勝率で各棋士の勝ち数を決める）で、昇級・降級点・降級を決め、次の期の順位を付ける。名人戦七番勝負は、プレイヤーが出ないときも自動で決める。
- 次の期の順位（要確認の点を簡略に）: 上のクラスから降級してきた棋士 → 残った棋士（今期の成績順） → 下のクラスから昇級してきた棋士 → 新四段、の順。
