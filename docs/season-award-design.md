# 期の終わりの表彰式と賞状帳

竜王戦・名人戦で1期を終えたときに、「終わった」と感じられる区切りを作る（2026-10-22）。

- 前は、結果の画面の主役のボタンが「次の期へ」だった。押すとすぐ次の期の入口へ進むので、1年を戦い終えた区切りがなく、終わった気がしない。
- そこで、結果の画面の主役を「表彰式へ」にした。縦書きの賞状を1枚渡して判子を押し、やこび姫が「第N期、おつかれさま！」とねぎらう。閉じると大会の選択へ戻る。次の期は、プレイヤーが自分で選んで始める。
- 賞状は「賞状帳」に残り、大会の選択からいつでも見返せる。
- 形は3案から、ユーザーが「表彰式と賞状」を選んだ。ほかの2案は次のとおり。
  - 幕が下りる短い演出だけ（軽め）
  - この期の歩みを1局ずつ流したあとに賞状（重め）

## 1. 機能設計メモ（Game_Nintendo_Design.mdの14章の形）

### 機能名：表彰式と賞状帳

- **一言で：** 1期を戦い終えたら、賞状を受け取ってから大会の選択へ戻る。
  - 「ギュッとして」きた1年を、表彰式で「パッと解消」する（G:2-2）。
  - 大事な瞬間は一拍止める（G:3-2）。紙が上がってから判子が落ちるまでの一拍と、判子の音で止める。
- **解く課題：**
  1. 終わった感がない。区切りの儀式と、画面を出ていく動きで解く。
  2. 結果がその場かぎりで流れてしまう。賞状として残る形にする（G:5-3 見返り）。
  3. 負けた期の最後が「敗退」で終わる。負けた期にも敢闘賞を渡して、最後をねぎらいで終える（G:7-2 勝った人も負けた人も楽しい）。
- **リスクとリターン：** 賞状の格は、その期の到達点で決まる。どこまで勝ち上がれば金・銀・朱の賞状がもらえるかが、次の期の目当てになる（G:5-2 目の前に吊られたごほうび）。
- **溜めと解放：**
  - 溜め: 結果の画面で、判子と番付・五重塔を見る。
  - 解放: 「表彰式へ」を押すと、紙が下から上がり（0.5秒）、一拍おいて判子が落ちる（0.7秒後。判子の音）。金・銀・朱の賞状なら紙吹雪が1回だけ降る。最後に、やこび姫のねぎらいと「大会の選択へ」が出る。
- **初めての人の最初の1分：** 初めて期を終えると、1枚目の賞状をもらう。大会の選択に「記録 › 賞状帳 1枚」が増えているのを見て、賞状が残ることを知る。
- **上級者の深さ：** 賞状帳に、竜王・名人の金の賞状が並ぶ。期の番号と成績が残るので、自分の歩みを振り返れる。
- **失敗したとき：** 負けた期にも賞状（敢闘賞）を渡す。
  - 文面は「最後まで力を尽くして戦いました。その健闘をたたえ」。
  - やこび姫のひとことは「勝った対局も負けた対局も、ぜんぶ次の力になるよ」。
  - 紙吹雪は出さず、静かに渡す（降級を派手に祝わない。竜王戦の結果の判子と同じ考え）。
- **ご褒美と使い道：**
  - ご褒美は賞状。賞状帳に集まり、いつでも開いて眺められる。
  - 格は4つで、賞状の縁の色と賞状帳の判子の色で見分ける。
    - 金: タイトル（竜王獲得・防衛、名人獲得・防衛）
    - 銀: タイトル戦に出た（竜王挑戦・名人挑戦・七番勝負に出場）
    - 朱: 優勝・昇級・進出（組の優勝と準優勝、昇級、決勝トーナメントと挑戦者決定戦への進出、順位戦の昇級）
    - 敢闘賞: それ以外
- **ほめる瞬間：**
  - 判子が着いた瞬間（音）と、紙吹雪（G:5-4）。
  - やこび姫は、どの格でも「第N期、おつかれさま！」から始める。
    - 金: 「○○、ほんとうにおめでとう！」
    - 銀: 「タイトル戦の大舞台、かっこよかったよ」
    - 朱: 「○○、よくがんばったね」
- **捨てるもの：**
  - 表彰式の中の「次の期へ」は作らない。区切りを作るのが目的なので、いったん大会の選択へ戻す。次の期は、竜王戦・名人戦の札から1回で始められる。
  - 賞状の印刷・画像の保存も作らない。
- **確かめ方：** 期を終えて表彰式を見た人が、そのまま次の期をすぐ始めずに、賞状帳を開くかどうかを見る。

## 2. 画面

- **結果の画面：** 竜王戦（`ShogiTournament.vue`）と名人戦（`ShogiMeijin.vue`）の主役のボタンを「表彰式へ」にした。
  - そのほか（判子・成績・次の期の1行・くわしく）は前のまま。
  - 名人戦は`ceremony`イベントで大会の画面に知らせ、賞状は大会の画面が出す。
- **表彰式（`src/SeasonAward.vue`）：** 画面全体に、縦書きの賞状を出す。右から順に次のものを書く。
  - 見出し「賞状」か「敢闘賞」
  - 「第二期竜王戦」
  - 賞（例「決勝トーナメント 進出」「C級二組順位戦 二位」）
  - 添え書き（例「C級一組へ昇級」）
  - 「（プレイヤー名） 殿」
  - 本文
  - 日付（二〇二六年十月二十二日）
  - 「やこび姫」と判子（竜／名）
- **賞状の書き方：**
  - 数字は漢数字にする。
  - 縁は格で変える。金と銀は二重線に内側の光、朱は朱の二重線、敢闘賞は茶の二重線。
  - 紙の幅は中身に合わせ、縦の長さは画面の高さに合わせる（`min(26rem, 100dvh − 15rem)`）。
  - 縦書きの字は、1字ずつ1文字分の箱に入れて並べる（`src/VerticalText.vue`、分け方は`src/core/vertical-text.mjs`）。箱の中は横書きで描く。字体（フォント）によっては漢字に縦書きの送り幅がなく、そのまま`writing-mode: vertical-rl`で書くと字が重なって潰れたため（2026-10-28に直した）。句読点は右上へ寄せ、長音・括弧は90度回し、句読点と閉じ括弧は前の字と同じかたまりにして列の頭に来ないようにする。戦法占いの札も同じ部品で書く。
- **表彰式の操作：**
  - どこを押しても演出を最後の形へ飛ばす（操作を止めない）。
  - 動きを減らす設定では動かさない。
  - 下に、やこび姫のひとことと「大会の選択へ」を置く。
  - ブラウザの戻る操作は表彰式を閉じ、結果の画面へ戻る。
- **表彰式を終えたとき：** 期の結果を見終えたことにする（竜王戦は`result-seen`、名人戦は`meijin-result-seen`）。そのうえで大会の選択へ戻る。竜王戦・名人戦の札は、次の期の入口を開く。
- **賞状帳：**
  - 大会の選択の「記録」の札「賞状帳」から開く。札の小さな説明は「N枚」で、まだないときは「期を終えるともらえる」。
  - 新しい順に1行ずつ並ぶ。各行は格の色の判子と「第N期 竜王戦 ○○」、成績、敢闘賞の印。
  - 押すと、その賞状を動かさずに開く（ボタンは「閉じる」）。

## 3. データとファイル

- **`src/core/season-award.mjs`：**
  - `ryuoAward(season, { playerName, at })`・`meijinAward(season, { playerName, at, classLabels, nextClass })`: 終わった期から賞状を作る。
  - `awardText(award)`: 縦書きの文。
  - `awardTalk(award)`: やこび姫のひとこと。
  - `awardLine(award)`: 賞状帳の1行。
  - `loadAwards`・`addAward`: 賞状帳の保存。
  - 漢数字は`kanjiNumber`・`kanjiText`・`kanjiDate`。
- **賞状の判定（竜王戦）：** 期の結果の`outcome`と、組のランキング戦の結果（`path`）から決める。
  - 組の賞（朱・敢闘）にだけ、昇級したら「N組へ昇級」を添える。
- **賞状の判定（名人戦）：** `result.outcome`から決める。
  - 昇級のときは、クラスと順位を賞にし、次のクラスを添える。
- **保存：**
  - `localStorage`のキーは`yacobihime:shogi-match:awards`。古い順の配列で、最大200枚。
  - 同じ大会の同じ期（`id`が`ryuo-2`・`meijin-1`の形）は1枚だけで、先にあるほうを残す。
- **渡すとき（`src/ShogiMatchGame.vue`）：**
  - 期が終わってキャリアに反映するとき（`finalizeRyuoSeason`、`recordMeijinOutcome`の期の終わり）に賞状帳へ足す。名前と日付は、そのときのものを書く。
  - 賞状帳を作る前に終えて、まだ結果を見ていない期にも、読み込んだときに賞状を足す。
  - 賞状帳は`awards`として大会の画面に渡す。
- **展示の「最初から」：** アプリのキーをまとめて消すので、賞状帳も消える。

## 4. 紙の大きさを測って決める（2026-10-29、ユーザーの報告「iPadの縦画面で見ると、賞状がこのような表示になる」。写真では、紙が1列分ほどの細さに縮み、「敢闘賞」の字が左で切れていた）

- **原因：** 縦書きの紙の幅を、ブラウザに中身から計算させていた（紙は横書きの画面の中の、縦書きの箱）。iPadのSafariは、この幅を中身より狭く計算し、はみ出した列が見えなくなっていた。この作業環境のChromiumでは、iPadの大きさでも崩れなかった。ただし横向きのスマホ（844×390）では、紙が低くなる分だけ横に長くなり、画面からはみ出して右の「敢闘賞」が切れていた。
- **直し方（`src/SeasonAward.vue`の`fitPaper`）：**
  1. 紙の各行（見出し・期・賞・名前・本文・日付・やこび姫）の位置を測り、右の端から左の端までに枠の余白を足して、紙の幅を決める。行の位置は紙の高さだけで決まり、紙の幅の計算の誤りに左右されない。紙が上がる動きの変形も数えない（`offsetLeft`・`offsetWidth`で測る）。
  2. 紙の高さは18rem〜26rem（画面の高さから15remを引いた値。背の低い画面でも18remは取り、横に長くなりすぎないようにする）。
  3. 紙が画面（ねぎらいとボタンの上）に収まらなければ、紙ごと縮める（`zoom`。字と枠の釣り合いはそのまま。0.5倍まで）。広い画面（iPad・パソコン）では、余裕があれば1.35倍まで大きく出す（前は広い画面の真ん中に小さな紙だった）。
  4. 測るのは、開いたとき・字体を読み終えたとき・画面の大きさが変わったとき。測るあいだの一瞬は紙を見せない。
- **原則：** U:7-5 画面の大きさと向き（どの大きさでも切れない）、D:5-3 ご褒美の見せ方（賞状は期の最後のご褒美なので、読める大きさで出す）。
- **確かめたこと：** この作業環境のChromiumで、賞状帳から敢闘賞（短い）と朱の賞状（昇級の添え書きつき・賞の名前が長い）を開いた。768×1024・820×1180・1024×1366・1180×820・1366×768・390×844・360×640・844×390で、紙が画面に収まり、字が切れないことを写真で見た。iPadのSafariでは確かめていない（この作業環境にはSafariがない）。実際に遊んでの確認は未確認。
