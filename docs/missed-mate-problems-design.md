# 見逃したn手詰めを、自分の詰将棋にする（設計 2026-10-27、実装・自動テスト済み）

対局で見逃した詰みを記録し、問題集で解き直せるようにする。いままでも「あなたの対局から」の問題はあったが、3手詰めまでで、問題集の一覧には出ず、復習の箱の期日が来たときに「やこび姫からの1問」として出るだけだった。

## 機能設計メモ（`Game_Nintendo_Design.md`の14章の形）

### 機能名：あなたの対局から（見逃したn手詰め）

- 一言で：対局で見逃した詰みが、自分だけの詰将棋になって、問題集の「あなたの対局」に並ぶ。
- 解く課題：見逃した詰みを、あとから自分で確かめる場所がない／長い詰みは問題にならなかった。
- リスクとリターン：なし（解き直しの場）。一発で解けば★、復習の箱から外れていく。
- 溜めと解放：対局で見逃す（悔しさ）→ 問題集で見つけ直す（スッキリ）。正解で「対局では見逃しちゃった詰みだね。もう見つけられるようになったよ！ 本番の大会でも決めよう！」。
- 初めての人の最初の1分：まだ問題がないときも棚は出し、「対局で詰みを見逃すと、ここに問題ができるよ」と、どうすれば増えるかを伝える。
- 上級者の深さ：5手・7手…と長い詰みも、自分の対局の局面で解ける。読み筋と違う詰み方でも正解になる。
- 失敗したとき：問題集と同じ。逃げられ方を盤に並べ、自動で元の局面に戻る。ヒントと「答えを見る」（読み筋の手順を1手ずつ）もある。
- ご褒美と使い道：解いた記録（★・✓）。7手詰めまでの見逃しは「つぎはこれ」の弱点の練習の入口にもなる。
- ほめる瞬間：解ききったとき。大会へつなげる一言を添える（AGENTS.mdの「このゲームの柱」）。
- 捨てるもの：答えを1つに決めつけること（読み筋は「答えを見る」の手順に使うだけで、判定は探索で広く認める）。
- 確かめ方：自動テスト（読み筋どおり・別の詰み方・詰まない王手・王手でない手）、ブラウザで棚と問題（スマホ縦・タブレット縦・デスクトップ）。

## 決めたこと

- **記録**（`src/core/review-problems.mjs`の`buildReviewProblem`）
  - 対局のあとの裏の解析（自由対局・竜王戦。`usePlayInsightAnalysis.ts`・`useRyuoStatsAnalysis.ts`）と、棋譜解析の振り返り（`useGuidedReview.ts`）で見つけた、プレイヤーが見逃した詰みを記録する。
  - 指す前の局面の解析の読み筋（pv）を手数分だけ取り、`problem-solver.ts`の`isMatingLine`で「どの手も指せる・攻め方の手はすべて王手・最後は詰み」を確かめる。確かめられたら、15手詰めまで、その手順を答えにした問題（`kind: 'line'`、`source: 'game'`）にする。
  - 読み筋がない・確かめられないときは、3手詰めまで、答えを書かない詰み探索だけの問題（`kind: 'mate'`。いままでどおり）にする。長い詰みは、実戦の局面では駒が多く、探索の時間の上限にかかるため。
  - 覚えるのは新しい40問まで（前は30問）。同じ局面は新しいほうで置き換える。保存は今までと同じ`yacobihime:shogi-match:review-problems:v1`。前の保存（3手詰めまでの`kind: 'mate'`）もそのまま読む。
- **判定**（`src/core/problem-set.mjs`の`judgeLineMove`・`judgeGameDeviation`）
  - 読み筋どおりの手は、すぐ正解にして、相手の応手も読み筋から出す（探索を待たせない。G:3-3）。
  - 読み筋と違う王手は、`judgeMateStep`（遠回りは認めない`slack: 0`）で、残りの手数で詰むかを確かめる。詰めば「対局の読み筋とは違うけど、◯◯でも詰むよ」と正解にし、相手の応手は探索で決めて続ける。そのあとは読み筋を使わず、手ごとに探索で判定する（`Game_Nintendo_Implementation.md`の9章「別の正しい答えを不正解にしない」）。
  - 詰まない王手は逃げ方を見せ、王手でない手は王手を促す（問題集と同じ）。探索が時間内に読み切れなかった手は、責めずに「読み切れなかったよ」と伝える。
  - 違う詰み方に進んだあとのヒントは、いまの局面から詰み探索で次の手を探す（`problemHint`）。
- **画面**（`src/ShogiProblemSet.vue`）
  - 問題集の区分のタブに「あなたの対局」を足す（4つ目）。新しい順に並べ、「10月26日の対局から・まだ解いていない」のように、いつの対局かと解いたかを添える。「つづきから」も同じ棚で使える。
  - タブは、狭い画面（34rem以下）では2列×2段に折り返し、横にはみ出さない。
  - 後手で詰ませる問題（あなたが後手だった対局）は盤を反転し、詰ませる側を手前にする（U:7-5。自分の対局と同じ向き）。
  - 長い詰み（5手以上）は、途中の台詞に「（4/7手）」のように進み具合を添える。
- **弱点の練習**（`play-insight.mjs`の`detectWeaknesses`）：「詰みを逃した」の弱点として数えるのは7手詰めまで（問題集の詰将棋の手数と同じ）。それより長い詰みは問題にはするが、弱点としては責めない。
- 根拠：G:6-1（上達そのものが楽しさ。自分の対局の局面で上達を見せる）、G:6-4（間隔をあけた復習。復習の箱にも入れる）、G:7-3（やり直しの単位を小さく。負けた対局の1局面から）、G:4-1（初心者にやさしく。長い詰みを弱点として責めない）、U:4-3（責めない文言）。
