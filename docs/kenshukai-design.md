# 研修会：F2クラスからA2・Sクラス、そして奨励会へ

大会の選択の「プロへの道」にある「研修会」のタイル（いままで準備中）を、遊べる大会にする。研修会に入ってF2〜Sの13クラスを上がり、A2に上がったら試験なしで奨励会6級に編入できる。

- 状態：実装（2026-10-24）。決めたことは4章、実装は10章。
- このゲームの柱（`AGENTS.md`）：主役は大会と物語。研修会は「プロへの道」の1段目で、奨励会（`docs/shoreikai-design.md`）へつながる。奨励会の入会試験に落ちた人の、もう1つの道にもなる。
- `docs/nintendo-design/Game_Nintendo_Design.md`の1章の長期の目標「研修会→奨励会→プロの道のり」の、最初の段。
- 処理は奨励会と同じく、画面・保存の仕組み・暦に依存しない形にする（後で作る棋士モードからも呼べるように）。

## 0. 見立て

- 奨励会は入会試験から厳しい。棋力が足りない人や、試験に落ちた人が「次に何をすればいいか」が、いまはない（D:4-3 安全網）。
- 実物の研修会は、クラスが13もあり、上がるたびに名前が変わる。「あと何勝でD1」という目の前のごほうび（D:5-2）を、奨励会より細かい刻みで作れる。
- 研修会ならではの現実のモチーフ（D:2-3）は、プロの先生との**指導対局**（駒落ち）。勝ち負けが昇級の成績にも数えられる。将棋のハンデ（D:4-6）を、物語の中で自然に体験できる。
- 強さは奨励会と同じく、研修会員の強さをレーティングで持ち、実際に指す相手のLvは難易度で決める。ただし研修会は、上のクラスほど相手が強いと感じられるよう、勝率の目安の幅（6〜8割）の中で、F2を易しく、Sを手ごわくする（7章）。

## 3. 遊びの流れ

```
入口（受験クラス・設定）
  → 入会試験（4局。成績で入るクラスが上下する。落ちない）
  → 例会（1日4局。2回に1回は、4局目がプロとの指導対局）をくり返し、昇級
  → A2に上がる：奨励会6級への編入の資格（すぐ編入しても、Sを目指して続けてもよい）
  → Sに上がる：研修会の頂点。修了証と、奨励会への編入
```

### 機能設計メモ（研修会という大会）

- 一言で：13のクラスを1つずつ上がり、A2で奨励会への扉を開く。
- 解く課題：
  1. 奨励会の入会試験に届かない人・落ちた人に、プロへの道の続きがない（安全網）。
  2. 駒落ち（ハンデ）を、ふつうの遊びの中で体験する場所がない。
  3. 「プロへの道」の札が、半分準備中のまま。
- リスクとリターン：受験クラス（上ほど近道だが、試験の相手が強い。D:4-2 悪魔の釜）。試験の成績しだいで、1つ上のクラスから入れる。
- 溜めと解放：昇級まであと何勝 → 昇級の判子と、名札が上のクラスへ掛かる。A2昇級 → 「奨励会6級に編入できる」の大きな判子（ギュッとしてパッと解消。D:2-2）。
- 初めての人の最初の1分：大会の選択で「研修会」を押す → やこび姫が「研修会は、プロを目指す子たちの会。クラスを上げて、A2に上がったら奨励会に入れるよ」と言い、おすすめの受験クラスが出ている。「受験する」ですぐ入会試験の1局目。
- 上級者の深さ：受験クラスを上げて近道する。Sクラスまで登る。指導対局の駒落ちを、上手を倒して勝ち越す。
- 失敗したとき：
  - 入会試験は落ちない（成績が悪ければ、1つ下のクラスから入る）。研修会そのものが安全網なので、門前払いしない（D:4-3）。
  - 負けが込むと降級点（奨励会と同じ数）。降級点が付く前に、やこび姫が「あと1つ負けると降級点」と知らせる。
- ご褒美と使い道：昇級の判子と名札の掛け替え。A2で奨励会6級への編入（入会試験を飛ばせる＝プロへの近道）。Sで修了証（賞状帳）。
- ほめる瞬間：連勝で昇級、指導対局でプロ（上手）に勝つ、A2昇級。
- 捨てるもの：女流棋士の資格（プレイヤーの性別は持たないので、プレイヤーには出さない。名簿の研修会員の便りに使う）。年齢制限。研修会どうしの手合いの駒落ち（研修会員どうしは平手）。5局目の希望対局。
- 確かめ方：みじかいで、勝率7割の人がD2から入って45局前後でA2に届くこと（10章）。どの画面からも「次の1局」をすぐ押せること。

## 4. 決めたこと（2026-10-24。ユーザーの「判断は任せます」による）

1. **入会試験は落ちない**。4局（実物どおりは8局）の成績で、受験クラスから1つ上・そのまま・1つ下のどれかで入る。落とさないのは、研修会が奨励会の安全網だから（D:4-3）。
2. **例会は1日4局**（実物どおり）。1局ずつ保存するので、途中でやめてもよい。
3. **指導対局**：2回に1回の例会の4局目は、竜王戦の名簿の棋士との駒落ち。手合いはクラスで決める（F：二枚落ち、E：飛香落ち、D：飛車落ち、C：角落ち、B：香落ち、A・S：平手）。勝ち負けは昇級の成績に数える（実物どおり）。駒落ちなので、レーティングとLvの壁には数えない。設定で「なし」にでき、なしなら4局とも研修会員と指す。
4. **降級点**は奨励会と同じ規模の値（みじかい1勝4敗、短め2勝6敗、実物どおり2勝8敗）。F2より下はない。
5. **奨励会への編入**：A2に上がったら資格。研修会の画面に「奨励会6級に編入する」をいつも出し、押すと研修会を閉じて、奨励会の入口へ（師匠を選んで「編入する」。入会試験はない）。Sを目指して続けてもよい。Sに上がったら研修会の頂点で、修了証をもらい、編入か終わるかを選ぶ。
6. **年齢制限はない**（研修会員は年をとり、ほかの研修会員は21歳で卒業する）。
7. **女流棋士**は、プレイヤーには出さない。名簿の女性の研修会員がB1に上がったら、便りで「女流棋士2級の資格を得た」と出す（現実のモチーフ）。
8. **奨励会の入会試験に落ちたとき**、不合格の画面に「研修会からA2に上がれば、試験なしで6級に編入できる」と、研修会への道を出す。
9. 天鷺羽音は研修会には出さない（奨励会の三段のまま）。同期（入会試験の相手から2人）は奨励会と同じく作る。

## 5. 研修会の世界（名簿）

- 竜王戦の名簿・奨励会の世界とは別に、研修会員の名簿を持つ。クラスごとに規模の人数（みじかい5名、短め6名、実物どおり8名）。名前・年齢・クラス・レーティング・棋風と特殊能力・得意戦法は、奨励会員と同じ作り方。
- 強さの目安（竜王戦の名簿と同じ尺度）：F2はR870、1クラス上がるごとに+25、A2がR1120（奨励会6級のR1150のすぐ下）、SがR1170。
- ほかの研修会員は、才能による伸びでクラスを上がる（奨励会と同じ考え方）。A2以上に上がった人は、半分が奨励会へ編入していなくなる（便り）。21歳で卒業。3か月ごとに新しく入会する。
- 例会1回は半月。

## 6. 入会試験と例会

- 受験クラス：F2〜C1。おすすめはいまの棋力から（`recommendedEntryClass`）。
- 入会試験：受験クラスの研修会員と4局（実物どおりは8局）。みじかい・短めは4勝で1つ上、2〜3勝でそのまま、0〜1勝で1つ下。実物どおりは7勝以上で1つ上、4〜6勝でそのまま、3勝以下で1つ下。
- 例会1回で4局。相手は同じクラスか、1つ上下の研修会員。同じクラスに同期がいれば、優先して当てる。
- 指導対局は、2回に1回の例会の4局目（設定が「あり」のとき）。相手は竜王戦の名簿の棋士（物語の人物は除く）。

## 7. 相手の強さ

- 研修会員のLvは、奨励会と同じく`tournamentLevel`（難易度とプレイヤーの棋力から、勝率6〜8割を目安にする）で決める。ただし、研修会員のレーティングはどれも6組の平均より300以上低く、そのままでは全員が「勝率8割」の下限に張り付く。そこで研修会のレーティングを、6組の平均のまわりに縮めて写してから換算する（`kenshukaiLevel`）。F2は勝率8割、Sは勝率6割くらいの相手になる。
- 指導対局の上手（プロ）は、棋士の本当の強さでは指さない（指導だから手加減する）。いまのクラスの研修会員の強さに、駒落ちのぶんを足した強さで指す（二枚落ち+200、飛香落ち+160、飛車落ち+120、角落ち+90、香落ち+40、平手+20。初期値）。

## 8. 画面

### 機能設計メモ（研修会の画面）

- 目的：いまのクラスと、昇級までの残り、次の1局が、ひと目で分かる。
- 画面の主役：名札掛け（13クラス。左のF2から右のSへ）。自分の名札は朱、同期は青。
- 情報の優先順位：1. 次の1局（相手と「対局する」） 2. 昇級までの残り 3. 名札掛け 4. 今日の例会の○●（4つ。指導対局は「指」の印） 5. 便り。
- 操作の流れ：入口 →「受験する」の1手で入会試験の1局目へ。
- 快の要素：昇級で名札が上のクラスへ掛かる動きと音（奨励会と同じ）。A2昇級の大きな判子。
- 作らないと決めたこと：研修会員全員の成績表。
- 確かめ方：3つの画面の大きさで、名札掛けと「対局する」が1画面に収まる。

- **入口**：題字「研修会」と名札掛け。下の枠に目標・やこび姫の一言・設定の要約・「変える」・「受験する」。
- **入会試験**：4つ（実物どおりは8つ）の○●と「あと何勝で1つ上から」。
- **例会**：名札掛け、昇級までの残り、今日の例会の○●、便り。A2以上なら、編入の札（「奨励会6級に編入する」）。
- **頂点（S）**：修了証の飾り、「修了証を受け取る」で表彰式、「奨励会へ編入する」「研修会を終える」。
- 対局中：対局の札は「研修会 D2」「研修会 入会試験（D2受験）」。指導対局は「指導対局（飛車落ち）」。背景は奨励会と同じ道場。

## 10. 実装（2026-10-24）

- **処理**：`src/core/kenshukai.mjs`（画面・保存の仕組み・暦に依存しない）。昇級の記録（`addToRecord`・`promotionReached`・`promotionProgress`）と降級点（`addToSlump`・`slumpWarning`）は、奨励会の関数をそのまま使う。テストは`kenshukai.test.mjs`。
  - 規定：`KENSHUKAI_SCALES`・`promotionRule`（上がった先のクラスで、F1へ・E2〜C1へ・B2〜Sへの3段階）、`examJoinClass`（入会試験の成績で入るクラス）、`shidoHandicap`（クラスで決まる手合い）、`kenshukaiLevel`（7章の換算）、`recommendedEntryClass`。
  - 世界：`createWorld`（クラスごとに規模の人数。A2以上は少し少なく）。ほかの研修会員は才能による伸びで上がり、A2・A1・Sの人は1か月に6%・12%・25%で奨励会へ移る（便り）。21歳で卒業。3か月ごとに入会。例会1回は半月。
  - 挑戦：`createKenshukaiRun`（入会試験から。竜王戦の名簿から指導対局の先生の候補を10人写す）、`recordKenshukaiGame`（1局を記録し、試験・例会を進めて次の1局を決める）、`describeKenshukai`（画面に出す形）、`nameboard`、`closeKenshukaiRun`（`transfer`は資格があるときだけ「編入」として残す）、`loadKenshukai`・`saveKenshukai`。
  - 例会の相手は、クラスが1つ上下までの研修会員。同じクラスに同期がいれば6割で当てる。ほかの研修会員の例会の結果は、プレイヤーの局ごとに、同じ回の対局を前に決めて速報に使う。
- **台詞と判子**：`src/core/kenshukai-speech.mjs`。判子は、S・A2（最大）、入会・昇級（Bから上は大きめ）、指導対局で勝った、降級点が消えた、降級、降級点。
- **画面**：`src/ShogiKenshukai.vue`（大会の画面の中に出す）。奨励会の画面の部品と名札掛け（`ShoreikaiNameboard.vue`を、列の数といちばん上の列を選べるようにした）を使う。入口・入会試験（○●と、どの勝ち数でどのクラスから入るかの3つの札）・例会（編入の札・名札掛け・昇級までの残り・今日の4局の○●と「指導」の印・便り）・Sクラス（修了証の飾り・「修了証を受け取る」・「奨励会へ編入」・「研修会を終える」）。
- **対局との連携**（`src/ShogiMatchGame.vue`）：`ryuoGame.event`に`kenshukai`を足し（大会の名前は`tournamentEventOf`で確かめる）、竜王戦・名人戦・奨励会と同じ`startRyuoMatch`で始める。指導対局は`learningStartPosition`の駒落ちの開始局面で、プレイヤーは下手（先手の側）、上手のCPUが先に指し、作戦の指定はしない。平手でないので、レーティングとLvの壁には数えない（`recordRatedGame`の平手の条件のまま）。千日手は、平手なら先後を入れ替え、駒落ちなら同じ手合いで指し直す。A2・Sに上がったら賞状を賞状帳に足す（`kenshukaiAward`）。対局の札は「研修会 D2クラス」「研修会 入会試験（D2受験）」、背景は道場。
- **奨励会とのつながり**：研修会の「編入する」で、研修会を閉じて、奨励会のキャリアに編入の資格を書き、奨励会の入口へ移る（`docs/shoreikai-design.md`の16章）。奨励会の挑戦の途中は、編入のボタンを押せない（「終えたら編入できるよ」）。奨励会の不合格の画面の「研修会へ」で、研修会の入口へ（やこび姫が編入の道を話す）。
- **ノート**：やこびノートの「大会」に研修会の札（いまのクラス・最高・挑戦・対局と、これまでの挑戦）。
- **見送ったこと**：`kenshukai.mjs`は、奨励会と同じく対局画面から静的に読む（終局ですぐに記録するため）。最初に読むJSが少し増える。プレイヤーの女流棋士の資格、年齢制限、研修会員どうしの駒落ち。
