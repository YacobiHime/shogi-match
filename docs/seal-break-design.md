# 封じ手で1日目を区切る：予告・封じ手の記入・休憩・2日目の朝（設計 2026-11-10）

依頼（2026-11-10）：「対局中の封じ手が、現在はただの邪魔な表示になっている。一旦休憩するために、ちゃんと将棋を中断するようにしたい。そこまでの対局を振り返るやつを強制的にするようにしたり。また、『次で封じ手』みたいな表示をしてもいいかも。」

ユーザーの答え（2026-11-10）：

- 封じ手のあとは、ホームに戻さない。ボクシングのラウンドの合間のように、ひと息つける画面にする。物語モードや棋士の1年なら、ノベルの場面をはさむ。いまは押したときだけ出る「形勢のグラフとやこび姫の助言」も、ここで出す。
- 封じ手の手は、2日目まで盤に出さない（本物どおり）。
- この文書は設計だけ。実装は、push できる claude.ai/code のセッションで行う。

関連：`docs/title-match-day-design.md`（1日目のまとめ・開封の札・勝負メシ・休憩のふりかえり）、`docs/match-stage-design.md`（舞台の札）、`docs/novel-scene-design.md`（ノベルの場面）、`docs/pro-year-design.md`（棋士の1年）。

## 0. いまの作り（2026-11-10 の main で確認）

| 場面 | いまの動き | 問題 |
|---|---|---|
| 封じ手の前 | 予告はない。対局の札の「1日目」が「2日目」に変わるだけ | どの手が封じ手になるか、指すまで分からない。じっくり考える溜めがない |
| 封じ手 | 40手を越えてプレイヤーが最初に指した手（`stageSealPly`）を、指したあとで封じ手にする（`sealTitleDay`）。札を1.8秒（`STAGE_CARD_MS`）出し、消えたらすぐ開封の札を1.8秒出す（`hideStageCard`） | 指した手はもう盤に出ていて、CPUもすぐに指す。札は対局を止めないので、盤の上にかぶさる邪魔な表示になっている |
| 1日目のまとめ | 対局の札の「2日目・まとめ」を押したときだけ、シート（`TitleDaySheet.vue`）が開く。対局は止めない | 押さない人は見ない。休憩の「間」になっていない |
| 中断 | 「対局を中断する」で保存してホームへ（`suspendMatch`）。封じ手とは関係がない | — |

## 1. 機能設計メモ

- 一言で言うと：封じ手の1手を封筒に入れたら、対局を止めて「1日目の終わり」の画面で息をつき、1日目をふりかえってから、2日目の朝に封筒を開けて再開する。
- 解く課題：
  1. 封じ手が、対局の流れを止めずに盤をふさぐだけの札になっている。
  2. 1日目のふりかえりが任意なので、休憩が「間」として生きていない（D:2-3）。
  3. どの手が封じ手か分からないので、「この1手」の緊張が生まれない（D:2-2 溜めと解放）。
- 溜めと解放：
  - 溜め：予告（あと○手）→「次の手が封じ手」→ 記入。
  - 区切り：休憩でふりかえる。
  - 解放：翌朝の開封で、盤に手が指される。
- 初めての人の最初の1分：
  - 封じ手の3手前から、対局の札に「あと3手で封じ手」と出る。
  - 封じ手の番になると、盤の上に「この手が封じ手」の帯が出て、やこび姫が一言そえる。
  - 指すと確認が出て、「封じる」を押すと封筒の演出になり、休憩の画面へ進む。
- 上級者の深さ：
  - 封じ手は相手に見られない。相手は一晩、どの手かを考える（演出の上だけ）。
  - 封じ手を控室の予想と外すことも、ひとつの楽しみ方になる（開封の札の「予想どおり／予想外」）。
- 失敗したとき：
  - 封じ手は記入の前に確認を出し、「考え直す」で戻れる。記入したあとは取り消せない（本物どおり）。
  - 休憩の画面からは、いつでも「ここで中断」を選べる。
- 捨てるもの：
  - 封じ手のあとに対局を続けたまま進む今の流れ。
  - 開封の札を封じ手の札のすぐあとに出す動き。
- 確かめ方：
  - 竜王戦・名人戦の七番勝負と、棋士の1年の二日制の七番勝負で、予告→記入→休憩→2日目の朝→再開までを通す。
  - 休憩中にリロードして、休憩の画面から戻れることを確かめる。

## 2. 流れ

```
1日目（対局）
  ├ 封じ手の3手前〜：対局の札「あと○手で封じ手」
  ├ 封じ手の番：盤の上に「この手が封じ手」の帯 ＋ やこび姫の一言
  └ プレイヤーが指す → 確認「この手を封じますか？」［封じる］［考え直す］
        ↓ 封じる（盤には出さない。CPUは指さない）
休憩（ラウンドの合間）── 全画面。対局の盤は隠す
  ① 封じ手の札：封筒に入れて立会人へ（いまの札を全画面にして、1.8秒＋押して進む）
  ② 1日目のまとめ（必ず出す）：形勢のグラフ／盤でふりかえる／控室の声／やこび姫の助言
  ③ ノベルの場面（物語モード・棋士の1年だけ。台本がなければ飛ばす）
  ④ ［2日目を始める］［ここで中断］
        ↓ 2日目を始める
2日目の朝
  ⑤ 「2日目の朝」の札 → 封じ手の開封の札（立会人が読み上げる）
  ⑥ 封じ手の手を盤に指す（動きつき）→ CPUの手番から再開
```

### 2-1. 予告（封じ手の前）

- 封じ手の手数は今と同じく `stageSealPly(userColor)` で決める。
- 対局の札の日付（`stageDayText`）を、次の手数ごとに書き分ける。
  - プレイヤーの残りの手番が3以下になったら「1日目・あと○手で封じ手」とする。○はプレイヤーの手番の数で、`(sealPly - moveCount + 1) / 2` を切り上げたもの。
  - プレイヤーの手番で `moveCount + 1 === sealPly` のときは「次の手が封じ手」とする。
- 封じ手の番になったら、盤の上の端に細い帯「この手が封じ手」を出す。この帯は盤をふさがない（札ではなく帯にする）。
- 同時にやこび姫の一言を出す（助言の欄）。例：「この手は封筒にしまうよ。相手は一晩この局面を考えるから、じっくり選んでね」。助言が「なし」の設定でも、この一言だけは出す（進行の知らせなので）。
- 封じ手の前に終局したら、何も出さない。

### 2-2. 封じ手の記入

- 封じ手の番に盤で指したら、手を盤に出す前に確認を出す：「▲4五歩 を封じ手にしますか？」［封じる］［考え直す］。
  - 「考え直す」を押したら、盤を指す前に戻す。
  - 成り・不成の選択は、今のとおり確認の前に済ませる。
- 「封じる」を押したら、次のように進める。
  - 手を `moveHistory` に入れず、`titleDay.seal` に控える：`{ ply, move, predicted, material, black, white, pending: true }`。
  - CPUの探索・助言の読み・持ち時間を止める（`suspendMatch` の止め方と同じ：`matchGeneration += 1`、`cpuTimer` を消す、`engine.stop()`、`coachAdviceScheduler.reset()`）。
  - 待ったは使えない。封じ手より前に戻す手段は、休憩の画面には置かない。
- `sealTitleDay` は今、指したあとの局面から駒の損得・戦型を数えている。封じ手を盤に出さなくなるので、記入の直前の局面から数える。値がほとんど変わらないので、記録の意味は同じ。

### 2-3. 休憩の画面（ラウンドの合間）

- 全画面にし、対局の盤は暗くして後ろに置く。ボクシングのラウンドの合間のように、「1日目 終了」の大きな見出しと、残りの段（①〜④）の点を上に並べる。
- ① 封じ手の札：今の `seal` の札の中身（封筒の絵・「1日目はここまで」・控室の予想）を全画面で出す。1.8秒で次へ進み、押せばすぐ次へ進む。
- ② 1日目のまとめ：今の `TitleDaySheet.vue` の `summary` を、この画面の中に出す。
  - 中身は今と同じ：形勢のグラフ、盤でふりかえる、戦型・駒の損得・考えた時間・勝負メシ、控室の声、封じ手。
  - ここに「やこび姫の助言」の欄を足す。2〜3行で、1日目の総評と2日目の方針を伝える（2-4）。
  - 必ず出す。「次へ」ボタンは画面の下に置き、出してから1秒は押せない（読まずに飛ばすのを防ぐ、短い溜め）。
  - 「封じ手」の行は、封じ手の手は書くが、その手の良し悪しは書かない。答え合わせは開封の札でする。
- ③ ノベルの場面（2-5）：台本があるときだけ出す。`NovelScene.vue` をそのまま使い、飛ばす操作も今のとおり。
- ④ 2つのボタン：
  - ［2日目を始める］（主役。大きいボタン）
  - ［ここで中断］：休憩の画面ごと保存してホームへ戻る。ホームの「対局を再開」から、④の画面に戻る。
- 戻る操作（`goBack`）は④へ飛ばす。まとめを開く前なら、まとめへ進める。

### 2-4. やこび姫の助言（休憩の画面）

- 新しい探索は足さない。助言の読み（`updateDedicatedCoachAdvice`）の最後の結果と、まとめの数字から作る。
- 3行で、上から次のことを言う。
  1. 総評：形勢の段（互角・少し良い・良い・苦しい）と、1日目の流れ（勝率の線の動き）。
  2. 2日目の方針：今の作戦の助言（`docs/coach-plan-advice-design.md`）の方針の文を1つ。例：「玉を固めてから攻めよう」。
  3. 励まし：段に合わせて1文。苦しいときも責めない（UI 8：評価で人を良い・悪いと判定しない）。
- 封じ手の良し悪しと、2日目の最善手は言わない。
- 文は `src/core/title-day.mjs` に `sealAdvice({ summary, plan, userColor })` として置く（画面に依存しない）。

### 2-5. ノベルの場面（物語モード・棋士の1年）

- 台本は、遊びの側が渡す。`ShogiMatchGame.vue` は「封じ手の夜の台本があれば流す」だけにする。
  - 棋士の1年：二日制の七番勝負（`pending.twoDay`）で、`proYearSealScene({ series, game, wins })` が台本を返す。宿の夕食・やこび姫と羽音の会話など。シリーズの勝ち負けに合わせて文を変える。
  - 物語モード：話の定義に `sealScene` を書いた対局だけ流す（話はこれから足すので、仕組みだけ用意する）。
  - 竜王戦・名人戦の大会：今はノベルを出さない（③を飛ばす）。あとで足せるように、同じ口にしておく。
- 台本は `docs/novel-scene-design.md` の12-3のテキスト形式で書き、検査（12-4）を通す。
- 最初に書く台本は、棋士の1年の1本（汎用の「封じ手の夜」）だけにする。シリーズの状況（リード・タイ・カド番）で台詞を3通りに分ける。

### 2-6. 2日目の朝

- ［2日目を始める］を押したら、「2日目の朝」の札を出し、続けて今の開封の札（`unsealView`。立会人・封じ手・予想どおり）を出す。
- 開封の札が消えたら、封じ手の手を盤に指す（今の着手の動き）。そのあと、`titleDay.seal.pending` を外して `moveHistory` に入れ、CPUの手番から再開する。
- 中断から戻ったときも、同じく⑤から始める。

## 3. 保存

| 項目 | 中身 |
|---|---|
| `titleDay.seal.pending` | 封じ手を記入して、まだ盤に出していないとき `true` |
| `titleDay.sealBreak` | 休憩の画面の段：`'card' \| 'summary' \| 'novel' \| 'ready'`。リロードと中断のあとは、`'ready'` 以外なら `'summary'` から、`'ready'` なら④から出す |
| 対局の保存（`persistMatchState`） | 休憩に入ったとき・段が進んだときに保存する。`suspendedMatch` に `sealBreak: true` を足し、ホームの「対局を再開」から休憩の画面へ戻れるようにする |

- 封じ手の手は `moveHistory` に入っていないので、保存した局面は「封じ手の直前」になる。再開のときに `titleDay.seal.move` を指してから続ける。
- 古い保存（`pending` がない）は、今までどおり封じ手が盤に出た状態として読む。

## 7. 実装のときに決めること

- 一日制の対局（棋士の1年の五番勝負など）の昼休みにも、同じ休憩の画面（①を除く）を使うか。今回は二日制の封じ手だけにする。
- 持ち時間を表示している対局では、休憩のあいだ時計を止めること（止めるのは決まり。表示の形だけ決める）。

## 8. 実装（2026-11-10、実装・自動テスト済み）

- 予告：`src/core/match-stage.mjs` の `sealCountdown`（`SEAL_COUNTDOWN_FROM` = 3）と、対局の札の日付の言葉 `stageDayLabel`。
  - 残りの数は、プレイヤーがあと何回指すか（封じ手の手を含む）を `ceil((sealPly - ply) / 2)` で数える。2-1の式とは、相手の手番のときだけ1少なくなる。相手の手番では、次に自分が指す手がもう封じ手なので、「あと1手」と出るほうが正しいため。
- 帯とやこび姫の一言：対局画面の `sealTurn`・`data-seal-band`・`SEAL_TURN_LINE`。
  - 帯は、盤の上の端の右に寄せた。名札と相手の時計が左上と中央に並ぶので、重ならないようにするため。
  - 押しても盤に届く（`pointer-events: none`）。
- 記入：
  - 封じ手の番に盤で指すと、`onPlayerMove` が手を盤に出さずに `askSeal` で確認を出す（`data-seal-confirm`。初めに選ばれているのは「考え直す」）。
  - 「封じる」で `confirmSeal` が次のことをする。
    - 封じ手を `sealTitleDay(ply, move)` で記録する（`seal.pending: true`、`sealBreak: 'card'`、考えた時間）。
    - CPU・助言の読み・持ち時間を止める。
  - 封じ手が盤に出るまでのあいだは、次のものを止める。
    - 盤の操作（`canMove`）と待った（`canUndo`）。
    - 時計（`matchClock` と秒読みの輪の `paused`）。
    - やこび姫の助言（`showCoachAdvice`）。
- 休憩の画面：新しい `src/SealBreak.vue`。
  - 中身は、封じ手の札、1日目のまとめ、ノベル（台本があるときだけ）、「2日目を始める・ここで中断・まとめをもう一度」。
  - まとめは `TitleDaySheet.vue` を `embedded` で中に出す（背景と閉じるボタンなし）。やこび姫の助言の欄（`advice`、`data-day-advice`）は、このとき足した。
  - 段は、ゲームの記録の `sealBreak` に保存する（`setSealBreakStep`）。
  - 戻る操作（`navigateBack` → `goBack`）は段を進めるだけで、対局からは離れない。
- やこび姫の助言：`src/core/title-day.mjs` の `sealAdvice`（`sealGrade`）。
  - 総評、2日目の方針、励ましの3行。
  - 形勢の段は4つ。勝率40%以下は「少し苦しい形」と言う（責めない言い方）。
  - 1日目の流れは、20手目あたりの勝率と封じ手のときの勝率の差で言う。
- ノベル：`src/core/pro-year-story.mjs` に、封じ手の夜の場面を3本足した（`pro-seal-lead`・`pro-seal-tie`・`pro-seal-kado`）。
  - どれを出すかは `proYearSealSceneId` が決める。
  - 対局画面の `sealBreakScene` は、棋士の1年の二日制の番勝負のときだけ場面を渡す。
  - 竜王戦・名人戦では、まだ出さない。
- 2日目の朝：`startSecondDay` →「2日目の朝」の札（`morning`。`data-morning-card`）→ 開封の札 → `playSealedMove`。
  - `playSealedMove` は、`pending` を外して `onPlayerMove(seal.move)` で盤に指し、CPU が続ける。
  - 盤を触って札を閉じても、同じ順に進む（`hideStageCard`）。
- 保存：
  - `normalizeDay` は、`seal.pending` と `sealBreak` を読む（`SEAL_BREAK_STEPS`）。
  - リロードと中断のあとは、`resumeSealBreakStep` の段から出す。④の前ならまとめから、④まで進んでいたら④から。
  - 古い保存（`pending` がないもの）は、盤に出たものとして読む。前の流れで封じ手を越えた局は、`legacySealTitleDay` で記録だけ残す。
- 7章で決めたこと：
  - 一日制の昼休みには使わない（二日制の封じ手だけ）。
  - 休憩のあいだ、時計は止める。表示はそのまま残す。
- 確かめたこと：
