# 竜王戦の画面の一新 ― ドット絵の「竜王への道」（設計 2026-10-22、段階A〜Cを実装）

`docs/ryuo-ux-redesign.md`（段階1〜3、実装済み）は、竜王戦の**中身**（目標の1行、勝てば／負ければ、竜王への道のデータ、節目、大番狂わせ、推しの段）を作りました。
この文書は、それを入れる**器（画面の見た目と演出）**を作り直す設計です。判定や台詞の処理（`core/ryuo-stakes.mjs`・`ryuo-road.mjs`・`ryuo-milestone.mjs`など）はそのまま使い、画面だけを替えます。

見本: `docs/ryuo-ui-renewal/mock-1.png`〜`mock-5.png`（作り方は同じ場所の`mock.html`。ブラウザで開くと5枚が並ぶ）。

読んだ指針: `Game_Nintendo_Design.md`（2-3 現実のモチーフ、3-3 最初にクライマックスを、5-2 吊られたごほうび、7-1、8-1、8-4 メニューは世界を語る）、`UI_Nintendo_Design.md`（2章の優先順位、4章、7-3 トーン、9章）。

## 1. いまの画面がワクワクしない理由

段階1〜3で、迷う所と待つ所はかなり減りました。それでもワクワクしないのは、**包装紙が管理画面のまま**だからです（D:8-4「メニューは世界を語る」）。

| いまの画面 | 何が起きているか | 指針 |
|---|---|---|
| 紺の四角いカードが縦に並ぶ | 竜王戦も、設定画面も、統計も、同じ見た目。特別な場所に来た感じがない | D:8-4 |
| 次の一局の札に、文が8行ほど | 主役（相手の顔と「対局する」）が、文に埋もれる | U:4、N:2-5 |
| 相手は四角に漢字1文字 | 人と戦う感じが弱い | D:8-1 |
| 竜王への道は、帯の中の細い線 | 「登っている」景色がない。主役になっていない | D:5-2 |
| 「対局する」を押すと、すぐ盤 | 対局の前の高まり（見せ場）がない | D:3-2、2-2 |
| 結果は統計とレーダーチャートが主役 | 「昇級した」喜びより、成績表を読む画面になっている | U:4-3 |

## 2. 決まったこと（2026-10-22）

- **見本（ryuo-mock系統）のデザインの感じは、すべて採用する。** 夜空とドット絵の山、点線の道と四角い段、下の次の一局の枠、大きな橙の「対局する」。ホーム画面（ドット絵のやこび姫・アイコン・夜空）と同じ世界にそろう。
  - Switch世代の丸いパネルの見本と、文字までドット文字にした見本も作ったが、どちらも採らない。文字は、いまのアプリのゴシック体のまま。
- **VS画面（見本3）は、ドット絵にせず、見本のまま採用する。**
- **実際の竜王戦に一人の棋士として参加する体験を損なわないよう、空想の要素だけを差し替える。** デザインの感じは変えない。

| 最初の見本 | 差し替え | 理由 |
|---|---|---|
| 山の頂上の「竜王城」 | 頂上は「竜王の座」: 金屏風と将棋盤、座布団2枚。横にいまの竜王の顔 | 竜王はお城の主ではなく、タイトル保持者。七番勝負の対局室と就位式の金屏風を表す |
| 山場の段の鳥居（門） | 扇子の印 | 鳥居は神社の印で、棋戦と関係がない。扇子は棋士の持ち物 |
| 麓の「6組の里」 | 麓の将棋会館（窓の灯るビルと看板） | ランキング戦は将棋会館で指す |
| やこび姫「てっぺんの竜王城まで、一局ずつ登っていこう！」 | 「6組から、竜王への挑戦がはじまるよ。一局ずつ登っていこう！」 | 同上 |

- **山は残す。** 山を登る道は、組を勝ち上がり頂点を目指すことのたとえとして分かりやすく、「棋界の頂点」という言い方とも合う。山のほかの景色（里・城・門）は、上のとおり実際の舞台に替える。

## 3. 機能設計メモ（Game_Nintendo_Design.mdの14章の形）

### 機能名：ドット絵の「竜王への道」

- 一言で：将棋会館の前の1回戦から、頂上の竜王の座まで、一局ずつ自分の駒が山を登っていく。
- 解く課題（2-5）：
  - 竜王戦が特別な場所に見えない（器の問題）
  - 目標と現在地が文で書いてあって、景色で分からない
  - 相手が文字だけで、戦う相手に見えない
  - 対局の前の高まりがない
- リスクとリターン（2-1）：次の段に次の相手が立ち、下の枠に「勝てば 準決勝へ／負ければ ここまで」。
- 溜めと解放（2-2）：VS画面で溜め、対局のあとの跳ねと「突破」の判子で解放。
- 初めての人の最初の1分：入口を開くと、カメラが頂上の竜王の座（いまの竜王）から麓の自分まで降りてくる（最初にクライマックスを。3-3）。「出場する」→ 地図 → 「対局する」→ VS → 盤。
- 上級者の深さ：相手の顔を押すと能力（レーダーチャート・特殊能力・使用率）、「表」でトーナメント表、名鑑。どれも1回押せば開き、道はふさがない。
- 失敗したとき：駒はその段に残り、段が灰色になるだけ。次にあること（敗者復活戦・期の結果）が下の枠に出る（7-1）。
- ご褒美と使い道：段を登ること自体。組優勝・挑戦権・竜王の節目の判子（段階3）。結果で、番付の自分の組が上がる。
- ほめる瞬間：勝ち上がりの跳ねと「突破」の判子、やこび姫の一言。
- 捨てるもの：画面いっぱいの統計（結果では「くわしく」の奥へ）、次の一局の札の常設の数字タイル、空想の舞台（城・門・里）。
- 確かめ方：段階4（`docs/ryuo-ux-redesign.md`の7章）と同じく、初めての人に説明なしで1局目まで進んでもらう。

## 5. 画面ごとの設計

### 5-1. 入口（見本1）

- 主役：題字「竜王戦」と「第3期」、山の全景、「出場する」。
- 頂上に竜王の座（金屏風・将棋盤）と、いまの竜王の顔（「竜王・天鷺善彦が待つ」）。麓に自分の駒とやこび姫。
- 開くと、カメラが頂上から麓の自分まで降りる（1.2秒。押すと飛ばす）。
- 目標の1行（「6組で2位以内なら昇級」）は、「出場する」のすぐ上の枠に。
- やこび姫の一言を押すと「竜王戦ってなに？」の説明。設定は右上の「設定」から（いまの設定の行とシートを、そのまま使う）。

### 5-2. 期の画面：竜王への道（見本2）

- 主役：山の地図と「対局する」。地図は縦に長く、枠の中だけを上下に動かせる（U:7-5）。開いたときは、いまの段が真ん中に来る。
- 段（下から）：将棋会館の前の1回戦 → 2回戦 → … → 組の決勝（扇子）→（負けて回れば敗者復活戦の分かれ道）→ 決勝T → 挑戦者決定戦（扇子）→ 七番勝負 → 頂上の竜王の座。
- 段の上：いまの段に自分の駒（将棋の駒の形、「自」）とやこび姫。次の段に次の相手の顔と「次の相手！」。組の決勝にライバル（羽音、反対の山で勝ち残っているとき）。頂上の横にいまの竜王（善彦）。いつか戦う相手が最初から見えている（D:5-2）。
- 上の帯：期の名前と段階、推しの段（「★推し 中村蓮さん: 準々決勝」）、右に「表」（トーナメント表を重ねて開く）。
- 下の枠（次の一局）：相手の顔（大きく）、「準々決勝の相手」、名前と段位、札3つ（棋風・いちばん高い能力・いちばん低い能力）、「勝てば 準決勝へ／負ければ ここまで」。その下に「対局する」。くわしい情報は顔を押すと開く。
- 大番狂わせの一言は、地図の上に吹き出しで（段階3の判定のまま）。

### 5-3. VS画面（見本3。見本のまま採用）

- 「対局する」を押すと、盤の前に1.2秒だけ出す。押すとすぐ盤へ。
- 画面を斜めに青（自分）と朱（相手）に分け、自分の駒「自」と名前・レーティング・先後、相手の判子と名前・段位・棋風・先後、真ん中に大きな「VS」。上に段階（「6組ランキング戦 準々決勝」）、下に「勝てば 準決勝へ」。
- 両側が画面の外から滑り込み、「VS」が落ちる動きを付ける。音は「VS」が落ちる1つだけ（新しく作る。下の7章）。

### 5-4. 対局のあと：勝ち上がり（見本4）

- 勝つと、自分の駒が次の段へ弧を描いて跳ぶ（0.6秒）。倒した段に「突破」の判子。
- 次の相手が段に現れ、どう勝ち上がってきたかを吹き出しで1行（段階2の`opponentArrivalLine`）。下の枠は次の相手に替わる。
- 組優勝・挑戦権などの節目は、段階3の判子をこの画面の見た目で出す。
- 負けたときは、駒はそのまま、段が灰色になるだけ（D:7-1）。

### 5-5. 期の結果（見本5）

- 主役：山の全景と、左の番付（1組〜6組）。今期どこまで登ったかに旗（「今期の最高 決勝T 1回戦」）。組が上がるなら、番付の自分の組が変わり「5組へ昇級」の判子。竜王になったときは、頂上の竜王の座に自分の駒。
- 数字は3枚の札だけ（戦績・いちばん光った項目・最長連勝）。レーダーチャートと統計は「くわしく」の奥へ。
- 主ボタン「次の期へ」。

### 5-6. 広い画面・横長の画面

- 横長（パソコン・タブレット横・スマホ横）では、左に山の地図、右に次の一局の枠と「対局する」。トーナメント表は「表」で右から重ねて開く。
- キーボードでも操作できるようにする（Enterで「対局する」・「出場する」、Escで戻る、Tで表）。

## 6. 実際の竜王戦との対応

| 画面の舞台 | 実際の竜王戦 | 出典・確認 |
|---|---|---|
| 麓の将棋会館（ランキング戦） | ランキング戦は将棋会館で指す | 要確認（期ごとの対局場） |
| 決勝T・挑戦者決定戦 | 決勝トーナメントの決勝だけ三番勝負。下の組ほど挑戦者決定戦まで多く勝つ | `docs/ryuo-sen-research.md`の4・5章 |
| 七番勝負 | 竜王と挑戦者が先に4勝を争う。全国の旅館・ホテル・寺社などで、2日制 | 同6章 |
| 頂上の竜王の座（金屏風と将棋盤） | 竜王になった棋士を祝う就位式と、七番勝負の対局室を、ひとつの絵で表す（ゲームとしての表現） | 表現 |
| 扇子 | 棋士の持ち物。山場の段の印にする | 表現 |

- 施設の名前やロゴは、実在のものを使わない（将棋会館は一般名として書く）。

## 10. 段階Aの実装（2026-10-22、実装・自動テスト済み）

- **山の地図**：`src/RyuoMountain.vue`。道の段（段階2の`core/ryuo-road.mjs`の`road`）を、SVGの四角だけで描く。
  - 配置は`src/core/ryuo-mountain-layout.mjs`の`mountainLayout`：段は下から66ずつ登り、左右に振ったつづら折り。頂上（竜王の座）は真ん中で、その下だけ96あける（金屏風と将棋盤の分）。図は幅390の座標で、画面ではそのまま拡大する（最大34rem）。山（4層の階段状の輪郭、`mountainLayers`）は図の外まで伸ばし、広い画面でも端が切れない。
  - 麓に将棋会館（ランキング戦があるとき）、山場の段（組の決勝・挑戦者決定戦）に扇子、頂上に金屏風・将棋盤・座布団、頂上の横にいまの竜王の顔。
  - いまの段に自分の駒（ゆっくり上下する）とやこび姫、その横に次の相手の顔と「次の相手！」の吹き出し（外側に出す）。相手の顔は押せる（くわしい情報）。組の決勝には、反対の山で勝ち残っているライバル（羽音の絵）。
  - 負けて通らなかった組の回戦は薄くし、そこへの道は通ったことにしない。
  - 地図は枠の中だけ上下に動き、開いたときはいまの段を真ん中より少し下に置く。
  - 対局から戻ったときの動き（段階2の道の動きを置き換え）：勝って段を上がると、駒が前の段から弧を描いて0.6秒で跳び、通った道が光る。番勝負・決勝トーナメントの途中は同じ段で跳ねる。押すと飛ばす。`prefers-reduced-motion`では駒を動かさない。音は段階2・3のまま。
- **期の画面**：`ShogiTournament.vue`の期の画面を、上の帯（期と段階、推しの段、「予想」「表」）・地図・次の一局の枠の3段に置き換えた（横長・広い画面では地図の右に枠）。いままでの大会の帯・カード・操作の帯は、期の画面では出さない（入口と結果は段階Cまで今のまま）。
  - 次の一局の枠：相手の顔（押すとくわしい情報）、「準々決勝の相手」、名前と段位、札3つ（棋風・いちばん高い能力・いちばん低い能力）、番勝負なら星取り、目標まであと何勝、勝てば／負ければ、やこび姫の1行（2行まで。押すと続き）、「対局する」。山場は上の縁が朱。
  - くわしい情報のシート（下から重ねて開く）：相手（羽音の一言・棋力・得意戦法・手番・能力のレーダーチャートと使用率・棋風と経歴・勝ち上がり方）、やこび姫の話、組優勝の予想。番勝負の星取りの一覧も出す。
  - 地図の上の知らせ（羽音の一言・大番狂わせ・次の相手の勝ち上がり方）は、対局から戻ったときだけ出し、押すと消える。
  - トーナメント表は「表」で画面いっぱいに重ねて開く。ブラウザの戻る操作は、シート→表→説明の順に閉じてから画面を戻る。
- 確かめ：`src/core/ryuo-mountain-layout.test.mjs`、`match-ui-regression.test.mjs`。ブラウザで、スマホ縦（390×844）・タブレット縦（820×1180）・デスクトップ（1366×768）・スマホ横（844×390）の、ランキング戦の途中・組優勝の直後・敗者復活戦・七番勝負・くわしい情報・トーナメント表を撮って確かめた（対局から戻る開き方は、開発用のビルドで再現した）。実際に竜王戦を遊んでの確認はまだ。
- **これから**：段階B（VS画面と「突破」の判子の見た目、「VS」の音）、段階C（入口のカメラと結果の山の全景）。

## 11. 段階Bの実装（2026-10-22、実装・自動テスト済み）

- **VS画面**：`src/RyuoVersus.vue`。見本3のまま、ドット絵にしない。期の画面の「対局する」を押すと出し、1.2秒（山場の一局は1.6秒）で対局を始める。押せばすぐ始まる。
  - 画面を斜めに青（自分）と朱（相手）に分け（横長の画面では左右）、両側が画面の外から滑り込み（0.22〜0.26秒）、「VS」が0.2秒遅れて落ちる（0.18秒）。
  - 上に段階、自分の駒「自」とレーティング・先後、相手の判子（羽音は絵）と段位・棋風・先後、下に「勝てば ○○」。
  - 山場（組の決勝・番勝負・ライバル）は、背景に金と暗い朱を混ぜる。
  - 音：「VS」が落ちて着く0.36秒に和太鼓の「ドン」（`public/audio/road_vs.mp3`、0.4秒。`move-sound.ts`の`vs`）。
  - `prefers-reduced-motion`では、滑り込みと落ちる動きを止める（時間はそのまま、押せば飛ばせる）。
