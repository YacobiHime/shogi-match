# 竜王戦の画面の一新 ― ドット絵の「竜王への道」（設計 2026-10-22、未実装）

`docs/ryuo-ux-redesign.md`（段階1〜3、実装済み）は、竜王戦の**中身**（目標の1行、勝てば／負ければ、竜王への道のデータ、節目、大番狂わせ、推しの段）を作りました。
この文書は、それを入れる**器（画面の見た目と演出）**を作り直す設計です。判定や台詞の処理（`core/ryuo-stakes.mjs`・`ryuo-road.mjs`・`ryuo-milestone.mjs`など）はそのまま使い、画面だけを替えます。

見本: `docs/ryuo-ui-renewal/mock-1.png`〜`mock-6.png`（作り方は同じ場所の`mock.html`。ブラウザで開くと6枚が並ぶ）。

読んだ指針: `Game_Nintendo_Design.md`（2-3 現実のモチーフ、3-3 最初にクライマックスを、5-2 吊られたごほうび、8-4 メニューは世界を語る、7-1、8-3）、`UI_Nintendo_Design.md`（2章の優先順位、4章、7-3 トーン、9章）。

## 1. いまの画面がワクワクしない理由

段階1〜3で、迷う所と待つ所はかなり減りました。それでもワクワクしないのは、**包装紙が管理画面のまま**だからです（D:8-4「メニューは世界を語る」）。

| いまの画面 | 何が起きているか | 指針 |
|---|---|---|
| 紺の四角いカードが縦に並ぶ | 竜王戦も、設定画面も、統計も、同じ見た目。特別な場所に来た感じがない | D:8-4 |
| 次の一局の札に、文が8行ほど | 主役（相手の顔と「対局する」）が、文に埋もれる | U:4、N:2-5 |
| 相手は四角に漢字1文字 | 人と戦う感じが弱い | D:8-1 |
| 竜王への道は、帯の中の細い線 | 「登っている」景色がない。主役になっていない | D:5-2 |
| 「対局する」を押すと、すぐ盤 | 対局の前の高まり（見せ場）がない | D:3-2、2-2 |
| 結果は統計とレーダーチャートが主役 | 「昇級した」喜びより、成績表を読む画面になっている | U:4-3 |

## 2. 決まっていること（2026-10-22）

- **ドット絵の見た目にする。** ホーム画面（ドット絵のやこび姫・アイコン・夜空）と同じ世界にそろえる。Switch世代の丸いパネルの見本も作ったが、ドット絵の方を選んだ。
- **実際の竜王戦の体験を損なわない。** お城などの空想の舞台は使わない。舞台は、実際の竜王戦の場所と儀式（将棋会館、決勝トーナメントの階段、特別対局室、旅館の七番勝負、就位式）にする。プロとして竜王戦に挑んでいる気持ちを、ゲームの見た目で強める。

## 3. 機能設計メモ（Game_Nintendo_Design.mdの14章の形）

### 機能名：ドット絵の「竜王への道」

- 一言で：将棋会館の1回戦から、金屏風の竜王まで、一局ずつ自分の駒が登っていく。
- 解く課題（2-5）：
  - 竜王戦が特別な場所に見えない（器の問題）
  - 目標と現在地が文で書いてあって、景色で分からない
  - 相手が文字だけで、戦う相手に見えない
  - 対局の前の高まりがない
  - 竜王戦の制度（組・決勝トーナメントの階段・七番勝負）を、説明を読まないと知れない。舞台を実際と同じ順に並べれば、地図を見るだけで分かる
- リスクとリターン（2-1）：次の段に次の相手が立ち、下の枠に「勝てば 準決勝へ／負ければ ここまで」。
- 溜めと解放（2-2）：VS画面で溜め、対局のあとの「勝ち上がり」の跳ねと速報で解放。
- 初めての人の最初の1分：入口を開くと、カメラが金屏風の竜王から将棋会館の自分まで降りてくる（最初にクライマックスを。3-3）。「出場する」→ 地図 → 「対局する」→ VS → 盤。
- 上級者の深さ：相手の顔を押すと能力（レーダーチャート・特殊能力・使用率）、「表」でトーナメント表、名鑑。どれも1回押せば開き、道はふさがない。
- 失敗したとき：駒はその段に残り、段が灰色になるだけ。次にあること（敗者復活戦・期の結果）が下の枠に出る（7-1）。
- ご褒美と使い道：段を登ること自体。組優勝・挑戦権・竜王の節目の判子（段階3）。番付で自分の名札が上の組へ動く。
- ほめる瞬間：勝ち上がりの跳ね、「竜王戦 速報」の見出し、やこび姫の一言。
- 捨てるもの：画面いっぱいの統計（結果では「くわしく」の奥へ）、次の一局の札の常設の数字タイル、空想の舞台。
- 確かめ方：段階4（`docs/ryuo-ux-redesign.md`の7章）と同じく、初めての人に説明なしで1局目まで進んでもらう。

## 4. 世界観とトーン（UI_Nintendo_Design.mdの7-3）

| 項目 | 決定内容 |
|---|---|
| キーワード | 夜の将棋会館、旅館の灯り、金屏風、ドット絵 |
| 連想した言葉 | 窓の灯り、提灯、暖簾、畳、襖、将棋盤、速報の見出し、番付の木札 |
| 色 | ホーム画面と同じ紺の夜空・クリーム・橙・ラベンダー。竜王戦の朱（判子・山場）と金（屏風・竜王）。影は黒ではなく濃い紺 |
| 形 | 角を1段欠いた四角（ドット絵の窓枠）。2重の縁と、右下にずらした影。丸みやグラデーションは使わない |
| 文字 | 見出し・名前・ボタンはドット文字（Webフォント「DotGothic16」。日本語の画数の多い字も読める）。説明の小さい文は、いまの丸ゴシック体のまま（読みやすさ優先。N:5-3） |
| 絵 | 建物・盤・屏風・階段は、CSSとSVGの四角だけで描く（画像を足さない）。人物は、やこび姫と羽音のドット絵。ほかの棋士は名前の1文字の判子（ミニキャラができたら同じ枠に入れる） |
| 動き | 待っている間は、窓の灯りと星がまたたき、自分の駒がゆっくり上下する。動きは1秒以内で、押すと飛ばす。`prefers-reduced-motion`では止める |

- フォントは、竜王戦の画面を開いたときだけ読み込む（最初の画面を重くしない。`AGENTS.md`）。展示用のインターネットなしのパッケージにも同じフォントを入れる（読めないときは丸ゴシック体に戻る）。

## 5. 画面ごとの設計

### 5-1. 入口（見本1）

- 主役：「竜王戦」のドット文字のロゴと「第3期」、下に地図の全景、「出場する」。
- 開くと、カメラが金屏風（いまの竜王の顔）から、将棋会館の前の自分の駒まで降りる（1.2秒。押すと飛ばす）。
- 目標の1行（「6組で2位以内なら昇級」）は、「出場する」のすぐ上の枠に。
- やこび姫の一言（「6組から、竜王への挑戦がはじまるよ！」）。押すと「竜王戦ってなに？」の説明。
- 設定は右上の「設定」から（いまの設定の行とシートを、そのまま使う）。

### 5-2. 期の画面：竜王への道（見本2）

- 主役：地図と「対局する」。地図は縦に長く、枠の中だけを上下に動かせる（U:7-5）。開いたときは、いまの段が真ん中に来る。
- 舞台（下から）：

| 段 | 舞台 | 見た目 |
|---|---|---|
| ランキング戦（1回戦〜組の決勝） | 将棋会館 | 窓の灯るビル、看板「将棋会館」 |
| 敗者復活戦 | 将棋会館の横の小道（分かれ道） | 道が横に分かれ、合流する |
| 決勝トーナメント | 階段 | 下の組の優勝者ほど下の段から登る（実際の竜王戦と同じ形）。自分が何段目から登るかが見える |
| 挑戦者決定三番勝負 | 特別対局室 | 畳と襖、将棋盤 |
| 竜王戦七番勝負 | 旅館 | 瓦屋根、提灯、暖簾 |
| 竜王 | 就位式の金屏風 | 屏風の前に将棋盤と、いまの竜王の顔 |

- 段の上：いまの段に自分の駒（将棋の駒の形、「自」）とやこび姫。次の段に次の相手の顔。組の決勝にライバル（羽音、反対の山で勝ち残っているとき）。金屏風の前にいまの竜王（善彦）。いつか戦う相手が最初から見えている（D:5-2）。
- 上の帯：期の名前と段階、推しの段（「★推し 中村蓮さん: 準々決勝」）、右に「表」（トーナメント表を重ねて開く）。
- 下の枠（次の一局）：相手の顔（大きく）、名前と段位、札3つ（棋風・いちばん高い能力・いちばん低い能力）、「勝てば 準決勝へ／負ければ ここまで」。その下に「対局する」。くわしい情報は顔を押すと開く。
- 大番狂わせの一言は、地図の上に吹き出しで（段階3の判定のまま）。

### 5-3. VS画面（見本3）

- 「対局する」を押すと、盤の前に1.2秒だけ出す。押すとすぐ盤へ。
- 画面を斜めに青（自分）と朱（相手）に分け、両側が画面の外から滑り込み、「VS」が落ちる。
- 上に段階（「6組ランキング戦 準々決勝」）と、対局場・先後（「東京・将棋会館／先手 あなた（振り駒）」）。下に「勝てば 準決勝へ」。
- 山場の一局（組の決勝・番勝負・ライバル）は1.6秒にし、背景を金と朱にする。七番勝負は「第4局 ○○県・○○旅館（2日制）」と出す（旅館の名前は架空）。
- 音は「VS」が落ちる1つだけ（新しく作る。下の7章）。

### 5-4. 対局のあと：勝ち上がり（見本4）

- 勝つと、自分の駒が次の段へ弧を描いて跳ぶ（0.6秒）。倒した段に「勝ち上がり」の判子。
- 上に「竜王戦 速報」の見出し（新聞の見出しのように。例「あなた四段、準決勝へ／杉山颯太三段に勝利。次は天鷺羽音四段と対戦」）。実際の棋戦の雰囲気を足す、現実のモチーフ（D:2-3）。3秒で消え、押せば消える。
- 次の相手が段に現れ、どう勝ち上がってきたかを1行（段階2の`opponentArrivalLine`）。
- 組優勝・挑戦権などの節目は、段階3の判子をこの画面の見た目で出す。
- 負けたときは、駒はそのまま、段が灰色になる。速報は出さない（D:7-1）。

### 5-5. 七番勝負（見本5）

- 七番勝負に入ったら、地図を旅館の場面に切り替える。7つの旅館（第1局〜第7局。1局ごとに対局場が変わる）を並べ、終わった局に○●。
- 真ん中に星取り（「2 - 1」「竜王まで あと2勝」「○○●□□□□」）。いちばん上の金屏風の前で、いまの竜王が待つ。
- 主ボタンは「第4局へ」。防衛戦も同じ画面（自分が金屏風の側）。

### 5-6. 期の結果：番付（見本6）

- 主役：番付の木札（竜王・1組〜6組）。自分の名札が、6組から5組へ動き、「5組へ昇級」の判子。竜王になったときは、名札が竜王の札へ上がり、金屏風の場面に切り替える。
- 数字は3枚の札だけ（戦績・いちばん光った項目・最長連勝）。レーダーチャートと統計は「くわしく」の奥へ。
- 主ボタン「次の期へ」。

### 5-7. 広い画面・横長の画面

- 横長（パソコン・タブレット横・スマホ横）では、左に地図、右に次の一局の枠と「対局する」。トーナメント表は「表」で右から重ねて開く。
- キーボードでも操作できるようにする（Enterで「対局する」・「出場する」、Escで戻る、Tで表）。

## 6. 実際の竜王戦との対応

| 画面の舞台 | 実際の竜王戦 | 出典・確認 |
|---|---|---|
| ランキング戦・決勝トーナメント・挑戦者決定戦は将棋会館 | 本戦までは将棋会館などで指す | 要確認（期ごとの対局場） |
| 決勝トーナメントの階段 | 5組・6組優勝は5勝、4組優勝は4勝…1組優勝は1勝で挑戦者決定戦。下の組ほど長い階段 | `docs/ryuo-sen-research.md`の4章 |
| 挑戦者決定三番勝負 | 決勝トーナメントの決勝だけ三番勝負 | 同5章 |
| 七番勝負は旅館 | 10〜12月、全国の旅館・ホテル・寺社などで、2日制・封じ手 | 同6章 |
| 金屏風の竜王 | 竜王になった棋士を祝う就位式を、金屏風で表す（式の細部はゲームとしての表現） | 表現 |
| 速報の見出し | 棋戦の結果が新聞・速報で伝わる雰囲気 | 表現（実在の新聞名は使わない） |

- 旅館・ホテルの名前、記事の見出しは架空にする。実在の会社・施設の名前やロゴは使わない。

## 7. 動き・時間・音

| 出来事 | 時間（初期値） | 音 | 重さ（Implementationの3-1） |
|---|---|---|---|
| 入口のカメラ（竜王から自分へ） | 1.2秒・押すと飛ばす | なし | — |
| VS画面 | 1.2秒（山場は1.6秒）・押すと飛ばす | 「VS」（新しく作る。短い和太鼓の「ドン」） | 段の山場に合わせる |
| 勝ち上がりの跳ね | 0.6秒 | 「段を登る」（段階2の音） | 小 |

| 節目の判子 | 段階3のまま | 「判子」（段階3の音） | 中〜最大 |
| 待っている間の動き（灯り・星・駒） | ゆっくり繰り返す | なし | — |

- BGMは付けない（駒音を邪魔しない。U:7-1）。
- 音を消していても、同じ出来事が見た目で伝わる。

## 8. 作る順番

1. **段階A（地図と下の枠）**：期の画面を、ドット絵の地図と次の一局の枠に置き換える。建物・階段・屏風の部品、DotGothic16の読み込み。いまの帯・カード・タブは消す。
2. **段階B（VS画面と勝ち上がり）**：VS画面、跳ねる動き、速報、「VS」の音。
3. **段階C（入口・七番勝負・結果）**：入口のカメラ、旅館の七番勝負の場面、番付の結果。
4. **段階D（確かめと調整）**：初めての人に触ってもらい、時間と文言を直す。

## 9. 決めてほしいこと

1. **舞台の並び**：将棋会館 → 決勝トーナメントの階段 → 特別対局室 → 旅館 → 金屏風、でよいか。
2. **自分の駒**：将棋の駒の形（「自」）＋横にやこび姫、でよいか。プレイヤー本人のドット絵（主人公）を作る案もある。
3. **VS画面**：毎局出してよいか（押せば飛ばせる）。山場だけにする案もある。
4. **速報の見出し**：入れてよいか。
5. **フォント**：見出しをドット文字（DotGothic16）にしてよいか。フォントを読み込む分、竜王戦の画面を初めて開くときに少し待つ。
6. **作る順番**：段階Aから順でよいか。
