# 遅れて読み込む部分が読めなかったとき

## 1. 起きたこと（2026-11-01、ユーザーの報告）

「終盤戦ボタンを押しても終盤戦が遊べない」。ページを読み込み直したら直った。

- 原因：終盤戦の局面のデータ（`src/core/endgame-start.mjs`）や、大会・教室・問題集・脳トレ・やこびノートなどの画面は、押したときに別のファイル（`dist/chunks/`の、名前に中身のハッシュを持つファイル）として読み込む。公開し直すとファイルが入れ替わり、前の名前のファイルはサーバーから消える。公開の前に開いたままのページは古い名前を読みに行って失敗する。
- 失敗を受け止める処理がなく（終盤戦は`void startEndgameNow()`）、押しても何も起きなかった（D:3-1 無反応をなくす、に反する）。
- 確かめ方：本番のサイトで終盤戦のファイルの読み込みを失敗させると、押しても何も起きないことをブラウザで再現した。

## 2. 決めたこと

- 読めなかった失敗（ブラウザごとの言い方を`src/core/chunk-reload.mjs`の`isChunkLoadError`で見分ける）なら、ページを1回だけ読み込み直して新しい版にする。読み込み直した時刻は`sessionStorage`の`yacobihime:shogi-match:chunk-reload`に残し、1分のうちに2回目の失敗があったら読み込み直さない（繰り返しを防ぐ。`claimChunkReload`）。
- 読み込み直さないとき・ほかの失敗のときは、ホームのやこび姫の吹き出しで「読み込めなかったよ。ページを読み込み直して、もう一度押してみてね」と6秒知らせる（`ShogiMatchGame.vue`の`onLazyLoadError`・`showLoadNotice`）。
- 画面はすべて`lazyScreen`（`defineAsyncComponent`の`onError`）を通す。終盤戦は`startEndgameNow`を`try`で包み、自分の対局は1局ずつ読み（読めない対局は飛ばす）、局面が選べなければ名局だけから選び直し、それでもなければ一言で知らせる。
- 原則：無反応をなくす（D:3-1）、迷わない・間違えない（UD:2の1）。

## 3. 実装（2026-11-01、実装・自動テスト済み）

- `src/core/chunk-reload.mjs`とテスト`chunk-reload.test.mjs`、`ShogiMatchGame.vue`の`lazyScreen`・`onLazyLoadError`・`showLoadNotice`・`loadNotice`、`match-ui-regression.test.mjs`。
- ブラウザ（390×844）：終盤戦と大会の画面のファイルを読めなくすると、1回目はページを読み込み直し、2回目は吹き出しで知らせる。ふつうのときは今までどおり終盤戦が始まる。
- まだ確かめていないこと：本物の公開し直しのあとに、開いたままのページで押したときの動き（公開してから確かめる）。
