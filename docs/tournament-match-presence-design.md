# 大会の対局画面に「大会らしさ」を足す（2026-10-23）

竜王戦・名人戦で、対局画面に変化がなく、特別感がなくて飽きる、という声への設計です。
`docs/match-stage-design.md`（対局の札・開幕の札・封じ手・タイトル戦の背景）の続きにあたります。

- 参照した指針: `docs/nintendo-design/Game_Nintendo_Design.md`（2-2 溜めと解放、2-3 現実のモチーフ、3-2 大事なところはストップ、4-4 でこぼこ、4-9 反応できて倒せるCPU、5-4 ほめる、8-1 キャラ立ち、8-3 応援する楽しみ、8-4 メニューは世界を語る）、`UI_Nintendo_Design.md`（2 優先順位、4-1 盤面が主役、5-3 メッセージ分類、7-2 動きは情報のため、8 見ている人）

## 0. 見立て

- 今の舞台の飾りは、重さの3段階（ふつう・大一番・タイトル戦）のうち、大一番とタイトル戦にしか付かない。いちばん数の多い**ふつうの局**（組のランキング戦・順位戦の途中）は、画面上の札が変わるだけで、自由対局とほぼ同じ。
- **竜王戦と名人戦で、対局中の見た目が同じ**。
- **相手の棋士が、盤の前では名前の札でしかない**。名鑑で見た棋風・特殊能力が、指しているあいだに感じられない。
- 自分が指しているあいだ、**大会の世界が止まっている**（ほかの棋士の結果は、終局のあとにまとめて出る）。

| | ふつう | 大一番 | タイトル戦 | 章 |
| --- | --- | --- | --- | --- |

| B. 中継（勝率バー・控室の一言） | ○ | ○ | ○（「中継」の札を金に） | 3 |

| E. 終局の判子 | ○（小） | ○（中） | ○（大） | 6 |
| F. 秒読みの演出（任意の設定） | 設定したとき | 設定したとき | 設定したとき | 7 |

- ふつうの局にもA〜Eを入れ、大一番・タイトル戦ほど大きくする（4-4 でこぼこ。重さの段階は`match-stage.mjs`の`weight`をそのまま使う）。
- どれも盤より目立たせない。盤の操作を止めない。札・吹き出しは押すと消え、決まった時間で消える（U:4-1、Game_Nintendo_Implementation.mdの3-2）。
- 自由対局・学習対局には出さない（大会だけの楽しみにする。柱「大会をもっと楽しむ」）。

## 2. A. 相手の棋士を生きて見せる

### 機能設計メモ

- 一言で：盤の向こうに、名鑑で見たあの棋士が座っている。
- 解く課題：相手が名前の札だけ。名鑑の能力が対局で感じられない。CPUの強さの理由が見えない。
- リスクとリターン：特殊能力の札が出ると「この人の終盤は正確だ」と分かり、指し方を変える判断材料になる（4-9 反応できて倒せる）。
- 溜めと解放：相手が「むむ…」と言い始めたら形勢がこちらに傾いた合図。「逆転の名手」の札が出たら、勝ちが近くても気を抜けない。
- 初めての人の最初の1分：相手の名札に顔の判子が付き、最初に「よろしくお願いします」と一言。
- 上級者の深さ：どの特殊能力が、どの場面で効くか（名鑑の札の1行と同じ）を盤の上で確かめられる。
- 失敗したとき：一言は飾り。指し手には関わらない。
- ご褒美と使い道：倒した棋士は、名鑑の対戦成績に残る（今の仕組み）。
- ほめる瞬間：苦手（頓死の癖など）が出たときは、やこび姫が「今だよ！」と添える。
- 捨てるもの：相手の顔の新しい絵（判子と羽音の絵を使う）。長い会話。CPUの思考を待つ演出。
- 確かめ方：ふつうの局・羽音戦・タイトル戦で、顔・一言・札が盤を隠さず、1局に出る数が多すぎないかを見る。

### 2-1. 顔の判子

- 相手の名札（盤の上の対局者名）の横に、期の画面の「次の相手」と同じ顔を出す（名前の1文字の判子。色は棋風。羽音は絵）。`ShogiTournament.vue`の`hud-face`と同じ見た目を、対局画面用に小さくする。
- 表情は、判子の傾きと色の濃さの3段（ふつう・余裕・苦しい）で見せる。形勢は、今の助言の読みの評価値（プレイヤーから見て±500点を境）から決める。助言が「なし」のときは、ふつうのまま。

### 2-2. 相手の一言

- 相手の名札から出る小さな吹き出し（2.5秒・押すと消える）。やこび姫の台詞の欄とは別にし、やこび姫の助言を上書きしない。
- 出す場面と例（棋風で言い方を変える。攻め将棋は強気、受け将棋は落ち着いた言葉）。

| 場面 | 例（攻め将棋） | 例（受け将棋） |
| --- | --- | --- |
| 対局の始め | 「よろしくお願いします。今日も攻めますよ」 | 「よろしくお願いします。じっくりいきましょう」 |
| 形勢が相手に傾いた（±500点を越えた最初） | 「ここから一気にいきます」 | 「このまま、手厚く」 |
| 形勢がこちらに傾いた | 「むむ…」 | 「まだまだ、ここからです」 |
| 終局（負け） | 「負けました。強かったです」 | 「参りました」 |
| 終局（勝ち） | 「ありがとうございました」 | 「ありがとうございました」 |

- 1局に出すのは、始め・終わりと、途中は2回まで。羽音は`ryuo-story.mjs`の台詞の口調で別に用意する。

### 2-3. 特殊能力の札

- CPUの指し手を選ぶとき、その場面で効いた特殊能力（`applyCharacter`の`activeTraits`）と手の種類（`oversight`・`mate`・`style`）を、もう`ryuoCpuMoves`に控えている。結果の画面の「特徴が出た場面」（`summarizeTraitMoments`）と同じ決まりで、効いた瞬間に相手の名札の下へ札を出す。
  - 例：「中村さんの『鬼の読み』！」（金の札）、「終盤の受けが正確！」（青の札）、「頓死の癖が出た！」（赤の札。やこび姫が「今だよ、チャンス！」と添える）。
- 同じ特殊能力の札は1局に1回。札は名鑑の札（`specialAbilityChips`）と同じ色と名前にする。
- 結果の画面の「特徴が出た場面」と同じ瞬間を数えるので、対局中に見た札と結果の画面の振り返りがそろう。

## 3. B. 中継（勝率バー・控室の一言）

### 機能設計メモ

- 一言で：テレビの将棋中継を見ているように、AIの勝率と控室の声が盤の横に流れる。
- 解く課題：形勢が見えない。見ている人に盤面の盛り上がりが伝わらない（U:8）。大会の「現実の手触り」がない（2-3）。
- リスクとリターン：勝率が見えると、勝負どころが分かる。代わりに、答えは教えない（控室は指し手を勧めない）。
- 溜めと解放：勝率バーが50%を越えて動くたびに溜まり、大きく振れた瞬間に控室が沸く。
- 初めての人の最初の1分：盤の横に「中継」の札と、青と赤の細いバー（先手◯%）が出ているだけ。
- 上級者の深さ：控室の一言で、相手の手の意味（研究手・勝負手）が分かる。
- 失敗したとき：勝率は「AIの読み」の目安。外れても対局には関わらない。
- ご褒美と使い道：なし（情報）。
- ほめる瞬間：勝率が大きく自分に振れた手には、控室が「今の一手で、控室がどよめいています！」と言う（好手のほめ言葉と重なるときは、ほめ言葉を先に）。
- 捨てるもの：プレイヤーの次の最善手を控室が言うこと（閃きの意味がなくなる）。解説者の新しいキャラクター（控室の声は、やこび姫の台詞の欄ではなく中継の札に、名前なしで出す）。
- 確かめ方：勝率が助言の評価値と食い違わないこと、控室の一言が1局に多すぎないこと。

### 3-1. 勝率バー

- 盤の横（縦画面では対局の札の下）に、細い横棒で先手・後手の勝率を出す（先手は青、後手は赤。盤の利きの色とそろえる）。数字は自分の側だけ「あなた 62%」。
- 値は、今の助言の読みの評価値を、棋譜解析の振り返りと同じ式（`guided-review.mjs`の`winRateFor`）で勝率にしたもの。新しい探索は足さない。
- 助言を「なし」にしているときは出さない（勝率は形勢の補助なので、補助を切った人には見せない）。見出しの「設定」のメニューに「中継（勝率と控室）」の切り替えを足し、外せるようにする（実装で、表示補助の欄ではなく設定のメニューにした。表示補助の欄は、狭い画面で3つの切り替えを折り畳む計算をしていて、4つ目を足すと押せる大きさを保てないため）。
- 値が変わるときは0.3秒でなめらかに動かす（動きを減らす設定では即座）。

### 3-2. 控室の一言

- 中継の札（勝率バーの上の1行）に、局面の節目で短く出す（5-3の「通常」の分類）。やこび姫の台詞の欄とは別。
- 出す場面と例（どれも、相手の指した手か、形勢についてだけ言う）。

| 場面 | 例 |
| --- | --- |
| 中盤の入り（30手を越えた最初） | 「控室：ここからが中盤戦。両者、作戦の方向が見えてきました」 |
| 相手の手で勝率が10%以上動いた | 「控室：今の△4五歩は鋭い一手と話題に」 |
| プレイヤーの手で勝率が10%以上自分に動いた | 「控室：今の一手で、控室がどよめいています！」 |
| 終盤の入り（どちらかの玉に王手が掛かった最初、または80手を越えた最初） | 「控室：いよいよ終盤戦。勝率は先手62%です」 |
| 大一番・タイトル戦の始め | 「控室：注目の一局がまもなく始まります」 |

- 1局に出すのは5回まで。同じ場面は1回。

## 4. C. ほかの対局の速報

### 機能設計メモ

- 一言で：自分が指しているあいだも、大会は動いている。
- 解く課題：ふつうの局に溜めがない。推しの棋士・ライバルの行方が対局中に分からない。
- リスクとリターン：なし（情報）。
- 溜めと解放：「推しの斎藤さん、勝ち！」「大番狂わせ！」が対局の途中に届く。次に当たる相手が決まる瞬間もある。
- 初めての人の最初の1分：中継の札に「速報」の1行が出る。
- 上級者の深さ：次の回戦の相手が、自分の対局中に決まる。
- 失敗したとき：なし。
- ご褒美と使い道：推しの棋士の勝ちは、期の画面と同じく推しの段に反映する（今の仕組み）。
- ほめる瞬間：推しが勝ったとき、やこび姫が「やったね！」と添える。
- 捨てるもの：ほかの対局の盤や棋譜を見せること。
- 確かめ方：速報の結果が、終局後の期の画面・トーナメント表と必ず一致すること。

### 4-1. 結果を先に決めておく（期のデータの変更）

- 今は、同じ回戦のほかの試合の一部が、プレイヤーの局が終わったあと（`recordUserGame`→`drive`）に決まる。速報を出すには、**プレイヤーの局を始める前に、同じ回戦のほかの試合を全部決めておく**必要がある。
  - 竜王戦: `advanceBracket`が、プレイヤーの試合を見つけても、同じ回戦のほかの試合を先に決め切ってから`user`を返すようにする。
  - 名人戦: 順位戦の同じ回戦のほかの対局（`playOthers`）を、`setPending`のときに決めて`pending.others`に持ち、`recordMeijinGame`はそれを使う。
- 決まる結果の中身は今と同じ決め方（`simulateMemberGame`）。乱数を使う順番が変わるので、種（seed）に頼るテストは見直す。保存してある途中の期も、そのまま続けられる（まだ決まっていない試合を、新しい順番で決めるだけ。決まった結果は変わらないので、前の保存の移しかえは不要）。

### 4-2. 出し方

- 速報は、同じ回戦のほかの試合の結果を、対局の20手ごと（プレイヤーの手番で、王手されていないとき）に1件ずつ中継の札に出す。並べる順は、推しの棋士・羽音・次に当たる可能性がある試合・大番狂わせ・そのほか。
- 例：「速報：中村五段が勝って準決勝へ。次の相手かも？」「速報：推しの斎藤さん、勝ち！」「速報：大番狂わせ！ 6組の新四段が八段に勝利」
- タイトル戦（ほかの試合がない）は、その期のほかのタイトル戦・順位戦の結果（`ryuo-league.mjs`の棋界の1年）から出す。
- 出した速報は、終局後の期の画面の「戻ったときの知らせ」と重ねて出さない。

## 5. D. 竜王戦と名人戦で背景を分ける

### 機能設計メモ

- 一言で：画面を見れば、どの大会の、どこまで来た局か分かる。
- 解く課題：竜王戦と名人戦が同じ見た目。勝ち上がっても景色が変わらない。
- リスクとリターン：なし（見た目）。
- 溜めと解放：竜王戦は勝ち上がるほど山の上の景色になる。名人戦は手数が進むほど夜が更け、長い戦いの緊張が溜まる。
- 初めての人の最初の1分：背景に山（竜王戦）か、夕方の将棋会館（名人戦）が見える。
- 上級者の深さ：順位戦の最終局は「将棋界の一番長い日」の札（A級の最終局）。
- 失敗したとき：なし。
- ご褒美と使い道：山の頂に近い景色は、勝ち上がったご褒美（5-2 目の前に吊られたごほうび）。
- ほめる瞬間：なし。
- 捨てるもの：背景の動き（雲が流れるなど。盤から目をそらす）。写真の背景。盤と升の色を変えること（升の強調に黄色を使わない決まりはそのまま）。
- 確かめ方：3つの画面の大きさで、背景が盤と駒の見やすさを落とさないこと（グレースケールで盤・手番・強調が区別できる。U:7-3）。

### 5-1. 竜王戦: 山の背景

- 期の画面の「竜王への道」と同じドット絵の色で、盤の後ろに山の稜線を薄く出す。いまの段で景色を変える。

| 段 | 景色 |
| --- | --- |
| 組のランキング戦・敗者復活戦 | 麓（緑の丘と将棋会館の屋根） |
| 決勝トーナメント | 中腹（岩と松） |
| 挑戦者決定三番勝負 | 雪の稜線 |
| 竜王戦七番勝負 | 今の金屏風と畳（変えない） |

### 5-2. 名人戦: 暮れていく空

- 順位戦は朝に始まり、深夜まで続く。盤の後ろの空を、手数で暮れさせる（0〜40手: 昼、41〜80手: 夕方、81〜120手: 夜、121手〜: 深夜の将棋会館の灯り）。色はゆっくり（2秒）変える。待ったで戻れば戻る。
- A級の最終局（順位戦の最終回戦）は、開幕の札に「将棋界の一番長い日」と出す。
- 名人戦七番勝負は、今の金屏風と畳のまま。

## 6. E. 終局の判子

### 機能設計メモ

- 一言で：勝った瞬間、盤に判子が押されて「準決勝へ」が決まる。
- 解く課題：勝っても、結果の窓が出るだけで、その局で何が決まったかの手応えが薄い（3-2）。
- リスクとリターン：なし（演出）。
- 溜めと解放：対局の札の「勝てば○○」（賭けているもの）が、勝った瞬間に判子になる。
- 初めての人の最初の1分：勝つと盤の上に朱の判子と音。
- 上級者の深さ：重さの段階で判子の大きさを変える（ふつう小・大一番中・タイトル大）。
- 失敗したとき：負けたときは判子を押さない。やこび姫が「感想戦で、どこが分かれ目だったか見てみよう」と言い、結果の窓の「感想戦」を主ボタンにする（責めない。U:4-3）。
- ご褒美と使い道：判子の文字は、期の画面の節目の判子（突破・優勝・挑戦・竜王）と同じ言葉と音（`stamp`）にする。
- ほめる瞬間：判子そのもの。
- 捨てるもの：負けたときの「敗退」の判子。長い演出（1.2秒まで、盤を触ると飛ばせる）。
- 確かめ方：勝ち・負け・タイトル獲得で、結果の窓が出るまでの時間が長すぎないこと。

### 6-1. 決まり

- 勝って終局したら、盤を1.2秒止め（今の`holdForImpact`）、盤の上に判子を押す。文字は対局の札の`stakes`から（「準決勝へ」「昇級！」「挑戦権獲得」「竜王獲得」「名人獲得」など）。そのあと結果の窓。
- 判子の大きさは重さの段階で3段。タイトル獲得は、判子のあとに紙吹雪を1.5秒（動きを減らす設定では出さない）。

## 7. F. 秒読みの演出（任意の設定）

### 機能設計メモ

- 一言で：大会らしい張りつめた時間。ただし負けにはしない。
- 解く課題：大会の対局に時間の緊張がない。
- リスクとリターン：なし（時間切れで負けにはしない）。
- 溜めと解放：10秒からの読み上げ音で緊張し、指した瞬間に止まる。
- 初めての人の最初の1分：既定はなし。エントリー設定の「秒読みの演出」で選んだ人だけ。
- 上級者の深さ：秒読みを意識して指す練習になる。
- 失敗したとき：0秒になっても何も起きない（「時間いっぱい」と出るだけ）。
- ご褒美と使い道：なし。
- ほめる瞬間：なし。
- 捨てるもの：時間切れ負け（初心者が楽しめなくなる。4-1）。持ち時間の消費の表示。
- 確かめ方：音を消しても、残り秒が目で分かること（U:5-3）。

### 7-1. 決まり

- 竜王戦・名人戦のエントリー設定に「秒読みの演出: なし／30秒」を足す（対局準備と同じ「項目: 値 [変更]」の行）。既定は「なし」。
- 「30秒」のとき、プレイヤーの手番ごとに、自分の名札のまわりに残り秒の輪を出し、10秒から1秒ごとに短い音（効果音のオン・オフに従う）。0秒で「時間いっぱい」と出して止まる。CPUの手番には出さない。
- 待った・閃き・図鑑を開いているあいだは止める。

## 8. 作る順番

1. **段階1（A・C）**: 相手の顔・一言・特殊能力の札、速報（期のデータの変更を含む）。いちばん数の多いふつうの局が変わり、今ある仕組み（特殊能力の判定・期の自動対局）を見せるだけで作れる。
2. **段階2（B）**: 中継の勝率バーと控室の一言。
3. **段階3（D・E）**: 竜王戦・名人戦の背景と、終局の判子。
4. **段階4（F）**: 秒読みの演出。

各段階で、純粋な処理（`src/core/`）とテスト → 画面 → 3つの画面の大きさ（390×844・820×1180・1366×768）での確認 → 文書 → コミットの順に進める。

## 10. 決めたこと（2026-10-23。ユーザーの「おまかせ」で、おすすめのとおり）

1. **勝率バーの表示**：助言が「なし」のときは出さず、表示補助で外せる。
2. **相手の一言の量**：始め・終わりと、途中2回まで。
3. **秒読みの演出**：既定「なし」、負けにはしない。
4. **速報のための期のデータの変更**：同じ回戦のほかの試合を先に決める（結果の決め方は同じで、乱数の順番だけ変わる）。

## 11. 段階1の実装（A・C。2026-10-23）

- **期のデータ**：竜王戦は`ryuo.mjs`の`advanceBracket`が、プレイヤーの試合を見つけても同じ回戦のほかの試合を決め切ってから止まる。名人戦は`meijin.mjs`の`setPending`が同じ回戦のほかの対局を`pending.others`に決めておき、`recordMeijinGame`はそれを使う（前の保存の途中の期で`others`がなければ、指したときに決める）。テストは`ryuo.test.mjs`・`meijin.test.mjs`。
- **純粋な処理**：`src/core/match-presence.mjs`（表情`opponentMood`、口調`opponentVoice`、一言`opponentLine`・`midgameMoment`、特殊能力の札`traitCard`、速報`roundNews`・`newsDue`）。特殊能力が「出た」の決まりは、結果の画面と同じ`player-character.mjs`の`traitMomentIds`（`summarizeTraitMoments`もこれを使うように直した）。テストは`match-presence.test.mjs`。
- **画面**：対局の札の相手の行に顔の判子（期の画面と同じ色。羽音は絵）を付け、表情は形勢で3段（傾きと濃さ）。その下に**中継の1行**（決まった高さ。スマホ・タブレットは1行、広い画面は2行ぶん）を置き、相手の一言（2.5秒）・特殊能力の札（3.5秒、金・青・赤の地）・速報（6秒）を出す。特殊能力の札は、一言や速報で上書きしない。押すと消える。
  - 一言を出すときは、名前の後に「」で囲む（「藤田恭平「よろしくお願いします。じっくりいきましょう」」）。
  - 頓死の癖が出たときは、やこび姫の台詞の欄にも「チャンスだよ！ 相手の玉に詰みがないか探そう！」と出す。
  - 速報は、プレイヤーの手番が来たときに、20手ごとに1件。リロードで戻ったときは、あいさつはしない。
- **まだのこと**：タイトル戦（ほかの試合がない）の速報（ほかのタイトル戦・順位戦の結果）は、段階1では出さない。段階2以降で、棋界の1年の結果から作る。
- **確かめたこと**：390×844・820×1180・1366×768で、竜王戦の6組ランキング戦を始め、顔の判子と始めのあいさつ、22手目まで進めた局面での速報（「速報：天鷺羽音さんが勝った！ 勝ち上がってくるよ」）が、盤の大きさを変えずに出ることを確かめた。特殊能力の札と表情の変化は、自動テストだけで確かめた（実際の対局で出る局面はまだ見ていない）。

## 12. 段階2の実装（B。2026-10-23）

- **純粋な処理**：`match-presence.mjs`の`playerWinRate`（棋譜解析の振り返りと同じ`winRateFor`の式）・`formatWinRate`・`roomComment`（始め・形勢が10%動いた・終盤の入り・中盤の入りを、1局にそれぞれ1回、合わせて5回まで）。テストは`match-presence.test.mjs`。
- **画面**：対局の札の相手の行の上に、決まった高さの勝率バー（「中継」の札、先手は青・後手は赤、「あなた 62%」）。値は助言の読みの評価値で、まだ読んでいないあいだは「—」と半分の位置。控室の一言は、段階1の中継の1行に出す（4秒、薄紫の字）。タイトル戦は「中継」の札を金地にする。
- **評価値の出どころ**：詳しい助言では、助言の読み（プレイヤーの手番の上位5手の読み）の評価値だけを使う。CPUの探索の浅い評価値を混ぜると、同じ手番のうちにバーが跳ねるため。応援のみでは、CPUの探索の評価値を使う。
- **設定**：見出しの「設定」のメニューの「中継（勝率と控室）」で切り替え、`localStorage`のキー`yacobihime:shogi-match:broadcast:v1`に覚える（既定はON）。
- **確かめたこと**：390×844・820×1180・1366×768で、竜王戦の6組ランキング戦を32手目まで進め、勝率バー（「あなた 51%」など）と「控室：ここからが中盤戦。両者、作戦の方向が見えてきました」が、盤の大きさを変えずに出ることを確かめた。形勢が動いたときと終盤の一言は、自動テストだけで確かめた。
