# ライバル・天鷺羽音の設計（2026-10-20、段階1を実装）

依頼: ドット絵のミニキャラ（銀髪・黄色の目・紺のセーラー服の女子高生）を、キャラクター「天鷺羽音」としてゲームに入れたい。出す場所はおまかせ、表情はとりあえず1枚。

読んだ指針:
- `Game_Nintendo_Design.md`: 8-1 キャラ立ち、8-2 シナリオは遊びの邪魔をしない、8-3 応援する楽しみ、4-4 でこぼこ、4-7 平均と平凡、4-9 反応できて倒せる、5-2 吊られたごほうび、7-2 勝った人も負けた人も楽しい、2-5 複数の課題を一度に解く、2-6 掛け算
- `UI_Nintendo_Design.md`: 4-1 対局画面の情報の優先順位、5-3 メッセージ分類、6-1 必要な瞬間に1つだけ、7-2 動きは情報のため、8 見ている人への配慮

## 1. 人物

### 1-1. 一言で（D:8-1）

**規則性で読む、名人の娘。** 冷静で計算が速く、指すほど強くなる。勝つなら序盤のうち。

### 1-2. 設定

| 項目 | 内容 |
|---|---|
| 名前 | 天鷺羽音（あまさぎ はのん） |
| 立場 | 女子高生。三段リーグを突破した新四段として、竜王戦に出る（3-1） |
| 性格 | 冷静。感情的になることは少ない。数学が好きで、規則性を見つけるのが好き。計算と思考が速い |
| 将棋 | 父親譲りの天性の脳機能で、読みの深さ・速さ・正確さがずば抜けている。力戦にむしろ強い。序盤から終盤にかけて徐々に強さを増す |
| 苦手 | 他人の気持ちがあまり分からず、不器用。マヨネーズとソースが大嫌いで、果物が好き |
| 家族 | 父は、史上最強の棋士と言われる天鷺善彦名人（4章） |
| プレイヤーとの関係 | 最初は「強い相手の1人」としか見ていない。負けると「絶対に許さないリスト」に名前を書き、以後は手を緩めない |

### 1-3. 台詞の書き方

- 短く、平らに話す。感嘆符（！）を使わない。「〜だよ」「〜でしょ？」「〜ない」で終える。
- ほめるときも、気持ちではなく事実で言う（「その手、確率で言えば低かった。でも正しかった」）。
- 自分を大きく言わない（「自分が一番だと思ったことなんて、一度も無いよ」）。勝っても喜びを見せない。
- 負けても取り乱さない。悔しさは「許さないリスト」のような、ずれた形で出す（不器用さ）。
- プレイヤーの呼び方は「あなた」。依頼の台詞の〈Player〉は「あなた」にする（今の竜王戦と同じ。プレイヤーの名前は保存していない）。
- 好物・苦手な食べ物の話は、対局と関係のない一言として、まれに出す程度にする（8-2。設定を説明しない）。

## 2. どこに出すか

| 案 | 合う点 | 合わない点 |
|---|---|---|
| **A. 竜王戦のライバル（採用）** | 依頼の台詞（「手を緩める気は無い」「許さないリスト」）は、何度も当たる相手の台詞。竜王戦には、今は顔も台詞もある相手が1人もいない（相手は名前と段位の文字だけ）。父を名人として棋界に置ける | 竜王戦を遊ばない人には会えない |
| B. 将棋教室の腕だめしの試験官 | 規則性・「どう、当たってる？」が出題者に合う | 「強いライバル」という設定と台詞が生きない。教室はやこび姫が先生で、2人が話すと読む量が増える |
| C. 自由対局の相手 | いちばん目にする | Lvを選んで指す画面に固定の人物を置くと、Lvと人物の強さが食い違う |

**Aにする。** 1つの登場で、次の4つを同時に解く（D:2-5）。
- 竜王戦に、顔と台詞のある相手がいない（8-1）。
- 組の決勝という山場に、目に見える「壁」がない（4-4, 5-2）。
- 他の棋士を応援・意識する理由が、推しの棋士だけ（8-3）。
- 天鷺の親子で、棋界の名人戦に物語ができる（4章）。

教室や自由対局は、竜王戦で会ったあとに広げる（9章の段階2）。

## 3. 竜王戦での仕組み

### 3-1. 名簿に入れる

- 名簿（`ryuo-roster.mjs`）に、固定の人物として入れる。乱数で作る棋士と同じ形に、`story: 'hanane'`を足す。
- **最初の組と段位**：三段リーグを突破した新四段（17歳、順位戦はC級2組）。プレイヤーが始める組に入れる（プレイヤーが竜王なら1組）。段位は竜王戦の昇段規定のとおり、2組なら六段、1組なら七段、それ以外は四段。
  - その組の乱数の棋士を1人減らし、組の人数は今のまま。
- **出場**：組にいれば毎期必ず出場する（`selectParticipants`）。
- **山の配置**：プレイヤーと同じ組なら、羽音を第1か第2シードにして、トーナメント表の反対の半分に置く（`placeRival`）。2人とも勝ち進めば、組の決勝で当たる（4-4 山場）。
- **勝ち上がってくる**：プレイヤーと同じランキング戦の表の自動対局だけ、羽音のレーティングに+120する（`HANANE_RIVAL_RUN_RATING`）。プレイヤーとの対局、ほかの組、棋界の1年には足さない。プレイヤーが勝ち進んだとき、組の決勝で羽音と当たる割合は、規模「最小」で約9割、「中」で約6割、「実物」で約5割（200期で測った）。
- **引退しない・個性が変わらない**：期をまたいでも、名簿から外さず、特徴を変えない（`ageCharacter`をかけない）。年齢とレーティングの変化は、ほかの棋士と同じ。組の昇級・降級も、ほかの棋士と同じ決まりで動く。

### 3-2. 強さ

- **レーティング**：その組の平均＋ばらつき2個分（`HANANE_RATING_SIGMA`）。6組なら1660で、2組の平均に近い。
  - レーティングからLvへの換算は今の`ratingToLevel`のまま。難易度7の6組では、組の平均Lv22、いちばん強いほかの棋士Lv23に対して、羽音はLv24。最高でもLv40（AGENTS.mdの上限）。
- **本気**：プレイヤーに一度でも負けていれば（名簿の対戦成績で、プレイヤーの勝ちが1以上）、プレイヤーと指すときのLvを、レーティング+40で換算する（`HANANE_GRUDGE_RATING`。Lvで1つ前後）。重ねない。自動対局のレーティングは変えない。

### 3-3. 棋風と特徴（D:4-7 とがらせる、4-9 倒せる）

| 種類 | 中身 | 設定との対応 |
|---|---|---|
| 棋風 | バランス型（攻め・受けの偏り0） | 冷静 |
| 得意 | 「読みがとても深い」（`deep-reading`・度合い2）、「詰将棋がとても得意」（`tsume`・度合い2） | 読みの深さ・速さ・正確さ |
| 得意（新しい特徴） | 「序盤より中盤、中盤より終盤と、指すほどぐんぐん強くなる」（`late-bloom`・度合い2）。序盤は手の精度を少し下げ（`sharpen: -0.3`）、中盤は上げて読みを1.2倍、終盤はさらに上げて悪手を抑え（`steady`）、読みを1.3倍にする | 序盤から終盤にかけて徐々に強さを増す |
| 苦手 | なし（力戦にもむしろ強い） | 天性の脳機能 |
| 得意戦法 | 相掛かり・角換わり（居飛車党） | 力戦になりやすい相掛かり |

- 攻略法は「序盤のうちにリードを取る」こと。やこび姫が対局前に言い、名鑑の得意の欄でも読める（D:4-5、4-9）。
- `late-bloom`は物語の人物だけの特徴で、乱数の棋士には付けない（`traitWeights`で0）。特徴の効き方が場面で変わるよう、`applyCharacter`は特徴の`effect`に場面（序盤・中盤・終盤）を渡す。
- 最初の案の苦手「定跡を外れると迷いやすい」は、ユーザーの決定（力戦にむしろ強い）で取りやめた。

## 4. 天鷺善彦名人（父）

- 名簿に固定の人物として入れる（`story: 'yoshihiko'`）。絵は作らない（名前と、やこび姫の紹介だけ）。52歳、九段。得意は「読みがとても深い」「序盤の研究がとても深い」「中盤がとても強い」。
- 通算の記録は、タイトル通算95期（竜王7・名人12・王位13・叡王3・王座19・棋王13・王将12・棋聖16）、通算1480勝430敗。
- **新しい名簿**：名人を持たせて始める。1組・A級に置き、レーティングは竜王と同じ1950。名人の獲得は通算多数（棋士名鑑の通算タイトルで「史上最強」が分かる数）。
- **今の名簿（移行）**：タイトルは持たせず、1組・A級の上位に加えるだけにする。翌年の名人戦の挑戦者になりやすいので、自然に名人戦で姿を見せる（保存した記録を書き換えない）。
- 強さの上限は、ほかの棋士と同じLv40。「史上最強」は通算の記録で表し、Lvの上限は越えない（AGENTS.md）。
- 引退しない。
- 対局すると（竜王戦の決勝トーナメントや七番勝負で当たると）、やこび姫が「天鷺善彦名人は、羽音さんのお父さん。史上最強って言われる人だよ」と紹介する。同じ期に羽音と対局していれば、羽音の言葉（「父さんの将棋は、規則性が見えない。だから強いんだと思う。」）を添える。善彦の台詞は作らない（8-2。人物を増やしすぎない）。

## 5. 台詞（場面ごと）

台詞は、対局前の札（6-1）と、終局後の振り返りに1つずつ出す。会話を続けて読ませない（D:8-2）。同じ場面に複数の候補があるときは、順に回す（同じ文を続けて出さない）。

| 場面 | 羽音の台詞 |
|---|---|
| 初めて当たる対局の前 | 「天鷺羽音。……よろしく。」／「あなたの棋譜、少しだけ見た。規則性は、まだ見えない。」 |
| 2回目以降（羽音が勝ち越し） | 「同じ形なら、同じ結果になるよ。」 |
| 2回目以降（許さないリストの後） | 「リストの名前は、まだ消してない。」／「今日は、手を緩めない。」 |
| 羽音が勝ったあと | 「読み通り。……どう、当たってる？」／「受け取ってばかりじゃいられないでしょ？ 次はあなたの番。」 |
| 初めて羽音が負けたあと | 「これは絶対に許さないリスト。勿論、あなたの名前も入っている。今後、あなたとの勝負で手を緩める気は無い。」 |
| 2回目以降に羽音が負けたあと | 「私は、自分が一番だと思ったことなんて、一度も無いよ。」／「その手、確率で言えば低かった。でも、正しかった。」 |
| プレイヤーが竜王の挑戦者・竜王になったとき | 「願いを全部叶えられるのは突き抜けた天才だけだよ。残念だけど、私はそうじゃない。……だから、次は私が勝つ。」 |
| 善彦と当たる対局の前（同じ期に羽音と対局していれば、やこび姫が伝える） | 「父さんの将棋は、規則性が見えない。だから強いんだと思う。」 |

- 依頼の台詞のうち6つを上の場面に入れた。「知らない。最新の記録までは追ってないよ。」は、新四段で始めることにしたので四段になる場面がなくなり、段階2（棋界の知らせ）に回す。「私にまかせて。」は、段階2の協力の場面（9章）に取っておく。
- 「プレイヤーが竜王の挑戦者・竜王になったとき」の一言は、段階1では出す場所がない（結果の画面は、羽音と指した直後だけ羽音の一言を出す）。段階2に回す。
- やこび姫の台詞は、羽音が相手のときだけ、いつもの紹介（`ryuo-speech.mjs`の`opponentLines`）の前に、羽音の紹介を1つ足す（「次の相手は天鷺羽音さん。天鷺名人の娘で、三段リーグを突破したばかりの新四段だよ。読みがすごく深くて、力戦でも崩れない。終盤ほど強くなるから、序盤のうちにリードを取ろう。」）。攻略の手がかりは、やこび姫が言う（羽音は自分の弱点を言わない）。

## 6. 画面

### 6-1. 機能設計メモ（UI_Nintendo_Design.mdの10章の形）

- **目的**：竜王戦の相手に、顔と一言で個性を持たせる。対局の前に「この相手には勝ちたい」と思わせる。
- **利用場面**：竜王戦で羽音と当たる対局の前と後。1期に0〜2回、数秒。
- **画面の主役**：対局前の札（「あなた VS 相手」）の、相手側の羽音の絵。
- **情報の優先順位**：1. 羽音の絵と名前・段位 2. 羽音の一言（1文） 3. Lv・得意戦法・手番の札（今のまま） 4. やこび姫の紹介と攻略の手がかり 5. くわしいプロフィール（今のまま、たたんでおく）。
- **操作の流れ**：今と同じ（札を見て「対局する」）。台詞のための操作は増やさない（読み飛ばしても遊べる）。
- **確認ダイアログ**：なし。
- **メッセージ分類**：羽音の一言は「通常」。初めて負かしたときの「許さないリスト」だけ「注目」（吹き出しの縁を羽音の色にする）。
- **初めて使う人への伝え方**：名前の上の小さな札「ライバル」と、絵の有無で、ほかの棋士と違うことを見せる。文の説明は付けない。
- **快の要素**：札が出るときに、絵を下から1回だけ軽く出す（`prefers-reduced-motion`では動かさない）。音は増やさない。
- **見ている人への配慮**：絵と名前が並ぶので、横から見ても誰と指しているか分かる。
- **作らないと決めたこと**：会話の場面（何往復もする会話）、表情の差分（今は1枚。9章）、対局中の羽音の台詞、プレイヤーの名前の入力。
- **検証方法**：竜王戦を6組から始め、羽音と当たる札・終局後の一言・名鑑を、スマホ縦・タブレット縦・デスクトップで確かめる。作った人以外に、札を見て「この人は誰で、どう強いか」が言えるかを聞く。

### 6-2. 出す場所

| 場所 | 出し方 |
|---|---|
| 対局前の札（`ShogiTournament.vue`の「あなた VS 相手」） | 相手側に羽音の絵（全身）と、吹き出しで一言。名前の上に「ライバル」の札 |
| 終局後の振り返り（竜王戦の結果の解説） | やこび姫の解説の前に、羽音の一言を1つ |
| トーナメント表 | 羽音の名前の横に小さな印（推しの印と区別できる形と色） |
| 棋士名鑑（`RyuoRosterBook.vue`） | 羽音の項目に絵（上半身）と、紹介の一言。善彦の項目に「羽音の父」 |
| 対局画面 | 今は出さない（9章の段階2） |

### 6-3. 絵の扱い

- **ファイル**：`public/characters/hanane-mini.webp`。ドット絵（37×80ドット）を8倍に拡大した、劣化のない透過webp（296×640px）。URLに`?v=1`を付け、差し替えたら上げる。
- **ドットの大きさをやこび姫にそろえる**：やこび姫の絵は縦53ドット、羽音は縦80ドット。同じ画面に並べるときは、1ドットの大きさをそろえ、羽音を縦に約1.5倍の大きさで出す（羽音のほうが背が高い高校生に見える）。ドットの細かさが違う絵を同じ大きさで並べると、絵の質が揃わず浮く。
- `image-rendering: pixelated`で拡大する（今のやこび姫と同じ）。
- **スマホ縦**：札の高さを増やさないよう、胸から上（上の40ドット）だけを切り出して出す。タブレット以上は全身。
- **色**：竜王戦の配色（紺・スレート・クリーム・橙・ラベンダー、`tournament-design.md`）の中で、羽音の印と吹き出しの縁には、絵の目の黄色（#d4a93a前後）を使う。朱（竜の印）と黄色の升の強調は使わない（AGENTS.mdの盤面の色）。

## 7. 保存と移行

- 名簿の保存形式（版2）は変えない。人物は、名簿の棋士に`story`を足しただけで、今の読み込みのまま読める。
- 人物のいない前の名簿には、次の期を始めるとき（`ShogiMatchGame.vue`の`enterRyuoSeason`）に、`withStoryMembers`で加える。善彦にはタイトルを持たせず、A級に入れる（保存した記録を書き換えない）。進行中の期には加えない。
- 「本気」かどうかは、今の対戦成績（`roster.vsUser`）から決める（新しい保存項目は作らない）。
- 台詞の候補は、対局の回数で順に回す（新しい保存項目は作らない）。

## 9. 作る順番

**段階1（この設計で作るもの）**
1. 名簿の固定の人物（羽音・善彦）、出場・山の配置、強さ・特徴、移行とテスト。
2. 台詞（`ryuo-story.mjs`）とテスト。
3. 画面：対局前の札・終局後の一言・トーナメント表の印・名鑑。
4. ブラウザで、6組から始めた竜王戦で確かめる（スマホ縦・タブレット縦・デスクトップ）。README・AGENTS.md・`tournament-design.md`を直す。

**段階2（会ってから広げる。今は作らない）**
- **「どう、当たってる？」の予想**：対局前に、羽音がプレイヤーの過去の棋譜からいちばん多い戦型を予想し、終局後に当たり外れを言う。規則性が好きな人物を、遊びで見せる。
