# ライバル・天鷺羽音の設計（2026-10-20、未実装）

依頼: ドット絵のミニキャラ（銀髪・黄色の目・紺のセーラー服の女子高生）を、キャラクター「天鷺羽音」としてゲームに入れたい。出す場所はおまかせ、表情はとりあえず1枚。

読んだ指針:
- `Game_Nintendo_Design.md`: 8-1 キャラ立ち、8-2 シナリオは遊びの邪魔をしない、8-3 応援する楽しみ、4-4 でこぼこ、4-7 平均と平凡、4-9 反応できて倒せる、5-2 吊られたごほうび、7-2 勝った人も負けた人も楽しい、2-5 複数の課題を一度に解く、2-6 掛け算
- `UI_Nintendo_Design.md`: 4-1 対局画面の情報の優先順位、5-3 メッセージ分類、6-1 必要な瞬間に1つだけ、7-2 動きは情報のため、8 見ている人への配慮

## 1. 人物

### 1-1. 一言で（D:8-1）

**規則性で読む、名人の娘。** 冷静で計算が速く、終盤は正確。ただし、決まった形から外れた将棋で迷う。

### 1-2. 設定

| 項目 | 内容 |
|---|---|
| 名前 | 天鷺羽音（読みは未定。10章） |
| 立場 | 女子高生。竜王戦には奨励会三段として6組から出る（3-1） |
| 性格 | 冷静。感情的になることは少ない。数学が好きで、規則性を見つけるのが好き。計算と思考が速い |
| 苦手 | 他人の気持ちがあまり分からず、不器用。マヨネーズとソースが大嫌いで、果物が好き |
| 家族 | 父は、史上最強の棋士と言われる天鷺善彦名人（4章） |
| プレイヤーとの関係 | 最初は「強い相手の1人」としか見ていない。負けると「絶対に許さないリスト」に名前を書き、以後は手を緩めない |

### 1-3. 台詞の書き方

- 短く、平らに話す。感嘆符（！）を使わない。「〜だよ」「〜でしょ？」「〜ない」で終える。
- ほめるときも、気持ちではなく事実で言う（「その手、確率で言えば低かった。でも正しかった」）。
- 自分を大きく言わない（「自分が一番だと思ったことなんて、一度も無いよ」）。勝っても喜びを見せない。
- 負けても取り乱さない。悔しさは「許さないリスト」のような、ずれた形で出す（不器用さ）。
- プレイヤーの呼び方は「あなた」。依頼の台詞の〈Player〉は「あなた」にする（今の竜王戦と同じ。プレイヤーの名前は保存していない）。
- 好物・苦手な食べ物の話は、対局と関係のない一言として、まれに出す程度にする（8-2。設定を説明しない）。

## 2. どこに出すか

| 案 | 合う点 | 合わない点 |
|---|---|---|
| **A. 竜王戦のライバル（採用）** | 依頼の台詞（「手を緩める気は無い」「許さないリスト」）は、何度も当たる相手の台詞。竜王戦には、今は顔も台詞もある相手が1人もいない（相手は名前と段位の文字だけ）。6組には奨励会三段の枠がちょうど1つある。父を名人として棋界に置ける | 竜王戦を遊ばない人には会えない |
| B. 将棋教室の腕だめしの試験官 | 規則性・「どう、当たってる？」が出題者に合う | 「強いライバル」という設定と台詞が生きない。教室はやこび姫が先生で、2人が話すと読む量が増える |
| C. 自由対局の相手 | いちばん目にする | Lvを選んで指す画面に固定の人物を置くと、Lvと人物の強さが食い違う |

**Aにする。** 1つの登場で、次の4つを同時に解く（D:2-5）。
- 竜王戦に、顔と台詞のある相手がいない（8-1）。
- 組の決勝という山場に、目に見える「壁」がない（4-4, 5-2）。
- 他の棋士を応援・意識する理由が、推しの棋士だけ（8-3）。
- 天鷺の親子で、棋界の名人戦に物語ができる（4章）。

教室や自由対局は、竜王戦で会ったあとに広げる（9章の段階2）。

## 3. 竜王戦での仕組み

### 3-1. 名簿に入れる

- 名簿（`ryuo-roster.mjs`）に、固定の人物として入れる。乱数で作る棋士と同じ形（`createMember`の形）に、`story: 'hanane'`を足す。
- **最初の組と段位**：プレイヤーが始める組に入れる。
  - 6組なら奨励会三段（6組の特別枠の1つを羽音にする）。
  - 5組・4組なら四段、3組以上なら六段（強い若手）。
- **出場**：プレイヤーと同じ組なら、毎期必ず出場する（`selectParticipants`で、6組の奨励会三段の枠と、他の組では最初の1人を羽音にする）。
- **山の配置**：プレイヤーと同じ組なら、トーナメント表の反対の山に置く。2人とも勝ち進めば、組の決勝で当たる（4-4 山場）。
- **引退しない・名簿から外れない**：奨励会三段は1期で入れ替わる決まりがあるが、羽音は外さない。
- **四段になる**：最初の期の終わりに、必ず四段になる（物語の区切り。新四段の知らせはやこび姫が一言で伝える）。以後は今の決まりどおり、竜王戦の成績で組を上がり下がりする。

### 3-2. 強さ

- **レーティング**：その組の平均＋ばらつき1.6個分（その組のおよそ上位5%）。6組なら約1600で、6組でいちばん強い相手の1人になる。
  - レーティングからLvへの換算は今の`ratingToLevel`のまま。最高でもLv40（AGENTS.mdの上限）。
- **成長**：名簿の期ごとの強さの変化（若手は伸びる）を、今のまま受ける。
- **本気**：プレイヤーに初めて負けたあとは、`grudge: true`を記録する。以後の対局では、羽音のレーティングに+40する（Lvで1つ前後）。
  - 「手を緩める気は無い」を強さで見せる。上げすぎると倒せなくなるので、1回だけで、重ねない（4-9）。

### 3-3. 棋風と特徴（D:4-7 とがらせる、4-9 倒せる）

| 種類 | 中身 | 設定との対応 |
|---|---|---|
| 棋風 | バランス型（攻め・受けの偏り0） | 冷静 |
| 得意 | 「詰将棋がとても得意」（今の`tsume`・度合い2）、「読みがやや深い」（今の`deep-reading`・度合い1） | 計算・思考が速い |
| 苦手（新しい特徴） | 「定跡を外れると、やや迷いやすい」（`off-pattern`・度合い1）。序盤・中盤で、定跡の形から外れた局面では手の精度を下げる（`sharpen: -0.5`） | 規則性が好き。他人の考えが読めない |
| 得意戦法 | 角換わり・相掛かり（研究の深い居飛車） | 規則性。父の将棋 |

- 苦手は、プレイヤーが見つけられる攻略法にする（D:4-5 ズルを許す、4-9 反応できて倒せる）。棋士名鑑と対局前のプロフィールに出るので、読めば「力戦にすればいい」と分かる。
- 「定跡を外れた」の判定は、対局画面が今使っている戦型の判定（`formation-tracker.mjs`）で、どの定跡の形にも当たらない局面とする。判定の仕方は実装のときに決め、決めたらこの章を直す。

## 4. 天鷺善彦名人（父）

- 名簿に固定の人物として入れる（`story: 'yoshihiko'`）。絵は作らない（名前と台詞だけ）。
- **新しい名簿**：名人を持たせて始める。1組・A級に置き、レーティングは竜王と同じ1950。名人の獲得は通算多数（棋士名鑑の通算タイトルで「史上最強」が分かる数）。
- **今の名簿（移行）**：タイトルは持たせず、1組・A級の上位に加えるだけにする。翌年の名人戦の挑戦者になりやすいので、自然に名人戦で姿を見せる（保存した記録を書き換えない）。
- 強さの上限は、ほかの棋士と同じLv40。「史上最強」は通算の記録で表し、Lvの上限は越えない（AGENTS.md）。
- 引退しない。
- 対局すると（竜王戦の決勝トーナメントや七番勝負で当たると）、やこび姫が「羽音さんのお父さん」と一言添える。善彦の台詞は作らない（8-2。人物を増やしすぎない）。

## 5. 台詞（場面ごと）

台詞は、対局前の札（6-1）と、終局後の振り返りに1つずつ出す。会話を続けて読ませない（D:8-2）。同じ場面に複数の候補があるときは、順に回す（同じ文を続けて出さない）。

| 場面 | 羽音の台詞 |
|---|---|
| 初めて当たる対局の前 | 「天鷺羽音。……よろしく。」／「あなたの棋譜、少しだけ見た。規則性は、まだ見えない。」 |
| 2回目以降（羽音が勝ち越し） | 「同じ形なら、同じ結果になるよ。」 |
| 2回目以降（許さないリストの後） | 「リストの名前は、まだ消してない。」／「今日は、手を緩めない。」 |
| 羽音が勝ったあと | 「読み通り。……どう、当たってる？」／「受け取ってばかりじゃいられないでしょ？ 次はあなたの番。」 |
| 初めて羽音が負けたあと | 「これは絶対に許さないリスト。勿論、あなたの名前も入っている。今後、あなたとの勝負で手を緩める気は無い。」 |
| 2回目以降に羽音が負けたあと | 「私は、自分が一番だと思ったことなんて、一度も無いよ。」／「その手、確率で言えば低かった。でも、正しかった。」 |
| 羽音が四段になったとき（やこび姫が伝える） | やこび姫「羽音さん、四段になったって！」 → 羽音「知らない。最新の記録までは追ってないよ。……でも、ありがと。」 |
| プレイヤーが竜王の挑戦者・竜王になったとき | 「願いを全部叶えられるのは突き抜けた天才だけだよ。残念だけど、私はそうじゃない。……だから、次は私が勝つ。」 |
| 父の話題（善彦が名人戦に出る年、年度の区切りで） | 「父さんの将棋は、規則性が見えない。だから強いんだと思う。」 |

- 依頼の台詞7つは、すべて上の場面に入れた。「私にまかせて。」は、段階2の協力の場面（9章）に取っておく。
- やこび姫の台詞（`ryuo-speech.mjs`の`opponentLines`）は、羽音が相手のときだけ、紹介の一言に変える（「次の相手は天鷺羽音さん。天鷺名人の娘で、終盤がとても正確。でも、定跡を外れると迷いやすいよ」）。攻略の手がかりは、やこび姫が言う（羽音は自分の弱点を言わない）。

## 6. 画面

### 6-1. 機能設計メモ（UI_Nintendo_Design.mdの10章の形）

- **目的**：竜王戦の相手に、顔と一言で個性を持たせる。対局の前に「この相手には勝ちたい」と思わせる。
- **利用場面**：竜王戦で羽音と当たる対局の前と後。1期に0〜2回、数秒。
- **画面の主役**：対局前の札（「あなた VS 相手」）の、相手側の羽音の絵。
- **情報の優先順位**：1. 羽音の絵と名前・段位 2. 羽音の一言（1文） 3. Lv・得意戦法・手番の札（今のまま） 4. やこび姫の紹介と攻略の手がかり 5. くわしいプロフィール（今のまま、たたんでおく）。
- **操作の流れ**：今と同じ（札を見て「対局する」）。台詞のための操作は増やさない（読み飛ばしても遊べる）。
- **確認ダイアログ**：なし。
- **メッセージ分類**：羽音の一言は「通常」。初めて負かしたときの「許さないリスト」だけ「注目」（吹き出しの縁を羽音の色にする）。
- **初めて使う人への伝え方**：名前の上の小さな札「ライバル」と、絵の有無で、ほかの棋士と違うことを見せる。文の説明は付けない。
- **快の要素**：札が出るときに、絵を下から1回だけ軽く出す（`prefers-reduced-motion`では動かさない）。音は増やさない。
- **見ている人への配慮**：絵と名前が並ぶので、横から見ても誰と指しているか分かる。
- **作らないと決めたこと**：会話の場面（何往復もする会話）、表情の差分（今は1枚。9章）、対局中の羽音の台詞、プレイヤーの名前の入力。
- **検証方法**：竜王戦を6組から始め、羽音と当たる札・終局後の一言・名鑑を、スマホ縦・タブレット縦・デスクトップで確かめる。作った人以外に、札を見て「この人は誰で、どう強いか」が言えるかを聞く。

### 6-3. 絵の扱い

- **ファイル**：`public/characters/hanane-mini.webp`。ドット絵（37×80ドット）を8倍に拡大した、劣化のない透過webp（296×640px）。URLに`?v=1`を付け、差し替えたら上げる。
- **ドットの大きさをやこび姫にそろえる**：やこび姫の絵は縦53ドット、羽音は縦80ドット。同じ画面に並べるときは、1ドットの大きさをそろえ、羽音を縦に約1.5倍の大きさで出す（羽音のほうが背が高い高校生に見える）。ドットの細かさが違う絵を同じ大きさで並べると、絵の質が揃わず浮く。
- `image-rendering: pixelated`で拡大する（今のやこび姫と同じ）。
- **スマホ縦**：札の高さを増やさないよう、胸から上（上の40ドット）だけを切り出して出す。タブレット以上は全身。
- **色**：竜王戦の配色（紺・スレート・クリーム・橙・ラベンダー、`tournament-design.md`）の中で、羽音の印と吹き出しの縁には、絵の目の黄色（#d4a93a前後）を使う。朱（竜の印）と黄色の升の強調は使わない（AGENTS.mdの盤面の色）。

## 9. 作る順番

**段階1（この設計で作るもの）**
1. 名簿の固定の人物（羽音・善彦）、出場・山の配置、強さ・特徴、移行とテスト。

**段階2（会ってから広げる。今は作らない）**
- **「どう、当たってる？」の予想**：対局前に、羽音がプレイヤーの過去の棋譜からいちばん多い戦型を予想し、終局後に当たり外れを言う。規則性が好きな人物を、遊びで見せる。
- 対局画面の相手側に、羽音の上半身を出す。
- 表情の差分（勝ったとき・負けたとき）。
- 竜王戦の外：ホームの「ライバル」の札、自由対局で羽音と指す、教室の卒業試験の相手。「私にまかせて。」は、プレイヤーが竜王を防衛する年に、羽音が研究相手になる場面で使う。

## 10. 決めること

1. **名前の読み**：「天鷺」と「羽音」の読み（例：あまさぎ・はのん）。読み上げとファイル名に使う。
2. **最初の立場**：奨励会三段で6組から出て、1期で四段になる流れでよいか。女流棋士にする案もある。ただ、6組の奨励会三段の枠がちょうど1つあり、四段になって同じ道を上がっていく姿が、プレイヤーと並んで成長するライバルに合う。
3. **父を出すか**：天鷺善彦名人を、絵なしで棋界に入れるか。入れない場合、4章と5章の父の台詞を外す。
4. **本気の強さ**：初めて負けたあとの+40（Lv1つ前後）でよいか。
5. **苦手の中身**：「定跡を外れると迷いやすい」でよいか（攻略法になり、名鑑で読める）。
