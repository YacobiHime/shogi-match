# 来た場所へ戻る

2026-10-29、ユーザーの依頼「大会で対局後にノートを見ると、『タイトルに戻る』ボタンしかないため、不便。修正して。」と、「やこびノートのコレクションで作戦を押して、『この作戦にする』を押した後にもタイトルに戻るボタンしか無い。このように、来た場所に戻れない場所が他にも無いか調べて、修正して。」

## 1. 調べたこと

画面から画面へ移る入口（画面の部品が親へ送る知らせと、対局画面の`*From*`の関数）を全部たどり、閉じたときにどこへ戻るかを見た。

| 来た道 | 前の戻り先 | 直したあと |
| --- | --- | --- |
| 大会の結果の画面 →「ノートを見る」 | 「タイトルへ戻る」でタイトル | 「大会へ戻る」で大会の結果の画面。ノートは「大会」の項目で開く |
| ノートのコレクション → 作戦のカード →「この作戦にする」→ 対局準備 | 対局準備の「← タイトル」 | 「← ノート」でノート（最後に見ていたコレクション） |
| ノートのコレクション → 作戦のカード → 選ばずに閉じる | 対局準備が残り、「← タイトル」 | 対局準備を通さずにノートへ |
| ノートの「対局する」→ 対局準備 | 「← タイトル」 | 「← ノート」 |
| ノートのコレクション → 定跡図鑑・手筋図鑑 | 「タイトルへ戻る」 | 「ノートへ戻る」でノート |
| 定跡図鑑の戦法占い →「この作戦で指す」・「完成形から指してみる」→ 対局準備 | 「← タイトル」 | 「← 図鑑」で定跡図鑑（図鑑をノートから開いていたら、図鑑の次はノート） |
| ノートの「棋力を測る」→ 棋力テスト → やめる | タイトル | ノート |
| ノートの「棋力を測る」→ 棋力テストの結果 →「ホームへ」 | タイトル | 「ノートへ戻る」でノート |

戻り先が正しかったもの（直していない）：教室から開いた図鑑（「戻る」で教室）、対局中に開いた図鑑（「対局へ戻る」）、教室の対局（終局で教室へ）、ノートの中の棋士名鑑・研究ノートの中継（ノートの中で閉じる）、大会の中の画面（大会の画面の`goBack`）、ホームから開く画面（タイトルへ戻るのが来た場所）。

## 2. 機能設計メモ（Game_Nintendo_Design.mdの「機能設計メモのテンプレート」の形）

### 機能名：来た場所へ戻る

- 一言で：見に行った画面から、1回の操作で元の画面へ戻れる。
- 解く課題：寄り道（作戦の手順を見る・観戦記を読む・図鑑を引く）のたびにタイトルから辿り直す手間（UD:3-2 導線のルール。階層を浅く）。寄り道が気軽になれば、ノートと図鑑が大会と対局への入口として働く（このゲームの柱）。
- 初めての人の最初の1分：ボタンの文字が、戻る先の名前（「大会へ戻る」「← ノート」「ノートへ戻る」「← 図鑑」）になる。押す前にどこへ戻るかが分かる（U:4 文言は具体的に）。ブラウザの戻る操作も同じ先へ戻る。
- 失敗したとき：選ばずに閉じても、来た画面へ戻るだけで何も変わらない（UD:5-2 取り消せる操作に確認はいらない）。
- 捨てるもの：画面の履歴を何段も積む仕組み（戻り先は、画面ごとに「どこから来たか」を1つだけ覚える。大会 → ノート → 図鑑 → ノート → 大会のように、つながった分だけ戻れる）。先へ進んだら（対局を始めた・大会へ進んだ・対局準備を開き直した）忘れる。
- 決めたこと：
  - 対局準備の「←」は、来た元があればその名前、なければ「タイトル」。対局準備はふだんタイトルから開くので、ほかの入口のときだけ変える。
  - 大会から開いたノートは「大会」の項目で開く（観戦記と寄せの記録がある）。図鑑・対局準備から戻ってきたときは、最後に見ていた項目のまま。
  - 大会の結果の画面へ戻るときは、結果をまだ「見た」にしていないので、結果の画面のまま戻る。
  - 「どの画面からも1回の操作でタイトルに戻れる」（UD:3-2）は、ノート・大会・図鑑の「タイトルへ戻る」を経て2回になる場面がある。来た場所へ戻るほうを優先した（ユーザーの依頼。寄り道の後の行き先として自然）。
- 確かめ方：ブラウザで上の表の流れを通し、ボタンの文字と戻った先を見る。ブラウザの戻る操作でも同じ先へ戻ることを見る。

## 3. 実装（2026-10-29、実装・自動テスト済み）

- 対局画面（`src/ShogiMatchGame.vue`）：
  - ノート：`noteFromTournament`（大会から開いた）・`noteInitialTab`・`openYakobiNote`・`openNoteFromTournament`・`closeYakobiNote`。ノートの部品は`initialTab`で開く項目を受け取る（`src/YakobiNote.vue`。覚えている項目は変えない）。
  - 対局準備：`pregameReturn`（`{ to: "note" }`か`{ to: "dex", fromNote }`）・`pregameBackLabel`・`leavePregame`（「←」と戻る操作）。`openPregame`で忘れ、ノート・図鑑から開いたときは開いたあとで入れ直す。作戦カードは`planSheetFromNote`で、選ばずに閉じたら`leavePregame`。
  - 図鑑：`dexFromNote`。閉じたら（定跡図鑑・駒や手筋の図鑑のどちらでも）ノートを開き直す。`dexBackLabel`は「ノートへ戻る」。
  - 棋力テスト：`skillTestFrom`（ノート・対局準備・4つの大会。前は`skillTestFromNote`。docs/first-play-design.mdの13章）・`returnToMeasureOrigin`・`closeSkillTest`・`closeSkillTestReport`。結果から竜王戦へ進む・1局指して確かめるときは忘れる。
- テスト：`src/core/match-ui-regression.test.mjs`の「ノート・図鑑から開いた画面は、閉じると来た場所へ戻る」と、観戦記の行の「大会の結果の画面から開いたノート」。
- 確かめたこと：`npm test`・型・ビルド・`git diff --check`。ブラウザ（この作業環境のChromium、390×844・820×1180・1366×768）で、大会の結果 →ノート（「大会へ戻る」・「大会」の項目で観戦記が見える）→ 大会の結果の画面（ボタンとブラウザの戻る操作の両方）、コレクションの作戦 →「この作戦にする」→ 対局準備の「← ノート」→ コレクション、作戦を選ばずに閉じる → ノート、対局準備でブラウザの戻る → ノート、手筋図鑑の「ノートへ戻る」→ 手筋のページ、棋力テストをやめる → ノート。
- 確かめていないこと：定跡図鑑の戦法占いから対局準備へ行き「← 図鑑」で戻る流れはブラウザで通していない（ソースの回帰テストだけ）。棋力テストの結果の「ノートへ戻る」も、テストを最後まで解いてはいない。実際に遊んでの確認は未確認。
