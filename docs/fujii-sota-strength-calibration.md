# 「藤井聡太並み」難易度の設定根拠

最終更新: 2026-08-31

## 結論

本作の「藤井聡太並み（推定）」は、次の設定とする。

| 項目 | 設定 |
|---|---:|
| UIプリセット値 | `480000` |
| 1手あたりの探索上限 | 480,000 nodes |
| MultiPV | 1 |
| 指し手選択 | 第1候補を常に選択 |
| 思考時間の安全上限 | 60秒 |

この値は藤井聡太棋士の棋力を厳密に再現するものではない。人間とエンジンを同じ条件で大量に対局させた公開データが存在しないため、公開されている棋士レーティング、将棋ソフトと人間レーティングの比較研究、探索量とElo差の知見を組み合わせた推定値である。

## 1. 藤井聡太棋士の位置付け

### 公式情報

日本将棋連盟の棋士データベースでは、藤井聡太棋士は九段で、竜王・名人を含む複数タイトルの保持・獲得実績を持つ。通算成績や年度成績から見ても、現役棋士の最高峰に位置すると判断できる。

- [日本将棋連盟: 藤井聡太 棋士データベース](https://www.shogi.or.jp/player/detail.php?player_id=00130242)
- [日本将棋連盟: 通算成績（棋士）](https://www.shogi.or.jp/game/?tab=all)

### 非公式棋士レーティング

日本将棋連盟は公式Eloレーティングを公表していない。そのため、棋譜結果から算出する民間サイトの値を参考値として使用した。

| 情報源 | 確認時の藤井棋士のレート | 2位との差 | 備考 |
|---|---:|---:|---|
| 棋士別成績一覧 | 2092 | 140 | 2026-05-13時点。平均的棋士を1500、K値16として計算 |
| shogidata.info | 2134 | 169 | 2026-08-08確認時の掲載値 |

- [棋士別成績一覧: レーティング計算方法](https://kishibetsu.com/rating.html)
- [棋士別成績一覧: 棋士ランキング](https://kishibetsu.com/ranking1.html)
- [shogidata.info: 棋士最新レーティング](https://shogidata.info/)

両サイトは計算方法や更新時点が異なるため数値は一致しないが、いずれも藤井棋士が1位で、2位に大きな差を付けている点は共通している。

## 2. 人間レートとエンジンレートを直接比較できない理由

Eloレーティングは、同じ対局集団内での相対的な強さを表す。次の数値はそれぞれ別の母集団で計算されるため、そのまま引き算できない。

- プロ棋士同士の公式戦から算出した棋士レート
- 将棋倶楽部24のオンライン対局レート
- 将棋エンジン同士の対局から算出したソフトレート

さらに、同じnodes数でも次の条件で棋力が変化する。

- エンジンと評価関数の世代
- スレッド数
- 定跡の有無
- ハッシュサイズ
- 持ち時間
- 局面の性質

やねうら王公式の検証でも、NodesLimitが同じでもスレッド数により最大R100程度の差が出た例が報告されている。

- [やねうら王公式: NodesLimit固定でThreadsを増やしても弱くならない件](https://yaneuraou.yaneu.com/2018/08/07/nodeslimit%E5%9B%BA%E5%AE%9A%E3%81%A7%E3%80%81threads%E3%82%92%E5%A2%97%E3%82%84%E3%81%97%E3%81%A6%E3%82%82%E5%BC%B1%E3%81%8F%E3%81%AA%E3%82%89%E3%81%AA%E3%81%84%E4%BB%B6/)

したがって、「棋士レート約2100だからエンジンもR2100にする」という設定は成立しない。

## 3. 48万nodesを採用した根拠

### 人間対局へ接続した公開実験

コンピュータ将棋協会誌 Vol.29には、ソフトレートと将棋倶楽部24レートを接続する近似式を作り、ノード制限した将棋ソフトを実際に将棋倶楽部24へ投入した検証が掲載されている。

その検証では、評価関数を変更して探索量を480,000 nodesへ増やした設定をソフトレートR2800相当とし、近似式上は将棋倶楽部24のR3381に対応すると推定している。ただし、R2800付近は近似式の適用範囲外に近く、実際のオンライン対局では対ソフト戦術の影響も受けている。したがってR3381は実測確定値ではなく、外挿を含む目安として扱う。

- [コンピュータ将棋協会誌 Vol.29](https://www2.computer-shogi.org/journal/CSA_vol29.pdf)

本作と論文ではエンジンや評価関数が異なるものの、「人間最高域を狙ったノード制限」の具体的な公開値として48万nodesを採用した。

### 探索量とElo差

第33回世界コンピュータ将棋選手権の技術資料では、ハードウェア・持ち時間差から棋力を推定する際に「探索量が2倍になるとR+80」という仮定が使われている。

- [第33回世界コンピュータ将棋選手権 アピール文書](https://www.apply.computer-shogi.org/wcsc33/appeal/appeal_final_detailed_230519.pdf)

この仮定を使うと、探索量変更による推定差は次式になる。

```text
推定レート差 = 80 × log2(変更後nodes / 変更前nodes)
```

現在のLv19「アマ四〜五段程度」24万nodesを基準にすると、48万nodesとの差は次のとおり。

```text
80 × log2(480000 / 240000)
= 80 × log2(2)
= +80 Elo
```

さらにLv19は2%の確率で安全な第2候補を選ぶ一方、Lv20は第1候補へ固定するため、
探索量と指し手選択の両方で「藤井聡太並み」をアマ四〜五段程度から分離する。

この「2倍で+80」も異なるエンジンの大会用推定であり、あらゆる局面やエンジンに共通する法則ではない。

## 4. 100万nodesから48万nodesへ変更した理由

最初は当時の「かなり強い」30万nodesの約3.3倍として100万nodesを暫定採用した。しかし、この値には藤井棋士または人間最高域と接続する直接的な根拠がなかった。

上記の式では、30万nodesから100万nodesへの増加は次の差になる。

```text
80 × log2(1000000 / 300000)
≒ +139 Elo
```

一方、48万nodesは人間対局へ接続した既存研究で実際に使われた値であり、100万nodesより根拠が具体的である。そのため、最高難易度を100万nodesから48万nodesへ修正した。

## 5. 指し手選択を第1候補固定にする理由

本作の低～中難易度はMultiPVから下位候補を選ぶことで意図的に弱くしている。最高難易度では次の設定にする。

- `multiPv: 1`
- `moveRank: { min: 1, max: 1 }`

これにより、探索結果の第2候補以下をランダムに選ぶ処理を排除する。「藤井聡太並み」という名称に対して、探索量を増やしてもランダムに悪い手を指す矛盾を避けるためである。

やねうら王がMultiPVとnodes制限に対応していることは公式資料で確認できる。

- [やねうら王 公式GitHub](https://github.com/yaneurao/YaneuraOu)
- [やねうら王Wiki: 思考エンジンオプション](https://github.com/yaneurao/YaneuraOu/wiki/%E6%80%9D%E8%80%83%E3%82%A8%E3%83%B3%E3%82%B8%E3%83%B3%E3%82%AA%E3%83%97%E3%82%B7%E3%83%A7%E3%83%B3)

## 6. この設定で再現できないもの

48万nodes・最善候補固定で再現するのは「人間最高峰に近い対局難易度」のみであり、藤井棋士本人の棋風を再現するものではない。

現在の実装では、次の要素は学習・再現していない。

- 藤井棋士の棋譜に基づく序盤選択傾向
- 長時間対局における時間配分
- 局面ごとの読みの深さの変動
- 人間特有の見落としや勝負術
- 対局相手に応じた作戦選択

名称には必ず「推定」を付け、厳密な棋力保証ではないことを示す。

## 7. 今後さらに精度を上げる方法

1. 本作と同一のWASMエンジン・同一評価関数で、Lv1〜20の実探索値による隣接レベル間の自動対局を行う。Lv0はランダム合法手のため別枠で測る。
2. 各設定で少なくとも数百局を実施し、95%信頼区間付きで相対Eloを算出する。
3. 藤井棋士の公開棋譜について、各局面でエンジン候補との一致率と平均評価値損失を測定する。
4. 同じ棋譜集合に対して各ノード設定の一致率・評価値損失を測り、藤井棋士の分布に最も近い設定を選ぶ。
5. エンジンまたは評価関数を更新した場合は、nodes値をそのまま引き継がず再測定する。

実際の棋譜との比較を行わない限り、48万nodesは公開資料から導いた暫定推定値である。
