# ノベルから使える設定（物語モードの参考）

ノベルのリポジトリ（`YacobiHime/novel`）の`docs/setting.md`・`docs/theme.md`・`docs/idea.md`・`docs/characters.md`・`design/characters.md`（2026-11-01に読んだ版）から、このゲームで使ってよい部分を写したメモです。

- **扱いの約束**（2026-11-01のユーザーの指定）：「novelリポジトリは、ミステリー作品なので、その部分以外は自由に参考にしていい。うまく将棋作品に取り込めるなら、なんでもOK」。
  - 使ってよい：人物（性格・好み・口調・経歴・人間関係）、舞台（燈ヶ丘高校など）、テーマ、将棋に関わる設定。
  - 使わない：ミステリーの部分（下の「使わない部分」）。
- このゲームですでに決めたこと（羽音がプロ棋士の新四段であること、善彦が竜王を含む多くのタイトルを持つこと、羽音は敬語と「！」を使わないこと、など）と食い違うときは、このゲームの決定を優先します。ノベルの設定は「使える材料」で、写す義務はありません。
- 羽音の性格と口調のくわしいところは`docs/hanane-character.md`、羽音のゲームでの立場は`docs/hanane-rival-design.md`、百花とやこび姫のメモは`docs/team-battle-design.md`の0章にあります。

## 1. 使わない部分（ミステリー）

- 黒姫真理の計画・「魔女」としての裏の顔・協力者・黒姫邸での指示の場面。
- 犯罪組織YATAと、善彦がYATAに入り込んでいること。真理と善彦の対立、ラスボスの正体。
- 事件・暗号・通信の傍受や電波妨害・公開鍵の報告などの情報戦。
- 続が真理の協力者として羽音に近づくこと（真理の指示・訓練・転校の理由）。

## 2. 舞台

- **燈ヶ丘（ともりがおか）高等学校**：羽音・百花（ノベルでは主人公の続も）が通う高校。羽音は、資料の多い空き教室を自分の居場所にしている。このゲームでは団体戦の自分たちの学校（`team-battle.mjs`の`SCHOOL_NAME`）。
- **瑞垣（みずがき）学院高等学校**：近くの別の高校（ノベルでは真理の学校）。団体戦の相手校などに使える。
- 時代は現代日本。

## 3. テーマ（物語モードの柱の候補）

- 問い：**自分より優れた人間が多くいる世界で、それでも自分は何を望むのか。**
  - 羽音の答え：自分より優れた者がいても、自分の強みを使い、自分が目指したい場所を目指していい。
  - 百花の答え：誰かより優れているからするのではない。好きだからすることにも価値がある。
- 将棋と「読み」：人物ごとに読み方が違う。将棋の遊び（CPUの棋風・解説）にそのまま使える。
  - 続：観察した情報から、粘り強く可能性を絞って読む。
  - 羽音：高い処理能力で、多数の可能性を高速に、機械的に読む（相手の打ちそうな手は予想しない）。
  - 真理：相手の性格や能力から打ちそうな手を予想し、確率の高い局面を深く読む。相手の読める深さを見積もり、その少し先で悪手になる局面へ誘導する（「7手先までしか読めないなら、11手先で悪手になる局面へ」）。
  - 善彦：相手の力量を正確に測り、その限界のわずか先に罠を置く。上の3人の強みをすべて単独で上回る。
- 描き方：人の成長と、関係の変化を丁寧に描く。

## 4. 人物

### 4-1. 戸鎖 続（とくさり つづき）— ノベルの主人公

- 8歳で天鷺名人（善彦）に憧れて将棋を始め、子ども王将戦で県優勝、中学の全国大会で3位。県内の中学生では絶対王者。
- 中学3年の8月に奨励会6級を受験し、一次試験を1勝3敗で不合格。「受かれば上京、落ちれば夢は諦める」と決めていて、プロをあきらめる。「将棋界には天鷺名人がいるから、俺がいなくても大丈夫です。」
- 悩み：どんなに努力しても上には上がいる。将棋を続けても意味がないのではないか。
- 羽音の道では、もう一度棋士を目指し、大学4年で奨励会三級への編入に挑んで不合格、アマチュアで指し続けて数年後にプロ編入試験に合格する（モデルは小山怜央四段）。百花の道では、将棋が好きだという原点に帰り、趣味として指し続ける。
- 性格：理性的で慎重、必ず先を読んでから動く。真面目でひたむき。集中するまで時間がかかり、瞑想や脳内将棋の習慣で集中を高める。成果がなくても考え続ける。やや内向的で、将棋は一人で取り組んできた。
- 棋風：丁寧な受け将棋で粘り、相手の隙を逃さず一気に攻める。中盤以降が非常に強い。居飛車の本格派で右四間飛車が得意。角換わり・相掛かり、雁木・中住まいで囲い、受けの強さを生かしてノーガードで攻めることもある（戸鎖流ノーガード戦法）。
- このゲームでの使い道（案）：プレイヤーの分身の物語の型（奨励会に落ちた・もう一度目指す）、または羽音の仲間の1人。続をそのまま出すかは、物語モードの設計で決める。

### 4-2. 天鷺 羽音（あまさぎ はのん）

- ノベル：燈ヶ丘高校2年。数学好きで空き教室に居着く。父は天鷺名人で、本気で将棋はしていないがかなり強い。重要な場面の決断・判断が非常に優れている。
- 百花との関係：百花は親友。百花の道では、百花に「羽音には分からないよね、私の気持ちなんて。」と言われてショックを受け、なかなか仲直りできない。そこから「人の気持ちなんて分からないままでいいと思ってた。でも、百花の気持ちは分かりたい。私の大切な友達だから。」と言うようになる。
- 性格・好み・口調・台詞の例は`docs/hanane-character.md`。

### 4-3. 桜乃 百花（さくらの ももか）

- 燈ヶ丘高校2年（2組）。羽音の親友。身長158cm（羽音は147cm。ユーザーの指定）。元気で声が大きい。よく笑い、すぐ怒ったりしょぼくれたり、目まぐるしい。見栄っ張りで、元気な割に自分に自信がない。明るいが能天気ではなく繊細。
- 他人の考えや気持ちを察する力が高く、悩んでいる人にすぐ気づく。共感性が高く、自分の意見を言うのを避けて他人に合わせやすい。自分の行動に葛藤や後悔を感じる、人間らしい子。心優しい。「人に求められる私でいたい。」
- 特技：人をよく観察していて、人間性から相手の考えを読む（将棋では「相手の気持ちを読む」解説・心の声に使える）。
- 趣味は読書。甘いものが好き、辛いもの・苦いものが苦手。将来の夢は幼稚園の先生。
- 口調：一人称「私」、相手は「○○くん」「○○ちゃん」（羽音は呼び捨て）。「！」をよく使い明るい。「ごめんね」が多く、自信がないと「～かなあ」「う～ん……」と濁す。気持ちを指摘するときは「それってさ……○○でしょ？」とやさしく確かめる。初対面ではきちんと「はじめまして、2組の桜乃百花です！」。
- 台詞の例：「私にできることなら何でも言ってね！」「好き嫌いはダメだよ！ちゃんと食べないと！」「う～ん……やっぱりそうなのかなあ…」「ごめんね遅くなって。」「大変だったんだね。」「たまには一緒に帰ろうよ。」「なんで私っていつもこうなんだろう…」
- このゲームでは、高校の団体戦の3人目で、やこび姫が宿っている（`docs/team-battle-design.md`の0章。この設定はこのゲームのもの）。

### 4-4. 天鷺 善彦（あまさぎ よしひこ）

- 羽音の父。将棋史上最強と言われる名人。羽音を何よりも大切にしている。続が8歳のころにはすでに名人。
- 性格：穏やかで礼儀正しく、誰にでも丁寧。声を荒げず、いつも余裕がある（演技ではなく本心）。
- 将棋：攻守に隙がなく、序盤から終盤まで最善を選び続ける完成された棋風。相手が最も準備してきた局面・得意な局面に進み、相手の最も良い将棋を引き出す。善彦と指す相手は必ず調子が良くなり、名局が多くて人気がある。相手が悪手を指すと悲しそうな顔をし、ひどいときは目のあたりを押さえて落胆する。先手勝率91%、後手勝率79%。持ち時間1分で43手先の詰みを読み切って勝ったことがある。
- 口調：一人称「私」、相手は「君」（目上・公の場では「あなた」）。穏やかな丁寧語。「ほう」「なるほど」「さて」「良いでしょう」「お待ちしていました」。台詞の例：「よく来ましたね。」「面白い作戦だ。ぜひ最後まで見せてほしい。」「羽音は元気にしていますか。」「さて――――始めましょうか。」「まさかここまでとは思いませんでしたよ。」
- このゲームの善彦の口調は、中継の解説（`docs/tournament-relay-design.md`の36〜43章。ユーザーが入力した台詞と、羽生善治・藤井聡太の話し言葉）に合わせてあります。物語の場面では、上の丁寧語の型も使えます。

### 4-5. 黒姫 真理（くろひめ しんり）

- 瑞垣学院高校2年。表は穏やかで上品な女子高生、素は冷たく鋭い。黒髪ロング、赤と黒の制服。口調は丁寧語で「フフ」「ごきげんよう」「ええ」。
- ノベルでは、ミステリーの中心の人物（1章）。その役どころは使わない。将棋の「読み」の型（3章）や、地道な脳トレと知識で天才に対抗する人物像は、ライバルの1人として使える候補。出すかどうかは物語モードの設計で決める。
