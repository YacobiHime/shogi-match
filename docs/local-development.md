# ローカル起動・定跡編集ガイド

この文書では、`shogi-match`をローカルで起動し、やこび姫の定跡を編集・確認する方法を説明します。

## 必要なもの

- Node.js 20以上
- npm
- Git

バージョンは次のコマンドで確認できます。

```sh
node --version
npm --version
git --version
```

## 初回準備

リポジトリを取得し、`shogi-match`へ移動して依存パッケージをインストールします。

```sh
git clone https://github.com/YacobiHime/shogi-match.git
cd shogi-match
npm install
```

すでにリポジトリと`node_modules`がある場合、通常は再インストール不要です。`package-lock.json`が更新された場合は、改めて`npm install`を実行してください。

## 定跡エディターを起動する

```sh
npm run opening-editor
```

開発サーバーが起動し、通常はブラウザで次の画面が自動的に開きます。

- 定跡エディター: <http://127.0.0.1:5173/opening-editor.html>
- 対局画面: <http://127.0.0.1:5173/game.html>

自動的に開かない場合は、上記URLをブラウザへ入力してください。終了するときは、起動したターミナルで `Ctrl+C` を押します。

## 既存の定跡を編集する

1. 「既存データ」から戦法または囲いを選びます。
2. 右側の「やこび姫の案内手」で手順を編集します。
3. 「次の案内手を入力」を押し、相手の応手を盤上で入力します。
4. 応手が分かれる局面では「この局面から分岐」を押します。
5. 出典、検証メモ、エンジン安全確認を入力します。
6. 自動検査を通過したら「JSONを書き出す」を押します。

案内手は「▲２六歩」のような日本語表記で表示されます。案内手または確認手順の手をクリックすると、その手を指す直前の局面と矢印を盤上で確認できます。

相手の応手は、完全一致する手だけで定跡を成立させる設定ではありません。その応手でも次の案内手が合法か、安全に続行できるかを確認するための実戦記録です。

## 完成後の派生戦法を設定する

戦法を選択すると、左側に「完成後に次の戦法を選ばせる」が表示されます。

1. チェックを有効にします。
2. 完成時に表示するやこび姫の案内文を入力します。
3. 「派生戦法を選択」から次に選ばせる戦法を追加します。
4. 不要な派生先は「削除」で外します。

現在の居飛車には、完成後の派生先として原始棒銀、早繰り銀、腰掛け銀が設定されています。

## 案内手に局面条件を設定する

各案内手の「条件 ＋」から、その手を表示するための盤上条件を追加できます。複数の条件はすべて満たす必要があります（AND条件）。

例えば「相手の8五に歩があり、相手の8二に飛車があるときだけ▲7八金を案内する」場合は、▲7八金の案内手へ次の2条件を追加します。

- 相手の・8五・歩・がいる
- 相手の・8二・飛・がいる

先手基準で設定した条件は、後手で補助するときに盤面と所有者が自動的に反転されます。条件は案内手の候補を出すための制限であり、条件を満たさない場合、その手は矢印に表示されません。

## 保存とJSON書き出し

- 「下書き保存」はブラウザの`localStorage`へ保存します。
- 下書きは同じブラウザ・同じローカルURLでのみ利用できます。
- 下書きは公開対局画面やFirebase Hostingへ自動反映されません。
- 「JSONを書き出す」は編集内容をローカルファイルとしてダウンロードします。
- 「JSONを読み込む」で、以前書き出したファイルを再編集できます。

内蔵定跡として公開版へ反映する場合は、書き出した内容を確認したうえで`src/core/opening-guide.mjs`と対応テストへ反映し、検証記録も更新します。

## 動作確認

変更後は次を実行します。

```sh
npm test
npm run build
git diff --check
```

- `npm test`: 自動テストを実行します。
- `npm run build`: 配布用ファイルを生成できるか確認します。
- `git diff --check`: 不要な空白やパッチ形式の問題を確認します。

`dist/`と`firebase-public/`は生成物です。直接編集しないでください。

## よくある問題

### ポート5173が使用中と表示される

別の開発サーバーが動いている可能性があります。以前起動したターミナルで`Ctrl+C`を押して終了してから、もう一度起動してください。Viteが別のポートを表示した場合は、ターミナルに表示されたURLを使用します。

### 案内手の矢印が表示されない

後続の案内手は、その手を指す直前まで確認手順が入力されている必要があります。相手の応手を入力し、対象の案内手が合法になる局面まで進めてください。

### JSONを書き出せない

右下の「自動検査」に表示された赤い項目を修正してください。少なくとも合法な実戦分岐とHTTPSの出典が必要です。
