# はじめての分岐と、大会へ向かう「つぎはこれ」（設計 2026-10-22）

依頼（2026-10-22）:

> 初めてプレイする際、
> - 駒の動かし方（ルール）から分からない → 将棋教室を最初から
> - ルールは分かるけど定跡が分からない → 将棋教室の途中の適切な場所から
> - ルールと定跡が少し分かる → 棋力測定でレーティングを設定 → 対局の指し手などをもとに、次に何をするべきかおすすめする（大会に出るべき、将棋教室のn章で何を学ぶべき、詰将棋のn手詰をやるべき、など）
> - ルールも定跡も十分に分かる → 棋力測定をして、自分にあった難易度で大会に挑もう！
>
> という感じで分岐するようにしたい。
>
> このゲームのメインコンテンツは大会と物語モード（後で実装）で、それを楽しむために詰将棋や教室や図鑑などの強くなるための機能がある。

同じ依頼の「CPUの段級位の作り直し」は`docs/level-ladder-design.md`に分けて書く。この文書のLvとレーティングは、作り直したあとの表（15級＝Lv1＝R30、1級＝Lv15＝R870、以降1LvあたりR60）で書く。

読んだ指針:
- `Game_Nintendo_Design.md`: 3-3 すぐに遊ばせる、4-1 初心者にはやさしく、4-2 難易度選択をリスクとリターンに、4-3 安全網、4-10 思っているより難易度を下げる、5-2 目の前に吊られたごほうび、5-8 情報としての称賛と自律性、6-1 上達そのものが楽しさ、6-2 自然なチュートリアル、6-3 強制感と攻略の自由、12 判断に迷ったとき
- `UI_Nintendo_Design.md`: 2 判断の優先順位、3-2 導線（盤まで2回）、6-1 必要な瞬間に1つだけ、4-3 結果画面

関連: `docs/home-roadmap-design.md`（強くなる道の5つの段）、`docs/home-next-adaptive-design.md`（「つぎはこれ」の見立て）、`docs/skill-measure-design.md`（棋力測定）、`docs/nyumon-mode-design.md`の17章（教室の「どのくらい知ってる？」）

## 0. このゲームの柱（メモ）

- **主役は大会と物語モード。** 大会は竜王戦と名人戦（実装済み）。物語モードは後で作る。
- **教室・問題集（詰将棋）・図鑑・終盤戦・自由対局は、主役を楽しむために強くなる道具。**
- 設計で迷ったら、「この機能は、大会（と物語）をもっと楽しむことにつながるか」を問う。
  - 「つぎはこれ」の練習は、最後は大会へ戻る道として勧める（「竜王戦の6組で勝つために、3手詰めを」）。
  - 強くなる道の終わりは「級・段を上げる」ではなく「大会で勝ち上がる」。
- `AGENTS.md`の「このゲームの柱」にも同じことを書く。

## 2. 機能設計メモ（Game_Nintendo_Design.mdの14章の形）

### 機能名：はじめての分岐と、大会へ向かう「つぎはこれ」

- 一言で：やこび姫が最初に「どのくらい知ってる？」を聞き、4つの入口から、その人がいちばん早く大会を楽しめる道へ案内する。
- 解く課題：
  - ルールは分かるのに、いきなり対局へ放り出される（定跡を学ぶ場所へ行けない）。
  - 指せる人が、教室の最初から歩かされる／いきなり強すぎる・弱すぎる大会に出る。
  - 「つぎはこれ」の練習が、教室の章や詰将棋の手数を具体的に指さない。
  - 主役の大会へ、いつ出ればいいか分からない。
- リスクとリターン：分岐は自己申告だけで決めず、1問か1局で確かめる（間違えても、ちょうどいい場所に置き直すだけで失うものはない）。
- 溜めと解放：棋力測定（溜め）→「あなたは5級くらい。竜王戦は難易度4がちょうどいいよ」（解放）→ すぐ大会。
- 初めての人の最初の1分：4つの札から1つ押すと、教室のレッスンか、測定の対局がすぐ始まる（盤まで2回。U:3-2）。
- 上級者の深さ：「十分に分かる」は、測定の1〜3局のあと、難易度を合わせた竜王戦の入口が開く。
- 失敗したとき：教室の1問を解けなくても「ここから一緒にやろう」で1つ前の章から始めるだけ。測定で測りきれなければ、今までどおり相手を近づけてもう1局。
- ご褒美と使い道：測定の結果が、そのまま大会の難易度と、つぎはこれの練習の行き先になる。
- ほめる瞬間：1問解けたら「1手詰め、解けたね！ 戦法と囲いから始めよう」。測定のあと「5級くらい！ 竜王戦で腕だめししよう」。
- 捨てるもの：
  - 長い質問票（知識を何問も聞く）。答えるのは1回の札と、多くて1問。
  - 自己申告だけで教室を大きく飛ばすこと。
  - 分岐で入口に鍵をかけること（どの入口もいつでも押せる）。
- 確かめ方：将棋を知らない人・駒の動きだけ分かる人・ウォーズで数局指した人・有段者の4人に、説明なしで最初の5分を遊んでもらい、たどり着いた場所が合っているかを見る（D:10-2）。

## 3. はじめての案内（4つの札）

案内の問いは今のまま「将棋はどのくらい知ってる？」。札を4つにし、易しい順に1本の階段として並べる（メニューではなく1つの物差しなので、3つ程度という目安（U:2-1）を1つ越えてもよいとする）。

| 札（id） | 見出し | 添える1行 | 押すと |
|---|---|---|---|
| `beginner` | はじめて | 駒の動かし方から、教室でいっしょに覚えよう | 教室の第1巻1章（今のまま） |
| `rules` | ルールは分かる | 戦法や囲いはまだ。教室の、ちょうどいいところから | 教室の「はじめる場所を決める1問」（4章） |
| `some` | 少し指せる | 戦法も少し分かる。1局指して、棋力を測ろう | 棋力測定（5章）→ ホーム（「つぎはこれ」が練習と大会を勧める。6章） |
| `player` | よく指している | 定跡も分かる。棋力を測って、大会に挑もう | 棋力測定（5章）→ 竜王戦の入口（難易度を合わせて。5-2） |

- いちばん下の「自分で選ぶ」は今のまま（案内を閉じてホームへ）。
- 前の版の答え（`welcome:v1`の`choice`）は読み替える: `rules`→`rules`、`player`→`player`（今の「ふだん指している」は「よく指している」と同じ扱い）。`some`は新しい答え。
- 強くなる道（`home-roadmap.mjs`）の、答えごとの始まり:

| 答え | 終えたことにする段 |
|---|---|
| はじめて | なし |
| ルールは分かる | 1（駒を覚える） |
| 少し指せる | 1・2（測定の1局で、初めての対局も終える） |
| よく指している | 1・2・3（詰みを覚える） |

## 4. 「ルールは分かる」：はじめる場所を決める1問

教室の`TUTORIAL_PLACEMENTS`の札は、自分で選ぶと「1手詰めなら解ける」を選びがちで、本当は解けないと第3巻でつまずく。札を聞く代わりに、盤で1問だけ解いてもらう（6-2 自然なチュートリアル。テキストより盤）。

- 問題: 1手詰め（教室の第2巻3章「1手詰め：頭金」と同じ易しさの問題を1つ。正解は探索で判定する今の仕組みを使う）。
- 解けた（1回目で）: 「1手詰め、解けたね！ 戦法と囲いから始めよう」→ 第3巻1章「居飛車と振り飛車」（今の札の`mate`）。
- 解けなかった: 正解を盤で見せて「ここから一緒にやろう」→ 第2巻1章「利きを見よう」（今の札の`rules`）。2回目は出さない（責めない。D:7-2）。
- どちらでも、始めるレッスンより前は「とばした」にする（今の`applyPlacement`。★・メダル・巻の称号は、腕だめしをクリアしないと付かないのも今のまま）。
- 押さずに地図から選ぶこともできる（「自分で選ぶ」を小さく。D:6-3 自由）。
- 教室を案内なしで初めて開いた人には、今までどおり4枚の札を出す。

## 5. 「少し指せる」「よく指している」：棋力測定から

### 5-1. 測定の最初の相手

案内の答えを、最初の相手の目安に使う（測れる手が足りない対局を減らす。`docs/skill-measure-design.md`の1章: 力の差が大きいと早く大差がつき、測れない）。

| 答え | 最初の相手 |
|---|---|
| 少し指せる | 続けて「どのくらい指せる？」の札で選ぶ（2026-10-25。`docs/skill-measure-design.md`の9章） |
| よく指している | 同じ |
| 案内なしでやこびノートから測る | 今までどおり、レーティングに近いLv |

- 足りなければ、今までどおり相手を近づけてもう1局（3局まで）。近づける幅は、作り直した表で同じ強さの差になるLvの数にする（`docs/level-ladder-design.md`の6章）。

### 5-2. 測ったあと

| 答え | 結果の画面の主ボタン | 小さなボタン |
|---|---|---|
| 少し指せる | 「ホームへ」（ホームの「つぎはこれ」が6章のとおり勧める） | 「竜王戦に出る」 |
| よく指している | 「竜王戦に出る」 | 「ホームへ」 |
| 案内なし | 今のまま | — |

- 「竜王戦に出る」は、竜王戦の入口（エントリー設定）を、測ったLvに合う難易度（`ryuo-strength.mjs`の`recommendedDifficulty`）にして開く。1行で「あなたは5級くらい。難易度4なら、6組の相手とちょうどいい勝負だよ」。設定はそこで変えられる（D:5-8 自律性）。
- 測りきれなかったとき（3局でも足りない）も、竜王戦へは進める。難易度は、そのときのレーティングから決める。

## 6. 「つぎはこれ」を、教室の章・詰将棋の手数・大会へつなぐ

今の「つぎはこれ」の見立て（`play-coach.mjs`の`recommendPlay`、`docs/home-next-adaptive-design.md`）はそのままにし、練習の行き先と、大会への誘いを足す。

### 6-1. 練習の行き先（弱点ごと）

対局の中身から見る弱点（今の4つと、逃した詰みの手数）に、行き先を「教室の章 → 問題集 → 今の練習」の順で当てる。教室の章は、まだ腕だめしをクリアしていないときだけ勧める（クリア済みなら次の行き先）。

| 弱点（判定は今のまま） | 1番目: 教室の章（未クリアなら） | 2番目: 問題集 | 3番目: 今の練習 |
|---|---|---|---|
| 詰みを逃した（1手詰め） | 第2巻3章「玉をつかまえよう」 | 詰将棋の1手詰め | 逃した局面の問題（今の復習） |
| 詰みを逃した（3手詰め） | 第2巻3章の「3手詰めに挑戦」から | 詰将棋の3手詰め | 同上 |
| 詰みを逃した（5手以上） | — | 詰将棋の5手詰め（7手は5手詰めを10問解いてから） | 同上 |
| タダで取られた | 第2巻1章「三手先まで考えよう」 | 練習問題 | 「駒の利き」の学習対局 |
| 序盤で不利 | 第3巻1章「戦法と囲いを知ろう」→ 第4巻（自分の戦法が居飛車なら2章、振り飛車なら1章） | — | 作戦カードの学習対局 |
| 終盤で崩れた | 第3巻3章「攻めと守りのコツ」→ 第5巻「序盤・中盤・終盤の作戦」 | 実戦詰将棋 | 終盤戦 |

- カードの見出しは行き先（「教室 第2巻3章：玉をつかまえよう」「3手詰めを5問」）、1行は理由と大会へのつながり（「前の2局で、3手で詰む局面を見逃したよ。詰みが見えると、竜王戦の終盤で勝ちきれる」）。数字は手数・局数だけで、評価値は出さない（今の決まり）。
- 押すと、教室ならその章の最初の未クリアのレッスン、問題集なら、その手数のまだ解いていない問題から始める。問題集は5問で一区切り（「5問解いたら戻ろう」）にし、区切りで「つぎはこれ」へ戻る。
- 今の決まりはそのまま: 練習は対局2局に1回まで、同じ種類を続けない、鍵はかけない。

### 6-2. 大会への誘い

大会は主役なので、強くなる道の4段目を待たずに勧める。

| 名前 | 出す条件 | カード |
|---|---|---|
| 竜王戦に出よう | 竜王戦に出たことがない、かつ（測定を終えた か レーティングの対局が3局以上）、かつ直前の2局で練習を勧めていない | 「竜王戦に出よう」／「あなたは8級くらい。難易度3の6組なら、勝ち上がれるよ」→ 竜王戦の入口（難易度を合わせて） |
| 名人戦にも出よう | 竜王戦の期を1つ終え、名人戦に出たことがない | 「名人戦に出よう」／「順位戦のC級2組から、名人をめざそう」→ 名人戦の入口 |
| 大会の次の期 | （今の「竜王戦の次の期」と同じ） | （今のまま） |

- 期の途中の「続きを指す」「○○対策」は今のまま、いちばん先に出す。
- 練習の1行には、期の途中なら次の相手を添える（「次の杉山さんは振り飛車党。対振り飛車の練習を」）。

### 6-3. 強くなる道の最後の段

5段目を「級・段を上げる」から「大会で勝ち上がる」に替える（名前と読み上げの文だけ。判定は今のまま「終わりなし」）。「つぎはこれ」は6-2と竜王戦のつづきが中心になる。
