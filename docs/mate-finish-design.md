# 寄せの記録・観戦記・自分の対局の中継

2026-10-29、ユーザーの依頼「大会で勝ったときに、何手詰めを寄せ切って勝ったかを記録したり演出したりするようにしたい。大会だったら観戦記に書いたりしたい。また、自分の対局についても後で中継を見て振り返れるようにしたい。」

## 1. 機能設計メモ（Game_Nintendo_Design.mdの「機能設計メモのテンプレート」の形）

### 機能名：寄せ切りの記録と、自分の対局の中継

- **何を作るか**
  1. **寄せの記録**：大会（竜王戦・名人戦・奨励会・研修会）の対局で、プレイヤーが詰ませて勝ったら、最後の寄せが「何手詰め」だったかを出す。終局の判子の下に「7手詰めで寄せ切り！」と出し、結果の窓にも書く。いちばん長い寄せは「自己最長」として残し、やこびノートの「大会」に見せる。
  2. **観戦記**：タイトル戦（二日制）の観戦記に、寄せの一文（「最後は89手目▲3二銀からの7手詰めで寄せ切った」）を足す。ふつうの大会の対局にも短い観戦記（見出しと3段落）を書き、同じ一文を入れる。
  3. **自分の対局の中継**：大会の自分の対局の棋譜（手と考えた時間）を残す。あとで、ほかの棋士の対局と同じ中継の画面で、解説・コメント・勝率バーつきで振り返れる。入口は、終局の結果の窓の「中継で振り返る」と、大会の中継の一覧の「あなたの対局」。
- **誰のためか**：大会を勝ち上がる人。勝った一局を味わい直し、どこで寄せ切ったかを誇れるようにする（このゲームの柱「大会をもっと楽しむ」）。
- **決めたこと**
  1. **「N手詰め」の数え方**（`src/core/mate-finish.mjs`の`finishingMate`）：詰将棋と同じく、詰ませた側の**最後の王手の連続**を、両者の手を合わせて数える（王手→応手→王手…→詰み）。最後の手が詰みでなければ数えない（投了・千日手など）。王手でない静かな手（詰めろ）で寄せたあと1手で詰ませたなら「1手詰め」。相手がもっと粘れたかは問わない（その局で実際に指された寄せを数える）。
     - 理由：盤の上の手順だけで決まり、終局の瞬間にすぐ出せる（D:3-3 遅さは罪）。エンジンの読みに頼ると、解析が終わるまで演出できない。
     - ユーザーの大会の対局では、CPUは投了しない（詰むまで指す）ので、勝ちはほぼ詰みで決まる。
  2. **演出の重さ**（G:3-1）：詰ませる勝ちは段階6。寄せの手数で判子の大きさを1段上げる（9手以上で1段、15手以上で紙吹雪）。長い寄せほど「どれぐらい良いことをしたか」が伝わる（D:4-8）。自己最長を更新したら「自己最長！」を添える（D:5-4 ほめてやれ）。前の記録がないときは「自己最長」と言わない（1局目は比べるものがない）。
  3. **記録**（`mate-finish:v1`）：寄せ切った局の数、いちばん長い寄せ（手数・大会・回戦・相手・日付）、最近の10局。数える範囲は大会の対局だけ（自由対局・教室は数えない。G:6-1の5）。
  4. **観戦記**：ふつうの対局の観戦記は`src/core/game-kansenki.mjs`の`writeGameKansenki`。見出し（勝った寄せの手数か、手数）・戦型・形勢の分かれ目（その局でやこび姫の読みがあったときだけ）・終局と寄せ。保存は観戦記と同じ`kansenki:v1`。大会の対局がふえるので、残す数を30局から60局にする。
  5. **自分の対局の中継**：
     - 終局したら、手・考えた時間（両者。秒）・終わり方・寄せの手数を`my-games:v1`に残す（新しい30局）。
     - 中継の画面は、棋譜を作る代わりに、残した手を1手ずつ軽いエンジンで読み、勝率・読み筋・最善手との差・悪手の印を付ける（`relay-game.mjs`の`replayKifuGame`）。読み終えた分は中継の棋譜と同じく保存し、2回目からはすぐ出す。
     - 解説と聞き手は、プレイヤーを「あなた」として紹介し、分身の対局と同じく、きつい笑いのコメントを出さない（責めない。G:7）。
     - 終局の解説も、ふつうの中継と同じく「N手詰め」で寄せ切ったと言う（すべての中継で共通）。
- **変えないもの**：対局の勝ち負け・記録・レーティングの数え方。ほかの棋士どうしの中継の作り方。
- **原則**：D:3-3（すぐ反応する）、G:3-1（出来事の重さ）、D:4-8（どれぐらい良いことをした？）、D:5-4（ほめてやれ）、G:6-1（ご褒美と記録の手順）、G:7（負けを責めない）。

## 2. 実装（2026-10-29、実装・自動テスト済み）

- **寄せの記録**：`src/core/mate-finish.mjs`（`mateStreak`・`finishingMate`・`mateTier`・`mateFinishText`・`mateKansenkiSentence`・`loadMateRecords`・`addMateRecord`・`saveMateRecords`。保存は`mate-finish:v1`）。テストは`mate-finish.test.mjs`（▲5二飛 △6一玉 ▲7二金の3手詰め、静かな手のあとの1手詰め、詰みでない棋譜、重さ・言葉、記録の自己最長と上限）。
- **演出**：終局の判子の大きさは`match-presence.mjs`の`finishStamp`の`mateTier`（9手以上で1段、15手以上で紙吹雪も）。対局画面（`src/ShogiMatchGame.vue`）は、詰ませて勝ったら`noteMateFinish`で数えて記録し、判子の下（`data-finish-mate`。自己最長なら「自己最長！」）と結果の窓（`data-result-mate`）に出す。
- **観戦記**：タイトル戦の観戦記（`title-day.mjs`の`writeKansenki`）は`mate`を受け取り、見出し（3手以上の寄せなら「○○、7手詰めで寄せ切る」）と最後の段落に寄せの一文を足す。ふつうの対局は`src/core/game-kansenki.mjs`の`writeGameKansenki`（形勢の分かれ目は、やこび姫の読みで残した勝率`gameRates`から）。対局画面の`writeTournamentKansenki`が大会のすべての対局で書く。残す数は60局。
- **自分の対局の中継**：
  - 保存：`src/core/my-games.mjs`（`myGameRecord`・`loadMyGames`・`saveMyGame`・`myRelaySpec`・`myRelayKey`。`my-games:v1`、新しい30局）。対局画面は、手ごとの考えた時間（`moveSeconds`）を数え、終局で`saveOwnGame`が残す。
  - 中継：`relay-game.mjs`の`replayKifuGame`が、残した手を1手ずつ読み、評価値・損・最善手・読み筋・印（序盤の小さな損は定跡、300点以上は疑問手、800点以上は決め手の悪手）を付ける。`useRelayGenerator.ts`は、項目に`kifu`があればこちらを使う。読んだ棋譜は中継の棋譜と同じく保存する。
  - 解説：`relay-commentary.mjs`は、プレイヤー本人（`kind: 'user'`）の局を「あなたの対局をふり返るよ」と紹介し、次の相手の台詞を出さず、分身と同じくきつい笑いを出さない（`isYou`）。詰みで終わった局は、すべての中継で「最後はN手詰め」と言い、終局の札にも書く。
  - 入口：結果の窓の「中継で振り返る」（`data-my-relay`。大会の画面の`relayKey`で開く）と、中継の一覧の「あなたの対局」（`relay-games.mjs`の`RELAY_SECTIONS.mine`。どの大会の対局も新しい順。行に「あなたの勝ち・7手詰め」）。中継の画面の上に「あなたの対局」の札。
- **ノート**：やこびノートの「大会」に「寄せの記録」（局数・いちばん長い寄せ・最近の5局）。観戦記の案内文を「大会の対局を指すと」に直した。
- **確かめたこと**：`npm test`（2030件）・型・ビルド・`git diff --check`。ブラウザ（この作業環境のChromium、390×844・820×1180・1366×768・844×390）で、保存した自分の対局が中継の一覧の「あなたの対局」に「あなたの勝ち・7手詰め」と出ること、開くと「あなたの対局」の札と「あなたの対局をふり返るよ」の解説で始まり、残した考えた時間で再生されること、ノートの「寄せの記録」を確かめた。横のはみ出しなし。
- **確かめていないこと**：実際に大会で詰ませて勝ったときの判子・結果の窓の「N手詰め」・「中継で振り返る」・観戦記（ソースの回帰テストと処理のテストだけ）。実際に遊んでの確認は未確認。

## 3. 大会の対局のあとには必ず観戦記（2026-10-29、実装・自動テスト済み）

ユーザーの依頼「竜王になった後に観戦記が無い。大会の対局後には絶対に付けましょう。」

- **原因**：観戦記を書く`writeTournamentKansenki`は、対局の舞台の札（`matchStage`）がないと何も書かずに戻っていた。札がないのは、前の版で始めた局や、期の情報から札を作れなかった局。また、2章より前の版は、二日制のタイトル戦の記録（`titleDay`）がないと書かなかった（竜王を獲った七番勝負の局もこれに当たる）。
- **直したこと**：
  - 舞台の札がなくても、大会の名前（竜王戦・名人戦・奨励会・研修会）と回戦の名前（`ryuoGame.label`）で、ふつうの対局の観戦記（`writeGameKansenki`）を書く。勝ち負け・決まったこと（竜王獲得・防衛、名人獲得・防衛）・寄せの手数は、札がなくても入る。
  - 二日制の札があっても1日目の記録がなければ、ふつうの対局の観戦記にする（前と同じ）。
  - 千日手の指し直し（勝ち負けがない）だけは書かない。指し直した局で書く。
- **ノートへの道**：大会の結果の画面の「ノートを見る」は、ノートを「大会」の項目で開き、観戦記がすぐ見える。「大会へ戻る」で結果の画面へ戻る（`docs/return-path-design.md`）。
- **確かめたこと**：ソースの回帰テスト（`match-ui-regression.test.mjs`。舞台の札がないときに戻らず大会の名前で書く）。ブラウザで、大会の結果の画面からノートを開くと「大会」の項目で観戦記が見えること。
- **確かめていないこと**：実際に竜王を獲った局のあとに観戦記が残ること（その局まで指していない）。実際に遊んでの確認は未確認。前の版で指した局の観戦記は、あとから書き足さない（その局の棋譜と形勢の記録が残っていないため）。
