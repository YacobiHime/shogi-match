# 駒の損得の表示（設計 2026-10-22、実装・自動テスト済み）

対局中・振り返り中に、いまの駒の損得を見られるようにする。いままでは、学習対局（教室の対局を含む）で駒を取ったマスにAI用の値（「＋540」「−495」など）を浮かべる。取得表示は持ち駒になる元の駒の値で数える（と金なら90）だけで、通常対局・竜王戦・振り返りでは、駒の損得を見る方法がなかった。

### 機能名：駒の損得

- 一言で：押すと、いまどれだけ駒得（駒損）しているかが数字で分かる。
- 解く課題：駒をいくつ取った・取られたかを、頭の中で数えないと分からない／振り返りで、どこで駒損したか分かりにくい。
- リスクとリターン：なし（補助の表示）。
- 溜めと解放：駒を取ると、取ったマスに「＋540」などが浮かび、状態表示の札を局面全体の損得に更新する。
- 初めての人の最初の1分：操作列の「駒の損得」を押すと、状態表示に「駒の損得 ±0」が出る。
- 上級者の深さ：振り返りで手を戻すと、その局面の損得に変わる（どこで駒損したかを追える）。
- 失敗したとき：なし。
- ご褒美と使い道：なし。
- ほめる瞬間：なし（駒得の数字の色だけ）。
- 捨てるもの：形勢の評価値（駒の損得は駒の値段だけで、玉の安全や駒の働きは数えない。評価値は棋譜解析で見る）。
- 確かめ方：ブラウザで、付け外しと、駒を取ったときの札の変わり方を見る。

## 決めたこと

- 操作列（閃き・待った・駒の利きの並び）に「駒の損得」の切り替えボタンを足す。押すまでは出さない（U:4-1「補助表示は消せるように」、駒の利きと同じ）。付け外しは端末に覚える（`localStorage`の`yacobihime:shogi-match:material-guide:v1`）。
- 付けているとき：
  - 状態表示（「あなたの番です」の帯）に、自分から見た駒の損得の札を出す。「駒得 ＋315」（緑）・「駒損 −180」（赤）・「駒の損得 ±0」（灰）。色だけでなく文字でも分かる。
  - 点数は、盤の上と持ち駒の駒の値段の合計を自分と相手で比べたもの（`piece-points.mjs`の`aiMaterialTotals`と`AI_PIECE_POINTS`。駒図鑑のAI用の表と共通で、歩90・香315・桂405・銀495・金540・角855・飛990、と金・成香・成桂・成銀540・馬945・竜1395。玉は数えない）。教室の入門用の点数は従来のまま残す。
  - 二人で指すときは、先手から見る（「先手 駒得 ＋315」）。
  - 振り返りでは、見ている局面の損得を出す。
  - 学習対局と同じく、駒を取ったマスにAI用の値（「＋540」「−495」など）を浮かべる。取得表示は持ち駒になる元の駒の値で数える（と金なら90）（通常対局・竜王戦でも）。
- 色は、駒得の数字（`BoardView.vue`の`.float-label`）・教室の札（`--material-good`・`--material-bad`）とそろえる（AGENTS.mdの「盤面の色の使い分け」）。
- 根拠：U:4-1（補助表示は本人が選ぶ）、U:7-3（色だけでなく文字でも区別）、G:3-1（結果を数字で見せる手応え）。

## 成りの分（2026-10-27、実装・自動テスト済み）

角と馬を交換すると、馬を取られた側は少し駒損になる（持ち駒になるのはどちらも角なので、成った分の90が消える）。いままでは、状態表示の札（盤と持ち駒の合計の差）には入っていたが、取ったマスの数字は元の駒の値段だけで±0に見え、成ったときにも何も出なかった。また、札は取り合いを2倍に数えていた（歩を1枚取ると数字は＋90、札は＋180）。

### 機能名：駒の損得（成りの分）

- 一言で：成った・成駒を取った/取られたときに「成り＋90」「成り−90」が出て、札の数字と浮かべた数字の合計がそろう。
- 解く課題：角馬交換やと金の交換で、どれだけ損をしたかが見えない／浮かべた数字を足しても札にならない。
- リスクとリターン：なし（補助の表示）。
- 溜めと解放：成った瞬間に「成り＋90」、成駒を取られると「−855」と、その下に小さく「成り−90」。
- 初めての人の最初の1分：駒の損得を付けて角を成ると、札が＋90増え、盤にも「成り＋90」が出る。
- 上級者の深さ：と金を取られると「−90　成り−450」。相手が手に入れるのは歩だけ（と金の遅早）、でもこちらは金と同じ働きの駒を失った、が2つの数字で分かる。
- 失敗したとき：なし。
- ご褒美と使い道：なし。
- ほめる瞬間：なし（数字の色だけ）。
- 捨てるもの：1つの数字にまとめること（まとめると、相手が得た分か自分が失った分のどちらかがうそになる）。
- 確かめ方：ブラウザで、角が成る→馬を取られる手順の数字と札を見る。

### 決めたこと

- 取ったマスの数字は、いままでどおり持ち駒になる元の駒の値段。成りの分（`piece-points.mjs`の`promotionBonus`。成った駒の値段−元の駒の値段）は、`materialPops`が別の小さな数字（`sub`）にし、取った駒の数字があるときは同じマスの下寄りにずらす（`offset`。`BoardView.vue`の`.float-label--sub`）。成るだけの手は「成り＋90」だけを出す。駒を取りながら成った手は「＋855」と「成り＋405」。
- 札の点数（`materialBalance`）は、浮かべた数字を足したものと同じにする: 盤と持ち駒を元の駒の値段で数えた差の半分（取り合いで2倍動くため）＋盤の上の成りの分の差。駒落ちの開始局面の差は、駒がまるごとない差なので半分にせずに足す。歩を1枚取ると＋90（前は＋180）、角が成ると＋90、角馬交換は馬の側が−90。
- 形勢の一言の方針（`coach-advice.mjs`の`POLICY_MATERIAL_MARGIN`「歩3枚とすこし」300）と、封じ手の札の駒の損得も、札と同じ数え方にした（前は2倍の数え方だったので、「歩3枚とすこし」が実際には歩2枚弱で出ていた）。
- 将棋教室の数字・合計（`materialSwing`）も、教室の点数で成りの分を数える（角8→馬10で「成り＋2」、と金7で「成り＋6」）。教室の「駒の点数 ▲・△」（盤と持ち駒の点数の合計を見せる台詞）はそのまま。
- 根拠：G:3-1（結果を数字で見せる手応え。成るのも駒を取るのと同じ段階2の出来事なので、同じ見せ方にする）、U:7-3（色だけでなく「成り」の文字と符号でも分かる）、G:6-2（数字を身近な尺度に。札と浮かべた数字の単位をそろえる）。
