# 駒の損得の表示（設計 2026-10-22、実装・自動テスト済み）

対局中・振り返り中に、いまの駒の損得を見られるようにする。いままでは、学習対局（教室の対局を含む）で駒を取ったマスに「＋6」「−5」を浮かべるだけで、通常対局・竜王戦・振り返りでは、駒の損得を見る方法がなかった。

### 機能名：駒の損得

- 一言で：押すと、いまどれだけ駒得（駒損）しているかが数字で分かる。
- 解く課題：駒をいくつ取った・取られたかを、頭の中で数えないと分からない／振り返りで、どこで駒損したか分かりにくい。
- リスクとリターン：なし（補助の表示）。
- 溜めと解放：駒を取ると、取ったマスに「＋6」が浮かび、状態表示の札が「駒得 ＋6」に変わる。
- 初めての人の最初の1分：操作列の「駒の損得」を押すと、状態表示に「駒の損得 ±0」が出る。
- 上級者の深さ：振り返りで手を戻すと、その局面の損得に変わる（どこで駒損したかを追える）。
- 失敗したとき：なし。
- ご褒美と使い道：なし。
- ほめる瞬間：なし（駒得の数字の色だけ）。
- 捨てるもの：形勢の評価値（駒の損得は駒の値段だけで、玉の安全や駒の働きは数えない。評価値は棋譜解析で見る）。
- 確かめ方：ブラウザで、付け外しと、駒を取ったときの札の変わり方を見る。

## 決めたこと

- 操作列（閃き・待った・駒の利きの並び）に「駒の損得」の切り替えボタンを足す。押すまでは出さない（U:4-1「補助表示は消せるように」、駒の利きと同じ）。付け外しは端末に覚える（`localStorage`の`yacobihime:shogi-match:material-guide:v1`）。
- 付けているとき：
  - 状態表示（「あなたの番です」の帯）に、自分から見た駒の損得の札を出す。「駒得 ＋3」（緑）・「駒損 −2」（赤）・「駒の損得 ±0」（灰）。色だけでなく文字でも分かる。
  - 点数は、盤の上と持ち駒の駒の値段の合計を自分と相手で比べたもの（`piece-points.mjs`の`materialTotals`。歩1・香3・桂4・銀5・金6・角8・飛10、成り駒は成った値段、玉は数えない）。教室の「形勢の3つのものさし」の駒の損得と同じ数え方。
  - 二人で指すときは、先手から見る（「先手 駒得 ＋3」）。
  - 振り返りでは、見ている局面の損得を出す。
  - 学習対局と同じく、駒を取ったマスに「＋6」「−5」を浮かべる（通常対局・竜王戦でも）。
- 色は、駒得の数字（`BoardView.vue`の`.float-label`）・教室の札（`--material-good`・`--material-bad`）とそろえる（AGENTS.mdの「盤面の色の使い分け」）。
- 根拠：U:4-1（補助表示は本人が選ぶ）、U:7-3（色だけでなく文字でも区別）、G:3-1（結果を数字で見せる手応え）。
