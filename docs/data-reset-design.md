# データリセットの種類（2026-10-31）

依頼: データリセットボタンでのリセットは、種類を増やしたい。大会の進捗だけリセット、直近の統計だけリセットのように。良いリセット設定を考えて。

読んだ指針: `UI_Nintendo_Design.md`（5-2 確認ダイアログの方針、3-2 導線のルール）、`UI_Nintendo_Implementation.md`（3-1 確認ダイアログ、4 文言、7-4 操作しやすさ、9 実装後のチェックリスト）、`UI_Nintendo.md`（3-4・3-5 確認の文とボタン）、`Game_Nintendo_Design.md`（4-3 安全網、4-4 単調な坂は山登りにならない、5-3 ご褒美の種類）。前の「最初から」の設計は`docs/exhibit-design.md`。

## 1. 機能設計メモ（Game_Nintendo_Design.mdの14章の形）

- **一言で**：「データリセット」を押すと、消す記録を8つから選べる。大会だけ、最近の対局の記録だけ、レーティングだけ、のように、やり直したいところだけ最初に戻せる。
- **解く課題**：今は全部消すしかなく、「竜王戦を6組からやり直したい」「棋力が上がったので弱点の見立てを新しくしたい」だけでも、名前・教室・コレクションまで消える。消したくないものを守るために、やり直しをあきらめてしまう。
- **リスクとリターン**：なし（記録の整理）。選んだものは取り消せないので、選んだあとに必ず確認を挟む。
- **初めての人の最初の1分**：「消す記録を選んでね」の一覧に、名前と、何が入っているかの1行が並ぶ。いちばん下の「すべて（最初から）」だけ赤い縁。
- **失敗したとき**：押し間違えても、確認の窓の最初のフォーカスは「戻る」。「戻る」・Esc・ブラウザの戻るで一覧へ戻り、一覧の「やめる」で閉じる（UD:5-2）。
- **捨てるもの**：細かすぎる選び方（竜王戦だけ・名人戦だけ、鍵ごとのチェックボックス）。大会どうしは名簿（棋士の世界）と順位戦を共有しているので、片方だけ消すと世界が食い違う。一覧は1画面に収まる8つまでにした（UD:3-2。迷わない数）。
- **確かめ方**：「大会の進み具合」を消して、竜王戦の期が消え、レーティングと名前が残ること（ブラウザで3つの大きさを確かめた）。自動テストで、ソースにあるすべての保存の鍵が、どれかの種類か「消さない設定」に入っていることを確かめる。

## 2. 種類と、分け方の理由

やり直したくなる場面ごとに分けた。同じ場面で一緒にやり直さないと食い違う記録は、同じ種類に入れる。

| 種類 | 消すもの | 残すもの | 分けた理由 |
| --- | --- | --- | --- |
| 大会の進み具合 | 竜王戦・名人戦の期と経歴、奨励会・研修会の挑戦、棋士の世界（名簿・順位戦）、大会の難易度（世界）、推しと予想、中継の記録、本局の途中、大会の中断した対局 | 賞状・観戦記・勝負メシ帳・研究ノート、レーティング、コレクション | いちばん多い「6組からやり直したい」。名簿と順位戦は全部の大会で共有するので一緒に消す。思い出（賞状など）は残す（D:5-3。手に入れたご褒美は取り上げない） |
| 最近の対局の記録 | 最近の勝ち負けと中身の要約（弱点の見立て・自分の能力の元）、弱点の練習の記録、続けて遊んだ日、自分の対局の棋譜 | レーティング・大会・教室・コレクション | 「直近の統計」。強くなったのに前の弱点を言われ続けるのを切る。レーティングは別（数局で合わせ直せるので） |
| レーティングと棋力 | レーティングと段級位、棋力カルテ（テスト・測定の見立て） | 対局の記録・大会・教室・コレクション | 家族で1台を使い始めた・測り直したいとき。おすすめの強さははじめに戻る。棋力測定で測り直せる（D:4-3） |
| 将棋教室 | レッスンの進み具合・メダル・称号、にがての記録、格言帳、利きメガネ、コツを使った回数 | 問題集・脳トレ・対局の記録 | 教室を最初から学び直したいとき |
| 問題集 | 解いた記録と解く時間（自己ベスト）、復習の予定、対局から作った問題 | 教室・脳トレ・対局の記録 | 解き直して★と時間を集め直したいとき（`docs/problem-set-timing-design.md`） |
| 脳トレ | 記録と判子のカレンダー、毎日のプログラム、記憶の宮殿と学校 | 教室・問題集・対局の記録 | 測定からやり直したいとき（最初の測定と比べる作りなので） |
| コレクションと思い出 | コレクションの印と着せ替えの解放、寄せの記録、賞状帳、観戦記、勝負メシ帳、研究ノート、占いで出た作戦 | レーティング・大会の進み具合・教室 | 集め直したいとき。大会の進み具合と分けたのは、ふだんは思い出を残して大会だけやり直したいため |
| すべて（最初から） | 名前を含む全部（今までの「最初から」と同じ） | 音と盤・駒の見た目 | 展示で来場者が替わるとき（`docs/exhibit-design.md`） |

- どの種類でも、端末の設定（音・盤と駒の見た目・解析の深さ・表示補助・読み上げなど）、名前、画面の覚え書き（ノートの開いていた項目など）、答えの送信の同意は消さない。これらは「すべて」でだけ消える（音と見た目は「すべて」でも残る）。
- 中断した対局の保存は、大会の対局（保存に`ryuoGame`があるもの）だけ「大会の進み具合」で消す。自由対局の中断はどれでも残す。

## 3. 画面

- 「データリセット」を押すと、選ぶ窓（`[data-data-reset]`）。見出し「消す記録を選んでね」、説明「選んだ記録だけを消すよ。音と盤・駒の見た目は、どれを選んでも残るよ。」、種類のボタン（名前と1行の中身。`[data-reset-group]`）、下に「やめる」。最初のフォーカスは「やめる」。「すべて（最初から）」だけ赤い縁にし、ほかと見分ける。
- 種類を押すと確認の窓（`[data-exhibit-reset-dialog]`）。主題を先頭に「大会の進み具合を消します。」、本文は「消えるもの：…。」と「…は残ります。」、ボタンは動詞の「消す」（「すべて」は「最初からにする」）と「戻る」（UD:5-2、N:3-5）。最初のフォーカスは「戻る」。
- 消したらページを読み直す（どの画面も、読み直せば消したあとの状態から始まる。開いている画面の状態を1つずつ戻すより確か）。`sessionStorage`は「すべて」のときだけ消す。

## 4. 実装（2026-10-31、実装・自動テスト済み）

- 種類と消し方は`src/core/data-reset.mjs`（`RESET_GROUPS`・`resetData`・`resetGroup`・`isMatchSnapshotKey`）。鍵の名前はここに直接書く（各モジュールを読み込むと最初に読むJSが重くなるため）。「すべて」は今までの`clearExhibitRecords`を使う。
- `src/core/data-reset.test.mjs`は、`src/`の中の`…KEY… = "…"`の形の保存の鍵を全部集め、どれかの種類か「消さない設定」（テストの`SETTING_KEYS`）に入っていることを確かめる。新しい保存の鍵を足したら、どちらかに入れないとテストが落ちる。
- 画面は`src/ShogiMatchGame.vue`の`resetChoice`・`chooseDataReset`・`acceptExhibitReset`、戻る操作は`navigateBack`（確認の窓→一覧→閉じる）。
- ブラウザ（390×844・820×1180・1366×768）で、一覧が1画面に収まり、横にはみ出さないこと、「大会の進み具合」の確認の文、「戻る」で一覧へ戻ること、消したあと竜王戦の期が消えてレーティングと名前が残ることを見た。
- 実際に遊んでの確かめは未確認。
