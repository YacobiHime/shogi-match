# ノベルの場面の作り方

この文書は、物語モード・団体戦・棋士の1年などのノベルの場面（会話の場面）を書く人のための手引きです。人でもAIでも、この文書だけを読めば、正しい台本を書いて、検査を通し、試し読みできるように書いてあります。

- エンジンの設計と決めた理由は`docs/novel-scene-design.md`（演出と台本の形は12章）。
- 画面は`src/NovelScene.vue`、演出の語彙と検査は`src/core/novel-direction.mjs`、台本の読み込みは`src/core/novel-script.mjs`。
- 語彙（動き・漫符など）を足したら、この文書の表も直します。`src/core/novel-library.test.mjs`が、表に全部のidがあるかを見張ります。

## 1. いちばん短い台本

`src/story/scenes/first-talk.md`のようなファイルに書きます。ファイルの名前と`id`は同じにします。

```
# 放課後
id: first-talk
bg: classroom
cast: hanane
summary: 放課後の空き教室で、羽音と少し話す。

: 放課後の空き教室。羽音がいた。
羽音: あ、来た。 [ぴょん]
羽音(smile): 一局、指す？
```

これだけで、場所の札・立ち絵・名前の札・文字送り・ログ・オート・飛ばすが全部動きます。`[ぴょん]`のような演出は、書かなくてもかまいません。

## 2. 書いてから遊べるまでの流れ

1. **書く**：`src/story/scenes/<id>.md`に台本を書く（この文書の3〜6章）。
2. **試し読み**：`npm run novel-editor`で開くページに台本を貼り、「再生」を押す。検査の結果も右に出る（9章）。
3. **検査**：`npm run novel:check`（ファイルを指定してもよい：`npm run novel:check -- src/story/scenes/first-talk.md`）。まちがいが0件になるまで直す。
4. **物語の目録に載せる**（メインの話のとき）：`src/core/story-mode.mjs`の`STORY_EPISODES`のメインの行に`scene: '<id>'`を書き、`status: 'soon'`を消す。第一話はいつでも、第二話からは前の話を読むと開く。
5. **テスト**：`npm test`。`novel-library.test.mjs`が`src/story/scenes/`の台本を全部検査し、まちがいがあると落ちる。

大会の途中で見せる場面（団体戦の節目など）は、いまはJavaScriptの台本（`src/core/team-story.mjs`・`src/core/pro-year-story.mjs`）にあります。そこへ演出を書くときは10章。

## 3. 台本の形

### 3-1. 頭

いちばん上に`# 題名`、続けて`項目: 値`の行を書きます。題名は場所の札に出ます（「放課後の空き教室」のように、場所か出来事の短い名前）。

| 項目 | 書くこと | 例 |
| --- | --- | --- |
| `id` | 場面の名前。小文字の英数字とハイフン。ファイルの名前と同じ | `id: main-01` |
| `bg` | はじめの背景（7章の表） | `bg: classroom` |
| `cast` | 立ち絵で出る人（左から並ぶ順）。あとで登場する人も書く | `cast: hanane momoka` |
| `summary` | 「飛ばす」で見せるあらすじ。1〜2文 | `summary: 放課後、羽音に誘われる。` |
| `voices` | 立ち絵のない、声だけの人の名前（空白で区切る） | `voices: 店員 先生` |
| `vars` | 遊びの中から入れる差し込みの名前（4-3） | `vars: title holder` |
| `start` | はじめから出ている人を、castと別に決めたいとき（ふつうは書かない） | `start: hanane` |

### 3-2. 本文

本文は1行に1つ。空の行は読み飛ばします。

| 書き方 | 意味 |
| --- | --- |
| `: 文` | 地の文（名前の札なし） |
| `羽音: 文` | 台詞。名前は表示の名前（羽音・百花）かid（`hanane`・`momoka`） |
| `羽音(smile): 文` | 表情つきの台詞。表情はidか呼び名（`羽音(笑顔)`）。書かなければ`neutral` |
| `あなた: 文` | プレイヤーの台詞。名前の札はプレイヤーの名前 |
| `店員: 文` | 声だけの人（頭の`voices:`に書いた名前） |
| `[...]` | 演出（5章）。行の後ろに書くとその行に、`[...]`だけの行は次の行に付く |
| `- 答え {値}` | 選択肢（6章） |
| `// メモ` | 書き手のメモ（画面に出ない） |

### 3-3. 1行の長さと行の数

- 1行は60字まで（窓に収まる）。長いときは2行に分けます。
- 1つの場面は12行までを目安にします（遊びを止めない。大会の幕間の場面は短く）。物語モードの長い話は、場面を分けて続けます。超えても動きますが、検査が注意を出します。

## 4. 人物と表情・差し込み

### 4-1. 人物

| id | 台本の名前 | 立ち絵 | 表情 | 口調のきまり |
| --- | --- | --- | --- | --- |
| `hanane` | 羽音・天鷺羽音 | あり | `neutral`（ふつう）・`smile`（笑顔）・`gentle`（やさしい）・`worried`（心配） | **敬語を使わない**（です・ます・ください・お願いします・ありがとうございます）。**「！」を使わない**。淡々としていて、「〜でしょ」「どう？」と問いかける。プレイヤーを「君」と呼ぶ（`docs/hanane-character.md`） |
| `momoka` | 百花・桜乃百花 | あり | `neutral`（ふつう）・`wry`（苦笑い）・`worried`（心配） | 明るく、「！」を使う。プレイヤーを`{you}`と呼ぶ |
| `you` | あなた・プレイヤー | なし | `neutral` | プレイヤーの気持ちを決めつけないよう、台詞は少なめに |
| `host` | 司会 | なし | `neutral` | 声だけ |
| `narration` | （地の文。`: `で書く） | なし | `neutral` | 「{name}は〜」のように三人称で書く |

- 羽音の敬語と「！」は、検査が「まちがい」として止めます。
- 百花に`smile`の表情はありません（`neutral`か`wry`を使う）。知らない表情は、検査がまちがいとして教えます。
- 善彦など、ほかの人物はまだ立ち絵がありません。出したいときは`voices:`に書いて声だけで出すか、11章の手順で人物を足します。

### 4-2. 差し込み

| 書き方 | 入るもの |
| --- | --- |
| `{name}` | プレイヤーの名前（「{name}は将棋会館の前に立っていた」） |
| `{you}` | 百花の呼び方（プレイヤーが選んだ「○○さん」「○○くん」など）。百花の台詞で使う |

### 4-3. 遊びの中から入れる差し込み

棋戦の名前など、場面を出すときに決まる言葉は、頭の`vars:`に名前を書き、本文で`{title}`のように使います。場面を出すコードで`libraryScene(id, { vars: { title: '棋王' } })`と渡します。物語の画面から読み直すときは、差し込みのない`{title}`のまま出るので、物語の目録に載せる台本では使わないか、どちらでも読める文にします。

## 5. 演出

`[...]`の中に、空白か「、」で区切って何個でも書けます。`[ぴょん] [！]`も`[ぴょん ！]`も同じです。演出は見た目だけで、押して進む・オート・ログは演出を待ちません。

### 5-1. だれの演出か

- 名前を付けなければ、**その行で話している人**の演出です（`羽音: そうだね。 [うなずく]`）。
- ほかの人には`名前:演出`と書きます（`羽音: 驚いた？ [百花:のけぞる]`）。
- 地の文の行の動き・漫符には、必ず名前を付けます（`: 二人は顔を見合わせた。 [羽音:かしげる] [百花:？]`）。

### 5-2. 動き（立ち絵が動く）

| id | 台本の書き方 | 使い道 |
| --- | --- | --- |
| `hop` | `[ぴょん]`・`[跳ねる]` | 小さくうれしい・気づいた |
| `jump` | `[大喜び]`・`[ぴょんぴょん]` | とてもうれしい（優勝など） |
| `nod` | `[うなずく]` | そうだね・分かった |
| `shake` | `[首を振る]`・`[いやいや]` | ちがう・いやだ |
| `tilt` | `[かしげる]`・`[首をかしげる]` | 分からない・不思議 |
| `bow` | `[おじぎ]`・`[礼]` | あいさつ・対局の礼 |
| `shiver` | `[ぶるぶる]`・`[震える]` | 緊張・こわい・寒い |
| `lean` | `[前に出る]`・`[ぐいっ]` | 身を乗り出す・強く言う |
| `recoil` | `[のけぞる]` | 驚いて引く |
| `sink` | `[しょんぼり]`・`[落ち込む]` | 残念・落ち込む |

### 5-3. 漫符（頭の上に小さな印）

| id | 台本の書き方 | 出る印 | 使い道 |
| --- | --- | --- | --- |
| `surprise` | `[！]`・`[びっくり]` | ！ | 驚く |
| `question` | `[？]`・`[はてな]` | ？ | 分からない |
| `sweat` | `[汗]` | 💦 | 困る・あせる |
| `heart` | `[ハート]` | ♥ | うれしい・好き |
| `anger` | `[怒]`・`[むっ]` | 💢 | 怒る・むっとする |
| `note` | `[音符]`・`[♪]` | ♪ | 楽しい・ごきげん |
| `idea` | `[ひらめき]` | 💡 | 思いつく |
| `sigh` | `[ため息]`・`[…]` | … | あきれる・言葉が出ない |
| `sparkle` | `[きらきら]` | ✦ | 目を輝かせる |

### 5-4. 表情だけ変える

話していない人の表情は`[名前:表情]`で変えます（`羽音: 負けたら終わり。 [百花:worried]`）。話している人の表情は`羽音(smile):`のように名前の後ろに書きます。表情は、次にその人が話すか、変えるまで続きます。

### 5-5. 登場と退場

| 書き方 | 意味 |
| --- | --- |
| `[enter]`・`[登場]` | 話している人が、ふわっと出てくる（向き`fade`） |
| `[enter:left]`・`[登場:左]` | 左から入ってくる（向き`left`） |
| `[enter:right]`・`[登場:右]` | 右から入ってくる（向き`right`） |
| `[百花:enter:right]` | ほかの人を登場させる |
| `[exit]`・`[退場]`・`[百花:exit]` | その行を言い終えてから、去る |

- 登場は**その行のはじめ**、退場は**その行を言い終えてから**です。「またね！ [exit]」と書けば、言ってから去ります。
- castにいて、最初の出来事が登場の人は、はじめは出ていません。
- 席は出ている人の数で決まります（1人は中、2人は左右、3人は左・中・右）。立てるのは3人まで。castの順に左から並びます。

### 5-6. 画面

| id | 台本の書き方 | 見え方 | 使い道 |
| --- | --- | --- | --- |
| `flash` | `[光る]`・`[フラッシュ]` | 白く光る | ひらめき・衝撃 |
| `quake` | `[揺れる]` | 画面が揺れる | 大きな驚き・ぶつかる |
| `blackout` | `[暗転]` | 暗くなってから明ける。文は明けてから出る | 時間が飛ぶ・場所が変わる |

### 5-7. 色（次に変えるまで続く）

| id | 台本の書き方 | 使い道 |
| --- | --- | --- |
| `memory` | `[回想]`・`[tone:memory]` | 昔の話（セピア色） |
| `dim` | `[暗く]`・`[tone:dim]` | 静かな夜・落ち込んだ空気 |
| `none` | `[回想おわり]`・`[もとの色]`・`[tone:none]` | もとに戻す |

### 5-8. 背景（次に変えるまで続く）

`[bg:night]`・`[背景:夜]`のように書きます。頭の`bg:`も同じ名前です。

| id | 呼び名 |
| --- | --- |
| `classroom` | 教室（夕方） |
| `hall` | 将棋会館 |
| `venue` | 会場 |
| `night` | 夜 |
| `street` | 帰り道（夕方） |
| `room` | 部屋 |
| `black` | 黒 |
| `white` | 白 |

場所が変わるときは、`[暗転] [bg:night]`のように暗転と一緒に替えると自然です。

### 5-9. 効果音

`[sfx:pop]`・`[音:ぽん]`のように書きます。音は短く、効果音のオン/オフに従います。

| id | 呼び名 | 使い道 |
| --- | --- | --- |
| `pop` | ぽん | 何かが出てくる・軽い驚き |
| `chime` | きらり | ひらめき・うれしい知らせ |
| `impact` | どん | 衝撃・決意 |
| `koma` | 駒音 | 駒を打つ・対局の始まり |
| `door` | 戸 | 戸を開ける・人が来る |
| `bell` | チャイム | 学校のチャイム・時間の区切り |

### 5-10. 文の見せ方と間（その行だけ）

| id | 台本の書き方 | 意味 |
| --- | --- | --- |
| `big` | `[大きく]` | 文を大きく（叫ぶ・大事な一言） |
| `small` | `[小さく]` | 文を小さく（ひとりごと・ささやき） |
| `slow` | `[ゆっくり]` | 文字をゆっくり出す（「……」のための間） |
| `fast` | `[早口]` | 文字を速く出す（あわてる） |
| `wait` | `[間:600]`・`[wait:600]` | 文が出始めるまで600ミリ秒待つ（0〜3000） |

## 6. 選択肢

問いかけの行のすぐ下に`- 答え`を並べ、その下に**2つ下げて**返しの台詞を書きます。返しは何行でもかまいません。`{値}`は答えの記録に使う名前（なくてもよい）。

```
司会: 好きな戦法は？
- 居飛車 {ibisha}
  羽音(smile): 私も。正面から殴り合うの、好きだよ。
- 振り飛車 {furibisha}
  羽音: へえ。じゃあ、今度指してみよう。
: 会場から拍手が起きた。
```

- 答えは3つまで（キーの1〜3で選べる）。
- 選んだ答えは`choose`のイベントで`{ line, choice, value }`として場面を出したコードに届きます。
- 「飛ばす」と、答えなかったことになります（あらすじのシートでそう伝える）。

## 7. 書くときのきまり

### 7-1. 物語のきまり

- 主役は大会（竜王戦・名人戦）と物語です。場面は「大会をもっと楽しみにする」方向で書きます（`AGENTS.md`の「このゲームの柱」）。
- ノベルのリポジトリ（`YacobiHime/novel`）は、ミステリーの部分（黒姫真理の計画と裏の顔・犯罪組織YATA・事件・暗号と情報戦・続が真理の協力者であること）だけは使いません。人物・舞台・テーマは使ってかまいません（`docs/novel-reference.md`）。
- このゲームで決めたこと（羽音はプロの新四段、敬語と「！」なし、など）がノベルと食い違うときは、このゲームを優先します。
- プレイヤーの気持ちを地の文で決めつけません（「{name}はうれしかった」より「{name}は盤を見つめた」）。

### 7-2. 演出のきまり

- **演出と同じ意味を、文でも伝えます。** 動きや音を見落としても話が分かるように（`[揺れる]`だけで地震を伝えない。「床が揺れた」と書く）。
- **1行の動きと漫符は、それぞれ2つまで。** 多いと、何が大事か伝わりません。大事な行だけに付け、ふつうの行は付けないほうが効きます。
- **大きい演出（`jump`・`quake`・`flash`・`blackout`）は、1つの場面に1〜2回まで。** いちばん大事なところのために取っておきます。
- 気持ちと表情と動きを合わせます（うれしい台詞で`worried`にしない、落ち込む台詞で`jump`しない）。
- 暗転は「時間が飛ぶ・場所が変わる」ときだけ。背景を替えるときは暗転と一緒に。
- `[回想]`を始めたら、終わりに`[回想おわり]`を書きます。

### 7-3. 文のきまり

- 1行60字まで、1つの場面は12行まで（3-3）。
- 「……」は言いよどむときだけ。文の頭に毎回付けない。
- 地の文は短く、現在のことを書く（「放課後。羽音がいた。」）。

## 8. 検査のまちがいと直し方

検査は「まちがい」（直さないと正しく見えない）と「注意」（きまりから外れている）を、行の番号と一緒に出します。

| 出る言葉 | 直し方 |
| --- | --- |
| 羽音は敬語を使いません:「です」 | 「〜だよ」「〜でしょ」「よろしく」のように書く |
| 羽音は「！」を使いません | 「。」か「……」にする |
| 百花の表情「smile」は知りません | 表の表情（`neutral`・`wry`・`worried`）を使う |
| 「善彦」はだれか分かりません | 立ち絵がなければ頭の`voices: 善彦`に書く |
| 演出「おどる」は知りません | 5章の表の名前を使う |
| 地の文の行の動きは、だれの動きかを書きます | `[百花:ぴょん]`のように名前を付ける |
| 百花は舞台に出ていないので動けません | 先に`[百花:enter]`で登場させる |
| 百花は出ていないので、退場できません | 退場の前に登場しているか確かめる |
| 下げた行は、選択肢の返しにだけ書けます | 行の頭の空白を消す |
| 1行が65字あります | 2行に分ける |
| 本文が15行あります | 場面を2つに分ける |

## 9. 試し読みのページ

```sh
npm run novel-editor
```

- 左に台本を書き、右に検査の結果と演出の早見表が出ます。書くたびに検査し直します。
- 「再生」で、本物の場面の画面で読めます。「この行から」は、台本の入力欄のカーソルがある行から読みます。Escか、最後まで読むと戻ります。
- はじめは見本の台本（`src/story/scenes/sample-direction.md`）が入っています。全部の種類の演出を使っているので、写して書き換えると早いです。
- ページは台本をファイルに保存しません。書いたら「コピー」で写し、`src/story/scenes/<id>.md`に貼ります（ブラウザには下書きだけ残ります）。

## 10. JavaScriptの台本（組み込みの場面）に演出を書く

団体戦（`src/core/team-story.mjs`）と棋士の1年（`src/core/pro-year-story.mjs`）の台本は、`line(who, face, text, fx)`の4つめに演出を書きます。名前はidで書きます。

```js
line('momoka', 'neutral', '優勝……！ 私たち、日本一だよ！', { act: 'jump', emote: 'sparkle' }),
line('narration', 'neutral', '二人そろって一礼する。', { act: { who: 'hanane', act: 'bow' }, sfx: 'koma' }),
line('hanane', 'gentle', '……うん。', { faces: { momoka: 'worried' } }),
```

| 欄 | 値 |
| --- | --- |
| `act`・`acts` | 動きのid（話す人）か`{ who, act }`、その配列 |
| `emote`・`emotes` | 漫符のid（話す人）か`{ who, emote }`、その配列 |
| `faces` | `{ 人のid: 表情のid }` |
| `enter` | 人のidか`{ who, from }`（fromは`left`・`right`・`fade`）、その配列 |
| `exit` | 人のid、その配列 |
| `screen` | `flash`・`quake`・`blackout` |
| `bg` | 背景のid |
| `tone` | `memory`・`dim`・`none` |
| `sfx` | 効果音のid、その配列 |
| `wait` | ミリ秒 |
| `size` | `big`・`small` |
| `speed` | `slow`・`fast` |

組み込みの場面も`novel-library.test.mjs`が検査します。

## 11. エンジンを広げるとき

| 足したいもの | 直す場所 |
| --- | --- |
| 動き | `novel-direction.mjs`の`NOVEL_ACTS`（`ms`は画面の長さ）と、`NovelScene.vue`の`novel-act-<id>`の動き（`@keyframes`）。この文書の5-2 |
| 漫符 | `NOVEL_EMOTES`（`glyph`が出る字）。5-3 |
| 画面の効果 | `NOVEL_SCREEN`と`NovelScene.vue`の`novel__fx--<id>`。5-6 |
| 背景 | `novel-ui.mjs`の`NOVEL_BACKGROUND_CSS`（CSSで描く）と`novel-direction.mjs`の`BACKGROUND_LABELS`。5-8 |

足したら、`npm test`（この文書の表に新しいidがないと落ちる）・`npm run typecheck`・試し読みのページで確かめます。

## 12. AIに台本を書いてもらうとき

ほかのAIに頼むときは、この文書と、使う人物の設定（`docs/hanane-character.md`・`docs/novel-reference.md`）を読ませてから、次のように頼みます。

```
docs/novel-authoring-guide.md のきまりに従って、src/story/scenes/<id>.md に台本を書いてください。
- 場面：<だれが・どこで・何をする場面か>
- 長さ：12行まで。1行60字まで。
- 演出：大事な行にだけ付け、大きい演出は1〜2回まで。演出と同じ意味を文でも書く。
- 書いたら npm run novel:check -- src/story/scenes/<id>.md を実行し、まちがいと注意が0件になるまで直す。
- 物語の目録に載せるときは、src/core/story-mode.mjs の STORY_EPISODES の行に scene を書き、npm test を通す。
```

書けたら、試し読みのページで実際に読んで、気持ちと演出が合っているかを人が確かめます。検査は書きまちがいを見つけますが、面白いかどうかは見つけられません。
