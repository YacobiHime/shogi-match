# 自由対局のプレイヤー同士（2026-11-05、実装・自動テスト済み）

## 設計メモ

- 目的：自由対局から同じ端末を使って2人で将棋を指せるようにする。
- 操作：自由対局の準備の先頭で「対局相手」を変更し、「CPUと対局／プレイヤー同士」を選ぶ。後者ではCPUの強さ・作戦・先後の入れ替えを出さず、先手・後手が交互に盤と持ち駒を操作する。
- 見た目：対局の盤と規則は既存のlocalモードを利用する。盤の向きは表示補助のひふみんアイで変更できる。自動では反転しない。
- 保存：対局のmodeにlocalを保存。ホームのある通常の入口はcpuとlocalの両方を復元できる。ホームのない埋め込みは従来どおり指定モードに一致した保存だけを復元する。ホームへ戻って別の遊びを始めると、選んだ二人対局の設定をCPUの遊びへ持ち込まない。
- 境界：二人対局はレーティング・棋力測定の対象外。オンライン通信対戦は今回の対象外。
- 根拠：UD:2 明快、UD:3-2 浅い導線、U:7-4 押せる大きさ。対局相手は通常の選択シートで選ぶ。
- 確認：保存のテスト、CPUと二人の切り替え・双方の着手・リロード復元・PC／スマホ／タブレットのブラウザ自動操作。実際に二人で遊んでの確認は未確認。

検証結果：全197ファイル・2,558テスト、保存と対局画面の関連97テスト、型チェック・公開用ビルド成功。ブラウザ自動操作で1366×768・390×844・820×1180の相手選択、先後の着手、CPUの自動応手がないこと、リロード後の続行、成り・駒の取り合い・双方の持ち駒の角打ちを確認。実際に二人で遊んでの確認は未確認。
