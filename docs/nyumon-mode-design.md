# やこび姫の将棋教室（入門モード） 設計

将棋をまったく知らない人が、ルールから始めて、寄せ・戦法・手筋・形勢判断まで段階的に学べる「やこび姫の将棋教室」の設計です。
学ぶ順番は『羽生善治の将棋入門 ジュニア版（新版）』の目次（全5巻の構成）を参考にします。

## 1. 方針

- **書籍は学ぶ順番の参考にだけ使う。** 本文・図・棋譜・問題は転載せず、教材はすべて自作する。画面に書名や著者名を出さない（監修・推薦と誤解されないため）。
- **1回の学習は短く。** レッスン1つは2〜5分、ステップ5〜10個程度。Duolingo Chessのように「読む→試す→できた！」をテンポよく繰り返す。
- **既存機能を教材として再利用する。** 駒図鑑・手筋図鑑・定跡図鑑・学習対局・棋譜解析を、レッスンの中から呼び出したり、レッスンの続きとして案内したりする。
- **正誤はコードで確かめる。** 盤面・正解手・詰みは、図鑑と同じように自動テストで合法性と正しさを検証する。
- **やこび姫が先生役。** 説明・励まし・ヒントはやこび姫の台詞で出す。物語（ストーリーモード）は後から台詞を足せる構造にしておく。

## 2. カリキュラム構成

構造は **巻 → 章 → レッスン → ステップ** の4階層です。書籍の5巻・12章を枠組みにし、巻・章の名前はやこび姫風に言い換え、レッスンは自作します。

| 巻 | 章 | 主なレッスン（案） | 使う既存機能 |
| --- | --- | --- | --- |
| **第1巻 さあ将棋をはじめよう** | 1. 将棋をはじめよう | 盤とマスの呼び方（筋・段）／駒の並べ方／先手と後手／交互に指す／勝ち負けは玉を詰ませること | 盤面表示 |
| | 2. 駒に親しもう | 歩・香・桂・銀・金・角・飛・玉の動き（1駒1レッスン）／成り／持ち駒と駒を打つ／反則（二歩・打ち歩詰め・行き所のない駒・王手放置） | 駒図鑑、駒の利き表示 |
| **第2巻 一局の流れを知る** | 1. 三手の読み | 自分→相手→自分の順に考える／タダで取られる手を見つける／駒得と駒損／両取り | 駒の価値tier表 |
| | 2. 実力者と初心者の対局 | 解説付きの棋譜を再生（序盤・中盤・終盤）。どこで差がついたかを考える | 棋譜解析、評価値グラフ |
| | 3. 寄せの考えかた | 王手と詰み／1手詰め／3手詰め／詰めろと必至／頭金・腹銀など詰みの形 | 手筋図鑑「詰みの形」 |
| **第3巻 攻めと守りの知恵** | 1. 駒組みと戦法のいろいろ | 居飛車と振り飛車／囲いの意味（舟囲い・美濃・矢倉）／戦法と囲いの組み合わせ | 定跡図鑑、やこび姫補助、学習対局（完成形から開始） |
| | 2. 実力者と初心者の対局 | 攻めと受けに注目した解説付き棋譜 | 棋譜解析 |
| | 3. 攻めと守りの知恵 | 攻めは飛角銀桂／受けの3つの方法（逃げる・取る・合駒）／玉の早逃げ | 手筋図鑑 |
| **第4巻 戦法と定跡に学ぶ** | 1. さまざまな振り飛車戦法 | 四間飛車・三間飛車・中飛車・向かい飛車を定跡どおりに指すドリル | 定跡図鑑、やこび姫補助 |
| | 2. さまざまな居飛車戦法 | 棒銀・早繰り銀・腰掛け銀・矢倉・角換わり・相掛かり・横歩取り | 定跡図鑑、やこび姫補助 |
| **第5巻 考えることを楽しもう** | 1. 将棋とはなにか、考える | 形勢判断の3要素（駒の損得・玉の堅さ・駒の働き）／評価値の見かた／大局観 | 棋譜解析、将棋AIの駒の価値 |
| | 2. 実戦に学ぶ手筋と格言 | 手筋図鑑の格言を、実戦形の問題で使う | 手筋図鑑 |

「実力者と初心者の対局」の棋譜は自作します。CPU（やねうら王）に指させた対局をもとに、解説を付けて教材化します。

## 3. レッスンの中身（ステップの種類）

1つのレッスンは、次の種類のステップを並べて作ります。

| 種類 | 内容 | 例 | 判定 |
| --- | --- | --- | --- |
| `explain` | 盤面とやこび姫の説明。色付け・矢印付き | 「歩は前に1マス進めるよ」 | 画面のどこを押しても進む（2026-10-16から。以前は「次へ」ボタン） |
| `move-piece` | 指定した駒を、目的のマスまで動かす | 盤に歩だけを置き、5三まで進める | 目的マスに着いたら正解 |
| `find-move` | 正解の一手を指す（正解が複数あってもよい） | 両取りになる桂打ち | 正解手と一致したら正解 |
| `choose` | 選択肢から答える | 「反則なのはどれ？」「どちらが駒得？」 | 選んだ選択肢で判定 |
| `mate` | n手詰めの問題。相手の応手は教材で固定する（必要ならエンジンで検証） | 1手詰め・3手詰め | 詰みになったら正解 |
| `replay` | 解説付きの棋譜を1手ずつ再生し、途中で質問を挟む | 実力者と初心者の対局 | 質問部分は `choose` か `find-move` |
| `play` | 条件付きの対局（学習対局の機能を使う） | 「角落ちのCPUに勝とう」「完成した美濃囲いから指そう」 | 勝敗や目標（例：駒得）で判定 |
| `open-dex` | 関連する図鑑の項目を開く | 「駒図鑑で金の動きをもう一度見よう」 | 任意（スキップ可） |

間違えたときは、1回目はヒント（マスの色付け）、2回目は正解の矢印を出します。正解するまで先へは進みません。

## 4. データ構造

```text
src/core/tutorial-curriculum.mjs   巻・章・レッスンの一覧（タイトル・順番・解放条件）
src/data/tutorial/volume1.mjs など  レッスンの中身（ステップの配列）
src/core/tutorial-runner.mjs       ステップの進行と正誤判定（画面から独立した純粋関数）
src/core/tutorial-progress.mjs     進捗の保存と読み込み
src/ShogiTutorial.vue              入門モードの画面
```

レッスン1件の形の例：

```js
{
  id: "v1-c2-pawn",
  title: "歩の動き",
  goal: "歩を前に進めてみよう",
  steps: [
    { type: "explain", sfen: "...", speech: "歩は前に1マスだけ進めるよ！", marks: [["5d", "reach"]] },
    { type: "move-piece", sfen: "...", from: "5e", target: "5c", speech: "5三まで進めてみよう" },
    { type: "choose", question: "歩はどこへ動ける？", options: [...], answer: 0 },
  ],
}
```

- **盤面の書き方：** 盤面・色付け・矢印の書き方は、図鑑（`src/core/reference-dex.mjs`）と揃えます。盤は `ShogiMatchBoard` の `markSquares`・`candidates`・`attackMarks` をそのまま使います。
- **正誤判定の置き場所：** `tutorial-runner.mjs` に置き、画面から切り離します。これで、Vueを通さずに単体テストで正誤判定を確かめられます。
- **既存データの参照：** 駒の動き・格言・定跡は既存データをIDで参照します（例：`{ type: "open-dex", kind: "tesuji", id: "head-gold" }`）。同じ解説を二重に持ちません。

## 5. 進捗と解放

- **保存先：** `localStorage` にレッスンごとの状態（未着手・クリア）と成績を保存します。対局の保存（`match-persistence`）とは別の鍵にし、「対局準備へ戻る」操作では消しません。
- **成績：** ヒントや間違いの回数から★1〜3を付けます。★3でなくても次へ進めます。
- **解放の順番：** 章の中では、前のレッスンをクリアすると次が解放されます。巻は、前の巻の最初の章を終えると解放します。上級者は「解放を無視して選ぶ」ことも可能にします。
- **復習：** クリア済みのレッスンは何度でもやり直せます。間違えたステップだけを集めた「復習」は後の段階で追加します。

## 6. 画面

1. **タイトル画面：** 「入門」の区分けを新設し、「入門」カードを1枚置きます。今の「対局」「図鑑」の区分けと並べ、学ぶ順番に「入門 → 対局 → 図鑑」の並びにします。
2. **本棚（巻の選択）：** 5巻を本の背表紙のように並べ、各巻の進み具合（例：12/20）を表示します。
3. **レッスン一覧：** 章ごとに、レッスンを道のように1列に並べます（Duolingo風）。クリア済みには★、次のレッスンを強調表示します。
4. **レッスン画面：** 上に進捗バーとタイトル、中央に盤、下にやこび姫の台詞と「次へ」「ヒント」「やり直し」を置きます（2026-10-16に作り直し。下の「レッスン画面の作り直し」を参照）。レイアウトとCSSは図鑑を下地にし、スマホ縦を最優先にします。
5. **結果画面：** ★の数、やこび姫のひとこと、「次のレッスン」「もう一度」「関連する図鑑」を表示します。

## 7. 既存機能の再利用

| 既存機能 | 入門での使い道 |
| --- | --- |
| `game-state`（合法手・指し手の適用） | 指した手の合法性、目的マスへの到達、詰みの判定 |
| `reference-dex`（駒・手筋・将棋界図鑑） | 駒の動きの色付け（`pieceReachSquares`）、格言の説明、図鑑へのリンク |
| `opening-guide`（定跡の手順とやこび姫補助） | 第3・4巻の定跡ドリル。案内どおりに指せたかの判定 |
| `learning-setup`（駒落ち・完成形・駒の利き） | `play` ステップの開始局面、駒の利きの表示 |
| 棋譜解析・評価値グラフ | 第2・3・5巻の解説付き棋譜と、形勢判断の説明 |
| やねうら王 | `play` ステップの相手、`mate` 問題の検証、自作棋譜の作成 |

## 8. テスト方針

- すべてのステップについて、盤面が正しい局面であることと、手番でない側が王手されていないことを確かめます。
- `find-move`・`move-piece` の正解手が合法手であることを確かめます。
- `mate` は、正解手順で詰みになること（相手に合法手がないこと）を確かめます。
- 参照する図鑑や定跡のIDが実在することを確かめます。
- 進捗の保存と読み込み、解放の条件を単体テストで確かめます。

## 10. 決定事項（2026-09-28）

1. **モード名：** 「やこび姫の将棋教室」。タイトル画面に「入門」の区分けを新設して置く。
2. **巻・章の名前：** 書籍の名前は使わず、やこび姫風に言い換える。
   - 第1巻「盤と駒をおぼえよう」（盤と駒にごあいさつ／駒となかよくなろう）
   - 第2巻「一局の流れをつかもう」（三手先まで考えよう／強い人の対局を観戦しよう／玉をつかまえよう）
   - 第3巻「攻めと守りのひみつ」（戦法と囲いを知ろう／攻めと受けを観戦しよう／攻めと守りのコツ）
   - 第4巻「戦法マスターへの道」（振り飛車にチャレンジ／居飛車にチャレンジ）
   - 第5巻「形勢を読んで、格言を生かそう」（形勢を読んでみよう／格言で強くなろう）
3. **成績：** ★1〜3。間違いとヒントの合計が0なら★3、2回までなら★2、それ以上は★1。最高記録を残す。
4. **解放：** 前のレッスンを終えると次が解放される。レッスン単位と章単位でスキップでき、スキップも「終えた」扱いで次へ進める。準備中のレッスンは解放の妨げにしない。
5. **進め方：** まず全体の構造（5巻12章・全レッスンの枠）を作り、中身を徐々に強化する。

## 11. 実装状況（2026-09-28）

- 実装済みのステップ：`explain`・`move-piece`・`find-move`（`anyDropOf`対応）・`mate`・`choose`・`open-dex`・`play`・`replay`
- 中身のあるレッスン：48（準備中なし）。
- ファイル：`src/core/tutorial-curriculum.mjs`（カリキュラム）、`src/core/tutorial-runner.mjs`（正誤判定）、`src/core/tutorial-progress.mjs`（進捗）、`src/core/tutorial-watch-games.mjs`（観戦の棋譜）、`src/ShogiTutorial.vue`（画面）
- `replay`ステップは、棋譜（`moves`）を`from`手目の局面から「戻る」「次の手」で1手ずつ再生する。`notes`は、その手を指した直後の手数をキーにした解説で、解説のない手は「▲7六歩と指したよ。」と表示する。最後の手まで見ると「次へ」を出す。棋譜の途中で「実力者の次の一手」を当てる問いは、同じ棋譜の手順を`moves`に持つ`find-move`・`mate`ステップを間に挟んで作る。
- 観戦の棋譜2局は、8手目までを手で決め、先手（実力者）をやねうら王の15万nodes探索の最善手、後手（初心者）をCPU Lv12・Lv8で指し継いで作った（`scripts/tutorial-watch-game.mjs`。乱数の種を指定すれば同じ棋譜を再現できる）。後手の悪手の指摘は、そのときの最善手をもとに書いている。自動テストで、解説の先頭に書いた指し手が棋譜の手と一致することを確かめている。
- 「3手詰めに挑戦」の3題は、1手詰めがなく、正解の初手に相手がどう応じても次の1手で詰むことを自動テストで確かめている。
- 盤で指すステップ（`move-piece`・`find-move`・`mate`）は、正解すると「正解！」を約1秒見せてから自動で次へ進む。自動で進むので「次へ」ボタンは出さない。選択肢も、正解すると解説を読む時間（`choiceAdvanceDelay`、1.4〜4.2秒）をとってから自動で進む（2026-10-16から）。

### レッスン画面の作り直し（2026-10-16）

「ボタンを押すのが面倒」「画面が見づらい」という声を受けて、`docs/nintendo-design/`の指針（遅さは罪、必要な瞬間に1つだけ教える、目標を1行で常に表示、無反応をなくす）に沿って作り直した。

| 変えたこと | 前 | 後 |
|---|---|---|
| 説明の進め方 | 1文ごとに「次へ」ボタン | 画面のどこを押しても進む。吹き出しに「タップで次へ ▼」。Enter・スペース・→でも進む。続けて押した誤操作（250ms）と、正解した押下（400ms）は無視する |
| 選択問題 | 正解しても「次へ」を押す。まちがえても全部の選択肢が残る | 正解すると自動で進む（押せば待たずに進む）。まちがえた選択肢は打ち消し線で押せなくする |
| ヒント | 「ヒント」ボタン | 10秒操作がないと、そっと大事なマスを出す（★に数えない）。まちがえたときの段階的なヒントは残す |
| 見出し | 戻るボタンと題名が2行に折り返す。「このレッスンをスキップ」が台詞の下に常にある | 1行にまとめ、狭い画面では戻るを矢印だけに。スキップは見出しの右端の小さなボタン |
| 進み具合 | 細い棒 | ステップごとの点。課題は四角、いまのステップは大きく |
| 台詞 | 小さな立ち絵と、台詞・正誤の欄が別々 | 大きな立ち絵の吹き出し1つに、課題の種類（やってみよう・クイズ・詰ませてみよう）と正誤の一言をまとめる。課題中は枠を琥珀色に |
| 選択肢の並び | 縦に積む | 収まるだけ横に並べる（盤を小さくしない） |
| 入り方 | ホームの「つぎはこれ」から本棚 → 巻 → レッスン | 「つぎはこれ」と、はじめての案内の「はじめて」からは、次のレッスンをすぐ始める |
| 結果 | 星を0.45秒ごとに付ける | 星より先に「できるようになったこと」。星は0.28秒ごと。「次のレッスン」にフォーカス |

### 地図と、続けて進む流れ（2026-10-16）

「並びが分かりづらい」「レッスンが短いわりに遷移が面倒」という声を受けて、教室の構造を作り直した。

| 変えたこと | 前 | 後 |
|---|---|---|
| 並び | 本棚（巻を選ぶ）→ 巻の中（章とレッスンの一覧）→ レッスン | 全レッスンを1本の道に並べた地図（`src/core/tutorial-map.mjs`）。巻の看板（進み具合と★）、章の看板（「この章をとばす」）、レッスンのマスを学ぶ順に縦に並べ、マスは左右にくねらせる。いまのマスに「ここから！」、開くとそこまでスクロール |
| マス | ▶・🔒・★の文字だけの一覧の行 | 丸いマス。済んだマスは琥珀色と★、いまのマスは大きく白く光る、閉じたマスは鍵。文字はレッスンの種類（駒のレッスンはその駒） |
| レッスンの間 | 1つ終えるたびに結果の画面 →「次のレッスン」を押す | 同じ章は、盤の上に「クリア！」と★を約1.7秒出して自動で次へ（押せば待たずに）。章の最後だけ「章クリア」の画面で、★とできるようになったことをまとめる |
| 見出しの進み具合 | レッスンの中のステップの点 | 章のレッスンの区切りの帯。いまの区切りを、レッスンの中の進み具合で塗る（短いレッスンが続いて流れていくことを見せる） |
| 閉じたマス | 押せない | 押すと、やこび姫が「光っているマスを終えると遊べるよ」と一言 |

- 対局のレッスン（`play`）は、終局後の結果の画面を残し、「次へ進む」で流れに戻る。
- 実装・自動テスト済み。ブラウザ（ヘッドレスChrome）で、デスクトップ・スマホ縦・タブレット縦の地図・クリアの知らせ・次のレッスンへの自動の移り・章クリア・地図のスクロールを確認した。実機での手動確認は未実施。
- `open-dex`で定跡図鑑を開くときは、図鑑を教室の上に重ねて開き、閉じると教室へ戻る。`id`に戦法のIDを書くとその戦法を、囲いのIDを書くと「囲い」のタブでその囲いを最初に表示する。戦法の練習レッスンの最後では、練習した戦法を開く。
- 盤で指した手、詰将棋の相手の応手、観戦で進めた手には、対局画面と同じ駒音（大駒を取る手と王手は強い音）を鳴らす。再生処理は`src/core/move-sound.ts`で対局画面と共有する。
- レッスン画面は、画面の幅によらず台詞と操作を盤の真下に付けて置く（横に並べると視線が離れて読みにくいため）。盤の枠は、台詞欄の高さを引いた残りに盤の縦横比で収まる大きさをスクリプトで決め、余った高さは台詞の下に残す。内容が多いときは隠さず画面ごとスクロールする。（2026-10-19に、台詞は盤の真上へ移した。18章）
- 第1巻の駒・第4巻の定跡・第5巻の格言レッスンでは、図鑑の見出し向けの文（「〜すること！」など）をそのまま台詞につながず、やこび姫が話しかける文にしている。
- 実装・自動テスト済み。ブラウザ（ヘッドレスChrome）で、スマホ縦（375×667・390×844）、タブレット縦（768×1024・820×1180）、タブレット横（1180×820）、デスクトップ（1366×768・1920×1080）の表示と、駒を動かして自動で次へ進むこと・駒音の再生が呼ばれることを確認した。実機での手動確認は未実施。
- 第4巻の定跡ドリルは定跡図鑑の手順から、第5巻の格言レッスンは手筋図鑑の項目から自動で作る。
- `play`ステップの対局条件（開始局面・手番・CPUのLv・閃き／待ったの回数・駒の利き・助言）はレッスンで固定し、対局準備画面を通さずに始める。条件は教室の画面に一覧で見せる。上書きした通常の対局設定は、教室の対局を終えると元に戻す（中断保存にも控え、リロード後も戻す）。
- 終局すると結果ダイアログの「教室へ戻る」（棋譜解析を完了したときも同様）から教室の結果画面へ戻り、勝敗とやこび姫の一言（レッスンごとの一言を添える）を見せてから★を1つずつ付ける。★は、閃き・待ったを使わずに勝つと3、勝つと2、負け・引き分けでも最後まで指すと1。★とクリアは終局後に記録する。
- 自動テスト（`src/core/tutorial.test.mjs`）で、全ステップの盤面の合法性・正解手・到達可能性・詰み・参照先を検証している。

## 12. 教室の大改良（2026-10-18）

「内容・遊び・画面を大きく強化してほしい。問題集の練習問題を織り込むのもあり」という依頼を受けて、`docs/nintendo-design/`の指針で見直した。

### 12-1. 見直す前の問題

| 指針 | 見直す前 |
|---|---|
| 盤で触らせながら教える（D:6-2、I:9） | 説明のステップが多い。最初のレッスンは説明4つにクイズ1つ。駒のレッスンも説明3つに課題2つ |
| 誘導つきから自由へ（D:6-4） | 「このマスへ動かそう」だけで、自分で道筋を考える課題がない |
| でこぼこ・ギュッとしてパッと（D:4-4, 2-2） | 難しさが平らで、章の終わりに山場がない |
| 前に学んだことを、間をあけて使わせる（D:6-4） | 復習の場面がない |
| ほめてやれ・情報としての称賛（D:5-4, 5-8） | 正解の一言が「正解！ すごいね！」だけで、何が良かったかを言わない |
| ごほうびには使い道（D:5-1） | ★だけで、集めても使い道がない |
| 1つで複数の課題を解く（D:2-5） | 問題集の練習問題・詰将棋と、教室の詰みのレッスンが別々にある |

### 12-2. 設計メモ（Game_Nintendo_Design.mdの14章の形）

- **一言で**：やこび姫と、盤を触りながら「できた！」を積み重ね、章の終わりの腕だめしで力を試す教室。
- **解く課題**：説明が長い／山場がない／復習がない／★に使い道がない／問題集と教室が別々、を、「課題を増やす」「章末の腕だめし」「メダルと称号」「問題集の問題を教室で解く」で同時に解く。
- **リスクとリターン**：駒取りゲームは、少ない手数で取りきるほど★が増える（最短手数を目標として見せる）。腕だめしは、まちがえずに解くほど良いメダルになる。
- **溜めと解放**：章の中は短い課題の連続（平地）、章の終わりに腕だめし（山場）。腕だめしを越えるとメダルの判を押し、章クリアでまとめてほめる。巻を終えると称号。
- **初めての人の最初の1分**：1つ目のレッスンで、説明1つのあとすぐ盤の駒を動かす。動かすたびに駒音、正解ではなまるが盤に出る。
- **上級者の深さ**：腕だめしの金メダル（まちがえずに解く）、駒取りの最短手数、3手詰めドリル、問題集の詰将棋。地図ではどのマスからでも遊べるよう、章ごと飛ばせる道は残す。
- **失敗したとき**：その場ですぐやり直せる（局面を戻すだけ）。まちがえるたびにヒントが1段ずつ強くなる。駒取りで取りきれなくなったら、自動で最初の局面に戻す。体力やライフは作らない（失敗しても先へ進める）。
- **ご褒美と使い道**：★（レッスン）、メダル（章の腕だめしの★で金・銀・銅）、称号（巻を終えると「〇〇 修了」。やこびノートの称号に残る）。問題集の練習問題・詰将棋を教室で解くと、問題集の記録にも付く。
- **ほめる瞬間**：正解ごとに、何が良かったかを1文で言う（課題の`praise`）。続けて正解すると「2れんぞく！」。駒取りを最短で取りきったら「最短！」。腕だめしをまちがえずに解いたら金メダル。
- **捨てるもの**：体力・ライフ・時間制限（失敗を罰にしない）。腕だめしの不合格（何度まちがえても最後まで解けばクリア。メダルの色で差を付ける）。レッスンごとの結果の画面（今までどおり、章の終わりにまとめる）。
- **確かめ方**：駒の動きを知らない人に、説明なしで第1巻を遊んでもらい、どこで止まるかを見る（実機での確認はユーザーが行う）。

### 12-3. 新しい課題の種類

| 種類 | 内容 | 判定 |
|---|---|---|
| `capture` | 駒取りゲーム。盤の1つの駒だけを動かして、相手の駒を全部取る。玉は置かない | 相手の駒が盤からなくなったら正解。目標の手数（`par`、最短手数）以内なら「最短！」、超えたら★の計算でまちがい1回に数える。歩・香・桂は、取りきれなくなったら最初の局面に戻す |
| `problem` | 問題集の問題（練習問題・詰将棋）を、問題集と同じ判定（`judgeProblemMove`）で解く。`problemId`で参照する | 問題集と同じ。相手の応手も問題集と同じ。解くと問題集の記録にも付く |

### 12-4. 腕だめし・メダル・称号

- 腕だめしは、章の最後のレッスン（`boss: true`）。その章の課題に、前の章の課題を1〜2問混ぜる（間をあけた復習）。観戦だけの章には置かない（平地）。
- メダルは保存せず、腕だめしのレッスンの★から決める（★3＝金、★2＝銀、★1＝銅、スキップは無し）。地図の章の看板、章クリアの画面に出す。
- 巻のすべてのレッスンを終え（クリアかスキップ）、その巻の腕だめしをすべてクリアすると、称号「将棋教室 第N巻 修了」（第5巻は「将棋教室 卒業」）を渡す。腕だめしをスキップしただけでは渡さない（称号は力を試した記録にする）。
- 称号の保存は、対局画面の称号（`player-profile.mjs`）に任せる（教室は`grant-title`で知らせるだけ）。順位（rank）は巻の番号（1〜5）で、竜王戦の称号（10〜）より低くし、ホームの所属の表示を竜王戦より先に変えない。教室を開くたびに、終えた巻の称号をまとめて知らせる（前の版で終えていた巻にも渡すため）。

### 12-5. 実装状況（2026-10-18）

| 項目 | 前 | 後 |
|---|---|---|
| レッスン | 48 | 61（ドリル3、腕だめし10を追加） |
| 課題（盤で指す・選ぶ） | 97（全ステップの42%） | 179（57%）。テストで、説明のステップが半分未満であることを確かめる |
| 駒取りゲーム | なし | 13問。目標の手数は、探索（`captureMinMoves`）で求めた最短の手数とテストで一致させる |
| 問題集の問題 | なし | 23問（練習問題10問すべてと、1手・3手詰めの詰将棋） |

- 第1巻の「将棋盤を見てみよう」は、説明4つとクイズ1つから、説明3つと課題3つ（マスの名前だけで玉を動かす`hideTarget`の課題を含む）にした。
- 駒のレッスンは、説明3つと課題2つから、説明2つと課題3つ（駒取りゲームを追加）にした。めあては「〇〇の動きがわかる」と短くした。
- 問題集の問題は、正解のあと自動では進めない（解説が長いため）。逃げる問題は、問題集と同じく、答えのあとの続きの1手まで指す。

- 実装・自動テスト済み。ヘッドレスChromeで、スマホ縦（390×844・360×640）・スマホ横（844×390）・タブレット縦（820×1180）・デスクトップ（1366×768）について、駒を動かす課題・駒取りゲーム（最短）・問題集の逃げる問題（まちがい→正解）・第1章の腕だめし（金メダル）を実際に操作して確かめた。実機での手動確認は未実施。

## 13. 見える化と、囲いの教え方（設計 2026-10-18）

「囲いを教えるとき、初期配置がとても弱く、囲った形が強いことを上手く説明したい」「駒の利きの見える化をもっと使いたい」「駒得したら緑で＋6、駒損したら−5と分かるようにしたい」「ほかにも改善点を探して、明快で楽しい教室にしたい」という依頼を受けた設計です。
`docs/nintendo-design/`の`Game_Nintendo_Design.md`（D）と`UI_Nintendo_Design.md`（U）に基づきます。章番号は「D:2-1」「U:5-3」のように書きます。

### 13-1. いまの問題

第3巻〜第5巻を中心に、レッスンの中身（ステップの種類の並び）を洗い直しました。

| 見つけたこと | いまの中身 | 外れている指針 |
|---|---|---|
| 囲いのレッスンで、盤を触らない | 「囲いで玉を守ろう」は説明2つ・図鑑・クイズ1つ。囲いが強いことを、言葉で言うだけ | 説明より先に盤で触れる（D:6-2）。テキストは最後の手段（U:6-1） |
| 居玉が弱い理由を見せていない | 「金銀3枚で守る」と言うだけ。初期配置も玉のそばに金銀があるので、言葉だけでは違いが伝わらない | 遊びの中心（どこが危ないか）を見せる（D:2-1） |
| 駒の価値が盤で見えない | 「駒の価値を知ろう」は説明・図鑑・クイズ。点数は文章の中だけ | 数字は身近な形で、その場で見せる（D:5-5、U:6-1） |
| 駒の利きの表示が教室にない | 利きの表示は学習対局だけ。教室では、駒を選んだときの青い点だけ | 「どこが危なく、何が取れるか」を盤上で見せる（D:2-1、11章の適用表） |
| 攻めと守りのコツが薄い | 第3巻3章の4レッスンは、どれも説明1つと課題1つ | 導入→展開→転調→結末（U:6-3） |
| 形勢判断が文章ばかり | 「形勢の3つのものさし」は説明3つとクイズ1つ。ものさしを盤で使わない | 上達が見える（D:6-1） |
| まちがえた理由が分からない | 取られる場所へ動かしても、「ちがうよ」と局面が戻るだけ。何が起きるかを見せない | 失敗した原因が自分で納得できる（D:7-2） |

### 13-2. 全体の考え：形勢の3つのものさしを、盤の上に見せる

第5巻で教える形勢判断の3つのものさし（駒の損得・駒の働き・玉の堅さ）を、それぞれ盤に見える道具にし、第1巻から少しずつ使わせます。依頼の3つは、この3つのものさしにそのまま当たります。

| ものさし | 見える化 | 初めて出る場所 | 第5巻での使い道 |
|---|---|---|---|
| 駒の損得 | **駒得の数字**：取ったら緑の「＋6」、取られたら赤の「−5」。課題の中の合計も出す | 第1巻の駒取りゲーム（説明より先に数字を見せる） | どちらが駒得かを数字で比べる |
| 駒の働き | **利きメガネ**：各マスに利いている駒の数を色と数字で見せる。取られるマスと、玉の逃げ道も見せる | 第2巻1章の新しいレッスンで手に入れる | 働いている駒と、遊んでいる駒を見分ける |
| 玉の堅さ | **攻めくらべ**：同じ攻め駒で、居玉と囲いを実際に攻めてみる。詰むまでの手数で堅さを比べる | 第3巻1章（囲いのレッスン） | どちらの玉が詰みに近いかを比べる |

- 1つの仕組みで、依頼の3つと、第3巻・第5巻の中身の薄さを同時に解きます（D:2-5）。新しいルールは足さず、駒・利き・詰み探索という既にある要素を組み合わせます（D:2-6）。
- 玉の堅さは、点数の式（玉のそばの金銀の数など）にしません。初期配置も玉の両隣に金がいるので、式では居玉が堅く見えてしまいます。実際に攻めて「何手で詰むか」で見せるのが、正しく、いちばん伝わります（D:12「将棋として正しいか」）。

### 13-3. 駒得の数字（＋6／−5）

Game_Nintendo_Design.md 14章の形：

- **一言で**：駒を取ると、その駒の値段が緑で浮かぶ。取られると赤で浮かぶ。
- **解く課題**：駒の価値を、説明する前に体で覚える。交換の損得を、言葉ではなく数字の動きで見せる。駒取りゲームを、点数を集める遊びにする。
- **リスクとリターン**：取りに行った駒が取り返されると、「＋5」のあとに「−10」が出て、合計が赤になる。取りに行く前に、取り返されないかを考える理由になる（D:2-1）。
- **溜めと解放**：交換が続くあいだは合計が揺れ、最後に緑で止まると解放。大駒（8点以上）を取ったときは、重さの段階3（80ms止める、強い駒音）にする（D:3-2、`Game_Nintendo_Implementation.md`の3-1）。
- **初めての人の最初の1分**：第1巻の駒取りゲームで、取るたびに「＋1」「＋6」が浮かび、合計が増える。値段の説明はまだしない。第2巻の「駒の価値を知ろう」で、「いままで出ていた数字が、駒の値段だよ」と種明かしする（見せてから言う。U:6-1）。
- **ほめる瞬間**：駒取りゲームを取りきったら「全部で＋12！」。詰みの課題で駒を捨てて詰ませたら、合計が赤でも「駒損でも、詰ませれば勝ち！」とほめる（格言「終盤は駒の損得より速度」につなぐ。情報としての称賛、D:5-8）。
- **捨てるもの**：成りの「＋6」（成りは駒得と別の考えなので、混ぜない）。対局者を良い・悪いと判定する表現（U:8）。

UI_Nintendo_Design.md 10章の形：

- **画面の主役**：盤。数字は取った升の上に、升の4割ほどの大きさで浮かび、0.9秒で上へ消える。操作は止めない。
- **合計の置き場所**：吹き出しの上の行（課題の種類の右）に「駒得 ＋1」（緑）、「駒損 −4」（赤）、「とりかえ ±0」（灰）。その課題で駒の取り合いが起きたときだけ出し、課題が変わると消す（必要なときだけ。U:4-1）。
- **色だけに頼らない**：符号（＋／−）と言葉（駒得／駒損）を必ず添える（U:5-3、色の見分けにくさ）。数字には白い縁取りを付け、木目の上でも読めるようにする。
- **メッセージ分類**：「通常」。大駒を取ったときだけ少し大きくする。「特別」は使わない（乱発しない。U:5-3）。
- **値段**：駒図鑑の「駒の価値 tier表」と同じ値（歩1・香3・桂4・銀5・金6・角8・飛10）。成った駒を取ったときは、持ち駒になる元の駒の値段にする（と金を取ったら＋1。2026-10-18にユーザーが決定）。tier表と教室で値を二重に持たないよう、値は1か所（`src/core/piece-points.mjs`）にまとめ、tier表もそこから読む。
- **出す場所**：教室の盤と学習対局（教室から始めた対局を含む。2026-10-18にユーザーが決定）で駒が取られるすべての場面。教室では自分の手、詰将棋・問題集の相手の応手、下の「取り返しの再生」、観戦（観戦の合計は「▲先手 ＋3」のように先手から見た値で、戻る・進むに合わせて計算し直す）。
- **見ている人への配慮**：数字は離れて見ても読める大きさにする（U:8）。

### 13-4. 利きメガネ（駒の利きの見える化）

- **一言で**：メガネをかけると、どのマスを誰が見張っているかが見える。
- **解く課題**：「タダで取られる」「タダで取れる」が見えない／詰みの理由（逃げ道がない）が見えない／ヒントが答えの矢印しかない、を同時に解く。
- **ご褒美と使い道**：第2巻1章の新しいレッスン「利きを見よう」の最後で、やこび姫から「利きメガネ」をもらう（道具を手に入れる喜び、D:5-3。道具にすることは2026-10-18にユーザーが決定）。そのあとは、どのレッスンでも見出しのメガネのボタンで付け外しできる。付けても★は減らさない（答えではなく、見方を教える道具なので。D:4-5「ズルを許す」）。付けた・外したは保存する。

見せ方は4つです。

| 見せ方 | 何を見せるか | いつ出すか | 色 |
|---|---|---|---|
| 利きの地図 | 各マスに利いている先手・後手の駒の数 | メガネを付けたとき。レッスンが`kiki`で指定したとき | 学習対局と同じ。先手は青、後手は赤、両方は紫の面と数字 |
| 取られるマス | 駒を選んだとき、動かすとタダで取られる行き先（動かしたあと、相手の利きがあり、自分の利きがない） | メガネを付けたとき。`danger: true`のレッスン | 青い点の外側に赤い輪 |
| 玉の逃げ道 | 相手の玉のまわり8マス。自分の駒が利いているマス、玉の味方の駒がふさいでいるマス、逃げられるマス | 詰ませたとき（詰みの理由として）、詰みの課題の1段目のヒント、攻めくらべの終わり | 利いているマスは青の面、逃げられるマスは緑（大事なマス）、ふさいでいるマスは印なし |
| 取り返しの再生 | 取られるマスへ動かしてまちがえたとき、相手がいちばん安い駒で取り返す手を指して見せ、「−10」を出してから局面を戻す | `refute: true`のレッスン（第2巻1章、第3巻3章） | 駒得の数字と同じ |

- **ヒントの段階を変える**：1段目のヒントを「見方」にし、2段目を答えの矢印にする（今は1段目がマス、2段目が矢印）。たとえば、タダの駒を探す課題では1段目で利きの地図を、詰みの課題では玉の逃げ道を出す。答えを言う前に、見方を渡す（U:6-1）。
- **出しすぎない**：利きの地図を、いつも出したままにしない。数字が多いと盤が読みにくくなるため（U:4-1）。レッスンが決めた場面と、メガネを付けたときだけにする。
- **初めて出たとき**：色の意味を、一度だけ一言で伝える（「青い数字は君の駒、赤い数字は相手の駒が見張っている数だよ」。U:6-2）。
- **色の約束**：`AGENTS.md`の「盤面の色の使い分け」に従う。緑は「大事なマス」なので、逃げ道（ここが大事）に使う。黄色は使わない。取られるマスの赤い輪は、相手の利き（赤）と同じ色相にする。実装したら、表に「利きの地図」と「赤い輪」を足す。

### 13-5. 攻めくらべ（居玉と囲い）

依頼の中心です。「初期配置は弱い」を、言葉ではなく、自分の攻めで確かめさせます。

- **一言で**：同じ攻め駒で、居玉と囲いを攻めくらべる。居玉はあっさり詰むのに、囲いはびくともしない。
- **解く課題**：居玉が弱いこと、囲いが強いこと、囲いを組む理由、を1つの体験で伝える。
- **流れ（ギュッとしてパッと。D:2-2）**：
  1. 相手は居玉（初期配置の金銀のまま）。竜と持ち駒の金で「王手で攻めて、詰ませてみよう」。3手で詰む（気持ちいい）。
  2. 詰んだ局面で、玉の逃げ道を出す。「玉のまわりの金銀が、逃げ道をふさいでいたね。真ん中の玉は、攻めがすぐ届くんだ」。
  3. 同じ竜と金で、今度は美濃囲いを攻める。王手を続けても詰まない（あれ？＝ギュッ）。
  4. 王手が続かなくなったら「守りきられた！」。くらべた結果を並べる：「居玉　3手で詰み／美濃囲い　詰まない」（パッ）。
  5. 「じゃあ、君の玉も囲ってみよう！」と、次の「囲いを組もう」へつなぐ（体験が動機になる）。
- **ルール**：王手だけを指せる。王手でない手は、駒をぽんと戻して「王手で攻めてみよう」（不可の分類。まちがいに数えない。U:5-4）。相手は、詰み探索でいちばん長く逃げる手を返す（`problem-solver.ts`の`findEscapeReply`）。王手の数は「王手 2回」のように出す。詰まない囲いは、王手を3回するか、王手が続かなくなったらクリア（`ATTACK_TEST_MAX_CHECKS`）。王手が続く回数は囲いで違う（美濃囲いは2回、舟囲いは3〜4回）ので、台詞でも札でも上限の回数は約束しない（2026-10-19。「王手を5回」と書いていたが、5回は指せなかった）。
- **失敗したとき**：居玉を詰ませられなかったら、通常の詰みの課題と同じヒント（1段目は逃げ道、2段目は矢印）。美濃囲いは詰まないのが正解なので、どう指してもクリア。
- **ほめる瞬間**：居玉を最短で詰ませたら「3手で詰んだ！ 居玉は弱いね」。美濃囲いでは「あきらめずに攻めたね。それでも詰まないのが囲いの強さだよ」。
- **局面の条件（テストで確かめる）**：
  - 居玉の局面と囲いの局面で、攻める側の駒（盤の上と持ち駒）を同じにする。
  - 居玉の局面は、3手以内に詰む。
  - 囲いの局面は、詰み探索で9手以内に詰まない。
  - 試作の結果：後手が居玉（`ln1gkg1nl/2s3s2/pppppp1pp/6p2/...`、銀は攻めに出た形。3四歩と突いた形で、2026-10-19に三段目の歩を直した。前は3三と3四に歩が並ぶ二歩だった）、先手が5五の竜と持ち駒の金のとき、居玉は▲5三竜△5二金▲6二金の3手で詰む。同じ攻め駒で、後手の美濃囲い（8二玉・7二銀・6一金・5二金）は11手以内に詰まない（`findMateLine`で確認）。
- **捨てるもの**：囲いの堅さの点数。CPUと最後まで指す攻防（長くなるので、王手の連続だけにする。D:9-1）。

### 13-6. 囲いを組もう

- **一言で**：半透明の「完成形」に向けて、自分で金銀と玉を動かして囲いを組み立てる（ものづくりの楽しさ。D:2-3）。
- **ルール**：
  - 囲いに使う駒（玉・金・銀、囲いの手順にある歩）だけを動かせる。ほかの駒は選べない。反則を最初から選べないのと同じ考え（U:5-4）。
  - 相手はお休み（今の`move-piece`と同じく、先手だけが続けて指す）。
  - 目的のマスには、置くべき駒を半透明で表示する。駒が着くたびに「カチッ」と止まり（段階2）、半透明の駒が消える。
  - 完成すると「美濃囲い 完成！」（特別の分類）。金銀がたがいに守り合う線（ひも）を一瞬引いて、「金と銀が手をつないでいるね」。目標の手数以内なら「最短！」。
- **手順の元**：定跡図鑑と同じ`opening-guide.mjs`の囲いの定義（`completionSquares`と`blackMoves`）から作る。目標の手数は、手順の長さと、探索で求めた最短の手数を、テストで一致させる。
- **`AGENTS.md`の囲いの決まり**：振り飛車用の囲い（美濃）は、先に飛車を振る（`blackMoves`の最初の手）。囲いの定義に振り飛車の手順を入れない決まりは、レッスンの側で「飛車を振る」課題を先に置くことで守る。
- **腕だめしでは**：半透明の駒を出さず、囲いの名前だけで組ませる（第1巻の`hideTarget`と同じ）。
- **ご褒美の使い道**：完成したら「対局で美濃囲いを完成させると、コレクションに印がつくよ」と、対局のコレクションへつなぐ（D:5-1）。教室で組んだだけでは印を付けない（印は対局で使った記録にする）。

## 14. 教室の仕上げと、教室と対局のつながり（設計 2026-10-18）

13章の見える化を公開したあとの次の段階。13-8で後回しにした候補と、教室で覚えた見方を対局でも同じ見た目で出すことをまとめて行う。

### 14-1. 設計メモ（Game_Nintendo_Design.mdの14章の形）

- **一言で**：まちがえた課題だけをすぐ解き直せて、教室で覚えた「利き・逃げ道・囲い」が、ふだんの対局でも同じ印で見える。
- **解く課題**：復習が腕だめしにしかない（D:6-4）／「駒を並べよう」が説明とクイズだけ（D:6-2）／第4巻の定跡ドリルで形の意味が見えない／教室の道具が対局で使えず、上達が対局につながって見えない（D:6-1）。
- **リスクとリターン**：にがてをもう1回は、まちがえずに解くと「にがて」から消える（残りが減るのが見返り）。
- **溜めと解放**：対局で囲いが完成した瞬間に「美濃囲い 完成！」と知らせる（ものづくりの解放。D:2-3）。
- **初めての人の最初の1分**：第1巻の「駒を並べよう」で、持ち駒を薄い完成形のマスへ打っていくと、最初の並べ方ができあがる。
- **上級者の深さ**：利きメガネを持っていれば、対局の「駒の利き」で取られるマス（赤い輪）も見える。
- **失敗したとき**：にがてをもう1回は、何度でもすぐ始められる。まちがえても★は減らない（★はレッスンの記録だけ）。
- **ご褒美と使い道**：利きメガネは学習対局でも使える（教室で手に入れた道具の使い道を増やす。D:5-1）。囲いの完成は、対局のコレクションの印につながる（初めての囲いなら「はじめて！」と添える）。
- **ほめる瞬間**：にがてを解いたら「にがて克服！」。対局で囲いを完成させたら、名前を出して知らせる。
- **捨てるもの**：にがての出し直しの日数（問題集の1日後・3日後・7日後）。教室は自分で選んで開くので、今回は章の中の苦手を数えるだけにする。対局中の玉の逃げ道を常に出すこと（王手されたときと、詰んだ局面だけ）。
- **確かめ方**：教室を一通り遊んだ人に、章クリアから「にがてをもう1回」を押してもらい、迷わず戻れるかを見る。

## 15. 駒得まで指す手筋と、序盤・中盤・終盤の作戦（2026-10-18）

「両取りをかけたあとなどに、駒得するまで指せるようにしたい」「序盤・中盤・終盤の方針を教室で教えたい」という依頼を受けた設計と実装。

### 15-1. 設計メモ（Game_Nintendo_Design.mdの14章の形）

- **一言で**：手筋をかけたら、相手の受けまで見て、駒得するところまで自分の手で指しきる。そのうえで、一局を序盤・中盤・終盤に分けて「いま何をする時間か」を、盤で触って覚える。
- **解く課題**：両取りの課題が、かけた1手で終わり、相手が逃げたあと本当に得をするところまで見えない（D:2-2 溜めと解放の「解放」がない）／序盤・中盤・終盤で何を考えればいいかが、どこにも書かれていない（D:6-1 次に学ぶ1つを示す）。
- **リスクとリターン**：さそいの歩は1点損をする（−1）。それで両取りの形を作り、金を取って合計＋5。「わざと損をして、もっと得をする」を数字で体験させる（D:2-1）。
- **溜めと解放**：両取り（溜め）→相手の受け→取りきる（解放）。取った瞬間に駒得の数字（＋6）が浮かび、合計の札が「駒得 ＋6」に変わる。
- **初めての人の最初の1分**：第2巻の「両取りをかけよう」で、桂を跳ねると相手の飛車が逃げ、残った金を取ると「合計＋6の駒得！」。
- **上級者の深さ**：相手は、損得がいちばん小さくなる受けを自分で選ぶ（決めた手順ではない）。銀の両取りでは、相手が飛車で金を守るので、取っても取り返されて「金と銀の交換で＋1」になる。うまく受けられても得になることまで見せる。
- **失敗したとき**：取らない手・安い駒を取る手はまちがいに数え、局面はそのまま（もう一度選べる）。取られて損をする取り方は、取り返しを見せてから戻す。角打ちの隙・詰めろの受け損ないも、相手の打ち込み・詰ませる手を見せてから戻す（なぜだめかが盤で分かる。D:7-2）。
- **ご褒美と使い道**：合計の駒得の数字。章の腕だめしのメダル（12-4）。
- **ほめる瞬間**：「合計＋5の駒得！」と、何が良かったか（「歩1枚を捨てて、金を両取りのマスへさそい出した」）を1文で言う（D:5-8）。
- **捨てるもの**：相手の応手を教材に書くこと（守る側の手は読みで決める。別の受け方をされても課題がこわれない）。終盤の長い説明（詰めろ・受け・連続王手を、それぞれ1つの課題にする）。序盤の定跡の暗記（第4巻のドリルに任せ、ここでは考え方だけ）。
- **確かめ方**：駒の動きを知っている人に、第2巻の両取りと第5巻の新しい章を遊んでもらい、合計の数字を見て「得をした」と分かるか、終盤の連続王手のわけを言えるかを聞く（D:10-2）。

### 15-2. 新しい課題の書き方

すべて`find-move`の書き足しで、判定は`src/core/tutorial-runner.mjs`、損得の読みは`src/core/material-tactics.mjs`（駒の値段は`piece-points.mjs`）。

| 書き方 | 内容 | 判定 |
|---|---|---|
| `untilGain: N`（`plan`） | 手筋をかけたあと、駒得するまで指す。1手目は`answers`、2手目からは`plan`（さそいの歩のあとの両取りなど）、そのあとは取る手 | 取る手は、いまいちばん得な取り方（取られて損をする形なら、その駒の値段を引いて比べる）。相手の応手は、攻める側の次の損得がいちばん小さくなる受け（`defendingReply`）。合計の損得がN以上で正解。最後に取った駒が取り返される形なら、取り返しまで見せる |
| `guardDrop: "B"` | 持ち駒を打ち込まれる隙を消す（角換わりの角打ち） | 指したあと、相手がその駒を打って両取りをかけ、受けのあとも駒得できる打ち込み（`dropThreat`）がなく、ほかに取られる駒もなければ正解。まちがえたら打ち込みを見せる |
| `threat: "mate"` | 詰めろをかける | 王手でなく、相手が何もしなければ次に1手で詰む手なら正解（詰ませる手も正解）。王手はまちがいに数えて「王手をしないで」と伝える |
| `defend: "mate"` | 自玉の詰めろを受ける | 指したあと、相手に1手で詰まされなければ正解。まちがえたら詰まされる手を見せる |

- 教材の局面では、自分の玉を1九に置き、1八の香と2九の金で囲う。相手の飛車が、王手や玉へのピン（駒を動けなくする手）で両取りから逃げられないようにするため。読みを入れてから、これらの逃げ道が見つかった局面を直した。
- テスト（`tutorial.test.mjs`）で、すべての`untilGain`の課題が、お手本と相手のいちばん良い受けで目標の損得に届くこと、手筋なしでは届かないこと、`guardDrop`は指す前に隙があってお手本で消えること、`threat`は1手詰めがなくお手本が詰めろであること、`defend`は相手の番なら1手で詰む形でお手本で受かることを確かめる。

## 16. 格言・手筋をはじめから、図鑑をその場で、読む量を減らす（設計 2026-10-19）

「最初のほうから手筋や格言の紹介をところどころ挟みたい」「図鑑をわざわざ見に行かせるのは面倒なので、図鑑の内容を説明に使い、その場で見られるようにしたい」「やこび姫の説明は盤の外にあり、視線を動かさないといけないので、読むのが少し面倒」という声を受けた設計。`docs/nintendo-design/`の`Game_Nintendo_Design.md`（D）・`UI_Nintendo_Design.md`（U）・`UI_Nintendo.md`（N）に基づく。

### 16-1. いまの問題（2026-10-19に数えた）

### 16-2. 設計メモ（Game_Nintendo_Design.mdの14章の形）

- **一言で**：大事なことは盤の上で、そのマスのそばに一言で出す。格言は、いま指した手そのものに「この手の名前は〇〇！」と札を付けて、第1巻から少しずつ集める。
- **解く課題**：視線の行き来（盤の上のひとこと）／文が長い（1ステップ1つのこと・40字まで）／色を言葉で探させる（色の札）／図鑑へ行く手間（その場の図鑑）／格言が最後にまとまっている（格言札を各巻に散らす）を、「盤の上に出す」という1つの方針で解く（D:2-5）。
- **リスクとリターン**：格言札はクイズにしない。自分で指した手に名前が付くことが見返り。
- **溜めと解放**：課題を解く（溜め）→ はなまる → 格言札がひらりと出る（解放）。札は格言帳（手筋図鑑）に入り、図鑑の項目が光る。
- **初めての人の最初の1分**：第1巻の銀のレッスンで、銀を斜めに動かして駒を取ると、札「銀は千鳥に使え」が出る。読まなくても、盤の上の一言（「ジグザグに進む」）と矢印で分かる。
- **上級者の深さ**：格言帳で、集めた格言を盤つきで見返せる（いまの手筋図鑑。集めた格言に★）。第5巻の格言の章は「総まとめ」として残し、格言の名前だけで手を探す力試しにする。
- **失敗したとき**：格言札はまちがえても出す（解き終えたら出す。罰にしない）。
- **ご褒美と使い道**：格言帳の★。図鑑で見返せる。対局のやこび姫の助言で、同じ格言の手を指したときに「〇〇だね！」と名前で呼ぶ（教室と対局をつなぐ。D:5-1。対局側は別の段階で作る）。
- **ほめる瞬間**：札を出すときの一言を「いま君が指した手が、これ！」にする（自分の手が名前の付いた手筋だったと分かる。D:5-4）。
- **捨てるもの**：教室から図鑑の画面へ移る「図鑑を見てみよう」のステップ（その場の図鑑に置き換える）。説明だけの格言紹介（必ず盤で指す課題と組にする）。長い説明文（40字を超える文は分けるか、くわしくの中へ）。
- **確かめ方**：将棋を知らない人に第1巻を遊んでもらい、盤から目を離した回数（下の吹き出しを読みに行った回数）と、レッスンのあとに覚えている格言を数える（D:10-2）。

### 16-3. 盤の上のひとこと（視線を動かさない）

- 盤の上のひとことは、ステップのデータから**自動で作る**（2026-10-19に決定）。しっぽ付きの小さな札（14字まで）を、見るマスのそばに出す。
  - 札はマスの上に出し、盤の上端なら下に、ほかの印のマスや駒に重なるなら左右へずらす（印と駒を隠さない。N:2-5）。
  - 1つの画面に1つだけ。課題では、正解のマスではなく「見るところ」（ねらう駒・大事なマス）に付ける（答えを書かない）。
  - どうしても言い回しを変えたいステップだけ、`note: { at, text }`で上書きできる（例外。基本は自動）。
- 自動で作るきまり（上から順に、最初に当てはまったもの1つ）:

| 場面 | どのマスに | 文 |

| 囲いを組もう | 薄い駒の1つ目 | 「ここへ組む」 |
| まちがえて取り返しを見せるとき | 取られたマス | 「取られる！」 |
| 正解したとき | 動かした駒 | ほめ言葉の最初の一句（「両取り！」。「！」で終わる14字までの一句だけ。「。」で終わる一句は説明なので出さない） |

  - どれにも当たらないステップには出さない。
  - テストで、すべてのステップについて、作られた札が14字まで・盤の中・印と駒に重ならないことを確かめる。
- 吹き出しの文は「1ステップ1つのこと、40字まで」にする。
  - いま60字を超える33ステップは、2つのステップに分けるか、盤の上のひとことに移す。
  - テストで、説明の文を60字まで、ひとことを14字までに保つ（目安は40字）。
- 色の札：吹き出しの文の「緑のマス」「赤いマス」「青い点」「赤い数字」「青い数字」の前に、盤と同じ色の小さな札（■）を自動で付ける。言葉と盤の色が同じ形で結びつく（`AGENTS.md`の盤面の色の表と同じ色）。
- 正解したときの一言（`praise`）の最初の一句（「両取り！」など）を、はなまると一緒に、動かした駒のマスのそばにも出す。吹き出しには続きの文だけを出す。
- 吹き出しの位置は変えない（盤の下、横長の画面では右）。盤の上に大事なことが出るので、吹き出しは「くわしく読みたい人が読む」場所になる（N:2-6 なければない方がよいが、なくせない）。

### 16-4. その場の図鑑（図鑑の画面へ行かない）

- `open-dex`のステップをやめ、`dex: { kind, id }`を書いた説明のステップにする。図鑑の項目を、そのレッスンの盤と吹き出しで見せる。
  - 盤：図鑑の局面・印・矢印（`sfen`・`marks`・`arrows`・`pieceSquare`）をそのまま使う。
  - 盤の上のひとこと：図鑑の見出し（「ふんどしの桂」）。
  - 吹き出し：図鑑の一言（`overview`）。図鑑の行（「意味」「使いどころ」「ポイント」）は、画面を押すたびに1行ずつめくる（3行なら3回。長い表を一度に見せない）。
  - 吹き出しの下に「図鑑でくわしく」の小さなリンクを残す（2026-10-19に決定）。押すと図鑑の画面をレッスンの上に重ねて開き、閉じるとレッスンの同じステップへ戻る（いまの、教室から図鑑を開いて戻る仕組みを使う）。押さなくても先へ進める。
- 駒の価値の表（`piece-values`）は、吹き出しの中に「歩1・香3・桂4・銀5・金6・角8・飛10」の駒の札を1行で並べる。
- 定跡（`kind: "opening"`）は、作戦カードと同じ小さな盤（`FormationThumb`）で完成形と手順の再生を見せる（やこび姫補助の作り直しで作った部品を使う）。
- 図鑑のデータは図鑑の1か所に置いたまま、IDで参照する（同じ説明を二重に持たない。4章）。

### 16-5. 格言札（第1巻から少しずつ）

- 課題のステップに`proverb: "<手筋図鑑のID>"`を書けるようにする。課題を解き終えたら（まちがえても）、盤の上に格言札を出す。
  - 札：格言の名前（大きく）と、図鑑の一言（`overview`）。盤はいま指したあとの局面のまま（図鑑の局面に切り替えない）。いま指した駒のマスを緑で示す。
  - やこび姫の一言：「いま君が指した手が、これ！」。
  - 押すと次へ進む。1レッスンに1枚まで。全部のレッスンには付けず、新しい手筋が自然に出てくるレッスンだけにする（16-5の表。第1巻は17レッスンに7枚。多すぎると特別さが薄れる。D:3-2）。

### 16-10. 読み上げ

- **一言で**：やこび姫の吹き出しを、端末の音声で読み上げる。盤から目を離さずに説明を聞ける（文字を読むのが苦手な子どもにも届く。D:6-2「言語がなくてもわかるように」に近づける）。
- **仕組み**：ブラウザの音声合成（Web Speech APIの`speechSynthesis`、日本語の声）を使う。新しい音声ファイルは作らない。
- **切り替え**：教室の見出しの帯に「読み上げ」のボタン（スピーカーの印。押すたびにオン／オフ）。既定はオフ（急に声が出ると驚くため。音は最初の操作のあとに有効にする。U実装:5）。選んだ状態は`localStorage`に保存する（キーは`yacobihime:shogi-match:tutorial-voice:v1`の形。READMEに書く）。日本語の声がない端末では、ボタンを出さない。
- **読むもの**：ステップが変わったときの吹き出しの文と、正解・まちがいの一言。盤の上のひとことは読まない（吹き出しと重なるため）。新しい文を読むときは、前の読み上げを止める（重ねない。U実装:5「同じ音の連打では前の音を止める」）。レッスンを離れたら止める。
- **読み方の直し**：音声合成は将棋の符号や駒の名前を読み違えるので、読む前に読み方を直す（`src/core/tutorial-voice.mjs`の純粋な処理にしてテストする）。
  - 「▲７六歩」→「せんて、なな ろく ふ」、「△３四歩」→「ごて、さん よん ふ」。
  - 駒：歩→ふ、香→きょう、桂→けい、角→かく、飛→ひ（「飛車」は「ひしゃ」）、と→と、成→なり、打→うつ。
  - 「＋6」→「プラス6」、「−5」→「マイナス5」、「★」は読まない。
- **音を消していても伝わる**：読み上げは吹き出しの文と同じ内容だけにし、読み上げにしかない情報は作らない（U実装:5「音だけで意味を伝えない」）。
- **作る順番**：16-8の段階1（盤の上のひとこと）と一緒に作る。

## 17. 分かるところから始める（設計 2026-10-19）

「最初にどの程度将棋を分かるか聞いて、それにあった部分から始められるようにしたい。ルールは分かるけど、定跡は一切知らない人は結構いそう」という依頼を受けた。
`Game_Nintendo_Design.md`（4-1, 4-3, 6-1, 6-2, 3-3）と`UI_Nintendo_Design.md`（2, 3-2, 5-2, 6-1）を読んで設計した。

### 17-1. いまの問題

| 指針 | いま |
|---|---|
| すぐ遊ばせる（D:3-3）、盤が出るまで最大2回（U:3-2） | 教室を初めて開くと、地図のいちばん上「将棋盤を見てみよう」から始まる。ルールを知っている人も、盤の筋・段と駒の動きを12レッスン以上こなすか、章の看板の「この章をとばす」を何度も押す必要がある |
| 課題と技能の釣り合い（D:6-1 フロー） | 知っていることの繰り返しで退屈し、教室をやめてしまう |
| 次に学ぶ1つを示す（D:6-1） | 「ルールは分かるが定跡は知らない」人が、どこから始めればよいか分からない。章をとばす操作は、とばした先が自分に合うか分からない |
| 初心者にはやさしく（D:4-1） | はじめての人には今のままでよい |

ホームの「はじめての案内」（`welcome.mjs`）は将棋の経験を3択で聞くが、答えは「教室・対局・棋力測定のどれから始めるか」にしか使っていない。教室の中のどこから始めるかは決めていない。

### 17-2. 設計メモ（Game_Nintendo_Design.mdの14章の形）

- **一言で**：教室を初めて開いたとき、やこび姫が「将棋、どのくらい知ってる？」と聞き、1回押すだけで、自分に合ったレッスンがすぐ始まる。
- **解く課題**：知っている人が退屈する／どこから始めるか分からない／章をとばす操作が何度も要る、を、最初の1問で同時に解く（D:2-5）。ホームの案内の答えも、おすすめとして生かす。
- **リスクとリターン**：先から始めるほど早く新しいことを学べる。合わなければ、とばしたレッスンはいつでも遊べ、やこび姫が戻ることを勧める（失敗の罰はない）。
- **溜めと解放**：なし（入口の仕組み）。とばした巻の腕だめしに挑戦して、メダルと称号を取り戻す楽しみを残す。
- **初めての人の最初の1分**：教室を開く → やこび姫の問いと4枚の札 → 1枚押す → そのレッスンの盤が出る（操作2回）。
- **上級者の深さ**：選んだ先から始めても、地図の章の看板の「この章をとばす」でさらに先へ行ける（今のまま）。
- **失敗したとき**：始めた章で続けてつまずいたら、やこび姫が一度だけ「少し前から復習する？」と聞く（17-5）。地図のとばしたマスは、いつでも押して遊べる。
- **ご褒美と使い道**：増やさない。とばしたレッスンには★が付かず、巻の称号は、その巻の腕だめしをクリアするまで渡さない（今の決まりのまま）。とばした腕だめしの看板に「挑戦できる」と添え、力を確かめてメダルを取る道を示す。
- **ほめる瞬間**：先から始めた人が、とばした巻の腕だめしで金メダルを取ったら「やっぱり分かってたね！」とほめる。
- **捨てるもの**：始める前の長い実力テスト（すぐ遊べなくなる。D:3-3）。答えによって教室の中身や難しさを変えること（同じ教室を、どこから入るかだけ変える）。自動でレベルを下げること（戻るかどうかはプレイヤーが選ぶ。I:11）。
- **確かめ方**：ルールを知っている人と知らない人に、説明なしで教室を開いてもらい、どの札を選ぶか、選んだ先で退屈・つまずきがないかを見る（実機での確認はユーザーが行う）。

### 17-3. 問いと選択肢

やこび姫：「将棋、どのくらい知ってる？」

選択肢は、あいまいな段階（初級・中級）ではなく、**できること**で書く。自分で選びやすく、選んだ理由が分かる（D:6-1、U:2 迷わない）。

| 札 | できること（札の小さな文） | 始めるところ | とばすもの |
|---|---|---|---|
| はじめて | 駒の動かし方から覚えよう | 第1巻1章「将棋盤を見てみよう」 | なし |
| 駒の動きは分かる | 成る・持ち駒・反則（二歩など）から | 第1巻2章「駒が成る」 | 盤と駒にごあいさつ、8つの駒のレッスン |
| ルールは分かる | タダの駒・両取り・詰みから | 第2巻「利きを見よう」 | 第1巻すべて |
| 1手詰めなら解ける | 囲いと戦法から | 第3巻「居飛車と振り飛車」 | 第1巻・第2巻すべて |

- 依頼の例「ルールは分かるが定跡は知らない」人は、「ルールは分かる」か「1手詰めなら解ける」を選ぶ。どちらも定跡（第3巻・第4巻）は飛ばさない。
- 札は4枚まで（U:3-1 選択肢は3つ程度。経験の段階なので1枚だけ足す）。札の並びは易しい順に上から。
- 「ふだん指している（段・級がある）」人の札は作らない。第3巻から始め、知っている章は章の看板からとばせる。札を増やすと迷う（U:2）。
- 札の下に小さく「地図から自分で選ぶ」。押すと問いを閉じ、地図を開く（今の教室と同じ）。

### 17-4. いつ聞くか・答えをどう使うか

- **聞くとき**：教室を開いたとき、レッスンの記録が1つもなく、まだ答えていないときだけ。2回目からは聞かない。
  - ホームの「はじめての案内」で「はじめて」を選んで教室に来たときは聞かない（もう答えている。第1巻から始める）。
- **ホームの案内の答えを、おすすめにする**：案内で「ルールは分かる」を選んだ人には「ルールは分かる」の札に、「ふだん指している」を選んだ人には「1手詰めなら解ける」の札に「おすすめ」の小さな札を付ける。決めつけず、押すのは本人（D:4-3 選ぶのはプレイヤー）。
- **選んだあと**：始めるところより前のレッスンを、すべて「とばした」に記録する（今の「この章をとばす」と同じ記録）。そして地図を通さず、始めるところのレッスンをすぐ始める（`autoStart`と同じ流れ）。
  - 「とばした」で決まること（今の決まりのまま）：次のレッスンの解放、ホームの強くなる道の段（第1巻をとばせば「駒を覚える」の段を終える）、利きメガネの所持（第2巻の利きのレッスンをとばした上級者も使える）。
  - 決まらないこと：★、章のメダル、巻の称号（腕だめしのクリアが要る）。
- **答えを保存する**：教室の記録（`yacobihime:shogi-match:tutorial:v1`）に`placement`（`beginner`・`pieces`・`rules`・`mate`・`map`のどれか）を足す。教室の記録を消せば、問いも出直す。読めないときは問わずに今の教室を開く（保存できない環境で毎回聞かない）。
- **選びなおす**：先から始めた人の地図の「つづきから」の下に、小さな「はじめから学ぶ（〇〇）」のボタンを置く。押すと、とばした最初のレッスンを始める（17-10で、とばした記録を消す案から変えた）。確認は出さない（何も消さないため。U:5-2）。

### 17-5. 合わなかったときの安全網

- 先から始めた人が、始めた章で、続けて2つのレッスンを★1で終えたとき（まちがいやヒントが多い）、2つ目を終えた直後にやこび姫が一度だけ聞く（章の区切りまで待つと、つまずいたまま章を終えてしまうため）。
  - 「少しむずかしかったかな？ 「〇〇」から復習してみる？」[復習する] [このまま進む]
  - [復習する]は、とばした中でいちばん近い章の、とばした最初のレッスンを始める（「駒の動きは分かる」なら歩兵、「ルールは分かる」なら歩兵、「1手詰めなら解ける」なら王手と詰み）。とばした記録は消さない（終えればクリアに変わる）。
  - 聞いているあいだは、次のレッスンへ自動で進まない。[このまま進む]なら今までどおり次へ進む。
  - 聞くのは1回だけ（`reviewOffered`を教室の記録に残す）。どちらも同じ大きさ（どちらが正しいとは言わない。D:4-3 恥ずかしくない安全網）。
- 地図の、とばした腕だめしのマスには「挑戦できる」と添える。押せば今までどおり遊べる。金メダルなら17-2の「ほめる瞬間」の一言。

### 17-6. 画面（UI_Nintendo_Design.mdの10章の形）

- **目的**：教室の入口で、自分に合ったレッスンへ1回で行かせる。
- **利用場面**：教室を初めて開いた人が、1回だけ。数秒。
- **画面の主役**：4枚の札（いちばん上の札に最初のフォーカス）。
- **情報の優先順位**：1. やこび姫の問い（1文） 2. 札の見出し 3. 札の小さな文（できること） 4. 「おすすめ」の札 5. 「地図から自分で選ぶ」。
- **操作の流れ**：教室を開く → 札を1回押す → レッスンの盤（2回。U:3-2）。
- **確認ダイアログ**：出さない。選び間違えても、とばしたマスはいつでも遊べ、「はじめから学ぶ」で戻せる（U:5-2）。
- **見た目**：教室の地図の上に重ねる大きなシート。やこび姫の顔と吹き出し、札は縦に4枚（スマホ縦で1画面に収める。タブレット・デスクトップでも縦に並べ、幅は読みやすい幅で止める）。札は今の教室の看板と同じ色調。
- **初めて使う人への伝え方**：札の見出しは経験、小さな文は「何から始まるか」。巻の番号は小さな文に出さない（番号では何をするか分からない）。
- **快の要素**：押すと札が軽く沈み、駒音を1回鳴らしてレッスンの盤へ。`prefers-reduced-motion`では動きをなくす。
- **戻る操作**：ブラウザの戻る操作は、問いを閉じて教室の外（ホーム）へ戻る（今の教室と同じ。問いは答えていない扱いのまま）。
- **読み上げ**：読み上げを使う設定なら、問いの1文だけを読む（16-10と同じ）。
- **作らないと決めたこと**：始める前の実力テスト、札ごとの長い説明、巻と章の一覧から選ばせる画面。

### 17-8. テスト

- 札の始めるレッスンIDが、カリキュラムに実在し、準備中でない（カリキュラムを直しても札が壊れないことを確かめる）。
- `applyPlacement`：始めるところより前がすべて「とばした」、始めるところとその後は「まだ」。クリア済みの記録は消えない。
- 選んだあとの`nextLesson`が、始めるレッスンになる。
- ホームの強くなる道：「ルールは分かる」以上を選ぶと、段1を終える。
- 巻の称号：とばしただけでは渡さない（今のテストを保つ）。
- `shouldAskPlacement`：記録が空で未回答なら真。記録がある・回答済み・ホームの案内で「はじめて」・読めない保存では偽。

### 17-9. 決めること

1. 札の数と区切り：17-3の4枚でよいか（特に「駒の動きは分かる」を入れるか。入れないと3枚になり、成る・持ち駒・反則があやしい人は第1巻1章から始めることになる）。
2. 安全網：17-5のように一度だけ聞くか。聞かずに地図の「とばしたマス」に任せるか。
3. 「1手詰めなら解ける」人に、第2巻の腕だめし「玉をつかまえよう」を最初に解かせて確かめるか（確かめると1〜2分かかるが、合わない人を早く見つけられる）。初期案は確かめない（すぐ遊ばせる。D:3-3）。

### 17-10. 決めたことと実装（2026-10-19）

決めること（17-9）は、ユーザーの「全部おまかせ」を受けて、すべて初期案にした: 札は4枚、復習のすすめは一度だけ、「1手詰めなら解ける」人を腕だめしで確かめることはしない。

設計から変えたこと:

- 「はじめから学ぶ」は、とばした記録を消さず、とばした最初のレッスンを始めるだけにした。記録を消すと、先のレッスンに鍵がかかり、続きから進めなくなるため（取り消せない変更を避ける。U:5-2）。
- 復習のすすめは、章の区切りではなく、続けて2つ目の★1を終えた直後に出す（17-5）。

実装:

- 札の定義は`tutorial-map.mjs`の`TUTORIAL_PLACEMENTS`（始めるレッスンは`v1-board`・`v1-promotion`・`v2-kiki`・`v3-rook-styles`）。判定は`tutorial-progress.mjs`の`shouldAskPlacement`・`recommendedPlacement`・`applyPlacement`・`firstSkippedLesson`・`shouldOfferReview`・`markReviewOffered`、復習の行き先は`tutorial-map.mjs`の`reviewLessonBefore`。
- 画面は`ShogiTutorial.vue`（問いのシート`data-tutorial-placement`、地図の`data-tutorial-from-start`、復習のすすめ`data-review-offer`）。はじめての案内の答えは、`ShogiMatchGame.vue`が教室を開く直前に読み直して`welcome-choice`で渡す（案内で選んだ直後でも反映する）。
- 「つぎはこれ」から教室を開いた（`autoStart`）ときも、問いに答えるまではレッスンを自動で始めない。
- 読み上げを付けている人には、問いの1文だけを読む（端末の声が後から届いても読む）。
- 「とばした」で決まることは今のまま。「1手詰めなら解ける」を選ぶと第2巻の最後もとばすので、ホームの強くなる道は「詰みを覚える」の段まで終えたことになる（後の段を終えていれば前の段も終えたことにする、今の決まりのとおり）。
- 自動テスト（`tutorial-map.test.mjs`）: 札の始めるレッスンが実在して易しい順に並ぶこと、前がすべて「とばした」になり次のレッスンが始めるレッスンになること、クリアの記録を消さず巻の称号を渡さないこと、強くなる道の段、聞く条件、おすすめ、保存と不正な値の破棄、復習のすすめの条件（★2をはさむと出さない・一度だけ・はじめからの人には出さない）、復習の行き先。`match-ui-regression.test.mjs`で、地図の前に問いを出すことと、復習のすすめのあいだは自動で進まないことを確かめる。
- ブラウザ（ヘッドレスChrome）で、スマホ縦（390×844・360×640）・スマホ横（844×390）・タブレット縦（820×1180）・デスクトップ（1366×768）について、問いのシートが1画面に収まること（スマホ横は札を2列）、おすすめの札、最初のフォーカス、札を押すとすぐレッスンが始まること、地図の「はじめから学ぶ」、2回目に開くと聞かないこと、案内で「はじめて」を選んだ人には聞かないこと、「地図から自分で選ぶ」を確かめた。復習のすすめは、「駒の動きは分かる」から始めて「駒が成る」★1のあと「持ち駒を打とう」をまちがえながら★1で終え、すすめが出て自動では進まず、「復習する」で歩兵が始まることを、スマホ縦・スマホ横・デスクトップで実際に操作して確かめた。実機での手動確認は未実施。
- 実装後のチェックリスト（`Game_Nintendo_Implementation.md`の12章・`UI_Nintendo_Implementation.md`の9章）: 判定・評価値は変えていない。確認ダイアログは増やしていない（札の選択・復習のすすめは取り消せる）。ボタンは動詞（「復習する」「このまま進む」）。責める言葉を使っていない（「少しむずかしかったかな？」）。タップ領域は44px以上（札は約58px、復習のボタンは48px）。フォーカスは見える（`:focus-visible`）。`prefers-reduced-motion`では札の沈みをなくす。保存のキーは今の教室の記録のまま、読めない値は捨てて遊べる。作った人以外に触ってもらう確かめはまだ。

## 18. 台詞を盤の真上に置く（2026-10-19）

「解説が下の方にあって視線移動が疲れる」という声を受けて、レッスン画面の並びを変えた。`UI_Nintendo_Design.md`の4-2（レッスン画面は盤面＋短い目標表示）・6-1（必要な瞬間に1つだけ）と、`UI_Nintendo_Implementation.md`の7-5（1画面に収める）に基づく。

| 変えたこと | 前 | 後 |
|---|---|---|
| 台詞の位置 | 盤と先手の駒台の下。タブレット縦では盤の上端から約870px下、デスクトップでは盤の下端の下 | 盤の真上（めあての帯のすぐ下）。めあて→台詞→盤→操作と、上から順に読める。盤の下の駒台をまたがない |
| 操作 | 台詞と同じ欄（盤の下） | 盤の下に残す（選択肢・観戦の「次の手」・評価値のグラフ・やり直す）。盤を見たあと手を伸ばす位置 |
| スマホの横向き | 盤の右に台詞と操作 | 同じ（盤の右の列に、台詞を上、操作を下に積む） |
| 盤が動かないこと | 台詞は盤の下なので、伸びても盤は動かない | 台詞の高さをレッスンのあいだ保ち（伸びた分は縮めない）、課題の間は一言の行と「やり直す」の場所を見えないまま空けておく。指した直後や正解の一言で、盤の位置も大きさも変わらない |

## 19. 利きメガネの「取られるマス」をCPUと同じ取り合いの計算にする（2026-10-20）

利きメガネの赤い輪（動かすと取られて損をする移動先）、まちがえた手のあとの取り返しの再生、駒得するまで指す課題の「取られる」判定は、`board-insight.mjs`の`isPieceLoose`で決めている。
これまでは「守りがない」か「自分より安い駒に狙われている」かだけを見ていたが、CPU（ロジックAI）と同じ取り合いの計算（`exchange-eval.mjs`、安い駒から順に取り合い、裏の利き・ピン・成りまで見る）に揃えた。
CPUが「取られる」と判断する場所と、教室で教える場所が一致する。教室の全レッスンの自動テスト（盤面・正解手・取り返し）は、変えずに通った。

## 20. 腕だめしで飛び級する（2026-10-20）

「腕だめしをクリアしたらその章を修了扱いにして、飛び級できるようにしたい」という依頼を受けた。
`Game_Nintendo_Design.md`（4-3 クリア扱いで飛ばせる安全網、4-8 どれぐらい良いことをした？、5-8 自律性、6-3 攻略の自由、3-3 すぐ遊ばせる）と`UI_Nintendo_Design.md`（5-2 確認ダイアログ、5-3 メッセージ分類）を読んで設計した。

### 20-1. 設計メモ（Game_Nintendo_Design.mdの14章の形）

- **一言で**：地図の先にある腕だめしに、いつでも挑戦できる。合格すれば、その章を「修了」にして次の章へ進む。
- **解く課題**：分かっている章を「この章をとばす」でとばすと、力を示した記録が残らない（「とばした」と「分かっている」が区別できない）。17章の札は4段階しかなく、間の章は1章ずつとばすしかない。腕だめしは、章の課題に前の章の課題を混ぜた試験なので、そのまま飛び級の試験に使える（D:2-5）。
- **リスクとリターン**：合格の基準は、まちがいとヒントが合わせて2回まで（★2以上）。合格すれば章のレッスンを全部とばせる。★1なら飛び級しないが、失うものはない（★の記録は残り、何度でも挑戦できる）。
- **溜めと解放**：章の山場（腕だめし）を、先に越えてもよい山にする。合格したら章クリアの画面で「飛び級、合格！」とほめる。
- **初めての人の最初の1分**：変わらない（光っているマスから順に進む）。先の腕だめしは点線の縁と「飛び級できる」の札で見せるだけで、押さなければ何も起きない。
- **上級者の深さ**：知っている章は腕だめしだけ解いて先へ進める。腕だめしの★でメダルが付くので、とばすより得になる。
- **失敗したとき**：★1なら地図へ戻し、やこび姫が「飛び級は、まちがいとヒントが2回までで合格だよ。「〇〇」から学んで、また挑戦してね」と次に学ぶレッスンを伝える。責める言葉は使わない（U:4-3）。

- **確かめ方**：章をとばしたことのある人に地図を見てもらい、点線の腕だめしを押したくなるか、合格・不合格の知らせで次に何をすればよいか分かるかを見る（実機での確認はユーザーが行う）。

### 20-2. 決まり

| 場面 | 動き |
|---|---|
| 地図 | 前に遊んでいないレッスンがある腕だめし（順に進んで届いていない腕だめし）は、鍵をかけず「挑戦できる」（点線の縁、マスの下に「飛び級できる」）。ふつうのレッスンの鍵は今のまま。鍵のマスを押したときの一言に「先の章の腕だめしに合格すると、飛び級もできるよ」を足す |

## 21. 2つのコース（じっくり基礎・すぐ使えるコツ）と、囲いの見くらべ（設計 2026-10-30）

### 21-2. 設計メモ（Game_Nintendo_Design.mdの14章の形）

- **一言で**：教室を2つのコースに分ける。「じっくり基礎」は今の道を軽くしたもの、「すぐ使えるコツ」は1つ1〜2分で、明日の対局でそのまま使える将棋の常識を12枚のカードで覚える。囲いの強さは、詰むかどうかではなく、逃げ道・打ち込みの隙・駒のつながりを盤の上で見くらべて覚える。
- **解く課題**：基礎が多すぎて飽きる／すぐ使える知識の入口がない／美濃囲いで駒を捨てるのが正解になっている／囲いが強い理由が見えない、を「2つのコース」と「囲いの見くらべ」の2つで同時に解く（D:2-5）。新しい道具は作らず、利きの地図・逃げ道・取られるマスの計算（`board-insight.mjs`・`exchange-eval.mjs`）を組み合わせる（D:2-6）。
- **リスクとリターン**：コツのカードは、どれから遊んでもよい（鍵なし）。カードの最後の課題は、その場の局面でコツを使う1手で、合えば★。じっくり基礎は今までどおり。
- **溜めと解放**：囲いの見くらべは、まず居玉の隙（赤い輪）と、ふさがった逃げ道を見せ（ギュッ）、切り替えると美濃囲いの隙が0・逃げ道が緑・金銀のひもが線でつながる（パッ。D:2-2）。
- **初めての人の最初の1分**：教室を開くと地図の上に「じっくり基礎」「すぐ使えるコツ」の2つのタブ。初めて開いたときの問い（17章）には、5枚目ではなく、下の小さなリンク「すぐ使えるコツだけ見る」を足す（札は4枚のまま。UD:3-1）。コツを選ぶと、12枚のカードの棚が出て、1枚押すとすぐ盤が出る（操作2回。UD:3-2）。
- **上級者の深さ**：コツのカードの最後に「対局で試す」（作戦カードでその戦法・囲いを選んだ自由対局。今の`play`ステップと同じ）。じっくり基礎は腕だめし・飛び級（20章）を今のまま。
- **失敗したとき**：今の教室と同じ（その場でやり直し、ヒントが1段ずつ強くなる）。
- **ご褒美と使い道**：コツのカードは終えると表に返って「使えるコツ」の札になり、コツの棚に並ぶ（集めて眺める。UD:7-4）。12枚そろうと棚に判子。称号は増やさない（教室の称号は巻の修了だけ。12-4）。使い道は「対局で試す」と、ふだんの対局でコツの形ができたときのやこび姫の一言（今の囲いの完成の知らせ`14章`と同じ仕組み。段階T4の候補）。
- **ほめる瞬間**：コツの課題を解いたら、コツの一言をもう一度言う（「飛車先の歩を交換できたね。歩が1枚手に入ったよ」）。囲いの見くらべでは、切り替えた瞬間に数字が変わるところを盤で見せる。
- **捨てるもの**：美濃囲い・舟囲いを王手で攻める攻めくらべ（`expect: "hold"`）。囲いの堅さの総合点数（13-2と同じ理由）。コツのカードの鍵と順番。じっくり基礎のレッスンを消すこと（寄り道にするだけで、遊びたい人は遊べる）。
- **確かめ方**：ルールを知っている人に、説明なしで「すぐ使えるコツ」を3枚遊んでもらい、1枚が2分で終わるか、明日の対局で使えそうと思うかを見る。囲いの見くらべは、見たあとに「なぜ美濃囲いは強い？」と聞き、3つのうち2つ以上を言えるかを見る（実機での確認はユーザーが行う）。

### 21-3. 囲いの見くらべ（攻めくらべの「守りきる」側の置き換え）

- **一言で**：同じ攻め駒に対して、居玉と囲いを切り替えながら、3つのめがね（逃げ道・打ち込みの隙・ひも）で見くらべる。
- **新しいステップ**`castle-compare`（説明の仲間。正解・不正解はない）。盤の上に「居玉 ⇄ 美濃囲い」の切り替えと、3つのめがねのボタンを置き、下に見くらべの表を出す。

  | めがね | 盤の印 | 表の数（例） | 言うこと |
  |---|---|---|---|
  | 逃げ道 | 相手が王手をしたとき、玉が逃げられるマスを緑、相手の利きで逃げられないマスを×（`kingEscapeMap`と同じ印） | 居玉 0 ／ 美濃囲い 2 | 「居玉は自分の金が逃げ道をふさいでいる。美濃囲いは逃げ道がある」 |
  | 打ち込みの隙 | 相手が持ち駒を打って王手でき、しかも取り返されないマスに赤い輪（利きメガネの赤い輪と同じ意味の色） | 居玉 2 ／ 美濃囲い 0 | 「美濃囲いは、どこに打っても取られる。駒を打たれづらい」 |
  | ひも | 守りの金銀と玉のあいだに、守り合っている線（13-6の「金銀のひも」と同じ線）。だれにも守られていない守りの駒（浮き駒）に赤い× | ばらばらの玉 浮き駒2 ／ 美濃囲い 浮き駒0 | 「金銀が手をつないでいる。1枚取られても、すぐ取り返せる」 |

- **将棋として正しく**：数はすべて局面から計算する（`src/core/castle-insight.mjs`、21-7）。台詞の数字も計算した値から作る。
  - 逃げ道は「相手のいちばん厳しい王手のあと」で数える（相手の王手のうち、玉の逃げられるマスがいちばん少なくなる手。取られて損をする王手は除く）。王手のない局面では、そのめがねを出さない。
  - 打ち込みの隙は、相手の持ち駒を玉のまわりに打つ王手のうち、取り合いの計算（`exchange-eval.mjs`）で取られて損をしない打ち場所。
  - ひもは、居玉ではなく「攻めに出て金銀がばらばらになった玉」と比べる。居玉の金は玉のすぐ横にいて玉に守られているので、ひもの数では居玉は弱く見えない。居玉の弱さは「戦場に近い・自分の金が逃げ道をふさぐ」なので、ひもで比べると正しくない（2026-10-30に計算して確かめた。居玉の守りのひもは8本、美濃囲いは3本）。
  - 見くらべる局面は、攻める側の駒（盤と持ち駒）を同じにし、テストで「表に出すめがねはすべて囲いのほうが良い」ことを確かめる。良くならないめがねは、その局面の組では出さない（データの`lenses`で選ぶ）。
- **操作**：切り替えとめがねのボタンを押すたびに盤の印と表の行が変わる（押した行を強調）。初めは「逃げ道」のめがねで居玉を見せ、切り替えを押させる。3つのめがねで両方を見たら「つぎへ」のボタンが光る（見ないで進むこともできる。押させることを強制しない。D:6-3）。
- **どこを置き換えるか**：
  | 場所 | いま | 変えたあと |
  |---|---|---|
  | 「囲いで玉を守ろう」の最初 | 攻めくらべ（美濃、`hold`） | 見くらべ（居玉 ⇄ 美濃囲い。逃げ道・打ち込みの隙）→ 見くらべ（ばらばらの玉 ⇄ 美濃囲い。ひも）。そのあとは今のまま（飛車を振る → 美濃囲いを組む → 金銀のひもの説明 → クイズ） |
  | 「居玉はあぶない」 | 攻めくらべ（居玉、3手で詰む）→ 逃げ道 → クイズ | 今のまま（居玉を本当に詰ませるのは正しい手なので残す） |
  | 第3巻1章の腕だめし | 攻めくらべ（舟囲い、`hold`） | 見くらべの問い：「打ち込みの隙が0なのはどっち？」のような`choose`（めがねの印を出した盤で答える） |
- `attack-test`の`expect: "hold"`は使わなくなる。仕組みは残し、テストで「教室のどのレッスンにも`hold`がない」ことを確かめる（もう一度使わないための約束）。

### 21-5. すぐ使えるコツ（12枚）

1枚は3〜4ステップ（説明1つ → 盤の課題1〜2つ → まとめ）。台詞は1文ずつ短く、盤の上のひとこと（16-3）を使う。正誤はすべて合法手と局面で判定する（13-10と同じテスト）。

| 章 | ID | コツ | 課題（判定） | 正しさの確かめ |
|---|---|---|---|---|

### 22-2. 残り8枚の判定（プレイヤーの手のあと。「相手」はCPU）

| コツ | 判定 | 札 |
|---|---|---|
| 戦う前に、玉を囲おう（`tip-castle-first`） | 駒を取る手で、指す前の両者の持ち駒が歩だけ（大きな駒の取り合いはまだ）で、自分の囲い（作戦カードの囲いのどれか）が完成している | 「囲ってから戦えた！」「コツどおり！ 玉が安全なまま戦えるね」 |
| 味方の利きがあるマスに進めよう（`tip-supported`） | 歩と玉でない駒を、駒を取らずに前へ進めた手で、行き先に相手の利きがあり、味方の利きもあり、取り合っても損をしない（`exchangeGain`が0以下） | 「味方の利きの上へ！」「コツどおり！ 取られても取り返せるね」 |
| タダの駒は取ろう（`tip-free-piece`） | 歩でない駒を取った手で、取ったあと相手がそのマスに利いていない | 「タダの駒を取った！」「コツどおり！ 駒得したね」 |
| 両取りをねらおう（`tip-fork`） | 動かした（打った）駒が、銀より上の駒か玉を2つ以上ねらい、行き先で取られても損をしない | 「両取り！」「コツどおり！ 次に駒得できるよ」 |
| 歩は持ち駒で使おう（`tip-pawn-hand`） | 歩がと金に成った手で、その歩が自分で打った歩（打ったあと、まっすぐ進んできた歩）だった | 「垂れ歩からと金！」「コツどおり！ 歩1枚でと金ができたね」 |
| 玉の頭に金を打とう（`tip-head-gold`） | 詰ませた手が頭金（`move-tesuji.mjs`の`head-gold`と同じ形） | 結果の窓の行「頭金」 |
| 玉は下段に落とせ（`tip-bottom`） | 詰ませた手で、最後の王手の連続（3手以上）のあいだに相手の玉が奥へ下がり、奥の2段（相手から見て1・2段目。下段）で詰んだ（教室のカードの▲2四金△2二玉▲2三金も2段目で詰む） | 結果の窓の行「下段に落とす」 |
| 終盤は、駒の得より速さ（`tip-speed`） | 最後の王手の連続（3手以上）の中で、王手した駒を相手が取った（駒を捨てた）うえで詰ませた | 結果の窓の行「駒を捨てて詰ます」 |

- 1つの手で2つ以上のコツができたら、全部数えて結果の窓に並べ、盤の札は先の1つ（12枚の並びの順）だけ出す。
- 出す対局・出す人・1局1回・始めの局面の扱いは21-14-2と同じ（覚えたコツだけ、対CPUの対局で棋力測定・検討・教室の対局を除く）。
- リロードで対局を戻したときは、その対局でもう出したコツの記録は戻さない（始めの局面と同じく、戻した局面でできている形は出さない）。結果の窓の行は、戻したあとに使ったコツだけになる。
