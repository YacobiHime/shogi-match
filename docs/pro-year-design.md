# 棋士の1年：カレンダーで過ごすプロの1年度

大会に「棋士の1年」を足す。新四段として4月1日から1年度を過ごし、カレンダーに書かれた対局日に、八大タイトル（竜王・名人・王位・王座・棋王・王将・棋聖・叡王）と一般棋戦（NHK杯・朝日杯・新人王戦・JT杯）の対局を指す。カレンダーから、各棋戦のトーナメント・リーグ・番勝負の進み具合を見られる。

- 状態：設計（2026-10-31）。作る順番は`docs/team-battle-design.md`の11章（P1〜P4）。
- ユーザーの依頼（2026-10-31）：「大会に、棋士としての1期を体験できるモードを追加したい。カレンダーみたいなのに対戦日程が書かれていて、八大タイトルやNHKなどの小さなタイトルみたいな、実際の棋士と同じ予定が組まれている。そこから、各大会のトーナメントやリーグの進捗状況も見られると良い。」
- これまでの方針：名人戦の設計（`docs/meijin-design.md`の13章）で「棋士として1年を過ごすモード（カレンダーで対局し、……ノベルゲーム風味の場面と物語つき）は、別のモードとして後で作る。共通の1年はそのモードで扱う」とし、`meijin.mjs`・`shoreikai.mjs`・`kenshukai.mjs`は暦に依存しない形にしてきた。`docs/player-world-note-design.md`は「棋士モードは1つの世界（名簿）の上に作る」とした。この設計はその「棋士モード」の最初の形。奨励会から始める道と物語の場面は後の段階。
- 読んだ指針：`Game_Nintendo_Design.md`（2-2 溜めと解放、2-6 掛け算、3-3 遅さは罪、4-3 安全網、4-4 でこぼこ、5-2 吊られたごほうび、5-5 スコアの見せ方、7-3 やり直しに見合う魅力、8-3 応援する楽しみ、9-1 いただく時間、14章）、`UI_Nintendo_Design.md`（2章、3-2、4章、5-2、9章、10章）、`Game_Nintendo_Implementation.md`（4・6・7章）、`UI_Nintendo_Implementation.md`（3・4・7-4・7-5）。

## 2. 機能設計メモ（Game_Nintendo_Design.mdの14章の形）

### 機能名：棋士の1年

- **一言で**：カレンダーの次の対局日へ進み、1局ずつ勝ち上がって、いつかタイトル戦の舞台に立つ（2-1）。
- **解く課題**（2-5）：
  1. 竜王戦・名人戦のほかの6つのタイトルと一般棋戦が遊べない（名簿の「棋界の1年」は裏で決まるだけ）。
  2. 棋士の世界が「1年」として見えない。いつ何の棋戦があるかを、プレイヤーが過ごして知る場がない（教えずに伝える。6-2）。
  3. 長い目標（予選→本戦→挑戦者→タイトル）を、短い1局の積み重ねで見せたい（5-2、4-4 でこぼこ）。
- **リスクとリターン**：どの対局を自分で指し、どれを分身に任せるか（任せると早いが、勝ち負けは分身の強さ次第）。勝ち上がるほど、強い相手・大きな舞台・タイトルに近づく。
- **溜めと解放**（2-2）：予選のブロックを勝ち抜く→本戦・リーグ入り（カレンダーに大きな印が増える）→挑戦者決定戦→番勝負。山場はカレンダーで先に見える（「3月10日 王将リーグ最終局」）。
- **初めての人の最初の1分**：大会の選択「棋士の1年」→ 難易度を選んで「デビューする」→ 4月のカレンダー（最初の対局日に印）→「次の対局日へ」→ その日の札「新人王戦 1回戦 ○○四段」→「対局する」。
- **上級者の深さ**：全棋戦の表、ほかの棋士の勝ち上がり、年度の終わりのまとめ（年間成績・将棋大賞の記録部門）、次の年度（シードと順位戦のクラスを持ち越す）。
- **失敗したとき**（7-1、4-3）：1つの棋戦で負けても、ほかの棋戦の予定が続く。1年を通して勝ちを積めば、順位戦の昇級や翌年のシードが残る。
- **ご褒美と使い道**（5-1）：タイトル獲得・棋戦優勝の賞状（賞状帳）、将棋大賞（記録部門）、年間成績の札。翌年度のシード（予選が減る）。
- **ほめる瞬間**（5-4）：予選のブロック優勝、リーグ入り、挑戦者決定、タイトル獲得、連勝の記録。
- **捨てるもの**：
  - 実在の棋士の名前（名簿の架空の棋士）。
  - 細かい規定（竜王戦の昇級者決定戦、棋王戦の敗者復活と二番勝負の差、王位リーグの残留、順位戦のフリークラス、銀河戦の勝ち抜き方式、加古川青流戦・達人戦）。
  - ほかの棋士のレーティングの増減（1年の中では名簿のまま）。
  - 名簿への書き戻し（6章）。
- **確かめ方**：竜王戦を遊んだことのある人に、4月から9月まで進めてもらい、カレンダーと棋戦の表で「いま何の途中か」を説明なしで言えるかを見る（10-2）。

### 画面の設計メモ（UI_Nintendo_Design.mdの10章の形）

- **目的**：大会の続きとして、棋士の1年を過ごす。いま何の棋戦の途中で、次の山場がいつかが分かる。
- **利用場面**：1局（10〜30分）ごとに開いて「次の対局日へ」。1年度で20〜60局。
- **画面の主役**：次の対局の札（日付・棋戦・段階・相手・「対局する」）。その下に月のカレンダー。
- **情報の優先順位**：1 次の対局（日付・相手）と「対局する」／2 月のカレンダー（自分の対局日の印と棋戦の色）／3 棋戦の一覧（自分の位置：予選2回戦・本戦ベスト8・敗退）／4 各棋戦の表（トーナメント・リーグ・番勝負）／5 年間成績。
- **操作の流れ**：入口 →「次の対局日へ」→ 日の札 →「対局する」（または「分身に任せる」）→ 終局 → カレンダーへ戻る。日付のマスを押すと、その日の対局（自分のとタイトル戦）を見る。
- **確認ダイアログ**：「分身に任せる」は取り消せないので確認する（初期フォーカスは「自分で指す」）。途中でやめる（棄権）は大会の選択の「途中でやめる」。
- **メッセージ分類**：段階が変わった知らせ（「棋聖戦 二次予選へ」）は状態表示の札。
- **初めて使う人への伝え方**：棋戦ごとの色の点（カレンダー）と、同じ色の棋戦の札。自分の対局日は丸で囲む。
- **快の要素**：段階が上がったときの判子（予選突破・リーグ入り・挑戦者）。
- **見ている人への配慮**：タイトル戦の日はカレンダーに金の印。日の札で「王位戦七番勝負 第3局 ○○王位 vs ○○八段」。
- **作らないと決めたこと**：1日ずつ進めるボタン（遅い。次の対局日・月の切り替えだけ）、週の表示。
- **根拠**：N:2-1・2-4（階層を浅く）、N:3-4・3-5（確認）、N:6-1。

## 3. 1年の作り（決めたこと。2026-10-31）

1. **暦**：年度は4月1日〜翌3月31日。始めた日の年度から（例：2026年10月に始めたら2026年度の4月1日から）。日付と曜日は本物の暦。
2. **期のめぐり**：棋戦ごとに、1つの期の段階（予選・本戦・リーグ・番勝負）と時期を「期の始まりの年度から数えた月」で持つ（`PRO_EVENTS`）。ある年度のカレンダーには、その年度にかかるすべての期の段階を並べる（前の年度に始まった期の番勝負と、今年度に始まる期の予選）。
3. **デビュー前の期**：始めた年度より前に始まった期は、デビューの前に自動で決めておく（プレイヤーは出ない）。そのため、1年目の名人戦・叡王戦・棋聖戦・王位戦・王座戦・竜王戦・王将戦の番勝負は、名簿の棋士どうしの観戦になる。プレイヤーが挑戦できるのは、デビュー後に始まった期から（棋王戦・朝日杯・新人王戦・NHK杯の予選などは1年目から勝ち上がれる）。
4. **段階の形**（実物の形を、遊べる大きさに縮める）：

   | 棋戦 | 期の段階（月は期の始まりの年度の4月を0として数える） | 番勝負 |
   | --- | --- | --- |
   | 叡王 | 予選（8人のブロック）6〜12月 → 本戦16名 1〜3月 | 五番（翌4〜6月） |
   | 名人 | 順位戦（自分のクラス10局）6月〜翌3月 | 七番（翌4〜6月。A級1位） |
   | 棋聖 | 一次予選（8人のブロック）5〜9月 → 二次予選（4人のブロック）10〜1月 → 決勝T16名 2〜5月 | 五番（翌6〜7月） |
   | 王位 | 予選（8人のブロック）7〜1月 → リーグ紅白各6名 2〜5月 → 紅白の優勝者の挑戦者決定戦 6月 | 七番（翌7〜9月） |
   | 王座 | 一次予選（8人）8〜12月 → 二次予選（4人）1〜3月 → 挑戦者決定T16名 4〜8月 | 五番（翌9〜10月） |

   | NHK杯 | 予選（8人）9〜1月 → 本戦32名 翌4月〜翌3月（毎週の放送） | ― |
   | 朝日杯 | 一次予選（8人）6〜9月 → 二次予選（4人）10〜12月 → 本戦16名 1〜2月 | ― |
   | 新人王戦 | トーナメント16名（26歳以下の六段まで）4〜9月 | 決勝三番（10月） |
   | JT杯 | 招待8名（タイトル保持者・強い順）6〜11月 | ― |

   - **予選のブロック**：予選は名簿の棋士をブロック（8人・4人）に分けたトーナメント。ブロックの優勝者が次の段階へ。プレイヤーは1つのブロックに入り、ほかのブロックは優勝者だけを決める（保存を小さくする）。
   - **シード**：本戦・リーグ・決勝トーナメントの残りの席は、タイトル保持者と、名簿のレーティングの上位から埋める。
   - **順位戦**：プレイヤーのクラス（名簿の順位戦の世界にプレイヤーがいればそのクラス、いなければC級2組）。10局の相手は同じクラスの棋士。ほかの棋士どうしの成績は回戦ごとにまねで決める。昇級の人数は`meijin.mjs`の`CLASS_RULES`。
   - **竜王戦の組**：プレイヤーの組（竜王戦のキャリアがあればその組、なければ6組）のトーナメントの優勝者が決勝トーナメントへ（組の上の席はシード）。
   - **新人王戦**：新四段は出られる。JT杯は招待なので、タイトルを持つまでは観戦。
5. **対局日**：段階の時期の中に、回戦ごとの日を割り当てる（平日。番勝負は1〜2週おき、2日制の七番勝負は2日続き）。プレイヤーの対局が同じ日に重なったら、後の段階を1日ずらす。
6. **ほかの棋士の対局**：日付が過ぎたら、その日の対局をレーティングの勝率（`ryuo-simulation.mjs`の`simulateMemberGame`）で決める。乱数の状態を保存に持つので、同じ保存から同じ結果を記録すれば同じ1年になる。記録を作るのは、プレイヤーと羽音のいるブロック・本戦・リーグ・番勝負の対局だけ（ほかのブロックは勝ち上がりだけ決める。保存を小さくするため）。
7. **プレイヤーの対局**：日の札の「対局する」で、竜王戦と同じ対局画面（相手のLvは大会の世界で`seasonPlayerOf`と同じ換算）。「分身に任せる」は、世界のレーティング（`worldRating`）の分身で、勝率で決める。
8. **進め方**：「次の対局日へ」で、次のプレイヤーの対局日まで進む（あいだの対局はすべて決まる）。対局日の札を残したまま月を見て回れる。プレイヤーの対局が残る日は、それより先へ進めない。
9. **年度の終わり**：3月31日を過ぎたら「年度のまとめ」（年間成績、棋戦ごとの成績、将棋大賞の記録部門の受賞、順位戦の昇級）。「次の年度へ」で続ける（順位戦のクラス・竜王戦の組・シードの権利を持ち越す）。
10. **翌年のシード**：ある期で本戦・リーグ・決勝トーナメントに入ったら、同じ棋戦の次の期は1つ上の段階から（予選を1つ飛ばす）。番勝負に出たら、次の期は本戦から。
11. **保存**：`yacobihime:shogi-match:pro-year:v1`。名簿は読むだけで書き戻さない（竜王戦・名人戦の期とは別の暦。名人戦の13章の案Bを守る）。名簿がなければ、研修会と同じく作る。
12. **難易度**：大会の世界（`tournament-world.mjs`）。入口の難易度の選択シートに「棋力を測る」（ほかの大会と同じ）。
13. **羽音**：羽音もこの年度の新四段として、同じ予選に出る（名簿の段位にかかわらず四段。順位戦はプレイヤーと同じクラスに入り、期の後半に必ず1度当たる。竜王戦の組もプレイヤーと同じ）。羽音の対局日はカレンダーに小さな印。羽音と当たる対局の前に一言（`ryuo-story.mjs`の口調）。年度のまとめに羽音の年間成績と直接対決。
14. **レーティング**：平手の自分の対局は、ほかの大会と同じくレーティングに数える（`RATED_EVENTS`に`pro-year`）。

## 4. 処理（`src/core/pro-year.mjs`。画面・保存の仕組みに依存しない）

- `PRO_EVENTS`：棋戦の定義（id・名前・色・種類・段階の時期と形・番勝負の勝ち数・2日制）。`TITLE_EVENTS`は八大タイトル。
- `createProYear({ seed, fiscalYear, roster, settings, userLevel, userName, userGroup })`：名簿から棋士を写し、前の年度に始まった期をデビューの前日まで決め、今年度の期を作る。
- `advanceToNextGame(state)`：次のプレイヤーの対局日まで進め、あいだの対局を決める。対局がなければ年度の終わりまで進めて`summary`を作る。
- `recordProGame(state, outcome)`：`'win'`・`'loss'`・`'draw'`（先後を替えて指し直し）・`'auto'`（分身に任せる。世界のレーティングの勝率）。回戦を閉じ、勝ち上がりと次の回戦を決める。
- `proYearSeason(state)`：対局画面の期の形（相手のLvを付けた棋士。Lvは保存の棋士に書かず`pending.level`に持つ）。
- `proYearView`（次の対局・棋戦の一覧と自分の位置・成績）、`monthView(state, year, month)`（月のカレンダー）、`dayView(state, date)`（その日の対局）、`eventView(state, eventId)`（段階ごとの表）、`gameLabel(state, game)`（対局の名前の札）。
- `yearSummary`・`startNextYear(state)`：年度のまとめと次の年度（昇級・シード・古い対局の片づけ）。

## 9. カレンダーの予定と「羽音」の印（2026-11-01、ユーザーの指摘）

- 指摘：「棋士の1年の最初の画面で、カレンダーに予定が表示されていない」「羽音が羽表示になっているが、羽音は二文字なので羽音表示でいい」。
- 原因：カレンダーの印は、組まれた対局と、始まった段階の残りの回戦の日だけから作っていた。デビューの日（4月1日）は、今年度の段階がまだ1つも始まっていない（段階は時期の初めの日に「次の対局日へ」で始まる）ので、何も出なかった。
- 直したこと：
  - まだ始まっていない段階の見込みの日を出す（`projectedItems`）。プレイヤーが入る段階（棋王戦の予選・新人王戦・順位戦など）は回戦の日を点線の「予定」、タイトル戦の番勝負は最低限の局数の日を★（2日制は前の日も）。日の割り当ては段階を始めるときと同じ式なので、始まれば同じ日に組まれる（前の段階が長引けばずれる）。その日のシートでは「この日ごろに指す予定だよ」（タイトル戦）・「勝ち残っていれば、この日ごろに指すよ」（自分）と書く。1年の見通しと次の山場が最初から見える（D:2-2 溜めと解放、UD:3 先が見える）。
  - 羽音の対局の印を「羽」から「羽音」にし、凡例も「羽音の対局」にした。
  - タイトル戦の★に、どのタイトルかの名前を添えた（「★名人」）。予定の★が並ぶと、どれが何の番勝負か分からないため。
- 確かめ：テスト（デビューの日の4月に自分の予定とタイトル戦の予定、6月に順位戦の予定、見込みの日と進めて組まれた日が同じ）・型・ビルド・ブラウザ3サイズ（デビューの直後の4月のカレンダー）。実際に遊んでの確かめは未確認。

## 10. 棋士の暮らし：研究会・将棋まつり・対局料、棋戦の表と観戦（2026-11-01、ユーザーの依頼）

依頼：「棋士の一年では研究会とかみたいなのを用意して、普通の棋士と同じ生活を楽しめるようにしたい。将棋まつりとかへの参加も面白そう。将棋まつりでは駒落ち指導対局や、ぐるぐる指導対局、トークショー、揮毫を書いたりなどをします。」「対局料のような制度があるといいかも。」「竜王戦などを押した時に表示されるトーナメントは、ちゃんと竜王戦みたいなトーナメントが表示されるようにしたい。また、観戦もできるといい。」

### 10-1. 機能設計メモ（Game_Nintendo_Design.mdの14章の形）

#### 機能名：棋士の暮らし（研究会・将棋まつり・対局料と研究の道具）

- **一言で**：公式戦のあいだの日に、研究会で腕を磨き、将棋まつりでファンと会い、対局料と賞金で研究の道具をそろえて、次の公式戦の相手を研究する（2-1）。
- **解く課題**（2-5）：
  1. 公式戦の日から日へ飛ぶだけで、棋士の「暮らし」がない（依頼）。
  2. 勝ち負けのほかに、1年をがんばった手応え（実物の棋士の物差し）がない。
  3. 公式戦の前に、相手を知る手段がない（大会の竜王戦の「○○対策」に当たるもの）。
  - 3つを、研究会（相手を知る）・お金（研究の道具を買う）・将棋まつり（ファンと謝礼）の1つの輪でまとめて解く（D:2-6 掛け算。D:5-7 実りがある：稼いで道具を買い、次の対局が楽になる）。
- **リスクとリターン**：研究会・まつりは寄り道（時間をかけるか、次の公式戦へ急ぐか）。研究の道具は高い（今買うか、貯めて上の道具を買うか）。
- **溜めと解放**（2-2）：対局料が少しずつ貯まり（次の道具まで「あと○万円」が見える。D:5-2）、買った次の公式戦で相手の作戦が分かる。タイトル・優勝の賞金で一気に増える。
- **初めての人の最初の1分**：デビューの日、羽音から研究会に誘われる一言。カレンダーに「研」の印。次の対局の札の下に「寄り道：4月15日 研究会［参加する］」。
- **上級者の深さ**：研究仲間の成績・道具の3段階・年間の獲得賞金ランキング・揮毫帳。
- **失敗したとき**（7-1）：研究会で負けても公式の成績には入らない。寄り道は行かなくても何も失わない（D:9-2。休んでも責めない）。
- **ご褒美と使い道**（5-1）：対局料・賞金・謝礼（お金）→ 研究の道具（相手の作戦が分かる）。ファン → まつりの謝礼が増える。揮毫 → 揮毫帳。研究会の勝ち → 研究仲間（公式戦で当たると相手の得意戦法が分かる）。
- **ほめる瞬間**（5-4）：研究会で勝つ（羽音の一言）、ぐるぐる指導で全員に勝つ／全員を楽しませる、トークショーで会場が沸く、賞金ランキング10位以内。
- **捨てるもの**：実物の金額（多くは非公表なので、ゲームの値で決める）、研究会の会場・日程の調整、税金や経費、移動の日、まつりの屋台、ファンの数の細かい増減の理由。
- **確かめ方**：棋士の1年を遊んだことのある人に、最初の2か月を遊んでもらい、研究会とまつりに「行きたい」と思うか、道具を買ったあとの公式戦で違いを感じるかを見る（10-2）。

#### 機能名：棋戦の表と観戦（棋士の1年）

- **一言で**：棋戦を押すと、竜王戦と同じトーナメント表・番勝負の星で、自分と羽音とタイトル戦の進み具合が見え、決着した対局は中継で観戦できる（8-3 応援する楽しみ）。
- **解く課題**：棋戦の表が対局の並びだけで、トーナメントに見えない（依頼）。ほかの棋士の対局を見られない（依頼）。
- **初めての人の最初の1分**：「棋戦」のタブ →「棋王戦」→ 予選のブロックの表（自分の札は琥珀）→ 決着した札の▶で中継。
- **捨てるもの**：記録を作らない予選のブロック（自分も羽音もいないブロック）の表と観戦。自分の対局の中継（振り返りと棋譜解析がある）。

### 10-2. 決めたこと

1. **棋戦の画面**：棋戦の札を押すと、棋戦の画面を全画面で重ねる（前の小さなシートをやめる。表は大きさが要るため。U:7-5）。上に期の切り替え（今年度に2つの期がかかるとき）、その下に段階のタブ（予選・本戦・リーグ・順位戦・番勝負）。はじめは、いま進んでいる段階（自分がいればその段階）。

2. **観戦**：決着した棋士どうしの対局（表の札の▶、その日のシートの「観戦」）を、竜王戦と同じ中継の画面（`RelayViewer.vue`）で見る。勝ち負けと展開は、1年のまねの記録（先手・勝ち方・形勢の線。対局に`rec`で残す）に沿ってエンジンが指す。自分の対局は出さない。解説者はこの1年の棋士から選ぶ。

4. **研究の道具**（お金の使い道。D:5-1）：3段階（研究用のノートパソコン30万円・研究用のデスクトップ80万円・研究用の高性能パソコン200万円）。成績のタブから買う。買うと、次の公式戦の札に「事前研究」を出す（1段：相手の得意戦法、2段：囲いも、3段：相手の特殊能力も）。次の道具までの残りを見せる（D:5-2）。
5. **研究会**：
   - デビューの日に、羽音と同期の若手2人の研究会に誘われる（羽音の一言。敬語・！なし）。日程は毎月の第1・第3水曜（公式戦のある日は翌日の木曜）。カレンダーに「研」の印。

## 11. ぐるぐる指導は、ほかの棋士と回って指し継ぐ（2026-11-02、ユーザーの指摘）

ユーザーの指摘「ぐるぐる指導対局は一人でやるわけじゃない。一人でやったら普通の指導対局と変わらない。複数の棋士がぐるぐる回って指すものです。なので、振り飛車党が居たりすると居飛車の藤井聡太が振り飛車を指さなきゃいけなくなって困ったりします。」

### 機能名：ぐるぐる指導（リレー）

- 一言で：あなたとほかの棋士2人が3つの盤の前を回り、1手ずつ指し継ぐ。前の人が振った飛車は、あなたも振り飛車で指し継ぐ。
- 解く課題：前の版は、あなた1人が3つの盤を順に指す多面指しで、ふつうの指導対局を3つ並べただけだった。ぐるぐる指導の面白さ（自分の作戦にならない盤を指し継ぐ・仲間の棋士の棋風が盤に出る）がなかった。
- リスクとリターン：自分の得意な形で指せない盤がある代わりに、ほかの棋士の手が盤を進めてくれる（3手に1手だけ指す）。
- 初めての人の最初の1分：はじめるの前に「○○五段・○○八段とあなたで、盤を回りながら1手ずつ指し継ぐよ」。盤の札に、いまその盤の前にいる棋士の名前（あなた・○○さん）。
- ほめる瞬間：全員に勝つ（前と同じ。ファンは1局10と全勝で20）。
- 捨てるもの：ほかの棋士の強さの読み（エンジンを使わず、ロジックAIの上の段で指す）、あなたが回る順番を選ぶこと（回る順は決まっている）。
- 確かめ方：処理のテスト（回る順・振り飛車党は平手の盤で飛車を振る・居飛車党は振らない・一緒に回る棋士の選び方）と、ブラウザで、はじめると盤の札に3人の名前が出て、1手指すと次の盤へ回り、ほかの盤もほかの棋士の手で進むことを見る。

### 決めたこと

- 回り方（`festival-simul.mjs`の`simulBoardOf`・`simulProAt`）：棋士3人（あなたと2人）と盤3つ。回る回数`round`で、棋士kは盤`(k + round) % 3`の前にいる。あなたが1手指すと、同じときにほかの棋士も前の盤で1手ずつ指し（アマチュアが指し返す）、みんなで次の盤へ回る。あなたの前の盤が決着していたら、ほかの棋士だけ指してもう1つ回る（`FestivalSimul.vue`の`partnersPlay`・`rotate`）。
- 一緒に回る棋士（`pro-festival.mjs`の`simulPartners`）：まつりごとに名簿から2人。振り飛車党（いなければオールラウンダー）を1人は入れる。棋風は得意戦法から（`simulStyleOf`。振り先は四間・三間・中・向かい）。
- 盤：子ども2人は駒落ち（六枚落ち・四枚落ち。上手は飛車がないので棋風は出ない）、大人1人は平手（先手のアマチュアから指す）。平手の盤で、振り飛車党の棋士は2手目から8二の飛車を振り先へ振り、居飛車党は序盤（上手の10手まで）に飛車を横に動かさない（`partnerMove`）。オールラウンダーは半分の確率で振る。
- 振った盤：札に「四間飛車」などを出し、あなたがその盤に来たら「○○さんが四間飛車に振ってる……！ この盤は四間飛車で指し継ごう」（`rangingMoveLabel`）。ほかの棋士から回ってきた盤は「○○さんから回ってきた盤」。
- ファン・「ここまで」・勝ち負けの数え方は前と同じ（勝ち負けは上手の側、つまり3人の棋士の側から見る）。
- 根拠：D:3-1（ルールの中の面白さ。前の人の作戦を引き継ぐ）、G:3（出来事の重さ。仲間の棋風が盤に出る）、UD:2（いま誰がどの盤にいるかを札で見せる）。

### 13-2. 機能設計メモ（Game_Nintendo_Design.mdの14章の形）

#### 機能名：1週を選んで過ごす1年

- **一言で**：毎週、対局のあいだの2つの時間を「研究・休む・研究会・まつり」に使い、整えた調子と対策で、重さの違う対局に臨み、年度の始めに選んだ3つの目標を目指す（2-1）。
- **解く課題**（2-5）：P1〜P5・P12・P13を、「週」という1つの単位で一度に解く。週ごとに小さな決断（P1・P4）、決断の結果が対局に返る（P6の一部）、週の帯と目標の帯で「いまどこか」が分かる（P5・P12・P13）。
- **リスクとリターン**（2-1）：
  - 研究すれば次の相手の対策（★）が深まるが、調子は回復しない。休めば調子が戻るが、対策は進まない。対局の多い週ほど、どちらを取るかで迷う。
  - 小さな対局を「勝負どころから」や分身で軽く済ませると早いが、勝ち負けの手綱は弱くなる。
- **溜めと解放**（2-2）：上の帯の「次の大一番まであと3週」のカウントダウン（溜め）→ 大一番の週は前夜の場面と大きな札（山場）→ 勝てば目標の進み具合が埋まり判子（解放）。
- **初めての人の最初の1分**：デビュー → 四段の朝（今の場面）→ 目標を3つ選ぶ（おすすめに印。そのまま「この3つで始める」でもよい）→ 今週の画面（今週の対局はない週。行動の枠に「研究」「休む」が並び、やこび姫が「最初の対局は再来週の新人王戦。相手を研究しておこう」）→「この週を進める」。
- **上級者の深さ**：調子と対策の管理（大一番の前の週に休みを入れる・同じ相手との番勝負で対策を持ち越す）、研究の道具（対策の上限と進み方が変わる）、目標の難しいもの（タイトル挑戦）。

- **ほめる瞬間**（5-4）：目標の達成（その場で判子）、大一番の勝ち（前夜の場面と対になる一言）、対策どおりの戦法を相手が指してきた（「研究がはまった」）。

### 13-3. 決めたこと

1. **週**：月曜はじまり。年度の最初の週は4月1日を含む週（月曜より前の日は使わない）。1年度はおよそ52週。今の「次の対局日へ」をやめ、「この週を進める」で日曜まで進める（あいだの対局はこれまでどおり決まる）。プレイヤーの対局が週の途中にあれば、その日で止まり、対局の札を出す（指し終えたら、週の残りを進める）。
2. **行動の枠**：1週に2つ。プレイヤーの公式戦が1局ある週は1つ、2局以上（二日制の番勝負・連戦）の週は0。選べる行動：
   - **研究**：次の公式戦の相手の対策を★1つ進める（上限は研究の道具：道具なし★1・ノート★2・デスクトップ★3・高性能は1回で★2進む）。調子は変わらない。
   - **休む**：調子を1段上げる。
   - **研究会**：その週に研究会の日があるときだけ（今の研究会。練習対局を指すか、顔を出すだけ（「見学する」）を選ぶ）。練習対局を指すと、研究仲間の相手の対策が★1（今のまま）。調子は変わらない。
   - **将棋まつり**：その週にまつりがあるときだけ（今のまつり）。謝礼とファン。調子が1段下がる（遠出の疲れ）。
   - 選ばなかった枠は「何もしない」（調子も対策も変わらない）。第2段階で「仕事」（解説・詰将棋作家など）を足す。
3. **調子**：5段（絶不調・不調・ふつう・好調・絶好調。値0〜4、始めは2）。
   - 変わり方：公式戦を1局指すと−1（二日制は−2）、勝つと＋1（気分。1局の勝ちで差し引き0）、休むと＋1、まつりで−1。0〜4に収める。
   - 効き方：自分で指すとき、閃きの数を設定の数から調子で−2〜＋2（設定が∞なら変えない。0より下にしない）。分身に任せる・勝負どころの局面の形勢では、勝率のレーティングに調子1段あたり±40。
   - 見せ方：顔の絵（羽音のドット絵ではなく、自分の名札の横の5つの点と言葉）。
4. **対策★**：次の公式戦の相手について0〜3。★1で相手の得意戦法、★2で囲いも、★3で特殊能力（今の`gearPrep`の段を★で出す）。分身の勝率に★1つあたり＋20。相手が変わったら0に戻す。同じ相手との番勝負の続きと、研究仲間（研究会で★1）は残す。相手の得意戦法を★1以上で研究していて、その戦法を相手が指してきたら、対局の始めに「研究がはまった」の判子と、閃きを1回足す（ほめる。5-4）。
5. **対局の重さ**（B）：対局ごとに3段の重さを決め、札の大きさ・既定の指し方・場面を変える。
   | 重さ | どの対局 | 札 | 既定の指し方 | 場面 |
   | --- | --- | --- | --- | --- |
   | 小 | 予選のブロックの1回戦・2回戦、NHK杯・朝日杯の予選 | 小さい札（1行） | 勝負どころから | なし |
   | 中 | ブロックの決勝、本戦、リーグ、順位戦、新人王戦 | ふつうの札 | 最初から | なし |
   | 大 | 挑戦者決定戦・番勝負・リーグの最終局（入れ替えがかかる）・順位戦の昇級がかかる局・羽音との公式戦・各棋戦の決勝 | 大きい札（金の縁）・前の週からカウントダウン | 最初から | 前夜の場面（今の羽音・タイトル戦の場面に足す） |
   - どの重さでも、指し方は3つから選べる（自分で選ぶ。5-8）：**最初から指す**／**勝負どころから指す**／**分身に任せる**（確認あり）。
6. **勝負どころから指す**（B）：対局の前に、相手と自分の分身の強さで40手前後まで指した局面（中継の棋譜を作る仕組み`useRelayGenerator`と同じ作り方。序盤は相手の得意戦法と自分の得意戦法）から、自分で続きを指す。形勢がどちらかに大きく傾く前（評価値±300以内）の局面で止める。調子と対策は、その局面の作り方（分身の強さ）に効く。勝ち負けは盤の上で決める。局面を作るあいだは「控室で準備しています」と出す（数秒〜十数秒。作れなかったら最初から指す）。レーティングに数えるのは、今と同じく平手で最初から指した対局だけ。
7. **今年の目標**（C）：年度の始め（デビューと「次の年度へ」）に、候補から3つ選ぶ。候補は状況で変わる（6〜8個）：
   - 順位戦で昇級する／勝ち越す、新人王戦でベスト4・優勝（出場できるあいだ）、どれかのタイトル戦で本戦・リーグに入る、タイトルに挑戦する、年間で○勝する（難易度で20〜30）、年間の勝率6割、羽音に勝ち越す、賞金ランキング10位以内。
   - やこび姫のおすすめ3つに印（はじめての年度は易しめ）。「この3つで始める」で決まる。年度の途中では変えない。
   - 上の帯にいつも3つの進み具合（「順位戦 5勝2敗」「新人王戦 ベスト8」「年間 12/25勝」）。達成したらその場で判子（D:3-2）。年度のまとめで、達成・あと一歩・届かずの判子を押し、やこびノートの札に残す。
8. **次の大一番**（C）：重さ「大」のいちばん近い予定（決まっているもの）を、上の帯に「次の大一番：新人王戦 決勝三番勝負 第1局（10月7日）あと3週」と出す。まだ決まっていない大一番は「勝ち進めば：王将リーグ入りまで あと2勝」と出す。
9. **画面**（I）：1年の画面の主役を「今週」にする。
   - PC：左の大きな欄に今週の札（7日の帯・今週の対局・行動の枠2つ・「この週を進める」）と、その下に「これからの3週」（週ごとの予定と対局の重さ。大一番の週は金の縁）、右の欄の上に自分の札（調子・対策・お金）と羽音の一言、右の欄の下に週のまとめ。上の帯に目標3つと次の大一番。月のカレンダー・棋戦・成績はタブ（今の画面をそのまま使う）。
   - スマホ縦：上の帯（目標3つを小さく・次の大一番）→ 7日の帯 → 今週の対局の札 → 行動の枠2つ → 下に固定の「この週を進める」。タブは「今週・カレンダー・棋戦・成績」。
10. **急ぐとき**：「次の対局の週まで、おまかせで進める」。おまかせの行動は、調子がふつうより下なら休む、そうでなければ研究（研究会とまつりには行かない）。今の「次の対局日へ」に近い速さを残す（D:3-3 遅さは罪）。

### 14-2. 機能設計メモ（Game_Nintendo_Design.mdの14章の形）

#### 機能名：仕事で育ち、世界に載る1年

- **一言で**：対局のない時間を「仕事」に使うと、お金とファンと分身の力が実り、自分の勝ちや取材の答えが毎週のニュースに載る（2-1・5-7）。
- **解く課題**（2-5）：P3・P6・P7・P8・P11を、「仕事」「分身」「ニュース」の3つの掛け算で解く。仕事が分身を育て、育った分身が対局を任せられるようにし、その結果がニュースになる（2-6）。新しい遊び（盤のルール）は足さず、今ある遊びを呼ぶ。
- **リスクとリターン**（2-1）：行動の枠は今と同じ2つ。仕事を入れると、研究（次の相手の対策）と休む（調子）の枠が減る。仕事はお金・ファン・分身の経験をくれるが、目の前の対局には効かない。「今週は大一番の前だから研究と休む」「対局のない週は仕事と研究」の迷いを作る。分身に任せた対局は、分身の経験にならない（育てる時間を取るか、任せて早く進むか）。
- **溜めと解放**（2-2）：分身の能力のLvの棒（あと経験いくつ）→ 週のニュースで「分身の寄せがLv4に」。ファンの数の節目（100・300・1000・3000）→ ファンレターが届く。解説の仕事は鍵つき（ファン300人か本戦・リーグ入りで開く）→ 開いた週のニュース「○○四段、大盤解説デビュー」。
- **初めての人の最初の1分**：第1週の今週の画面で、行動のシートに「仕事：指導（日曜・謝礼10万円・ファン＋10・分身の受け＋2）」が並ぶ。選んで週を進めると日曜で止まり、仕事の札に「遊ぶ」「さっと済ませる」。週が終わると「将棋ニュース」の札（見出しは「新四段○○、デビュー週に指導対局」）。
- **上級者の深さ**：分身の能力の組み立て（どの行動と仕事で、どの能力を伸ばすか）。解説の仕事のクイズの当たり（当たるほど謝礼・ファン・経験が増える）。記録のランキング（勝率・連勝）を狙う。
- **失敗したとき**（7-1）：仕事の遊びで負けても失敗でも、謝礼の基本とファンは出る（指導対局は勝ち負けで謝礼が変わらない。詰将棋は解けた数、クイズは当たった数で上乗せ）。取材の答えに外れはない（どれを選んでもファンが増え、記事の調子が変わるだけ）。
- **ご褒美と使い道**（5-1）：お金（研究の道具を買う。今の使い道）、ファン（将棋まつりの謝礼が増える。今の使い道。解説の仕事が開く）、分身の能力（分身に任せる・勝負どころからの勝ちやすさ）、ファンレター（成績のタブに残る。読み返せる）、ニュースの見出し（年度のまとめに「今年の見出し」3本）。
- **ほめる瞬間**（5-4）：ニュースの見出しに自分の名前（何が良かったかを書く：「5連勝、新人王戦ベスト4へ」）。分身のLvが上がった能力の名前と、何をしたから伸びたか（「詰将棋の仕事で寄せがLv4」）。解説の仕事でクイズを当てたら視聴者のコメント（今の中継の仕組み）。
- **捨てるもの**：仕事の種類を4つ以上にすること、仕事の遊びを新しく作ること（今ある遊びを呼ぶだけ）、ニュースの毎日の更新、SNSのまね、分身の能力を自分で振り分ける操作（何をしたかで決まる）、分身のLvを上げるためだけの遊び。
- **確かめ方**：第1段階の形で4〜6月を遊んだ人に、第2段階で同じ期間を遊んでもらい、仕事を選んだ週の数、ニュースの札を開いた回数、分身に任せた対局の数と勝ち負けを見る（10-2）。

#### 画面の設計メモ（UI_Nintendo_Design.mdの10章の形）

- **目的**：今週の時間の使い道に「仕事」が加わり、その結果（ニュース・分身の伸び）が今週の画面で分かる。
- **画面の主役**：今までどおり今週の札（13-2）。ニュースは今週の札の上に1枚（見出しと2行）、分身は今週の札の下に1行。
- **情報の優先順位**：1 今週の対局と「この週を進める」／2 行動の枠（研究・休む・研究会・まつり・仕事）／3 将棋ニュースの見出し・取材の依頼／4 調子と対策★・分身の1行／5 カレンダー・棋戦・成績（記録のランキング・ファンレター）。
- **操作の流れ**：行動の枠 → シートで「仕事」を選ぶ → 週を進める → 仕事の日で止まる → 仕事の札「遊ぶ」（指導対局・詰将棋3問・解説のクイズを今の画面で開く）か「さっと済ませる」→ 週の終わりにニュースの札。取材は今週の札の中の札を押す → 3つの答えから選ぶ（1回押すだけ）。
- **確認ダイアログ**：出さない（「さっと済ませる」は出来高が下がるだけで、取り消せる損ではない。UD:5-2）。
- **メッセージ分類**：ニュースは状態の知らせ（札。押すと紙面）。分身のLv上がりはニュースの1行（その場で止めない。多すぎるため）。ファンレターと解説デビューは見出し（ストップしないが目立つ）。
- **初めて使う人への伝え方**：最初に仕事が並ぶ週だけ、行動のシートの仕事の行にやこび姫の一言（「仕事をすると分身も育つよ」）。分身の1行は棒と「Lv」で、押すとレーダーチャート。
- **快の要素**：紙面の見出しの大きな字と自分の名前、ファンレターの封筒、分身のLvの棒が伸びる動き。
- **見ている人への配慮**：解説の仕事は中継の画面（視聴者のコメントが流れる）で遊ぶので、見ている人も楽しい（N:6-1 将棋3席）。
- **作らないと決めたこと**：ニュースのタブ（今週の札とシートで足りる）、分身の別の画面（シートで足りる）、仕事の予約（その週の依頼だけ）。
- **検証方法**：ブラウザで4つの大きさ（390×844・820×1180・1366×768・844×390）。仕事を選んで週を進め、仕事の日の札・さっと済ませる・ニュースの札・取材・分身のシートまで。
- **根拠**：UD:2（迷わない）、UD:5-2、N:2-1（階層を浅く）、N:6-1（将棋3席）。

### 14-3. 決めたこと

1. **棋士の仕事**（E）：週の行動に「仕事」を足す。その週の依頼（0〜2件。週ごとの種で決める）の中から1つまで選べ、行動の枠を1つ使う。仕事の日（曜日）で週が止まり、仕事の札で「遊ぶ」か「さっと済ませる」を選ぶ。

   | 仕事 | 中身（今ある遊びを呼ぶ） | 曜日 | 謝礼 | ファン | 分身の経験 | 開く条件 |
   | --- | --- | --- | --- | --- | --- | --- |
   | 指導 | 将棋サロンでの駒落ちの指導対局1局（まつりの指導対局と同じ。あなたが上手。お客の棋力で手合いを決める） | 日 | 10万円（勝ち負けによらない） | ＋10 | 受け＋2・視野＋1 | はじめから |
   | 詰将棋 | 将棋雑誌の詰将棋欄の監修。問題集の詰将棋3問（今の練習の5問と同じ出し方を3問にする。手数は5〜11手） | 月 | 5万円＋1問5万円（最大20万円） | ＋5 | 寄せ＋2・読み＋1（解けた問題1つごとに寄せ＋1を足す） | はじめから |
   | 解説 | タイトル戦・注目局の大盤解説。その週か前の週に決着した注目局を中継の画面で見て、次の一手クイズ5問に答える（今の`startQuiz`） | 土 | 15万円＋当たり1問3万円 | ＋20＋当たり1問5 | 大局観＋2・発想＋1（当たり2問ごとに大局観＋1） | ファン300人か、どれかの本戦・リーグ入り（D:5-1 解放のご褒美） |

   - 「さっと済ませる」は遊ばずに記録する。謝礼とファンは基本の分（指導10万・詰将棋は2問分の15万・解説は当たり2問分）、分身の経験は基本の分だけ（上乗せなし）。D:9-1。
   - 仕事は週に1つまで（同じ週に仕事ばかりにならない。13-3の2の枠2つは研究・休むと取り合う）。
   - 依頼が来ない週：自分の公式戦が2局以上ある週（枠が0）、年度の最後の週。
2. **分身を育てる**（G）：
   - 分身（自分の席）は、8つの能力（研究・大局観・視野・発想・読み・安定感・寄せ・受け。`player-abilities.mjs`の`ABILITIES`）ごとに経験とLv（1〜10）を持つ。始めはどれもLv1。
   - Lvの上がり方：LvからLv+1へは「Lv×4」の経験（Lv2まで4、Lv3まで8…。Lv10まで合計180）。初めは早く、上ほどゆっくり（D:4-4）。
   - 効き方：能力の差（名簿の`character.abilities`と同じ尺度）＝（Lv−1）×3（Lv10で＋27。名簿の上限30の中）。この差を自動対局の重み（`ABILITY_SIM_WEIGHTS`。安定感は1として数える）で平均し、3倍した値を分身の強さの上乗せ（レーティング。全部Lv10で＋81）にする。分身に任せる対局の勝ち負け・勝負どころの局面の寄せ方・分身に任せるの「勝つ見込み」に、調子と対策★と同じく足す（実装のとき、名鑑の棋士の能力の計算へ入れる案は、自動対局の上乗せの上限（±60）で頭打ちになり、見込みの数字とも合わなくなるのでやめた。D:4-8 見返りが行為に見合う）。自分で指すときの強さは変えない（あなたの腕のまま）。
   - 経験の入り方：

     | したこと | 分身の経験 |
     | --- | --- |
     | 研究 | 研究＋2 |
     | 休む | 安定感＋1 |
     | 研究会（練習対局を指した） | 読み＋2・発想＋1（勝てば発想＋1） |
     | 将棋まつり | 発想＋1・受け＋1 |
     | 仕事 | 上の表 |
     | 自分で最初から指した公式戦 | 視野＋1・大局観＋1（勝てば寄せ＋1）。分身はあなたの指し方から学ぶ |
     | 勝負どころから指した公式戦 | 読み＋1（勝てば寄せ＋1） |
     | 分身に任せた公式戦 | なし（任せると早いが、育たない。2-1） |

   - 年度をまたいで持ち越す。前の保存は、全部Lv1から。
   - 見せ方：今週の札の下に「分身」の1行（いちばん高い能力・今週伸びた能力・次のLvまで）。押すと分身のシート（今のレーダーチャート`RadarChart.vue`、8つの能力のLvと経験の棒、分身に任せたときの見込みへの効き）。行動のシートの各行の右に「分身：研究＋2」を足す。
3. **将棋ニュース**（D）：
   - 週を閉じたとき（13-3の11の週のまとめ）を、「将棋ニュース」の札にする：見出し1本（大きな字）・記事の行（今のまとめの行。4行まで）・記録の1行（ランキングの動き）。
   - 見出しの選び方（強い順に1つ）：タイトル獲得・棋戦優勝 → 挑戦決定・本戦／リーグ入り・順位戦の昇級 → 自分の連勝（3・5・7・10…）→ 羽音との公式戦の結果 → 自分の初勝利・勝ち数の節目（10・20・30…）→ 解説デビュー・ファンの節目 → タイトル戦の決着・角番 → 羽音の大きな結果（本戦入り・挑戦） → ふつうの週は棋界の話題（今年度の勝率の1位の棋士など）。
   - 見出しは自分の名前を段つきで書く（「○○四段、5連勝で新人王戦ベスト4」）。負けた週も責めない書き方（「○○四段、羽音四段に惜敗 次の順位戦へ」。5-8・7-2）。
   - 年度のまとめに「今年の見出し」3本（強い順）。
4. **記録のランキング**（D）：成績のタブに4部門（勝数・勝率（10局以上）・対局数・連勝）。各部門の上位3人と、自分（10位以内なら順位。外なら「10位まで あと○勝」のように近い目当て。5-6 低い順位で恥をかかせない）。数え方は年度のまとめの将棋大賞の記録部門と同じ。

### 15-2. 機能設計メモ（Game_Nintendo_Design.mdの14章の形）

#### 機能名：人と歩く棋士人生

- **一言で**：師匠・兄弟子・同期と会って指すほど絆が深まり、段が上がるたびに短い場面が開く。年度の結果は段位と名簿に残り、何期も続けるほど自分の棋士人生が厚くなる（8-1・5-1）。
- **解く課題**（2-5）：P9・P10・P14。人の場面は、物語モードの先駆け（同じノベルの部品と台本の書き方）。
- **リスクとリターン**（2-1）：週の行動に「人に会う」を足す。枠2つを研究・休む・仕事と取り合う。会うと絆と小さな効き目（人ごとに違う。15-3の2）、目の前の対局の対策は進まない。
- **溜めと解放**（2-2）：絆の段の棒（あと何回）→ 段が上がった週の始めに場面。段5で、その人ならではの効き目（15-3の3）。昇段の節目（勝数規定のあと○勝）→ 昇段のニュースと取材。

- **上級者の深さ**：誰の段5を先に取るか（研究の★の上限・大一番の前の調子・羽音戦の閃き・研究会の経験の倍）。何期も続けて、段位とタイトルの歩みを積む。
- **失敗したとき**（7-1）：絆は下がらない。会わない週が続いても減らない（D:9-1 いただく時間。遊べない人を罰しない）。年度を早く締めても、絆と分身と段位はそのまま持ち越す。
- **ご褒美と使い道**（5-1）：場面（物語のストーリー選択のサブ「棋士の1年」から読み直せる）、段5の効き目、昇段（見出し・取材・名前の段）、名簿への書き戻し（竜王戦・名人戦の世界に、自分のタイトルと組とクラスが残る）。

- **捨てるもの**：好感度が下がる仕組み、贈り物、恋愛の分岐、人を増やすこと（5人まで）、毎週の会話（場面は段が上がったときだけ）、Hの「空いた週の救済」、名簿の棋士のレーティングの書き戻し（世界の物差しを崩すため）。
- **確かめ方**：2年度目まで遊んだ人に、会う行動を選んだ回数、場面を飛ばした回数、年度を締めた時期、書き戻しを選んだかを見る（10-2）。

#### 画面の設計メモ（UI_Nintendo_Design.mdの10章の形）

- **目的**：今週の時間を人に使えること、その人との間柄と次の場面までが分かること。年度の終わりに、1年が段位と名簿に残ったと分かること。
- **画面の主役**：今までどおり今週の札。人は分身の1行の下に1行（顔5つと段の印）。押すと人のシート。
- **情報の優先順位**：1 今週の対局と「この週を進める」（公式戦が終わったら「年度を締める」）／2 行動の枠／3 ニュース・取材・絆の場面／4 調子・分身・人の1行／5 カレンダー・棋戦・成績（棋士の歩み）。
- **操作の流れ**：行動の枠 → 「人に会う」→ 誰に会うかのシート（5人。今週会える人だけ押せる）→ 週を進める → 段が上がったら次の週の始めに場面（ノベル。飛ばせる）。年度の終わり → 年度のまとめ → 「棋士の世界に残す」札（残す・残さない）→ 次の年度へ。
- **確認ダイアログ**：「年度を締める」だけ出す（残りの週を飛ばし、取り消せないため。UD:5-2）。書き戻しは札の2択がそのまま確認になる。

- **初めて使う人への伝え方**：最初の週だけ、行動のシートの「人に会う」にやこび姫の一言（「会うと、その人との場面が見られるよ」）。
- **快の要素**：絆の段の駒の印が1つ増える動き、場面の立ち絵、昇段の判子、歩みの行が1行増える。
- **作らないと決めたこと**：人のタブ（シートで足りる）、会話の選択肢での好感度の上げ下げ、書き戻しの細かい選択（全部か、しないか）。
- **検証方法**：ブラウザで4つの大きさ（390×844・820×1180・1366×768・844×390）。人に会う→段が上がる→場面、公式戦が終わる→年度を締める→まとめ→書き戻し→次の年度の歩み。

### 16-2. 画面の設計メモ（UI_Nintendo_Design.mdの10章の形）

#### 機能名：棋士の1年の今週の札（操作の見直し）

- **目的（コンセプトとの関係）**：1週を「見る→（必要なら直す）→進める」の1手で済ませ、考える時間を「どの行動にするか」「どの指し方にするか」の判断だけに使う。大会の主役の1つ（棋士の1年）を、何十週も続けて遊べる軽さにする。
- **利用場面**：1年度で約52週。1回の遊びで数週〜十数週を進める。PCではマウス、スマホでは親指。
- **画面の主役**：今週の札（7日の帯・今週の行動・対局の札・決めるボタン）。
- **情報の優先順位**：1 決めるボタン（この週を進める／指し方の3つ）と今週の行動／2 今週の対局と相手（ランクの1行）／3 調子・対策★／4 目標と次の大一番（上の帯）／5 ニュース・分身・人・カレンダー・棋戦・成績（右の列か、タブ）。
- **操作の流れ（手数）**：
  - 対局のない週：先週と同じ行動が入った今週の札 →「この週を進める」（1回）。変えるときは行動の札を1回押してから進める（2回）。
  - 対局の週：「この週を進める」→ 対局の日で止まる → 指し方を1つ押す（2回）。分身に任せるときは、同じ場所をもう1回（3回。マウスは動かさない）。
- **確認ダイアログ**：分身に任せる・年度を締めるだけ（取り返しがつかない）。中央のシートをやめ、押したボタンのある段をその場で確認の段に変える。初期フォーカスは「自分で指す」「週を過ごす」（取り消し側）。実行は右、取り消しは左（UI_Impl:3-1）。
- **使うメッセージ分類**：通常（行動の入れ替え・持ち越しの印）、注目（確認の段）、不可（選べない行動をそもそも出さない。2つ選んであっても不可にはしない。16-3の2）。
- **初めて使う人への伝え方**：最初の週は、やこび姫のおすすめの行動が入った状態で始まり、札に「おすすめ」の印。次の週から「先週と同じ」の印。文章で説明しない。
- **快の要素**：行動の札を押すと番号の印がぽんと入れ替わる短い動き（0.2秒）と、決定の音（今の音を使う）。
- **見ている人への配慮**：対局の札に相手のランクの1行（色と文字）を出し、横から見ても格上か分かる。
- **作らないと決めたこと**：行動の「いつもの方針」の設定画面（先週と同じで足りる。設定は奥に置かない。N:2-4）、行動の予約（何週も先の行動を決める）、確認をなくすこと（N:3-4の注意。取り返しのつかない2つは残す）、ダブルクリックで任せる近道。
- **検証方法**：今の画面と新しい画面で、4月から6月までを遊んでもらい、①1週あたりの押した回数とマウスの移動距離、②行動を選び忘れた週の数、③分身に任せるまでの時間を比べる（N:8-6）。
- **根拠**：N:2-2・2-4・2-7・3-2・3-4・5-4、UD:2・5-2、UI_Impl:3-1・7-4。

### 16-3. 決めたこと

1. **行動は持ち越す（Q1）**：新しい週は、先週選んだ行動を同じ順に入れて始める。札の見出しに「先週と同じ」の印。
   - その週に選べない行動（研究会のない週の研究会、まつりのない週のまつり、依頼のない仕事、選べない人に会う）と、枠が増えた分は、おまかせの決まり（13-3の10。調子がふつうより下なら休む、そうでなければ研究）で埋め、その札に「おまかせ」の小さな印。
   - 枠が減った週（対局が1局）は、先に選んだほうから入れる。枠が0の週は何も入れない（今のまま）。
   - 「何もしない」を選んだ枠も持ち越す（選んだのは遊ぶ人。N:3-4の信頼）。
   - デビューの最初の週と年度の始めは、おまかせの決まりで入れて「おすすめ」の印。
   - これで、行動を選ばずに週が過ぎることはなくなる。保存は`week.actions`を新しい週に写すだけで、項目は足さない。
2. **行動は1回押せば入る札にする（Q2）**：行動のシートをやめ、今週の札の中に、選べる行動を札で並べる。
   - 札には名前と効き目（「対策 ★1→★2」「調子 ふつう→好調」）を先に書く。押す前に結果が分かる（UD:2）。
   - 並びは2段：「いつでも」（研究・休む・人に会う）と「今週だけ」（研究会・まつり・仕事の依頼）。1段に3つまで（N:2-1）。
   - 人に会うは1枚の札にし、押すと5人の顔の小さな選び（札のすぐ下に開く）。仕事の依頼が2つ以上ある週は、今週だけの段に並べる（多いときは2段目を折り返す）。
   - 選んだ札は琥珀色で、右上に何番目かの番号（①②）。選んだ札を押すと外れる。
   - 2つ選んであるときに別の札を押すと、先に選んだほう（①）と入れ替わる（番号が詰まる）。「2つまで」の不可を出して外させる手間を作らない（N:4-7 判定の幅：意図を汲む）。入れ替わったことは、外れた札の番号が消える動きで見せる。
   - 研究と休むは、今までどおり2つの枠に入れられる（2回押すと①②、もう1回押すと外れる）。ほかの行動は、もう入っている札を押すと外れる（実装で決めた。16-6）。
   - 今の`chooseWeekAction`（枠の番号と行動）はそのまま使い、画面で「どの枠に入れるか」を決める（空いた枠→なければ①を外して詰める）。
3. **選ぶものと決めるボタンを1枚の札に入れる（Q3）**：
   - PCは3列をやめて2列にする。左（約790px）が今週の札、右がそのほかの見るもの（ニュース・分身・人の行と、カレンダー・棋戦・成績・相手のタブ）。
   - 今週の札のいちばん下の段を「決める段」にし、右下にいつも主役のボタン（「この週を進める」・指し方の3つ・年度を締める・仕事の2つ）を置く。どの週でも、決めるボタンは同じ右下の場所に出る（N:2-2 同じものは同じ場所。手が覚える）。

### 18-2. 機能設計メモ（Game_Nintendo_Design.mdの14章の形）

### 機能名：奨励会から始める棋士の1年

- **一言で**：三段リーグを抜けた四段が、免状を受け取ったその足で、棋士としての日々を始める。
- **解く課題**（2-5）：
  1. 四段の式のあとに次の舞台がない（溜めの解放のあとの「前進」がない。2-2）。
  2. 奨励会と棋士の1年が別の人の物語になっている（棋士番号・師匠・同期・羽音との関係が途切れる）。
  3. 実物の「前期の三段リーグは10月1日、後期は4月1日のデビュー」を、教えずに体験させたい（6-2）。
- **リスクとリターン**：秋のデビューは1年目が半年（公式戦は2〜4局。12月の竜王戦6組が最初の公式戦）で、順位戦は次の4月から。その代わり、次の年度を「2年目」として、はじめての1年度より半年分の研究会・仕事・分身の経験を積んで迎えられる。
- **溜めと解放**：三段リーグの最終日の結果発表（溜め）→ 四段の判子と免状（解放）→ 棋士の1年の入口「奨励会から・棋士番号第N号・10月1日デビュー」→ 四段の朝の場面（前へ進む）。
- **初めての人の最初の1分**：四段の画面でやこび姫が「免状を受け取ったら、棋士の1年へ。前期の三段リーグで上がったから、10月1日にデビューだよ！」→「免状を受け取る」→ 賞状 → 棋士の1年の入口（奨励会からの札が出ている）→「デビューする」→「四段の朝（奨励会から）」。
- **上級者の深さ**：入口の設定の「デビュー」で「新四段として（4月1日）」も選べる（奨励会の記録を使わずに、羽音と同じ日にデビューする）。
- **失敗したとき**：半年で勝てなくても、次の年度は4月1日から順位戦・新人王戦・目標で始まる（半年の年度は将棋大賞の記録部門に数えない）。棋士の1年をやめて始め直しても、奨励会の記録は残り、もう一度奨励会からデビューできる（4-3）。
- **ご褒美と使い道**：棋士番号と奨励会の歩みが、棋士の1年の「棋士の歩み」のいちばん古い行と、やこびノートの棋士の1年の札に残る。
- **ほめる瞬間**：四段の朝の場面（羽音「来たね」、師匠の電話、奨励会の同期の便り、百花の「おめでとう」）。
- **捨てるもの**：
  - 三段のうちに棋戦に出ること（18-3の5）。
  - 進行中の棋士の1年に、奨励会の記録を後から付けること（18-3の6）。
  - 奨励会の同期を、棋士の1年の棋士にすること（同期の多くはまだ奨励会員で、名簿の棋士でないため。場面の便りの名前だけにする）。

## 19. 結果を丁寧に見せる・タイトルの防衛を作り込む（2026-11-13、ユーザーの依頼「棋士の1年で、結果をもっと丁寧に表示したい。今はうっかり飛ばしてしまいそう。また、タイトル戦で防衛する時の作り込みが弱い。防衛したのに獲得になっていたりする。プレイヤーは藤井聡太みたいな強さでプレイするものだと想定して作り込もう。」）

### 19-1. 今の問題（確かめたこと）

全部の公式戦に勝つまね（藤井聡太のような強さを想定）で3年度を回して確かめた（種7）。

1. **タイトルを持っている人が、そのタイトルの予選・挑戦者決定戦に出ていた。** `stageEntrants`がタイトル保持者を除くのは期を作った時点の保持者（`cycle.holder`）だけで、あとから自分が保持者になってもプレイヤーを入れていた。2年度目は7つのタイトルを持ったまま、7つの挑戦者決定戦を指していた。
2. **挑戦者まで自分で勝ち上がると、防衛戦が0局で終わる。** 番勝負の2人が同じ（保持者＝挑戦者）なので「相手がいないときの防衛」で黙って終わり、防衛も通算期数も数えなかった（3年目の`titleCounts`が全部1のまま）。
3. **防衛しても「○○を獲得」**（`finishStage`の節目の言葉・終局の判子「冠 ○○獲得！」・ニュース・賞状・ノート・年度のまとめ「○○ 獲得」）。失冠も「○○戦七番勝負で敗退」で、取られた重さが伝わらない。
4. **結果は終局の窓の1行だけ**（`proYearResultLine`。節目を「・」でつないだ1行）。ボタンを押せば1年の画面へ戻り、その後どこにも出ない。続けて押すと、タイトル獲得も読み飛ばせてしまう。分身に任せた対局・週を進めるあいだに決まった結果は、ニュースの見出しにしか残らない。
5. （ついでに見つけた）竜王戦のランキング戦で昇級しても、組が変わるのが次の年度の4月で、次の期のランキング戦（12月から）は前の組のまま指していた（1期遅れて効く）。

### 19-2. 機能設計メモ（Game_Nintendo_Design.mdの14章の形）

### 機能名：結果の札と、タイトル保持者の1年

- **一言で**：1局ごとの結果と、防衛・奪取・失冠・永世称号を、1枚ずつめくる札でしっかり味わう。タイトルを持てば、挑戦者を待ち受けて防衛する1年になる。
- **解く課題**（2-5）：
  1. 結果をうっかり飛ばす（19-1の4）。
  2. 防衛が「獲得」と言われる・防衛戦が起きない（19-1の1〜3）。
  3. 藤井聡太のような強さで遊ぶ人に、2年度目からの目標がない（全部取ったあとが単調。4-4）。保持者は「挑戦を受ける側」になり、連覇・通算期数・永世称号・○冠という次の山を見せる（5-2）。
- **リスクとリターン**：防衛戦は、挑戦者決定戦を勝ち抜いた勢いのある相手と番勝負を指す（負ければ失冠、タイトルの対局料と賞金を失う）。勝てば連覇と通算期数が伸び、永世称号が近づく。
- **溜めと解放**：挑戦者が決まった日に「防衛戦の相手が決まった」の札（溜め）→ 番勝負の1局ごとに「防衛まであと1勝」「カド番」（溜め）→ 防衛の札「○○防衛 3連覇」と判子・紙吹雪（解放）。永世称号に届いた年は、さらに1枚「永世○○」の札。
- **初めての人の最初の1分**：初めてタイトルを取ると、終局の窓のボタンが「結果を見る」になる。1年の画面で「この1局」の札（勝ちの判子・番勝負の星・獲得した賞金）→ 次へ → 「叡王 獲得」の大きな札（判子と一言）→ 次へ → 「初タイトル」の一言 → 「棋士の1年へ」。
- **上級者の深さ**：通算期数・連覇・防衛の回数を棋戦ごとに記録し、永世称号の条件（実物の規定）までの残りを、棋戦の画面と札に出す。同時に持つタイトルの数（二冠〜八冠・全冠制覇）にも札。
- **失敗したとき**：失冠しても責めない札（「叡王を失冠 3期のあいだ守った」）。前の保持者は、次の期の挑戦者決定の段階にシードされる（実物の王位戦のリーグ・王将戦のリーグ・竜王戦の1組などに当たる）。すぐに取り返しに行ける（4-3）。取り返したら「奪還」。
- **ご褒美と使い道**：防衛・奪還・永世称号の賞状（賞状帳）、やこびノートの称号（「永世竜王」など）と通算期数、年度のまとめの「防衛3・獲得1」、ニュースの見出し。永世称号は揮毫の言葉の数（今の`crowns`）にも数える。
- **ほめる瞬間**：防衛した瞬間（「3連覇！ 挑戦者の勢いを受け止めたね」）、カド番をしのいだとき、永世称号、○冠。何を守ったか・何期目かを1文で言う（G:5）。
- **捨てるもの**：
  - 永世称号の「襲位」（実物は引退後に名乗る名人など）。ここでは条件に届いたら称号として残すだけ。
  - タイトル保持者の対局の休み・前夜祭などの行事の作り込み（前夜の場面は12章にある）。
  - 結果の札を自動で送る形（読み飛ばしの原因になるため。押して進むだけ）。
- **確かめ方**：強い設定で2年度を遊んでもらい、①防衛戦の番勝負が起きるか、②どの札で何を守った・取ったかを説明なしで言えるか、③連打して読み飛ばすことがないか、を見る（10-2）。

### 19-3. 決めたこと

### 21-1. 原因

- 棋戦の画面（`ShogiProYear.vue`の`pro-year__event-screen`）は格子（grid）で並べていた。格子の列の幅は、はじめの値では中身のいちばん広い幅まで広がる（`min-width: auto`）。そのためトーナメント表の幅（スマホで482〜818px）まで列が広がり、表が画面の右へはみ出していた。
- 表の部品（`RyuoBracket.vue`）は、枠より広いときは枠の中で横に動かす作りになっている（竜王戦と同じ）。ところが枠が表と同じ幅まで広がっていたので動かせず、右側が切れたままだった。
- 同じ格子の行の数が決まっていたため、期のタブがない棋戦（王座戦の本戦・朝日杯・新人王戦・JT杯など）では、中身が高さ256pxの行に押し込まれていた。ブロックの予選（棋聖戦の二次予選など）では「ほかのブロック」と「勝ち上がり」の文が重なっていた。

### 21-2. 直したこと

- 棋戦の画面と中身の欄を、縦に積む形（flex）に変えた。幅は画面まで（`min-width: 0`）にし、中身の欄が残りの高さを取る。トーナメント表は残りの高さいっぱいに広がり、表の中で縦と横に動く（竜王戦の表と同じ回戦の見出しとスナップ）。表のいちばん小さい高さは`min(40vh, 16rem)`。
- 細い縦画面（幅600px以下）では、期・段階・ブロックのタブを1行にして横に動かす。選んだタブ（はじめは「いま」の段階）が見えるように送る（`revealSelectedTabs`）。タブは44pxの高さのまま。
- 背の低い横画面（高さ600px以下）では、見出しとタブを左の列、表を右の列に高さいっぱいで並べる（U:7-5の1）。
- 表の部品（`RyuoBracket.vue`）で、中継の印（▶）が最後の列の札の右から少し出て、表が4〜5pxだけ横に動いていたので、印を出すときは表の右に10pxあける（`WATCH_EDGE`。竜王戦の表も同じ）。

### 21-3. 確かめ

- ブラウザ（ヘッドレスのChrome）で、棋士の1年の年度の途中（1月）の保存から、11の棋戦の表のある段階（16か所）を開いた。390×844・360×640・820×1180・1366×768・844×390で、表の枠が画面の幅に収まり、表より広いときは枠の中で横に動き、横にはみ出さないこと、文が重ならないことを見た。
- 中身の欄が動くのは、360×640の叡王戦（段位別予選のあと。ブロックのタブとほかのブロックの文が長い）の10pxだけ。
- 本物のスマホでの指での動かしやすさは未確認。

## 22. 相手が羽音・善彦のときのノベルの場面（2026-11-14、ユーザーの依頼「羽音との対局の時など、ノベルゲームパートが変化するようにしたい。羽音からの防衛戦なのに羽音に応援されるのは不自然だったりする。」）

読んだ指針: `Game_Nintendo_Design.md`（2-2 溜めと解放、7-2 勝った人も負けた人も楽しい、8-1 キャラ立ち、8-2 ゲームのシナリオ、9-1 いただく時間、14章のテンプレート）、`Game_Nintendo_Implementation.md`（7 負けとやり直し、10 キャラクターと台詞）、`docs/novel-authoring-guide.md`（台本のきまり・声だけの人）、`docs/hanane-character.md`（羽音の口調）。

### 22-1. 今の問題

- 夜の場面（12章・20章）は、どれも「羽音と百花から電話」で、羽音はいつも応援する側。対局の相手がだれでも同じ台本だった。
  - 封じ手の夜（`proYearSealSceneId`）は相手を見ない。羽音が挑戦者の防衛戦でも、羽音が「中継、見てた」「いつもの将棋で取りに行って」と電話してくる（ユーザーの指摘）。
  - 番勝負のあとの夜（連覇・永世称号・失冠）も相手を見ない。羽音に{title}を取られた夜に、羽音が「取り返しに行くんでしょ」と慰めの電話をかけてくる。
  - 善彦（羽音の父）からタイトルを取りに行く前夜も、羽音はふつうに「君なら取れると思う」と言う。父のことに触れない。
- 羽音とのタイトル戦の前夜は、場面が出ない（`proYearSceneDue`は相手が羽音なら「公式戦の初手合」だけを見て、見たあとはnull）。四段の朝の「上の舞台で会おう」の約束が果たされる、いちばん大きな山場なのに。
- 羽音とはじめて当たる対局を分身に任せると、次の対局で「公式戦で当たるのは、はじめてだね」と言ってしまう。

### 22-2. 機能設計メモ（Game_Nintendo_Design.mdの14章の形）

### 機能名：相手で変わる夜

- **一言で**：盤の向こうにだれが座るかで、夜の場面の顔ぶれと言葉が変わる。羽音が相手なら、羽音は電話をかけてこない。宿の廊下や前夜祭で、ライバルとして会う。
- **解く課題**（2-5）：
  1. 相手に応援される、ちぐはぐな場面（ユーザーの指摘）。
  2. 「上の舞台で会おう」の約束の解放がない（溜めっぱなし。2-2）。
  3. 善彦が相手のときの、羽音の気持ちの置き場がない（8-1。羽音は父と比べられることを気にしている。絆の場面`pro-bond-hanane-4`）。
- **リスクとリターン**：場面は読むだけ。飛ばせる（あらすじ）。どれも12行まで（9-1）。
- **溜めと解放**：
  - 四段の朝の「上の舞台で会おう」（溜め）→ 羽音とのタイトル戦の前夜「本当に来たね」（解放）。
  - 羽音との番勝負の封じ手の夜は、星で3通り（リード・五分・カド番）。羽音の言葉も、勝っている側・負けている側で変わる。
  - 番勝負のあとは、勝っても負けても羽音と対局室で一言かわし、そのあと百花から電話（7-2 勝った人も負けた人も楽しい）。
- **初めての人の最初の1分**：羽音とのタイトル戦の第1局を押すと、前夜祭の壇の上に羽音。「四段の朝に言ったこと、覚えてる？」。
- **上級者の深さ**：相手が羽音か善彦か、挑戦か防衛か、星の数で場面が変わる。物語のサブ「棋士の1年」に並び、集めて読み返せる。
- **失敗したとき**：羽音に負けた夜も、羽音は慰めを言わず「次の期、待ってる。上の舞台で、また会おう」と次へつなぐ（G:7）。善彦に負けた夜は、羽音が電話で「父さん、帰りの車でずっと君の将棋の話してた」と伝える（責めない）。
- **ご褒美と使い道**：物語のサブの場面（読み返せる）。
- **ほめる瞬間**：善彦に勝った夜の善彦の「途中から、あなたの手を予想するのをやめました。そのほうが面白かったので」。何がすごかったかを、相手の言葉で言う（G:5）。
- **捨てるもの**：
  - 羽音・善彦との番勝負の毎局の場面（封じ手の夜と前夜で足りる）。
  - 善彦の立ち絵（まだない。声だけの人で出す。`novel-authoring-guide.md`の4-1）。
  - 羽音・善彦以外の相手ごとの場面（名簿の棋士は架空で、人物の設定がない）。
- **確かめ方**：羽音が挑戦者の防衛戦を指してもらい、封じ手の夜に羽音が応援してこないこと、ライバルとして会うことが、説明なしで分かるかを見る（10-2）。
