## 2. 機能設計メモ（Game_Nintendo_Design.mdの14章の形）

### 機能名：竜王への道

- **一言で**：一局勝つごとに、竜王への道を一歩ずつ登る。次の一歩と、その先で待つ相手（ライバルの羽音、竜王の天鷺善彦）が、いつも見えている。
- **解く課題**（D:2-5）：①何を目指すか分からない ②次の対局に賭けているものが見えない ③勝っても何も起きない ④結果のあと続けて遊ぶ導線が弱い、を、「道」1つの見せ方で解く。
- **リスクとリターン**：次の一局の札に「勝てば〇〇、負ければ〇〇」を出す（例：勝てば組の決勝、負ければ敗者復活戦）。強い組ほど道の先にいる相手が強い。
- **溜めと解放**（D:2-2, 4-4）：ふつうの回戦（平地）と、ボスの回戦（組の決勝＝羽音、挑戦者決定戦、七番勝負＝竜王）を、道の上で見た目から分ける。ボス戦の前は札が大きくなり、勝つと道の線が光って、次の段へ駒が進む。
- **初めての人の最初の1分**：大会の入口で、道の全体（いま6組の1回戦、てっぺんに竜王）と、この期の目標（「6組で2位以内に入ると昇級」）を見て、「参加する」1つを押す。説明はその場で必要な分だけ（U:6-1）。
- **上級者の深さ**：トーナメント表（全体）・相手の能力・名鑑・統計・推し・予想は、今までどおり、押せば出る（2つ目の層）。
- **失敗したとき**：負けても、道の上で「どこまで登ったか」と「次は何があるか」（敗者復活戦・次の期の組）をすぐ見せる。責めない。次の対局（または次の期）へ1回押せば進む（D:7-1, 7-2）。
- **ご褒美と使い道**：組優勝・昇級・挑戦権・竜王に、重さの違う演出と、記録（番付の段・称号）。昇級すると、次の期の道のスタートが1段上になる（目で見える進歩。D:6-1）。
- **ほめる瞬間**：勝って道を1段登ったとき（小）、ボスに勝ったとき（中）、昇級・挑戦権（大）、竜王（最大）。やこび姫の一言は、何が良かったか（能力の穴を突いた・逆転した）を言う（D:5-4、5-8）。
- **捨てるもの**：最初の7ページの説明（必要な瞬間の1行に分ける）。スマホで、主役（次の対局と道）をタブの裏に隠すこと。全員の対局を1局ずつ見せる観戦（待たせる）。新しいルールや通貨（遊びの骨組みは今の竜王戦のまま。D:2-6 掛け算）。
- **確かめ方**：竜王戦を初めて開く人に、説明なしで、①1局目を始めるまでの押す回数と時間、②「次は誰と、勝つと何が起きるか」を言えるか、③負けたあと次に何をするか迷わないか、を見る（U:9）。

## 3. 見た目の方針（世界観。U:5-3、D:8-4）

- **キーワード**：竜王戦・番付・対局室・扇子・夜空（今のホームの夜空と、竜の朱・金の配色を引き継ぐ）。
- **道**：下から上へ登る1本の道（すごろくの盤のように、駒の形の印が段の上に乗る）。段は回戦ごと。ボスの段は、扇の形の大きな札にする。
- **相手の顔**：絵は羽音（と、のちに善彦）だけ。ほかの棋士は、名字の1文字を朱の判子のような丸い印にし、棋風の色（攻め＝朱・受け＝藍・バランス＝金）で縁取る（色だけに頼らず、棋風の言葉も添える）。
- **色の約束**：自分は金、相手は朱、勝ち上がりの線は金（今の橙を引き継ぐ）、負けた線は灰。盤の升の色の表（AGENTS.md）とは別の画面なので重ならないが、黄色を盤の上に使わない約束は守る。
- **文字**：見出しは今の明朝（竜王戦らしさ）、数字と操作の文字はゴシック。縦書きの名前はやめ、横書きにする（読みやすさを優先。U:5-3）。

## 4. 画面ごとの設計

### 4-1. 大会の入口（エントリー）

- **主役**：竜王への道の全体図（6組からてっぺんの竜王まで。竜王の段には天鷺善彦の名前と六冠）と、「参加する」ボタン。
- **この期の目標**を1行で出す：「6組のランキング戦で2位以内なら昇級。優勝すれば決勝トーナメントへ」。今の組と規模から決まる。
- **設定**は「おすすめ（難易度9・規模 中・敗者復活あり…）で参加する」を1行にまとめ、「変える」で今の選択シートを開く（今の「項目: 値 [変更]」の行はシートの中へ）。
- **説明**：7ページの説明は、入口からは外し、「竜王戦ってなに？」（小さな入口）に残す。代わりに、最初の期だけ、場面ごとに1行を出す（1回戦の前「勝てば2回戦。2位以内で昇級だよ」、敗者復活戦の前「ここで勝てば、まだ昇級できるよ」…。U:6-1）。

### 4-2. 竜王への道（期の画面の主役）

- 今の上の帯（5つの四角）とタブを置き換え、期の画面の主役にする。
- 段：いまの組の回戦（1回戦…組の決勝）→ 決勝トーナメント → 挑戦者決定三番勝負 → 竜王戦七番勝負 → 竜王。今いる段に自分の駒、次の段に次の相手の印。終わった段は金の線でつなぐ。
- 段の横に「あと何勝で何か」を出す：「組優勝まであと3勝」「昇級まであと1勝」（D:5-2 吊られたごほうび）。
- ボスの段：組の決勝（羽音がいれば羽音）、挑戦者決定戦、七番勝負（竜王）。道の上に、まだ遠くても顔（印）を出しておく（いつか戦う相手が見えている）。
- スマホ縦：道（上）と次の対局の札（下）を縦に積み、タブをやめる。トーナメント表は「表を見る」で開く2つ目の画面にする。デスクトップ：左に道、中央に次の対局、右にトーナメント表（今の右の欄）。

### 4-3. 次の一局（VSの札）

- **主役**：左右に自分と相手の名札（印・名前・段位）、真ん中に大きな「VS」。名札の下に、相手の一番の武器と穴（「終盤S・受けD」）と棋風の一言。
- **賭けているもの**：札の上に「勝てば〇〇／負ければ〇〇」（例：「勝てば組の決勝」「負ければ敗者復活戦へ」「負ければこの期はここまで」）。
- **やこび姫**：作戦の手がかりを1行だけ（能力の穴から。今の`opponentLines`の最初の1つ）。続きは「もっと聞く」。
- **操作**：大きな「対局する」1つ。相手の能力・くわしい情報・手番は、今どおり押せば開く。
- **ボス戦**の札は一回り大きく、背景に扇、羽音・善彦は絵と一言（羽音は今の台詞の仕組みを使う）。

### 4-4. 対局のあと（勝ち上がりの瞬間）

- 対局画面の結果ダイアログの主ボタンを「道へ戻る」にし、押すと大会の画面へ。
- 大会の画面に戻ったとき、勝っていれば、自分の駒が次の段へ進み、通った線が金に光る（約0.6秒。押すと飛ばす。動きを減らす設定では、光る線だけ）。続けて、次の相手の印が出て、「〇〇さんが終盤の逆転で勝ち上がってきた」のように、相手がどう勝ってきたかを1行（自動対局の勝ち方を使う。D:8-3）。
- 負けていれば、駒はその段に残り、印に「ここまで」の線。すぐ下に次にあること（敗者復活戦・この期の結果）と、その主ボタン。
- 次の対局があれば、主ボタンは「次の対局へ」（VSの札が出て、そのまま「対局する」）。

### 4-5. 節目の重さ（Game_Nintendo_Implementation.mdの3-1の重さの段階に合わせる）

| 出来事 | 重さ | 見せ方（短く、押すと飛ばす） |
|---|---|---|
| ふつうの回戦に勝つ | 小 | 駒が1段進み、線が光る |
| ボス（組の決勝・羽音）に勝つ | 中 | 札が裏返って「突破」の印、羽音の一言 |
| 組優勝・昇級 | 大 | 番付の段が1つ上がる判子（「5組へ昇級」）、やこび姫 |
| 挑戦権を得る | 大 | 道のてっぺんの竜王の段が光り、「七番勝負へ」 |
| 竜王になる・防衛 | 最大 | 今の紙吹雪に、称号の授与と、道のてっぺんに自分の駒 |
| 負けて期が終わる | — | 演出なし。どこまで登ったかと、次の期の目標を静かに出す（D:7-2） |

### 4-6. 期の結果

- **主役**：組の移動（「6組 → 5組 昇級」の判子）と、道のどこまで登ったか（道を小さく）。
- **できたこと**：統計のいちばん良い軸（「終盤の寄せが安定していたよ」）を1行。レーダーチャートと統計は下に（今のまま）。
- **次の目標**：「次の期は5組から。2位以内でまた昇級」。
- **主ボタン**を「次の期へ」にする（今の「大会選択へ」は小さく）。文字が切れているボタンは、短い言葉にする（「表を見る」「ノートを見る」）。

### 4-7. 観戦と応援（軽く）

- 推しの棋士・組優勝の予想は今のまま。道の画面の右上に、推しの今の段（「推しの〇〇さん: 準決勝」）を小さく出す。
- 大番狂わせ（レーティング差200以上の勝ち、逆転勝ち）があったら、やこび姫が1行で知らせる（1期に数回まで）。全部の対局を見せることはしない（待たせない。D:9-1）。

## 6. 動きと音（U:7-2、Implementation）

- どの動きも1秒以内、押すと飛ばす。`prefers-reduced-motion`では動かさず、色の変化だけにする。
- 音は今の効果音（駒音・振り駒）を使い、新しい音は足すなら「段を登る」「判子」の2つまで（決めてほしいこと4）。音を消していても、見た目だけで伝わるようにする。
- 待ち時間（自動対局を進める計算）は、今でもほぼ0秒なので、演出のための待ちは作らない。

## 7. 作る順番

1. **段階1（導線と主役）**：入口を1画面・1ボタンにし、説明を場面ごとの1行に分ける。次の一局をVSの札にし、「勝てば／負ければ」を出す。結果ダイアログから「道へ戻る」→「次の対局へ」の導線。期の結果の主ボタンを「次の期へ」に。スマホのタブをやめ、主役を縦に積む。
2. **段階2（竜王への道）**：道の図を作り、上の帯と置き換える。勝ち上がりの動き、次の相手の勝ち上がり方の1行。ボスの段。
3. **段階3（節目と応援）**：節目の重さごとの演出（判子・突破・挑戦権）、推しの段、大番狂わせの一言。
4. **段階4（確かめと調整）**：初めての人に触ってもらう、時間と押す回数を測る、文書の数値を直す。

## 8. 確かめ方

- 自動テスト：目標の1行・「勝てば／負ければ」・あと何勝・次の期の目標を、期の状態から決める純粋な関数にして、組・規模・段階ごとにテストする。導線（結果ダイアログ→道→次の対局）は`match-ui-regression.test.mjs`と大会の画面のテストで。
- ブラウザ：スマホ縦・タブレット縦・デスクトップで、入口・期の画面・ボスの札・対局のあと（勝ち・負け）・結果を撮って確かめる。
- 人：竜王戦を初めて遊ぶ人に、説明なしで1局目まで進んでもらい、押す回数・時間・迷った場所を記録する（U:9）。

## 9. 決めてほしいこと

1. **道を主役にする**：期の画面の主役を「竜王への道」と「次の一局」にし、トーナメント表は押して開く2つ目の画面（デスクトップでは右の欄に残す）にしてよいか。
2. **説明7ページをやめる**：入口の説明を外し、最初の期だけ場面ごとの1行に分けてよいか（7ページは「竜王戦ってなに？」に残す）。
3. **対局のあと**：結果ダイアログから一度大会の画面へ戻し、勝ち上がりの動きを見せてから「次の対局へ」にする案（押す回数は今と同じ2回）でよいか。動きを省いて、結果ダイアログから直接次の対局へ進む案（1回）もある。
4. **新しい音**：「段を登る」「判子」の効果音を足してよいか（足さない場合は見た目だけ）。
5. **相手の顔**：羽音以外の棋士は、名字1文字の判子のような印でよいか（絵は描かない）。善彦の絵を作る予定はあるか。
6. **作る範囲**：段階1から順に作るか、段階1と2をまとめて作るか。

## 10. 決まったこと（2026-10-21）

1. 道を主役にする：はい。トーナメント表は、狭い画面では押して開く2つ目の画面、広い画面では右の欄に残す。
2. 説明7ページをやめる：はい。7ページは「竜王戦ってなに？」で開くシートに残す。
3. 対局のあと：はい（結果ダイアログから大会の画面へ戻し、勝ち上がりを見せてから次の対局へ）。
4. 新しい音：はい（「段を登る」「判子」の2つ。段階2・3で作る）。
5. 相手の顔：今は名前の1文字の判子にする。ただし、棋士のミニキャラのドット絵を作るかもしれないので、顔の枠は絵も入る作りにする（羽音はもう絵を入れる）。
6. 作る範囲：段階1から順に作る。

## 11. 段階1の実装（2026-10-21、実装・自動テスト済み）

- **賭けているもの**：`src/core/ryuo-stakes.mjs`の`matchStakes`が、段階・組・回戦・規模から「勝てば／負ければ／目標まであと何勝／山場か」を決める。期の状態からは`ryuo.mjs`の`pendingStakes`で作り、`describeSeason`の`pending.stakes`に入れる。
  - 負けたときの行き先は、規模ごとの敗者復活戦の枠（`revivalSlots`）で決める。規模「中」の6組は降級がないので敗者復活戦がなく「竜王戦はここまで」、5組は「敗者復活戦へ」。小さな規模の敗者復活戦は、勝ち抜いても「降級をまぬがれる」だけ。
  - 山場（`boss`）は、組の決勝・敗者復活戦の決勝・番勝負と、ライバル（羽音）との一局。
- **入口**：1列・1ボタン。「この期の目標」（`entryGoalLine`。例「6組で2位以内なら昇級。優勝すれば決勝トーナメントへ」）、組の階段、やこび姫のひとこと、設定の要約1行（「変える」で今の行を開く）、「竜王戦ってなに？」（7ページのシート）。
- **次の一局**：VSの札に、判子のような顔（自分は「自」、相手は名前の1文字。色は棋風で朱＝攻め・藍＝受け・金＝バランス。羽音はドット絵）、相手の棋風と能力の一番と穴、目標まであと何勝、「勝てば（金）／負ければ（灰）」。山場は朱の太い枠と「山場」の札。
- **やこび姫**：札の中では1行だけ。最初の期は、いまの段階の決まり（竜王戦の説明を場面ごとに分けたもの）、2期目からは相手の能力の穴からの作戦。ライバル戦は羽音攻略の一言。続きは「もっと聞く」。
- **画面の並び**：タブをやめた。狭い画面では縦に積み、トーナメント表は「トーナメント表を見る」で画面いっぱいに重ねて開く（「閉じる」で戻る）。広い画面は左に次の一局、右にトーナメント表。画面を切り替えたら、中身の欄を上から見せる。
- **言葉**：期の画面の主ボタンは「対局する」。結果ダイアログの大会の対局のボタンは「竜王戦へ戻る」（期が終わったときは「結果を見る」）。期の結果の主ボタンは「次の期へ」（次の期の入口へ）、脇は「表を見る」「ノートを見る」。結果には「次の期」の目標を1行出す。
- **まだのこと**：道の図と勝ち上がりの動き（段階2）、節目の演出（段階3）。結果ダイアログから大会の画面に戻ったときの「次の対局へ」は、段階2の勝ち上がりの動きと一緒に作る。
- 基づいた原則：U:1-1（1画面1目的）、U:4（優先度の高いものから大きく）、U:6-1（説明は必要な人に、必要な場面で）、U:3-2（ボタンは短い動詞）、D:2-1（リスクとリターンを見せる）、D:5-2（吊られたごほうび＝あと何勝）。
- 確かめ：`src/core/ryuo-stakes.test.mjs`、`match-ui-regression.test.mjs`。ブラウザで、スマホ縦（390×844）・タブレット縦（820×1180）・デスクトップ（1366×768）の入口・設定・説明・期の画面・もっと聞く・表・結果を撮って確かめた。実際に遊んでの確認はまだ。

## 12. 段階2の実装（2026-10-21、実装・自動テスト済み）

- **道のデータ**：`src/core/ryuo-road.mjs`の`seasonRoad`が、期の状態から段（いまの組の1回戦〜組の決勝 →（負けて回れば）敗者復活戦 → 決勝トーナメント → 挑戦者決定戦 → 七番勝負 → 竜王。防衛戦は七番勝負と竜王防衛の2段）を作る。`describeSeason`の`road`に入る。
  - 段の状態は、通過・いまの段・ここまで（負けた段）・通らない（負けたあとの組の回戦。薄く点線）・まだ・到達（竜王）。
  - 山場の段（組の決勝・挑戦者決定戦・七番勝負・竜王）は、朱の菱形の印。
  - 顔：いまの段に次の相手、七番勝負にいまの竜王（防衛戦では挑戦者）。組の決勝には、反対の山で勝ち残っているライバル（羽音）の絵（まだ負けていないあいだだけ）。
  - 昇級の印：残っている人数が昇級の人数以下になる回戦（規模「中」なら組の決勝。昇級1名の規模では決勝トーナメント）に「昇級」。
  - プレイヤーの対局の記録に回戦（`round`）を残し、直前の対局の段（勝ち上がりの出発点）を決める。前の版の記録には回戦がないので、そのときは動きを見せない。
- **道の画面**：`src/RyuoRoad.vue`。大会の帯の5つの四角を置き換え、期の画面と結果の画面に出す（入口は組の階段があるので出さない）。左から右へ並べ、いまの段に自分の駒（「自」の将棋の駒の形）。狭い画面では道だけを横に送って、いまの段を真ん中に見せる。
  - 設計の4-2では「デスクトップは左に道」としていたが、帯の中に横に並べても1366×768で9段が収まり、トーナメント表の幅を減らさずにすむので、どの画面でも帯の中に横に置く。
- **勝ち上がりの動き**：竜王戦の対局から竜王戦の画面へ戻ったとき（`ShogiMatchGame.vue`の`tournamentFromGame`）だけ、1回見せる。
  - 勝って段を上がったとき：駒が前の段から0.6秒で登り、通った線が金に光る（1.1秒）。「段を登る」の音（`public/audio/road_climb.mp3`。ド・ミ・ソ・ドを上へ、0.4秒。`move-sound.ts`の`climb`）。
  - 番勝負・決勝トーナメントの途中で勝ったとき：同じ段で印が跳ね、同じ音。
  - 負けて敗者復活戦へ回ったとき：駒が移るだけ（光らせない、音なし。D:7-1）。負けて期が終わったときは動きなし。
  - 道を押すと、動きを飛ばす。`prefers-reduced-motion`では駒を動かさず、光る線だけ。重さは3-1の「小」（ふつうの回戦に勝つ）。
- **相手の勝ち上がり方**：`opponentArrivalLine`が、次の相手が前の回戦をどう勝ってきたか（自動対局の勝ち方）を1行にする（例「杉山颯太さんは、前の回戦を序盤のリードを守りきって勝ち上がってきたよ。」）。VSの札の下に出す（D:8-3 肩入れする理由）。
- **決めたこと**：対局のあとの主ボタンは「次の対局へ」にせず、段階1の「対局する」のままにした。戻った画面にVSの札がもう出ているので、押す回数は結果ダイアログの「竜王戦へ戻る」と「対局する」の2回（決まったこと3と同じ）。
- **まだのこと（段階3）**：節目の演出（突破・昇級の判子・挑戦権）と「判子」の音、推しの段、大番狂わせの一言。
