# 技の演出（手筋・囲い・戦法の名前が出て光る）

## 1. 依頼（2026-11-02）

ユーザーの言葉：「将棋ウォーズや将棋クエストのように、垂れ歩やふんどしの桂や割打ちの銀などの手筋や、何らかの囲いや手筋や形を使ったら、その名前が出て光ったりするなどの演出が出るようにしたい。」

## 2. 今の作り（調べたこと）

- 手筋の判定は2つある。`move-tesuji.mjs`の`detectTesuji`（コレクションの印。頭金・両王手・ふんどしの桂・桂の王手・十字飛車・腹銀・叩きの歩・金底の歩・5三のと金）と、`tesuji-shape.mjs`の`detectTesujiShape`（棋力テスト。ふんどしの桂・割り打ちの銀・十字飛車・王手飛車・両取り・田楽刺し・焦点の歩・叩きの歩・端玉には端歩・腹銀・一間竜）。垂れ歩はどちらにもない（教室のコツの「垂れ歩からと金」は、と金になった手で数える）。
- 手筋を指しても、盤の上には何も出ない。やこび姫がほめ言葉で名前を言う（`move-praise.mjs`の`TESUJI_PRAISE`）だけ。
- 囲いは、完成した瞬間に盤の真ん中に白い札「美濃囲い 完成！」が1.6秒出る（`castleCallout`）。戦法には何も出ない。相手の手筋・囲いには何も出ない。
- 教室のコツの形ができたら、同じ札の場所に「教室のコツ」の札が出る（`tip-moments.mjs`）。
- 盤の縁を光らせる仕組み（`boardImpact`。神の一手と詰み）と、CPUの応手を少し待たせる止め（`holdForImpact`）がある。

## 3. 機能設計メモ（Game_Nintendo_Design.mdの14章・UI_Nintendo_Design.mdの10章の形）

### 機能名：技の演出

- **一言で**：手筋・囲い・戦法を使った瞬間に、その名前が盤の上に大きく出て、指した駒が光る。名前を知らずに指した手にも名前が付き、「いまの手は○○だったのか」と分かる（D:5-4 ほめてやれ、D:6-1 上達そのものが楽しさ、N:4-3 見た目で気づかせる）。
- **解く課題**：
  - 良い形を作っても盤が無反応で、手応えがない（D:3-1 無反応をなくす）。
  - 手筋の名前を覚える場面がない（教室・図鑑で読んでも、対局で結びつかない）。
  - 相手の手筋に気づかないまま両取りをかけられる（相手の技も小さく知らせる）。
- **リスクとリターン**：見た目のご褒美だけで、勝ち負けやレーティングは変えない（D:5-8 外からのご褒美で遊びを支配しない）。
- **溜めと解放**：駒を置いた瞬間（音）→ 指した駒のマスに光の輪 → 名前の帯が横から入る → 止まって読める → 消える。CPUの応手は、帯を読めるまで少し待つ（D:3-2 大事なところはストップ）。
- **初めての人の最初の1分**：自由対局で、角道を開けて飛車を振ると「戦法 ノーマル四間飛車」。美濃囲いを組むと「囲い 片美濃 完成」。相手の銀と金に桂を打つと「手筋 ふんどしの桂 ★★」と盤が光る。
- **上級者の深さ**：技に3つの段階（★・★★・★★★）。めったに出ない技（王手飛車・両王手）は虹色。はじめて使った技には「はじめて！」と出て、終局後にコレクションの手筋のページに印が付く。
- **失敗したとき**：なし（演出だけ。指し手を止めない）。
- **ご褒美と使い道**：やこびノートのコレクションの「手筋」のページに、新しく足した手筋（割り打ちの銀・王手飛車・両取り・田楽刺し・焦点の歩・端玉には端歩・一間竜・垂れ歩・尻金）も並べる。印が付いた手筋は図鑑で読み返せる（今までどおり）。
- **ほめる瞬間**：技を使った手。名前と★で何が良かったかを伝え、やこび姫のほめ言葉（今までどおり）とそろえる（D:5-8 情報としての称賛）。
- **捨てるもの**：
  - 長いカットイン（キャラクターの絵が出る数秒の演出）。止める時間が長いと遊びを止める（D:3-3 遅さは罪）。帯は1.5秒以内。
  - 詰ませた手の演出（終局の判子が出るので重ねない。詰み形の名前はコレクションに残る）。
  - 演出の種類を買う・選ぶ仕組み（課金のエフェクトのようなもの）。
  - 中継（観戦）の画面での演出（後の候補）。
  - 局面の良し悪しでの判定（形だけで決める。悪手の手筋にも名前は出す。名前を覚えるのが目的のため）。
- **確かめ方**：手筋を含む局面を作って指し、4つの大きさのブラウザで帯と光を見る。実際に遊んで、多すぎてうるさくないか・短すぎないかを見てもらう（未確認）。

### UI_Nintendo_Design.mdの10章の項目

- **目的**：盤の上で何が起きたかを、名前と光で伝える（UD:7-2 動きは情報を伝えるために使う）。
- **画面の主役**：盤（帯は盤の上に重ねるが、押せない。盤の操作を止めない）。
- **情報の優先順位**：1 技の名前、2 種類（手筋・囲い・戦法）と★、3 はじめての印・コツどおりの印、4 指した駒の光、5 ねらう駒の赤い輪。
- **操作の流れ**：操作なし。演出のあいだも盤を触れる。盤を触ると、CPUを待たせる止めは打ち切る（G:3-2）。
- **確認ダイアログ**：なし。
- **使うメッセージ分類**：「特別」（自分の技）と「注目」（相手の技）（UD:5-3）。
- **初めて使う人への伝え方**：テキストは名前だけ。光る場所で「この駒の手だ」と分かる。
- **快の要素**：段階ごとに音を変える（★は2音、★★は3音、★★★は4音の上がる音）。音は作った音（ファイルを使わない）。効果音のオン/オフに従う。
- **見ている人への配慮**：名前は大きく、盤の上の真ん中。離れていても読める。
- **作らないと決めたこと**：上の「捨てるもの」。
- **検証方法**：上の「確かめ方」。
- **根拠**：N:2-3（分類と見た目の1対1）、N:3-3（待たせない）、N:5-2（動きで気づかせる）、U:6（演出は1.5秒以内）、U:7-3（色だけで示さない）。

## 4. 決めたこと

### 4-1. 技の目録と判定（`src/core/move-waza.mjs`）

1. **手筋**（盤の形だけで決める。良い手かどうかは見ない）：
   - 今の2つの判定をまとめて使う（`detectTesujiShape`の形と、`detectTesuji`の形）。
   - 新しく2つ足す。
     - **垂れ歩**：持ち駒の歩を、相手の陣の1つ手前（指した側から見て4段目）に打つ。前のマスに相手の駒がなく、打った歩がただで取られない（相手の利きがないか、自分の利きもある）。
     - **尻金**：持ち駒の金を、相手の玉の真後ろ（玉の側から見て1つ下）に打つ。
   - 頭金は詰ませた手だけ（今の判定のまま）。詰ませた手は演出を出さないので、コレクションにだけ残る。
2. **囲い**：今までの囲いの完成（`formation-tracker.mjs`の名前のうち、コレクションの囲い）。
3. **戦法**：形の判定（`formation-tracker.mjs`）が、その手で新しく戦法の名前を付けたとき（コレクションの戦法）。
4. **段階**（★の数と色）：
   - ★（銀色）：叩きの歩・焦点の歩・垂れ歩・桂の王手・金底の歩・端玉には端歩・両取り・5三のと金、ふつうの囲いと戦法。
   - ★★（金色）：ふんどしの桂・割り打ちの銀・十字飛車・田楽刺し・腹銀・一間竜・尻金、穴熊・ミレニアム・ダイヤモンド美濃・銀冠などの堅い囲い、藤井システムなどの名のある戦法。
   - ★★★（虹色）：王手飛車・両王手。
5. **1つの手に出す技は1つ**：段階の高いもの → 手筋 → 囲い → 戦法の順に選ぶ。

### 4-2. 見せ方（`src/WazaCutin.vue`）

1. **自分の技**：盤の真ん中に、横から入る帯（左上に種類「手筋」「囲い」「戦法」、真ん中に大きな名前、右に★）。指した駒のマスに光の輪が広がる。両取り・田楽刺しなどは、ねらった駒のマスに赤い輪（色の決まりの「ねらう駒＝赤」）。
2. **相手の技**：盤の上の端に、小さな帯「相手の手筋 ふんどしの桂」（朱の縁）。光の輪は出すが、音は小さく、止めない（UD:5-3の「注目」）。
3. **1局で同じ技の2回目から**は、小さな帯にする（同じ演出を繰り返さない。D:3-2 止めの長さは重要度に比例）。
4. **はじめての技**（コレクションにまだない）は、帯に「はじめて！」の札を付け、少し長く出す。
5. **教室のコツと同じ手**：コツの札を出す手（3回目まで）で技も出たら、技の帯に「コツどおり！」を添え、コツの札は出さない（1つの手に札は1つ）。技がなくコツだけなら、今までどおりコツの札。
6. **長さ**：★は1.2秒、★★は1.35秒、★★★は1.5秒（U:6の1.5秒以内）。相手の技と2回目からは0.9秒。押すと消える（帯は押せないが、盤を触ると消す）。
7. **止め**：自分の技（大きな帯）のときだけ、CPUの応手を★0.5秒・★★0.7秒・★★★0.9秒待たせる（今の`holdForImpact`の仕組み。盤を触ると打ち切る）。
8. **動きを減らす設定**では、横から入る動きと輪の広がりをなくし、色と音だけにする（G:3-2）。
9. **出す場面**：対CPUの対局（自由対局・学習対局・大会）。棋譜の検討中・教室・問題集・二人で指す対局では出さない。詰ませた手・投了の直前の手でも出さない（終局の判子が出る）。
10. **表示補助の「技の演出」**で消せる（はじめは付いている。保存`waza-effect:v1`。設定なのでデータリセットでは消さない）。

### 4-3. コレクション

- 自分が指した手筋は、`detectWaza`の手筋をそのままコレクションの手筋の印にする（今までの9つに、割り打ちの銀・王手飛車・両取り・田楽刺し・焦点の歩・端玉には端歩・一間竜・垂れ歩・尻金を足して18）。名前と一言は`move-waza.mjs`の目録`WAZA_TESUJI`。保存の形は今までと同じ（`collection.tesuji`のID）。
- やこびノートのコレクションの「手筋」のページは、この18を並べる。

### 4-4. 音（`src/waza-audio.ts`、計画は`move-waza.mjs`の`wazaChime`）

- 段階ごとに、上がる音を2〜4つ（★: ミ・ラ、★★: ド・ミ・ソ、★★★: ド・ミ・ソ・ド＋きらめき）。相手の技は低い2音を小さく。1音0.07〜0.09秒、全部で0.4秒以内。
- 駒音のあとに鳴らす（駒音を消さない。G:3-3 重要度の高い音を優先）。
