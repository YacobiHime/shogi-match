# 棋士のレーティングと勝率を実物に合わせる

2026-10-22。ユーザーの要望は次の2つ。

- 「レーティング分布や、レーティング差ごとの勝率などを現実に合わせたい」
- 「R1600の人がR2163の人に勝てる確率は何％か、に基づいてCPU同士の対局結果を決めたい」

## 2. 前の作りの問題（2026-10-22に測った）

**勝率:**
- 自動対局（`simulateMemberGame`）は、序盤・中盤・終盤に正規分布の乱数を足して勝ち負けを決めていた。差が小さいうちはElo式とほぼ同じだった（差100で64.3%、Elo式は64.0%）。
- 差が大きいと、強いほうが勝ちすぎていた。乱数の裾が正規分布で、Elo式（ロジスティック）より細いため。
  - R1600がR2163に勝つ確率は約2%（Elo式は3.8%）。
  - 差700では0.6%（Elo式は1.7%）。
- 能力の配分・相性・特殊能力が、組み合わせによっては勝率を最大11%動かしていた。
- タイトル戦だけ、その年の調子（ばらつき60）を足していた。

**分布:** 名簿の棋士は、平均1522・標準偏差181（広すぎる）。いちばん上は2050で、低すぎた。

## 3. 決めたこと

### 3-1. 勝ち負けはElo式で決める

- 1局の勝率は、Elo式 1/(1+10^(−d/400)) で決める。
- dは、次の3つを足したもの。
  - **レーティングの差**
  - **先手の+17**: 先手勝率約52.4%にあたる。
  - **小さな上乗せ**: 能力の配分・戦法の相性・特殊能力（研究の鬼・大局観・鬼の読み・大舞台に強い・逆転の名手）を、レーティングに直したもの。合わせて±60まで（差0なら勝率は41.5〜58.5%の間）。
- **安定感:** レーティングの差の効き方を、±15%の幅で変える。安定感の高い棋士どうしは差どおりになり、低い棋士どうしは番狂わせが増える。差0の勝率（5割）は変えない。
- **勝ち方の展開:** 今までどおり、序盤→中盤→終盤と形勢を進める対局のまねで作る。
  - 先に決めた勝ち負けに合う展開が出るまで、80回まで引き直す。
  - 合わなければ（大差の番狂わせ）、最後の展開を裏返す。
  - これで、序盤型が逃げ切る・終盤型が逆転する、という勝ち方の違いは残る。測ると、勝ち方の割合は前とほぼ同じだった。
- **タイトル戦:** その年の調子は足さず、ほかの対局と同じ勝率で決める。強い棋士は実物と同じようにタイトルを持ち続けることがある。
- **結果に残す値:** `simulateMemberGame`の結果に、この1局のaの勝率（`probability`）を残す。

### 3-2. レーティングの分布を実物に合わせる

- 尺度は平均1555・標準偏差145にする（`PRO_MEAN_RATING`・`PRO_RATING_SD`）。
- 組の平均は、実物の竜王戦の組の平均にする。6組は、棋士全体の平均が約1555になる値にする。
  - 1組1786・2組1659・3組1635・4組1584・5組1524・6組1450
  - ばらつき: 85・75・75・80・85・105
- 善彦（名簿でいちばん強い）は2130（実物の1位に合わせた）。
- 新四段は1430前後にする。
- 最初の名簿の順位戦のクラスは、強い順（ゆらぎ込み）で決める。C級2組も強い順で選び、45歳を過ぎた棋士は後ろに回す。
  - 前は若い順だったので、C級2組の平均が1414と低すぎた。実物は1544。
- 8つの名簿の平均で測ると、次のとおり。

| 項目 | 名簿（8つの平均） | 実物 |
|---|---|---|
| 全体の平均・標準偏差 | 1559・144 | 約1555・143〜155 |
| 上位3人 | 2130・1981・1928 | 約2130・1977・1946 |
| 1〜5組の平均 | 1802・1658・1641・1576・1519 | 1786・1659・1635・1584・1524 |
| A級・C級1組・C級2組の平均 | 1843・1581・1507 | 1816・1568・1544 |

- 毎期の終わりに、名簿は平均と標準偏差を最初の値にそろえる（今までどおり）。だから、この分布は期を重ねても保たれる。

### 3-3. 前の名簿の移しかえ

- 名簿に`ratingModel`（尺度の版。今は2）を持たせる。
- 2でない名簿は、読み込むときに全員を同じ1次式で平均1555・標準偏差145へ直す（`rescaleRosterRatings`）。
  - 順位は変わらない。
  - 善彦は2130より下げない。
- 進行中の竜王戦・名人戦の期は、期の始めの写しで指すので、その期の中は前の値のまま。次の期から新しい値になる。

### 3-4. 変わらないもの

- **プレイヤーが指す相手のLv:** 難易度の基準点（6組の平均の棋士をLv30）からの差で換算する。6組の平均が1380から1450に上がっても、基準点も一緒に動くので、6組の相手のLvは変わらない。
  - 上の組との差は少し縮む。1組と6組の差は380から336になる。
- **プレイヤーのレーティング:** CPUのLvの自己対局の尺度で、棋士の尺度とは別。変えない。
- **能力のランク:** レーティングから平均を決める式（`abilityBase`）は変えない。平均の棋士はC〜Dのまま。
