# 大会を途中でやめる（棄権・退会）

2026-10-29、ユーザーの依頼「大会を途中でやめることができるようにしたい。」

## 1. いままで

- 竜王戦・名人戦の期は、始めたら最後の自分の対局まで指すしかなかった。期の途中では「棋士の世界を最初に戻す」（`docs/player-world-note-design.md`の7章）も押せなかった。
- 奨励会は、年齢制限で退会になるか、四段になるまで続いた。自分から退会する道はなかった。
- 研修会は、いちばん上のSクラスに上がったときだけ「研修会を終える」があった。

## 2. 機能設計メモ

### 機能名：大会を途中でやめる

- **一言で**：始めた大会を、いつでも自分で終わりにできる。竜王戦・名人戦は「棄権」、奨励会は「退会」、研修会は「やめる」。
- **解く課題**
  - 遊びたい期が終わらないと、ほかの大会・難易度・世界のやり直しへ進めない。
  - 合わない難易度で始めた期に縛られる。
  - 「棋士の世界を最初に戻す」が期の途中で押せない。
- **リスクとリターン**（D:2-1）：やめても、それまでの記録は消さない。そのかわり、残りの対局は不戦敗になる。棄権を「負けそうな期をなかったことにする」道にしないためで、記録と賞状の重みを守る。ほかの棋士どうしの残りの対局は、ふつうの期と同じに最後まで決まる。昇級・降級・竜王・名人も、その結果で決まる。
- **初めての人の最初の1分**：大会の選択の画面のいちばん下に、進行中の大会ごとのボタンが出る（「竜王戦 第3期を棄権する」）。押すと、何が起きるかを書いた確認が出る。はじめは「続ける」が選ばれている（UD:5-2 取り消せない操作の確認）。
- **失敗したとき**：確認の「続ける」か、画面の外を押せば何も起きない。戻る操作でも閉じる。
- **捨てるもの**
  - 期をなかったことにする取り消し（記録の重みが消えるため）。
  - 期の画面の中のボタン（ふだんの道「対局する」の邪魔になり、押し間違えやすい。UD:4-1）。期の画面から戻れば、大会の選択に出る。
- **確かめ方**：期の途中で棄権したあと、結果の画面・表彰式・次の期・棋士の世界のやり直しが、ふつうに進むか。実際に遊んで確かめてもらう。

### 2-1. 決めたこと

1. **竜王戦・名人戦の棄権**（`src/core/tournament-withdraw.mjs`の`withdrawRyuoSeason`・`withdrawMeijinSeason`）
   - いつもの「負けを記録する」処理（`recordUserGame`・`recordMeijinGame`）を、自分の対局がなくなるまでくり返す。敗者復活戦・番勝負・順位戦の残りの回戦も、同じ仕組みで決まる。
   - 不戦敗には`forfeit: true`、期には`withdrawn`、結果には`withdrawn`と不戦敗の数`forfeits`を付ける。
   - 期が終わったあとは、ふつうと同じ流れに乗せる（キャリア・称号・賞状・名簿）。棄権した期は、このあとの対局の観戦を待たずに、すぐ確定する（`settleRyuoSeason`・`settleMeijinSeason`）。
2. **数えないもの**：不戦敗は盤で指していないので、レーティング・棋力の見立て・統計の解析・名鑑の対戦成績（`ryuo-roster.mjs`の`addVsUser`）には数えない。期の勝ち負けの数には入れる。
3. **奨励会**（`shoreikai.mjs`の`withdrawShoreikaiRun`）：会員なら「退会（自分から）」として経歴に残す。入会試験の途中なら、会員でないので経歴に残さず閉じ、あとで受け直せる。
4. **研修会**：いままでの`closeKenshukaiRun`で、どのクラスでも閉じる（経歴にここまでの成績が残る）。
5. **中断した対局**：やめた大会の中断した対局は、続けられないので消す。
6. **見せ方**
   - 結果の画面の大きな見出しは「途中で棄権」。名人戦は「途中で棄権しました（不戦敗n局）」の1行を足す。竜王戦の結果のくわしい文は「n勝n敗（途中で棄権。不戦敗n局）」。
   - 「棋士の世界を最初に戻す」が押せないときの一言は「終わるか、途中でやめてから戻せるよ」にした。
   - 分身の期（観戦）も同じボタンで棄権できる。
