# やこび姫補助（定跡補助）の作り直し 設計

「定跡補助のUIとゲームデザインが分かりづらい。初心者は囲いや戦法の相性が分からないし、名前しか映らないので、どんな形でどんな特徴があるのかが分からない。戦法を徐々に解放してもいい」という声を受けた設計です（2026-10-18）。
`docs/nintendo-design/`の`Game_Nintendo_Design.md`（D）・`UI_Nintendo_Design.md`（U）・`UI_Nintendo.md`（N）に基づきます。
戦法・囲いの手順と判定（`src/core/opening-guide.mjs`、`AGENTS.md`の「戦法・囲いの案内」）は変えません。変えるのは、選び方・見せ方・解放の仕方です。

## 2. 設計メモ（Game_Nintendo_Design.mdの14章の形）

- **一言で**：やこび姫から「作戦カード」をもらって、完成形の絵を見ながら選ぶ。指すほど新しいカードが増えていく。
- **解く課題**：名前だけで分からない／相性が分からない／選択肢が多すぎる／集める楽しみがない／中断が分かりにくい、を「作戦カード」1つで解く（D:2-5）。
- **リスクとリターン**：攻めの作戦は速いが玉が薄い、受けの作戦は堅いが遅い、をカードの札（「攻め」「受け」、★の難しさ）で見せ、選ぶこと自体を駆け引きにする（D:2-1）。
- **溜めと解放**：対局中は、完成形の駒を盤に薄く出し（囲いを組もうと同じ）、1枚ずつ埋まっていく。完成で「〇〇 完成！」（実装済み）。
- **初めての人の最初の1分**：対局準備の「あなたの作戦」で、最初から使える3枚のカード（棒銀・四間飛車・中飛車）から1枚を選ぶ。カードには完成形の小さな盤と、一言（「銀で端から攻める、まっすぐな作戦」）が描いてある。
- **上級者の深さ**：全部の作戦は「作戦帳」に残し、解放した人・ふだん指している人はすぐ全部使える。囲いはカードの中で替えられる（相性の良いものだけを並べる）。
- **失敗したとき**：中断したら、理由を一言で伝え、今の局面から近い作戦カードを2〜3枚並べて、すぐ選び直せる。
- **ご褒美と使い道**：作戦を対局で完成させると、次の作戦カードが増える。増えたカードはすぐ次の対局で使える（D:5-1）。教室の第4巻で練習した戦法も、その場で使えるようになる（教室と対局をつなぐ。D:2-6）。
- **ほめる瞬間**：新しいカードが増えたとき、終局画面でやこび姫が「早繰り銀を覚えたね！ 次の対局で使ってみよう」と知らせる。
- **捨てるもの**：対局中の`<select>`（カードの一覧に置き換える）。専門用語の群の名前（「居飛車で攻める」「振り飛車で受ける」「びっくり作戦」に言い換える）。合わない囲いを「押せない」で見せること（合う囲いだけを並べる）。
- **確かめ方**：駒の動きは知っているが戦法を知らない人に、説明なしで対局準備から1局指してもらい、作戦を選ぶまでの時間と、選んだ理由を聞く（D:10-2）。

## 3. 作戦カード

### 3-1. カードの中身

1枚のカードは「戦法」と「その戦法に合う囲い」の組（作戦）です。

```
┌──────────────────────┐
│ ［完成形の小さな盤］   四間飛車＋美濃囲い  │
│  ・・・・・・・・・   「受けてさばく、     │
│  ・・飛・・・・・・    振り飛車の基本」   │
│  ・角・銀金・銀玉・   ［受け］［振り飛車］★☆☆ │
│                    完成させた回数 3     │
└──────────────────────┘
```

| 部品 | 中身 | 元のデータ |
|---|---|---|
| 完成形の小さな盤 | 自分の側の下4段だけを、駒の文字で描く。戦法の駒と囲いの駒を両方置いた形 | `opening-guide.mjs`の手順を平手から指し進めた局面（学習対局の完成局面と同じ作り方） |
| 名前 | 「四間飛車＋美濃囲い」。一体型は1つの名前（「矢倉」） | `label` |
| 一言 | 何をする作戦かを1文で（20字前後） | 新しく書く（`opening-catalog.mjs`） |
| 札 | 「攻め」「受け」「カウンター」のどれか、「居飛車」「振り飛車」、難しさ★1〜3 | 新しく書く |
| 回数 | 対局で完成させた回数（コレクションの印） | `collection.mjs` |

- 囲いはカードの中の「囲い：美濃囲い［替える］」で替えられる。替えるときは、その戦法に合う囲いだけを、合う順に並べる（◎いちばん合う・○合う）。合わない囲いは並べない（押せない選択肢を見せない。N:2-2）。
- カードを押すと、手順を1手ずつ見られる詳しい画面を開く（12-1のとおり、カードの小さな盤を動かす）。下に「得意なこと」「苦手なこと」「コツ」を1行ずつ出す（`opening-explanations.mjs`の`overview`・`aim`・`tip`・`caution`、囲いは`overview`・`weakness`）。「この作戦にする」で決める。

### 3-2. 並べ方

カードは、言い換えた3つの群に分けて、横一列に並べる（N:2-1 混ぜない・少なく見せる）。

| 群 | 入る作戦 |
|---|---|
| 居飛車で攻める | 棒銀、早繰り銀、腰掛け銀、矢倉、角換わり、相掛かり、右四間飛車 など |
| 振り飛車で受ける | 四間飛車、三間飛車、中飛車、向かい飛車、藤井システム など |
| びっくり作戦 | 鬼殺し、筋違い角、パックマン、嬉野流 など（奇襲） |

- いちばん上に「迷ったら、やこび姫に占ってもらう」（戦法占い。7章）を置く。
- 今の局面から作れない作戦（後手専用・手順が進んで届かないもの）は、一覧から外す（今の`availability`と同じ判定）。

### 3-3. 戦法と囲いの組（推奨の囲い）

戦法ごとに、合う囲いを`id`で持つ（今は解説の`castles`の文の中にしかない）。◎は解説の`castles`の最初に書いてある囲い、○はそれ以外の囲いを、そのまま`id`に起こす（解説と食い違わないようにする）。最初の8戦法は次のとおり。テストで、すべての組が先手・後手で完成局面まで指せることを確かめる（`learning-setup.mjs`の`buildFormationStart`）。

| 戦法 | ◎ | ○ |
|---|---|---|
| 原始棒銀 | 中住まい | カニ囲い |
| 早繰り銀 | 金矢倉 | 中住まい |
| 腰掛け銀 | 金矢倉 | |
| 矢倉 | （居飛車と金矢倉の組を1枚のカードにする） | |
| ノーマル四間飛車 | 本美濃 | 高美濃、振り飛車銀冠、振り飛車穴熊 |
| ノーマル三間飛車 | 本美濃 | 高美濃、振り飛車穴熊 |
| 原始中飛車 | 片美濃 | 本美濃 |
| ノーマル向かい飛車 | 本美濃 | 金無双、振り飛車穴熊 |

その他の戦法の組は、解説の`castles`の文から起こし、テストで確かめて決めた（`src/core/opening-catalog.mjs`）。

- 右玉は戦法と一体の囲い（ほかの戦法と組み合わせない）なので、○から外した。
- 角換わり＋金矢倉、角換わり4五桂速攻＋早囲い、筋違い角＋舟囲いは、先に指す角換わりの手順で銀が8八へ上がるなどして囲いまで指し進められないため、中住まいだけにした。
- 相手の応手しだいの戦法（横歩取り3三角型・青野流・ひねり飛車・角換わり4五桂速攻・鬼殺し・パックマンなど）は、待つだけの相手では完成局面まで指せないため、組のテストから外している。

## 4. 段階的な解放

### 4-1. 段

| 段 | 作戦 | 使えるようになる条件（将棋の行為。G実装:6-1） |
|---|---|---|
| 入門 | 原始棒銀＋中住まい、ノーマル四間飛車＋本美濃、原始中飛車＋片美濃 | 最初から |
| 基本 | 早繰り銀、腰掛け銀、矢倉、三間飛車、向かい飛車 | 入門の作戦を対局で1回完成させる。または、教室の第4巻でその戦法の練習を終える（その戦法だけ） |
| 応用 | 角換わり、相掛かり、横歩取り、ゴキゲン中飛車、右四間飛車、藤井システム など | 基本の作戦を2種類、対局で完成させる |
| びっくり作戦 | 奇襲の作戦すべて | 竜王戦に出る（竜王戦の棋士が使ってくる作戦として出会う） |

- 囲いは作戦と一緒に増える。カードの◎・○の囲いは、その作戦と同時に使える。そのほかの囲い（穴熊・ミレニアムなど）は、応用の段で使えるようになる。
- まだ使えないカードは、名前とシルエット（盤の絵を影にしたもの）と条件だけを見せる（存在だけ見せる。G実装:6-1-4）。
- 新しく使えるようになったカードには「NEW」を付け、終局画面とやこび姫の一言で知らせる。

### 4-2. 安全網（鍵で慣れた人をふさがない）

- はじめての案内で「ふだん指している」を選んだ人、レーティングが初段相当以上の人は、最初から全部使える。
- 作戦帳の下に「ぜんぶの作戦を使う」のスイッチを置く（強くなる道の入口を薄くするのと同じく、自分で選べる余地を残す。D:4-3、U:6-1）。
- 解放の記録は新しい鍵に置かず、コレクション（完成させた回数）・教室の進み具合・竜王戦の成績から毎回計算する。

## 5. 選ぶ場所

- **対局準備に「あなたの作戦」の行を足す**（`pregameSides`の自分の側。`AGENTS.md`の対局準備の決まりどおり「項目: 値 [変更]」の行と選択シート）。
  - 値は「四間飛車＋美濃囲い」のようにカードの名前。既定は「なし」。
  - ［変更］で作戦カードのシートを開く。対局前の落ち着いたときに選べる。
- **対局中のやこび姫補助の欄**は、`<select>`をやめ、選んだカードを小さく出す（完成形の小さな盤・名前・「完成まであと3手」）。「作戦を変える」で同じシートを開く。
- 相手（CPU）の「戦法・囲いを指定」も、同じカードのシートで選ぶ（相手は解放と関係なく全部選べる）。

## 6. 対局中

- **完成形を盤に薄く出す**：選んだ作戦のまだ埋まっていないマスに、完成形の駒を薄く描く（教室の「囲いを組もう」の`ghost-piece`と同じ見た目）。矢印（次の一手）と合わせて、「どこを目指しているか」を盤で見せる。学習対局と、強くなる道の段が5段目より前の人は既定で出し、ほかの人は補助の欄の切り替えで出す。
- **進み具合**：補助の欄の小さな盤で、埋まった駒を濃く、残りを薄く描き、「あと3手」を出す。
- **中断したとき**：欄を黙って空にせず、「作戦を変えよう」の札を出す。やこび姫が理由を1文で言い（今の文を短くする）、今の局面から近い作戦カードを2〜3枚（「あとN手」付き）並べる。1つ押せばすぐ続けられる。

## 7. 戦法占い（YES/NOチャート）

2026-10-18にユーザーと決めた内容（戦法占いだけを作る・置き場所は対局準備と定跡図鑑・結果は初心者が指しやすい8戦法）を、作戦カードにつなぐ。

- 一言で：やこび姫に3つ答えると、上から下へ分かれる道をたどって「君は四間飛車タイプ！」と言い切ってもらえる。
- 解く課題：戦法の名前も相性も知らない人が、最初の1枚を選べない（N:2-9）。占いの形にして、選ぶことそのものを遊びにする（D:2-3）。
- 溜めと解放：答えるたびに道が琥珀色に伸び、まだ着ける結果だけが明るく残る。最後に1つの結果が光る。
- 初めての人の最初の1分：作戦カードのシートの「迷ったら占う」か、定跡図鑑の「迷ったら、やこび姫に占ってもらう」を押し、3問に答える（15秒ほど）。
- 上級者の深さ：占いは寄り道。結果からそのまま作戦カードを選べ、占わずに選ぶ道もふさがない。
- 失敗したとき：「ひとつ前の質問へ」で1問戻れ、結果の画面の「もう一度占う」ですぐやり直せる。
- ご褒美と使い道：出た作戦は、まだ使えない段でもその場で使えるようになる（「NEW 占いのごほうびで、この作戦が使えるようになったよ」）。すぐ「この作戦で指す」で使える（D:5-1）。
- ほめる瞬間：結果で、選んだ答えから「なぜ合うか」を1文で言う（D:5-8 情報として伝える）。
- 捨てるもの：4〜5問の質問（8つの結果は2の3乗なので、どの道も3問で足りる。問いを増やしても長くなるだけ。D:3-3）。「はい・いいえ」のボタン（答えは「動かしてみたい！」「動かさずに戦う」のように、選んだ中身が分かる言葉にする。U実装:8）。モード占い。
- 確かめ方：戦法を知らない人に占ってもらい、結果の作戦で1局指したあと、「自分に合っていたか」を聞く（D:10-2）。

| 質問 | 答え | 行き先 |
|---|---|---|
| 飛車を横に動かして、戦ってみたい？ | 動かしてみたい！／動かさずに戦う | 振り飛車の質問／居飛車の質問 |
| 相手より先に、攻めたい？（居飛車） | 先に攻めたい！／準備してから | 攻め方／先に作るもの |
| 好きな攻め方は？ | まっすぐ一直線！／とにかく速く！ | 原始棒銀／早繰り銀 |
| 先に作りたいのは？ | がっちりした守り／どっしりした攻めの土台 | 矢倉／腰掛け銀 |
| 相手の攻めを受け止めるのは好き？（振り飛車） | 受け止めて反撃！／自分から攻めたい | 定番か／攻める場所 |
| まずは定番の形から覚えたい？ | 定番から！／ちょっと変わった形も | 四間飛車／三間飛車 |
| どこから攻めたい？ | ど真ん中から！／相手の飛車の正面から | 中飛車／向かい飛車 |

- 結果の画面の行き先は、作戦カードのシートからは「この作戦で指す」（その作戦を選ぶ）だけ、定跡図鑑からは「この作戦で指す」（通常対局の対局準備の「あなたの作戦」に入れる）・「完成形から指してみる」（学習対局の完成形から）・「図鑑で手順を見る」（図鑑でその戦法を開く）の3つ。
- 実装：質問の木と結果は`src/core/opening-fortune.mjs`（テストで、すべての道が3問で8つの作戦のどれかに着き、8つすべてに着けることを確かめる）、画面は`src/OpeningFortune.vue`。占いで出た作戦は`localStorage`のキー`yacobihime:shogi-match:opening-fortune:v1`に残し、解放の計算（`opening-unlocks.mjs`の`extraIds`）に渡す。

## 9. テスト

- 目録：すべての戦法・囲いのidが`opening-guide.mjs`にある。推奨の囲いの組が先手・後手で完成局面まで指せる（`buildFormationStart`）。群・段・札がそろっている。

- 占い：すべての道が8戦法のどれかに着く。8戦法すべてにたどり着く道がある。
- 対局画面：`match-ui-regression.test.mjs`に、`<select>`がなくなりシートで選ぶことと、中断の札を足す。

## 11. 決めたこと（2026-10-18）

1. 解放の強さは設計どおり（ユーザーは「おまかせ」）。まだ使えない作戦はシルエットと条件だけを見せて選べなくし、「ぜんぶの作戦を使う」のスイッチと、案内・レーティングの安全網で開けられるようにする。
2. 対局中に完成形の駒を薄く出すのは、強くなる道の5段目より前の人と学習対局で既定にする。
3. 「あなたの作戦」の既定は「なし」。行とシートに「おまかせ」ボタンを置き、押すとやこび姫が使える作戦から1枚を選んで入れる（まだ完成させたことのない作戦を優先する。相手の作戦が振り飛車と分かっていれば居飛車の作戦から選ぶ）。→ 2026-10-25に「やこび姫のおすすめ」へ変えた（13章）。

## 13. 分かりやすさの見直し（2026-10-25）

ユーザーの声：「定石補助が分かりづらい。だいぶ前（戦法・囲いの2つの選択）の方が分かりやすかった。おまかせを押すと別の戦法に変わるのが特に分かりづらく、どういう機能か分からなかった。中盤以後はどの戦法・囲いにも組めないので、何も組めなくなったら表示を消してもいい」。

調べて分かったこと：

- 対局中の［おまかせ］は、押すたびにくじを引き直していた（★1を2倍の重みで選ぶ）。押した結果が読めず、2回押すと別の作戦に変わる。
- 欄の見出しは「やこび姫補助」だけで、スマホでは見出しも隠れる。何をする欄か、どこに何が出るかを言っていなかった。選んだあとは「四間飛車＋美濃囲い」の1行だけで、前の2つの選択にあった「戦法」「囲い」の区別が消えていた。
- 対局中のカードは、手順の途中を広く認める判定（`availableOpeningDefinitions`）で並べていたため、40手目でも原始棒銀などが並んだ。

### 機能名：定跡の案内（やこび姫補助の見直し）

- 一言で：選んだ戦法と囲いの名前がいつも見え、盤の矢印をたどれば組み上がる。
- 解く課題：おまかせの結果が読めない／何をする欄か分からない／中盤で組めない作戦が並ぶ、の3つを、「決まったおすすめ」「名前の札と1行の説明」「組めるときだけ出す」でまとめて解く。
- リスクとリターン：変えない（作戦を選ぶと、案内どおり組める代わりに、相手の指し手で崩れることがある）。
- 溜めと解放：完成までの残りを「あと◯マス」「あと◯手」で見せ、完成で解放する（今までどおり）。
- 初めての人の最初の1分：対局が始まると、欄に「＋ 戦法・囲いを選ぶ　選ぶと、組み上がるまでの指し手を盤の矢印で教えるよ」の1行。押すとシートのいちばん上に「やこび姫のおすすめ　棒銀　完成まであと5手。迷ったら、まずはこれ」がある。押して完成形と手順を見て、［この作戦にする］。欄に「戦法 棒銀」「囲い なし」と出て、盤の矢印の手を指す。
- 上級者の深さ：ふだんどおり、シートから好きな作戦を選べる。各カードに「あと◯手」が付くので、局面に合う作戦を選び直せる。
- 失敗したとき：作戦が続けられなくなったら、序盤のうちは「作戦を変えよう」の札（今までどおり）。中盤に入ったら札も欄も出さない。
- ご褒美と使い道：変えない（完成の回数・NEW・解放）。
- ほめる瞬間：変えない（完成したとき）。
- 捨てるもの：対局中の［おまかせ］ボタン。くじ引きのおまかせ（`autoPickPlan`）。学習対局だけ欄をいつも開いていた分け方。
- 確かめ方：初めての人に、説明なしで対局を始めてもらい、欄が何をするものか言えるか、おすすめを押して選べるかを見る。40手目まで指して、欄が消えることを見る。
